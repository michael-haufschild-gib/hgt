# Which routes ask for the same theorem?

**The strongest identification is quantitative.** Fix a desired zero abscissa b. Prime midpoints, removable Möbius heads and modular pulse decay read the same b with different calibrations. At b=5/6 a square-conductor prefix and a sparse gcd deficit have exact calibrations too. A proof of any one complete estimate pays all the others. Proving fragments of several estimates pays the common obstruction only if a transfer controls the missing fragment. [Midpoint](../../../formal/GaloisForLFunctions/ExceptionalLayerTheory/SquareConductors/ThePrimeMidpointInTwoAdjacentGcdHorizons.lean#L319) · [Head height](../../../formal/GaloisForLFunctions/RestrictedFactorizationCalculus/TheSharpHeightOfARemovablePrimeHead.lean#L178) · [Ringdown](../../../formal/GaloisForLFunctions/BlackHoleRingdown/TailEnergy/RegularityAndReceiverEquivalence.lean#L737) · [Gcd and conductor](../../../formal/GaloisForLFunctions/ExceptionalLayerTheory/SquareConductors/SquareAndSixthPowerSamplesOfTheReciprocalPrimeOctave.lean#L534)

Three kinds of entries follow. **Equivalent** means that a theorem, or the stated composition of theorems, transfers the complete assertion in both directions. **Reduction** means a sufficient construction or a branch of a proof. **Shared obstruction** identifies a common mathematical difficulty for which no transfer of partial solutions is asserted. **A practical constraint on combining routes.** The 5/6 table gives exact tests on five routes, including two tests within LSR. Using one to prove another requires an independent estimate with the correct domain and constants. The proposed arithmetic route in the [research programme](obstacles-summary.md#preferred-route) specifies the signed term on which to seek such an inequality.
