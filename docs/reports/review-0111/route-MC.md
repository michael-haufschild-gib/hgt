For MC the building blocks run from a signed observable, through the classical strips, to half-power cancellation.

1. A sign-reading statistic with an exponent, sub-RH. Build a finite, cutoff-quantitative observable of the damped Möbius row that reads the signs of μ on composite moduli through successor or Bézout structure. It must separate the proved parity pairs below damping ½ with an exponent; current statistics separate them only qualitatively. Every step below half damping needs this, because sign-blind data stop exactly at ½.
2. Uniform integer producers, sub-RH. Make the growing-alphabet Hecke stencils explicit as ε → 0: support, coefficients and the constant C_ε in ψ, θ ≤ (1 + ε)x + C_ε log²x. The first target is an error term of zero-free-region quality, uniform in ε.
3. Type-II bilinear forms past the coherent barrier, sub-RH. Get past the Q ≍ P^{5/3} barrier in the cross-scale dispersion of actual Möbius and prime rows. The proved replacement input is square-root cancellation in twisted short intervals for actual prime packets at a fixed exponent.
4. A first strip, ≥qRH. Get any power saving at the diagonal d ≍ Q, where the statistic reduces to long-window Möbius partial sums. Any such saving is exactly a fixed zero-free strip Θ < 1. Equivalent forms are an escaped Möbius saving at any θ > 0, or a uniform Vaughan power gain.
5. Named strips, ≥qRH. Bound the near-band Chebyshev cyclotomic energy on a band of positive-power width by O(N^{5/3+ε}), which gives the 5/6 strip. Then improve it to O(N^{3/2+ε}), which gives the 3/4 strip.
6. The receiver at one fixed damping ε < ½. Prove a signed contraction of the Bézout interior martingale, 2M^int + 2·counterterm ≤ (1 − δ)E_T + C. Equivalently, the long-modulus quadrature must cancel to relative precision 1/T. This gives the strip Θ ≤ ½ + ε.
7. Closing step. Transport block 6 to every ε > 0 with a budget independent of the horizon, which rules out the interior bump ¬RH would force. This is equivalent to RH: half-power cancellation M(x) = O(x^{1/2+δ}) for every δ > 0, or equivalently the trivial gauge point being typical.
