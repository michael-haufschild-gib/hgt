## KernelsOnGroupsAndTheirNegativeIndex (uses ACS FiniteConfigurationPontryaginLaw)

## HyperbolicPairsAndTheIndexFormula
- Characters χ: G →* ℂ; reflection χ†(u) = conj χ(u⁻¹) (involutive; |χ†(u)| = |χ(u)|⁻¹; χ† = χ iff unitary). On ℚ_{>0}, χ(u) = u^{ρ−1/2} reflects to 1 − ρ̄.
- pairKernel h = ωχ + ω̄χ† (Hermitian; symmetric in pair). Toeplitz form = 2 Re(ω A(c) conj B(c)), A = Σc_aχ(x_a), B = Σc_aχ†(x_a); unitary χ: 2 Re ω |A|².
- Upper bound: p ⪰ 0 plus κ pairs has κ ≤ #pairs (form ≥ 0 on common kernel of A_j).
- Lower bound: if one u separates (|χ_j(u)| ≠ 1, 2κ values χ_j(u), χ_j†(u) distinct), κ = #pairs exactly (Krein–Langer index formula). Proof: orient |w_j| > 1; family u^d, u^{N+d} (d < 2κ); test vectors X^N E − F via inverse Vandermonde interpolation; pair terms −2Σ|ω_j||w_j|^N|a_j|², positive part ≤ p(1)(Σ|c|)² bounded in N.
- One non-unitary pair: index exactly 1 regardless of positive part ("a pair is never paid"). Unitary χ with Re ω ≥ 0: pair kernel positive definite.

## TheIndexUnderRotationDampingAndCoalescence (uses OneGridHidesTwoGridsDecide for valChar)
