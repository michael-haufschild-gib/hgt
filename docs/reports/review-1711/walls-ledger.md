# Walls on the path to RH

Three questions separate the routes. **P** asks how much cancellation the arithmetic source produces. **R** asks which signed quadratic forms that source can force to be nonnegative. **U** asks whether an estimate survives increasing height, rank, aperture or order, and whether any exceptional zeros remain. A single route can meet all three. A method limit applies only to its stated class. A bound on ζ is an achieved result; its optimality is usually unknown.
