# One-sided Weil criteria: positivity on the sign cones at the log-integers

- **ID:** MC-WEIL-ONE-SIDED
- **Stage:** 3-formalized
- **Type:** THEOREM (Lean)
- **Source:** MC conjecture loop, cycle 158 (`1-in-progress/mc-conjecture-loop-2026-09-28.md`). This card dualizes `weil-cone-summable-excess-rigidity.md` (cycle 157) and HF's `weil-cone-summable-deficit-rigidity.md`.
- **Statement.** For a Weil test `f` (`C²`, compact support), let `k_f = f ⋆ f̃` and `ℓ_n(f) = Re(k_f(log n) + k_f(−log n))/√n`. Define two cones of nonnegative combinations `Σ c_f k_f`:
  - the **nonpositive cone** `P₋`: `Σ c_f ℓ_n(f) ≤ 0` for every `n ≥ 2`;
  - the **nonnegative cone** `P₊`: `Σ c_f ℓ_n(f) ≥ 0` for every `n ≥ 2`.

  Then:
  - RH ⟺ `W_Λ ≥ 0` on `P₋` ⟺ `W_Λ ≥ 0` on `P₊`.
  - **Robust forms.**
    - If `Σ(U − Λ)⁺/√n < ∞` and `W_U ≥ 0` on `P₋`, then RH holds.
    - If `Σ(Λ − L)⁺/√n < ∞` and `W_L ≥ 0` on `P₊`, then RH holds.

## Goal
- **What it says.** Weil's criterion restricted to either sign cone at the log-integers is still equivalent to RH.
  - On `P₋` the prime sum `−Σ Λ(n)ℓ_n` is a nonnegative term. There, RH is exactly the statement that the primes' positive contribution always compensates the negativity of the pole and archimedean part.
  - On `P₋`, `W_U ≥ W_Λ` whenever `U ≥ Λ`. So the robust form allows any summable surplus of prime mass, and the criterion is insensitive to `ℓ¹(n^{−½})` errors on the favorable side.
- **What it does not say.** The dual certificate is forced, not free.
  - The Riesz extension produces `lam ∈ C` (full-cone Weil-positive) with `lam ≤ U`, and rigidity then forces `lam = Λ`.
  - So `Λ` cannot be relaxed downward on `P₋`. For `lam ≤ Λ` with `lam ≠ Λ`, `W_lam ≥ 0` on `P₋` is false.
  - No LP slack exists.

## Paper proof
Write `V = ⊕_{n≥2} ℝ` (finitely supported sequences), and `T(f) = (ℓ_n(f))_n ∈ V`; this is finite because `k_f` has compact support. Write `A(f)` for the pole and archimedean part, so that `Re W_lam(k_f) = A(f) − ⟨lam, T(f)⟩`.

1. **Duality** (`HTGeometry.exists_le_of_nonneg_on_nonpos_cone`).
   - In `V × ℝ`, let `s` be the convex cone generated by `(T f, A f)`, `(e_n, U(n))` and `(0, 1)`. Every `x ∈ s` has a certificate `c ≥ 0` with `Σc_f T f ≤ x₁` and `Σc_f A f + ⟨U, x₁ − Σ c_f T f⟩ ≤ x₂` (induction over the cone).
   - For `x = (0, t) ∈ s` the certificate lies in `P₋`, so `t ≥ Σ c_f Re W_U(k_f) ≥ 0`. Hence the functional `(0, t) ↦ t` is nonnegative on `s ∩ ({0} × ℝ)`.
   - `s + ({0} × ℝ) = V × ℝ`. Positive coordinates come from `(e_n, U(n))`. Negative coordinates come from the pair tests `h ± h(· − log n)`, with `h` a bump of radius `< 1/(4(n+1))`: `k = (1+σ²)k_h + σ(k_h(·+log n) + k_h(·−log n))`, so `T(h + σh(·−log n)) = 2σ‖h‖₂²/√n · e_n`, using the gap `|log m − log n| ≥ 1/(n+1)`.
   - M. Riesz extension gives `g ≥ 0` on `s` with `g(0, t) = t`. Put `lam_n = −g(e_n, 0)`. Then `lam ≤ U` and `⟨lam, T f⟩ ≤ A f`, i.e. `lam` is full-cone Weil-positive.
2. **Rigidity.** `(lam − Λ)⁺ ≤ (U − Λ)⁺` is summable against `n^{−½}`, so `lam = Λ` (`WeilExcess.eq_vonMangoldt_of_weilPositiveFull_of_summable_excess`). Hence `W_Λ` is full-cone positive, which is RH (`riemannHypothesis_iff_weilPositiveFull_vonMangoldt`).
3. **Mirror.** For `P₊`, apply step 1 to `−T` and `−L`, then use summable-deficit rigidity (`eq_vonMangoldt_of_weilPositiveFull_of_summable_deficit`).
4. **Converse.** RH gives `W_Λ ≥ 0` on every autocorrelation, hence on every cone.

## Open questions exposed
- **Prime-free sufficient condition.** `W_Λ ≥ A` on `P₋`, so `A ≥ 0` on `P₋` would imply RH. Whether `A ≥ 0` on `P₋` holds is open.
  - Tests supported inside `(−log 2, log 2)` lie in `P₋` and satisfy `A = W_Λ ≥ 0` (archimedean positivity of Yoshida and Connes–Consani).
  - For wider tests the sign constraints at `log 2, log 3, …` bind, and no corpus result decides the question.
- **Nonemptiness of `C`** [now formal, cycle 160: `exists_weilPositiveFull_iff_primeBlindPositive`, `primeBlindPositive_of_riemannHypothesis`; abstract lemma `HTGeometry.exists_of_nonneg_on_null_cone`]. The same duality, with the pair tests `h ± h(·−log n)` supplying both signs and no envelope, gives `C ≠ ∅ ⟺ A ≥ 0` on `P₀ = {Σ c_f ℓ_n(f) = 0 ∀ n}`. This is prime-blind positivity. Whether `C ⊆ {Λ}` holds unconditionally is open; if it does, then RH ⟺ `A ≥ 0` on `P₀`.
