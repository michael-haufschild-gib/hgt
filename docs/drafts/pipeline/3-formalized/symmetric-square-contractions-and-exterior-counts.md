### Theorem 1 (`[PROVED HERE]` — Exterior Kernel Counts Force Unitarity in All Genera)
Let $D$ be a `CurveDatum` on a finite index type $\iota$ with scale $q > 1$ and Frobenius eigenvalues $\alpha_i = \sqrt{q}\,\beta_i$. For each $k \in \mathbb{N}$ and polynomial $P \in \mathbb{R}[X]$, define
$$\operatorname{exteriorEigenvalue}_D(S) := \prod_{i \in S} \alpha_i, \qquad \operatorname{exteriorDetDeg}_D(k, P) := \prod_{S \in \binom{\iota}{k}} P\bigl(\operatorname{exteriorEigenvalue}_D(S)\bigr).$$
1. **Reality and multiplicativity:** `D.conjPerm` induces a bijection $S \mapsto S.\text{map}(D.\text{conjPerm})$ of $\binom{\iota}{k}$ sending $\operatorname{exteriorEigenvalue}_D(S)$ to $\overline{\operatorname{exteriorEigenvalue}_D(S)}$. Since real polynomials commute with conjugation, $\overline{\operatorname{exteriorDetDeg}_D(k, P)} = \operatorname{exteriorDetDeg}_D(k, P) \in \mathbb{R}$. At $k = 1$, $\operatorname{exteriorDetDeg}_D(1, P) = \operatorname{detDeg}_D(P)$.
2. **Unitary positivity:** Suppose $\|\beta_i\| = 1$ for all $i \in \iota$, so $|\alpha_i| = \sqrt{q}$ and $|\lambda_S| = (\sqrt{q})^k$ for every $S \in \binom{\iota}{k}$. Partition $A = \binom{\iota}{k}$ into $A_+ = \{S : \operatorname{Im}\lambda_S > 0\}$, $A_- = \{S : \operatorname{Im}\lambda_S < 0\}$, and $A_0 = \{S : \operatorname{Im}\lambda_S = 0\}$. The map $S \mapsto S.\text{map}(D.\text{conjPerm})$ gives a bijection $A_+ \leftrightarrow A_-$ conjugating $P(\lambda_S)$, so $\prod_{S \in A_+ \cup A_-} P(\lambda_S) = |\prod_{S \in A_+} P(\lambda_S)|^2 \ge 0$. For $c \ge (\sqrt{q})^k$ and $P(X) = c \mp X$, every $S \in A_0$ has $|\operatorname{Re}\lambda_S| = |\lambda_S| = (\sqrt{q})^k \le c$, so $c \mp \operatorname{Re}\lambda_S \ge 0$. Hence $\operatorname{exteriorDetDeg}_D(k, c \mp X) \ge 0$.
3. **Forcing unitarity across all genera:** Suppose $\operatorname{exteriorDetDeg}_D(k, c \mp X) \ge 0$ for every $1 \le k \le |\iota|/2$ and every $c > (\sqrt{q})^k$. Assume for contradiction that some $i_0 \in \iota$ has $\|\beta_{i_0}\| \neq 1$. Since $\|\beta_i\| \cdot \|\beta_{\text{fePerm}(i)}\| = 1$, $\iota$ is nonempty and $R := \max_{i \in \iota} |\alpha_i| > \sqrt{q}$. Let $M := \{i \in \iota : |\alpha_i| = R\}$ and $k := |M| \ge 1$.
   - For $i \in M$, $|\alpha_{\text{fePerm}(i)}| = q/R < \sqrt{q} < R$, so $\text{fePerm}(M) \cap M = \emptyset$, giving $2k = |M| + |\text{fePerm}(M)| \le |\iota|$, i.e., $1 \le k \le |\iota|/2$.
   - Since $|\alpha_{\text{conjPerm}(i)}| = |\alpha_i|$, `conjPerm` maps $M$ injectively into $M$, hence $M.\text{map}(\text{conjPerm}) = M$. Thus $\overline{\lambda_M} = \lambda_M$, so $\lambda_M \in \mathbb{R}$ and $|\operatorname{Re}\lambda_M| = |\lambda_M| = R^k > (\sqrt{q})^k$.
   - For any $S \in \binom{\iota}{k}$ with $S \neq M$, there exists $j \in S \setminus M$ (otherwise $S \subseteq M$ and $|S| = |M|$ forces $S = M$), so $|\alpha_j| < R$ while $|\alpha_i| \le R$ ($|\alpha_i| > 0$) for all $i \in S$; hence $|\lambda_S| < R^k$.
   - Set $r_2 := \max\bigl((\sqrt{q})^k,\, \max_{S \in \binom{\iota}{k} \setminus \{M\}} |\lambda_S|\bigr) < R^k$ and $c := (r_2 + R^k)/2$. Then $(\sqrt{q})^k < c < R^k$.
   - On $A_+ \cup A_-$, $\prod_{S \in A_+ \cup A_-} (c \mp \lambda_S) = |\prod_{S \in A_+} (c \mp \lambda_S)|^2 > 0$ because $\operatorname{Im}(c \mp \lambda_S) = \mp \operatorname{Im}\lambda_S \neq 0$ on $A_+$.
   - On $A_0 \setminus \{M\}$, every $S$ has $|\operatorname{Re}\lambda_S| \le |\lambda_S| \le r_2 < c$, so $c \mp \operatorname{Re}\lambda_S > 0$.
   - At $M \in A_0$, either $\operatorname{Re}\lambda_M = R^k$ (giving $c - \operatorname{Re}\lambda_M = c - R^k < 0$) or $\operatorname{Re}\lambda_M = -R^k$ (giving $c + \operatorname{Re}\lambda_M = c - R^k < 0$).
   - Thus either $\operatorname{exteriorDetDeg}_D(k, c - X) < 0$ or $\operatorname{exteriorDetDeg}_D(k, c + X) < 0$, contradiction.
4. **Explicit `complexFake` calibration:** On `complexFake` ($q = 16$, eigenvalues $(8i, -8i, 2i, -2i)$), the $6$ subsets of size $2$ have exterior eigenvalues $+64, -16, +16, +16, -16, +4$, so at $c = 17 > 16 = \sqrt{16}^2$,
   $$\operatorname{exteriorDetDeg}_{\text{complexFake}}(2, 17 - X) = (17 - 64)(17 - 4)(17 - 16)^2(17 + 16)^2 = -665379 < 0.$$

### Theorem 2 (`[PROVED HERE]` — Vertical Correspondence Symmetric Squares and Curve Vertical Positivity)
1. Let $G$ be an additive commutative group and $\varphi : G \to \mathbb{R}$ satisfy `IsEvenPosDef φ`. For every $h \in G$ and $c \in \mathbb{R}$, define
   $$(\operatorname{symSquareShift} h\, c\, \varphi)(u) := (1 + c^2)\,\varphi(u) - c\,\varphi(u + h) - c\,\varphi(u - h).$$
   - Evenness: $\varphi(-u) = \varphi(u)$ and $\varphi(-u \pm h) = \varphi(u \mp h)$ give $(\operatorname{symSquareShift} h\, c\, \varphi)(-u) = (\operatorname{symSquareShift} h\, c\, \varphi)(u)$.
   - Positive definiteness: For $x : \operatorname{Fin} n \to G$ and $w : \operatorname{Fin} n \to \mathbb{R}$, evaluating the Gram form of $\varphi$ at $\operatorname{Fin.append}(x, x + h)$ with weights $\operatorname{Fin.append}(w, -c w)$ expands identically to $\sum_{i, j} w_i w_j (\operatorname{symSquareShift} h\, c\, \varphi)(x_i - x_j) \ge 0$.
   - On cosine modes ($G = \mathbb{R}$): $\operatorname{symSquareShift} h\, c\, (\cos(t \cdot))(u) = \bigl((e^{-iht} - c)(e^{iht} - c)\bigr).\text{re} \cdot \cos(t u) = |e^{-iht} - c|^2 \cos(t u)$.
2. For any `CurveDatum` $D$ with nonnegative point counts $N_m(D) \ge 0$ for all $m \ge 1$ and $\|\beta_i\| \le \sqrt{q}$ (in particular both `goldenDatum` and `complexFake`), for every $\sigma > 1$, the vertical log-derivative section
   $$u \mapsto (\log q) \sum_{m=1}^\infty N_m(D)\, q^{-m\sigma} \cos(m u \log q)$$
   is `IsEvenPosDef` (`isEvenPosDef_cosineTrace`), since $|N_m(D)| = N_m(D) \le q^m + 1 + |\iota| q^{m/2} \le (2 + |\iota|) q^m$ makes $\sum_{m \ge 1} N_m(D) q^{-m\sigma}$ summable for $\sigma > 1$ ($q^{1 - \sigma} < 1$). Over $\mathbb{Z}$, adding the archimedean $\Gamma_\mathbb{R}$ completion (`CompletedPositiveSystem 1 d`) collapses the entire class to $\mathbb{R}^\times \cdot \zeta$ (`completedPositiveSystem_one_iff`).

### Theorem 3 (`[PROVED HERE]` — Archimedean Midpoint Symmetric-Square Contraction on `CompletedPositiveSystem`)
For $\beta \in \mathbb{R}$, define $P_\beta(s) := (s - \beta)(s - (1 - \beta))$ and the midpoint symmetric-square multiplier
$$M_\beta(s) := \frac{(s - 1/2)^2}{(s - \beta)(s - (1 - \beta))}.$$
1. **Exact archimedean symmetric-square identity:** For all $\beta, t \in \mathbb{R}$,
   $$-\,e^{t/2}\bigl(e^{(\beta - 1/2)t} - 1\bigr)\bigl(e^{(1/2 - \beta)t} - 1\bigr) = e^{\beta t} + e^{(1 - \beta)t} - 2 e^{t/2} = \bigl(e^{\beta t / 2} - e^{(1 - \beta)t / 2}\bigr)^2 \ge 0.$$
2. **Bochner positivity:** For $\beta \in [0, 1]$ and $\sigma > 1$, $s = \sigma + iu$ has $\operatorname{Re}(s - \beta) = \sigma - \beta > 0$, $\operatorname{Re}(s - (1 - \beta)) > 0$, $\operatorname{Re}(s - 1/2) > 0$. Thus
   $$\operatorname{Re}\bigl(-\logDeriv M_\beta(\sigma + iu)\bigr) = \operatorname{Re}\left(\frac{1}{s - \beta} + \frac{1}{s - (1 - \beta)} - \frac{2}{s - 1/2}\right) = \int_0^\infty e^{-\sigma t}\bigl(e^{\beta t/2} - e^{(1 - \beta)t/2}\bigr)^2 \cos(t u)\, dt.$$
   Since $0 \le e^{-\sigma t}(e^{\beta t/2} - e^{(1-\beta)t/2})^2 \le 2 e^{-(\sigma - 1)t}$ on $t > 0$ with $\sigma - 1 > 0$, `isEvenPosDef_laplace_cos` yields `IsEvenPosDef`.
3. **Removable-singularity `OrderOneEnvelope` lemma:** Let $f : \mathbb{C} \to \mathbb{C}$ be entire in `OrderOneEnvelope` with $f(z_0) = 0$. Then $g := \operatorname{dslope} f\, z_0$ is entire (`differentiableOn_dslope`), satisfies $(s - z_0) g(s) = f(s)$ everywhere, and lies in `OrderOneEnvelope`: on $\overline{B}(z_0, 1)$ it is bounded by continuity, while for $\|s - z_0\| > 1$ we have $\|g(s)\| \le \|s - z_0\|\,\|g(s)\| = \|f(s)\|$.
4. **Zero-cost contraction (`contractRealPair`):** Let `CompletedPositiveSystem κ d F Λ` satisfy $\Lambda(\beta) = 0$ with $\beta \in \mathbb{R}, \beta \neq 1/2$. By `zero_re_mem_Icc`, $\beta \in [0, 1]$, and by `sym_Λ`, $\Lambda(1 - \beta) = 0$ with $1 - \beta \neq \beta$. Applying `dslope` successively at $\beta$ and $1 - \beta$ yields an entire function $Q \in \operatorname{OrderOneEnvelope}$ with $(s - \beta)(s - (1 - \beta)) Q(s) = \Lambda(s)$. Define $F_c(s) := F(s) M_\beta(s)$ and $\Lambda_c(s) := Q(s)(s - 1/2)^2$.
   - On $\{\operatorname{Re} s > 1\}$, $M_\beta$ is holomorphic and nonvanishing, so $F_c$ is holomorphic and nonvanishing, $-\logDeriv F_c = -\logDeriv F + (-\logDeriv M_\beta)$ has `IsEvenPosDef` vertical sections, and $(s(s-1))^\kappa \Gamma_\mathbb{R}(s)^d F_c(s) = \Lambda(s) M_\beta(s) = \Lambda_c(s)$.
   - For all $s \in \mathbb{C}$, $\Lambda_c(s) P_\beta(s) = \Lambda(s)(s - 1/2)^2$. Since $P_\beta(1 - s) = P_\beta(s)$, $((1 - s) - 1/2)^2 = (s - 1/2)^2$, $P_\beta(\bar{s}) = \overline{P_\beta(s)}$, and $P_\beta(s) \neq 0$ off $\{\beta, 1 - \beta\}$, continuity gives $\Lambda_c(1 - s) = \Lambda_c(s)$ and $\Lambda_c(\bar{s}) = \overline{\Lambda_c(s)}$ everywhere. Thus `CompletedPositiveSystem κ d Fc Λc` holds, with $\Lambda_c(1/2) = 0$.
5. **Finite-step elimination of all real off-critical zeros (`exists_real_offCritical_free`):** By `real_zero_archimedean_budget` applied to $\emptyset$, every `CompletedPositiveSystem κ d F' Λ'` satisfies $4 \operatorname{ord}_{1/2}(\Lambda') + 5d < 9\kappa$, hence $\operatorname{ord}_{1/2}(\Lambda') < 9\kappa$. 6. **Direct $\kappa = 1$ real off-critical nonvanishing without numerical Gamma bounds:** If `CompletedPositiveSystem 1 d F Λ` had $\Lambda(\beta) = 0$ with $\beta \in \mathbb{R} \setminus \{1/2\}$, then both $(F, \Lambda)$ and `(Fc, Λc)` lie in `CompletedPositiveSystem 1 d`. ### Theorem 4 (`[PROVED HERE]` — Pole-Paid Symmetric-Square Contractions for Complex Quartets)
Let `CompletedPositiveSystem κ d F Λ` satisfy $\Lambda(\rho_0) = 0$ where $\rho_0 = 1/2 + a + i\gamma_0$ with $0 < a < 1/2$ and $\gamma_0 \neq 0$. By `sym_Λ` and `conj_Λ`, $\Lambda$ vanishes at the $4$ distinct points $r_1 = 1/2 + a + i\gamma_0$, $r_2 = 1/2 + a - i\gamma_0$, $r_3 = 1/2 - a + i\gamma_0$, $r_4 = 1/2 - a - i\gamma_0$. Let $Q_{\text{off}}(s) = \prod_{j=1}^4 (s - r_j)$ and $Q_{\text{crit}}(s) = ((s - 1/2)^2 + \gamma_0^2)^2 = (s - (1/2 + i\gamma_0))^2 (s - (1/2 - i\gamma_0))^2$.
1. **Single-pole quartet contraction for $0 < a \le 1/4$ (`contractComplexQuartet_of_le_quarter`):**
   Define $W^{(1)}_{a, \gamma_0}(s) := \frac{(s - 1/2)^2}{s(s - 1)} \cdot \frac{Q_{\text{crit}}(s)}{Q_{\text{off}}(s)}$. Its negative log-derivative on $\sigma > 1$ has Laplace cosine weight $e^{-\sigma t} w_1(t)$ where
   $$w_1(t) = \bigl(e^t + 1 - 2 e^{t/2}\bigr) + 2\cos(\gamma_0 t)\bigl(e^{(1/2 + a)t} + e^{(1/2 - a)t} - 2 e^{t/2}\bigr) = e^{t/2}\Bigl[\bigl(e^{t/4} - e^{-t/4}\bigr)^2 + 2\cos(\gamma_0 t)\bigl(e^{at/2} - e^{-at/2}\bigr)^2\Bigr].$$
   Since $e^{t/4} - e^{-t/4} = (e^{t/8} - e^{-t/8})(e^{t/8} + e^{-t/8}) \ge 2(e^{t/8} - e^{-t/8})$ and $x \mapsto e^x - e^{-x}$ is increasing on $[0, \infty)$ ($0 < a \le 1/4 \implies at/2 \le t/8$), we have $(e^{t/4} - e^{-t/4})^2 \ge 4(e^{t/8} - e^{-t/8})^2 \ge 4(e^{at/2} - e^{-at/2})^2 \ge 2|\cos(\gamma_0 t)|(e^{at/2} - e^{-at/2})^2$, so $w_1(t) \ge 0$ (and $w_1(t) \le 3 e^t$) for all $t > 0$. Dividing $\Lambda$ by $Q_{\text{off}}$ via four `dslope` steps yields `CompletedPositiveSystem (κ + 1) d (F · W^{(1)}_{a,γ_0}) Λc` whose quartet of zeros has been replaced by critical-line zeros at $1/2$ and $1/2 \pm i\gamma_0$.
2. **Double-pole quartet contraction for all $0 < a < 1/2$ (`contractComplexQuartet`):**
   Define $W^{(2)}_{a, \gamma_0}(s) := \frac{(s - 1/2)^4}{s^2 (s - 1)^2} \cdot \frac{Q_{\text{crit}}(s)}{Q_{\text{off}}(s)}$. Its Laplace cosine weight is $e^{-\sigma t} w_2(t)$ where
   $$w_2(t) = 2 e^{t/2}\Bigl[\bigl(e^{t/4} - e^{-t/4}\bigr)^2 + \cos(\gamma_0 t)\bigl(e^{at/2} - e^{-at/2}\bigr)^2\Bigr] \ge 0$$
   because $0 < a < 1/2 \implies at/2 < t/4 \implies 0 \le e^{at/2} - e^{-at/2} < e^{t/4} - e^{-t/4}$ and $|\cos(\gamma_0 t)| \le 1$. Thus multiplying by $W^{(2)}_{a, \gamma_0}$ produces `CompletedPositiveSystem (κ + 2) d (F · W^{(2)}_{a,γ_0}) Λc` with the quartet contracted onto $\{1/2, 1/2 \pm i\gamma_0\}$.
