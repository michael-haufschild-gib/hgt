# Real branch times of the heat cover accumulate at the time of ξ unless zeros escape

- **Stage:** 3-formalized
- **Type:** THEOREM (Lean)
- **Question:** review-1211 §2.19 Q5 (the group generated by the monodromy and its relation
  to conjugation).

`H_τ` the heat family, `H_0 = Ξ`. A *branch time* is a time with a multiple zero. For real
`a < b` the segment is `γ(s) = a + s(b − a)`. A zero `z₀` of `H_a` *escapes* along `γ` if it
continues as a continuous family of zeros on `[0, s*)`, `s* ≤ 1`, with modulus tending to
infinity at `s*`.

## Theorems

1. Along a path of real times the conjugate of a lift is a lift.
2. Along a path of real times without branch times, a lift that starts at a nonreal zero is
   nonreal at every parameter.
3. If `a < 0 < b` and `[a, b]` contains no branch time, infinitely many nonreal zeros of `H_a`
   escape along the segment.
4. `0` lies in the closure of the real branch times, or there is `ε > 0` such that for all
   `−ε < a < 0 < b < ε` infinitely many nonreal zeros of `H_a` escape along `[a, b]`.
5. A real branch time has a multiple zero away from the centre.
6. If `a < 0` and `[a, 0]` contains no branch time, a nonreal zero of `H_a` escapes along
   `[a, 0]` or lifts to a nonreal zero of `H_0 = Ξ`.
7. For every `a < 0`: RH fails, or `[a, 0]` contains a branch time, or every nonreal zero of
   `H_a` escapes along `[a, 0]`.
8. RH fails, or `0` lies in the closure of the nonpositive real branch times, or there is
   `ε > 0` such that every nonreal zero at every time `a ∈ (−ε, 0)` escapes along `[a, 0]`.

## Proof

1. `H_{τ̄}(z̄)` is the conjugate of `H_τ(z)`.
2. If the lift `z` is real at `s₁`, then `z` and `z̄` are two lifts with the same value at
   `s₁`; lifts that meet start at the same zero, so `z(0)` is real.
3. `H_a` has infinitely many nonreal zeros (`riemannHeat_neg_nonreal_zeros_infinite`), `H_b`
   finitely many (`riemannHeat_nonreal_zeros_finite`). A nonreal zero of `H_a` that does not
   escape lifts to `[0, 1]` (continuation alternative); its end is a nonreal zero of `H_b` by
   2. If only finitely many escaped, infinitely many would lift, two of them to the same
   zero, and transport is injective.
4. If `0` is not in the closure, an interval `(−ε, ε)` is free of branch times; apply 3.
5. The centre value is positive at real times.
6. Continuation alternative and 2; `H_0(z) = ξ(½ + iz)`.
7. Under RH the zeros of `H_0` are real (`riemannHypothesis_iff_riemannHeat_zero_real`).
8. 7 for all `a` in an interval `(−ε, 0)` free of nonpositive branch times.
