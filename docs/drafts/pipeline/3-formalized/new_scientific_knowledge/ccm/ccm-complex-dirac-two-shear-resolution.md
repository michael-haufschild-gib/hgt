```text

        [0, 0,        1],               [1, 0, 0],

        [i, 0, 0],

```

The kernel is exactly the line generated by `v=(a_n,a_n Z,0)`, and Lean computes

```text
v* B_re v = 2 a_n² Re Z,
v* B_im v = 2 a_n² Im Z,
det(H + t B_re + u B_im) = -2(t Re Z + u Im Z).
```

```text

```

```text

(v*B_im v)'(0) = -2 a_n² M_n < 0,
```

so the complex lift replaces the real determinant's quadratic center tangency with a simple
oriented transverse crossing. Every nonempty finite label-preserving packet inherits the same
strict positivity and unique-zero classification by summing joint energies, not amplitudes.
