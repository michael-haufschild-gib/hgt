## Theorem

Over a characteristic-zero field `K`, define polynomial current matrices

```text
E_k = [ 0  t^k ],   F_k = [  0    0 ],   H_k = [ t^k    0  ].
      [ 0   0  ]          [ t^k  0 ]          [  0   -t^k ]
```

Their Lie brackets satisfy

```text
[E_i,F_j]=H_(i+j),
[H_i,E_j]= 2 E_(i+j),
[H_i,F_j]=-2 F_(i+j).                                     (1)
```

Let `L_2` be the Lie subalgebra generated by

```text
E_0, E_1, F_0, F_1.                                      (2)
```

Then for every `k>=0`,

```text
E_k in L_2,   F_k in L_2,   H_k in L_2.                   (3)
```

Thus the constant and linear modes available after removing position and velocity generate all
polynomial modes of `sl_2(K[t])`.

Moreover, in any Lie-module representation, if a vector is annihilated by the four generators in
`(2)`, then it is annihilated by every mode in `(3)`. Lean therefore certifies the full propagation
from depth-two gauge invariance to polynomial-current invariance, not only matrix membership.

## Proof

Equation `(1)` is direct two-by-two matrix multiplication. From `(2)`,

```text
H_1=[E_0,F_1] in L_2.
```

If `E_k in L_2`, then

```text
E_(k+1)=(1/2)[H_1,E_k] in L_2.
```

The analogous identity with `F_k` has coefficient `-1/2`, so induction gives every `E_k` and
`F_k`. Finally `H_k=[E_0,F_k]`.
