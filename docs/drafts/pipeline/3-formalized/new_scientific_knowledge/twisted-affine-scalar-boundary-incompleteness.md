## Setup

Let `C -> K` be an ordinary differential field extension of characteristic zero with `C` a
differential constant field.  Let

```text
tau_i : K ~= K                                             (i in I)
```

commute with the derivation and fix `C`.  Put

```text

Q_Sigma(K) = K^I / delta(K).                              (1)
```

Choose `h in K` such that its constant-coefficient differential orbit is non-torsion in the
simultaneous quotient:

```text
for every nonzero P(D) in C[D] and every k in K,
some i satisfies tau_i(k)-k != P(D)h.                     (2)
```

Define the affine source increment

```text
omega_i = tau_i(h)+h.                                    (3)
```

## Theorem A: the twisted increment remains scalar-boundary non-torsion

**[PROVED HERE]** For every nonzero `P(D)` and every `k in K`, some `i` satisfies

```text
tau_i(k)-k != P(D)omega_i.                               (4)
```

### Proof

Assume contrariwise that equality holds for every `i`.  Commutation of `tau_i` with `D` gives

```text
P(D)omega_i = tau_i(P(D)h)+P(D)h.                        (5)
```

Set

```text
k' = (k-P(D)h)/2.
```

Using (4)--(5),

```text
tau_i(k')-k' = P(D)h                                    (6)
```

for every `i`, contradicting (2).  `QED`

Equivalently, in the scalar quotient,

```text
[omega] = 2[h],                                         (7)
```

so the scalar capacity module generated by `[omega]` is free whenever that generated by `[h]`
is free.

## Theorem B: the affine observable can nevertheless have zero capacity

Let the source act on the scalar observable

```text

```

by the affine law

```text
tau_i(z) = -z+omega_i.                                  (8)
```

Equation (8) is an identity by (3), but `z` belongs to the base field.  Hence `z` is
differentially algebraic over `K` and its actual differential transcendence degree is zero.
The naive scalar boundary built only from `[omega]` has free rank one by Theorem A.

Thus:

```text
scalar boundary rank = 1,
actual observable rank = 0.                             (9)
```

This is a direct counterexample to extending the translation theorem to arbitrary affine source
systems while discarding their linear part.

## Theorem C: the missing invariant is exactly the gauge class

For a one-dimensional base-linear change `y=Bz+u`, the transformed linear part of (8) is

```text

```

It becomes `+1` in every direction if and only if there is one `B in K^*` satisfying

```text

```

for every `i`.  Therefore, whenever no such common anti-invariant unit exists, the `-1` system is
not gauge-equivalent to a translation system.  The mismatch (9) is carried by the nontrivial
simultaneous semilinear gauge class.
