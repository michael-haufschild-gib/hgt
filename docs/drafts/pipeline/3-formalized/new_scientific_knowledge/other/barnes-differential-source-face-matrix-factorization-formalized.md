## Closed formal theorem

Lean proves the exact analytic-to-derived chain used by the card:

1. the actual rationally independent Barnes logarithmic-derivative source has differential-
   translation annihilator equal to the principal ideal generated by
   `fullLadder N = ∏ j (T_j - 1)`;
2. polynomial translation operators embed faithfully in
   `ℂ[δ,T₁^{±1},…,T_N^{±1}]`, carry `fullLadder N` to the Laurent relation `f_N`, and extend the
   principal annihilator ideal exactly to `(f_N)`;
3. `D_N/(f_N)` has the proved length-one free resolution
   `0 → D_N --f_N→ D_N → D_N/(f_N) → 0`;
4. for each selected face `j`, multiplication by `p_j` and `x_j` gives the exact two-periodic
   matrix factorization on the canonically equivalent quotient;
5. for every nonempty face set `S`, base change to `B_S = D_N/(x_j : j ∈ S)` kills `f_N`, so the
   resolution has `B_S` in degrees zero and one and the zero module in every degree at least two.
