## 1. Statement

Let

```text
Omega = {(p,e) : p prime, e>=0},
ray(p,e)=p,
t(p,e)=log(p^(e+1)).
```

For a complex prime-power profile `a : Omega -> C`, assume that at one nonzero carrier `u`

```text
a(p,e) != 0  ->  sin(u t(p,e))=0.                      (1)
```

Then:

1. the active prime-ray set of `a` is subsingleton;
2. `a` is finite-prime local;
3. its class in the complete prime-clock quotient

   ```text
   (Omega -> C) / {profiles active on finitely many prime rays}
   ```

   is zero.

Consequently, if `f` is a finite-abscissa arithmetic profile supported on positive prime powers
and its prime-power coordinates satisfy `(1)`, then its analytic Dirichlet carrier already
belongs to the coordinate field generated by the rational coordinate and all finite-prime Euler
germs. It supplies no new global relative prime-clock direction.

This includes an infinite one-prime tower. No finite-depth, boundedness, polynomial valuation
order, or finite-Rees hypothesis is used.

## 2. Proof

Suppose two distinct prime rays `p!=q` are active, at depths `e,d`. By `(1)`,

```text
sin(u(e+1)log p)=sin(u(d+1)log q)=0.
```

Hence integers `m,n` satisfy

```text
u(e+1)log p=m pi,
u(d+1)log q=n pi.
```

Cross-multiplication gives

```text
u((e+1)n log p-(d+1)m log q)=0.
```

Since `u!=0`, integer-linear independence of distinct prime logarithms gives
`(e+1)n=(d+1)m=0`, hence `m=n=0`. This contradicts
`u(e+1)log p!=0`. Therefore active prime support is subsingleton and hence finite.

Finite-ray profiles are exactly the local submodule killed by the source quotient. Thus the
clock class of `a` is zero. For a finite-abscissa positive-prime-power arithmetic profile, the
exact analytic prime-clock correspondence identifies finite-ray locality with membership in the
pulled finite-prime Euler coordinate field. This proves the analytic classification.
