```text

```

normals; `ι` indexes all transverse directions. Define polynomial modes

```text

```

```text

```

together with the single one-sided linear root `F_1` generate, for every `k`,

```text

```

In every Lie-module representation, annihilation by the minimal generator family propagates to
all modes in `(1)`.
