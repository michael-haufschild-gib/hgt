### Proof

The characters (z^k) are orthonormal in (L^2(S^1)).  Hence

\[
 \|f_N\|_2^2
 =\frac1N\sum_{k=0}^{N-1}1=1.
\]

At (z=\zeta), every summand in `(2)` equals (1/\sqrt N),
giving the second identity in `(3)`.  The transverse operator acts
only on (eta), so

\[
 \widehat A^m(f_N\otimes\eta)
 =\lambda^m f_N\otimes\eta,
\]

which proves `(4)`.

A continuous linear functional for topology `(5)` is bounded by a
constant times a finite sum of its defining seminorms.  For any finite
set (M\subset\mathbb N), that bound on (u_N) would be

\[
 |\operatorname{ev}_\zeta(f_N)|
 \le C\sum_{m\in M}\lambda^m,                               \tag{6}
\]

whose right side is independent of (N), whereas the left side is
(\sqrt N\to\infty).  This contradiction proves discontinuity.

The same functions occur as boundary coefficients of
((dz_{\mathrm{normal}}/z_{\mathrm{normal}})\wedge f_N\eta).
Thus `(1)` is not an auxiliary point functional: it is an actual
