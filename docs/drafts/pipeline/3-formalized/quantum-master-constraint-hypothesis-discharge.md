## Exact relation

For a bounded constraint `C` on a Hilbert space, define `M = C†C`.  Then

`Re ⟨ψ, Mψ⟩ = ‖Cψ‖²` and `M ψ = 0 ↔ C ψ = 0`,

because `⟨ψ, Mψ⟩ = ‖Cψ‖²`, and `M† = M`.  Thus `M` has exactly the same physical vectors as `C` but automatically satisfies the self-adjointness premise of the Ward layer.

For a finite family `Cᵢ`, define

`M_C = ∑ᵢ Cᵢ†Cᵢ`.

Then

`Re ⟨ψ, M_C ψ⟩ = ∑ᵢ ‖Cᵢψ‖²`,

so positivity of every summand gives

`M_C ψ = 0 ↔ ∀ i, Cᵢ ψ = 0`.

This is the finite-family form of the master-constraint programme and directly matches the joint-physical-state interface already present in `FrozenConstraint`.
