## Mathematical Mechanism
1. **Dyadic seventh-power top-collar reserve (`TheTopCollarHasADyadicSeventhPowerReserve.lean`):**
   Decompose the top collar $(M, N]$ ($M = N / \text{linearDefectCutoff}(c)$) into dyadic shells $B_j$ around $N e^{-y_j}$. On each shell $B_j$ of logarithmic width $\le 1/2$, the prime-horizon test satisfies $\kappa Q(H_j) \ge -C_{\mathrm{sh}} \int H_j^2$, while the bulk aliasing density supplies $(g_1 / c^7) \log N \cdot (N / n)^7$ on $B_j$. Below a fixed critical multiple $c \le 2 K_{1,\mathrm{far}} (\log N)^{1/8}$, half of the $(N / n)^7$ aliasing weight absorbs both the short-window Weil floor and the cross-shell prime interaction, retaining a positive $(g_0 \log N / (8 c^7))\, S_{7,z}$ reserve with $S_{7,z} = \sum_{n \in (M, N]} (N / n)^7 z_n^2$ (`exists_critical_multiple_far_reserve`).
2. **Logarithm-free critical conductor residuals (`LogarithmFreeCriticalConductorResiduals.lean`):**
   On `Icc 1 N`, the normalized Ramanujan vector satisfies $\sum_{n \le N} c_m(n)^2 / n \ge (c_0 / (1 + \log m))\,\varphi(m) \log N$ (`sum_ramanujanSum_sq_div_ge`), removing the secondary $\log\log N$ denominator loss. Combining this norm floor with eighth-moment Fourier decay $|\widehat{\psi}(u)| \le C_\psi (1 + |u|)^{-4}$ of `tiltedUnitSpline` yields logarithm-free off-diagonal Gram bounds on low conductors $m \le Q_1 = \lfloor (\log N)^{13/32} \rfloor$ and dual seventh-power collar control $(c^7 / \log N) \sum_{m \le Q_1} \|r_m\|_{d7,M}^2 / E_m \le g_0 / 2048$ (`exists_critical_multiple_low_packet_and_collar_budget`).
3. **Subexponential cutoff and critical Schur closure (`CriticalMultipleCompleteWeilPositivity.lean`):**
   Below $c \le (\log N)^{1/16}$, `eventually_tiltedUnitSpline_spectralFloorWeilMatrix_posDef_below_one_eighth` gives positive definiteness of `spectralFloorWeilMatrix c N`. On $(\log N)^{1/16} \le c \le 2 K_1 (\log N)^{1/8}$, split $x = y + u_0 + u_1 + w$ along $V_{Q_1} \subset V_{R_0} \subset V_{R_1}$ at $Q_1 = \lfloor (\log N)^{13/32} \rfloor$, $R_0 = \lfloor \exp\sqrt{\log N} \rfloor$, and $R_1 = \lfloor \exp(\log N / (1 + \log\log N)^5) \rfloor$. Setting $k = \log N / (2 D (1 + \log\log N)^5)$ and $b = (g_0 D / 4)(1 + \log\log N)^5$ makes $b k = g_0 \log N / 8$ independent of $\log\log N$, while $c \ge (\log N)^{1/16}$ gives $\log N / c^7 \le (\log N)^{9/16} \ll k$. Pairing $r_m$ with $u_0$ via deep/top rows, with $u_1$ in $L^2$, and with $w$ via prefix $L^2$ plus dual/primal seventh-power collar masses (`inner_sq_le_prefix_add_topCollarSeventh`) closes the Schur complement on the whole space.
