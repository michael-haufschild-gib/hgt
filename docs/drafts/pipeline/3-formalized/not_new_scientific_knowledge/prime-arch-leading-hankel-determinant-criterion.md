# Prime--archimedean leading Hankel determinant criterion

- **ID:** prime-arch-leading-hankel-determinant-criterion
- **Stage:** 3-formalized
- **Type:** THEOREM (Lean) -- BRIDGE
- **Source:** the fixed normalized continued prime--Gamma Taylor germ
- **Statement:** RH is equivalent to strict positivity of one leading Hankel determinant in every
  finite degree.  The matrices are defined directly from source Taylor coefficients and contain no
  Xi zero coordinates.

## Result

Let

\[
S_n(i,j)=\operatorname{analyticTraceMoments}(G,i+j),
\qquad
G(z)=\operatorname{normalizedTraceMomentGerm}
  (\operatorname{continuedPrimeArchSourceRelativeTrace})(z).
\]

Then Lean proves

\[
\left(\forall n\in\mathbb N,\ \det S_n>0\right)
\iff
\left(\forall n\in\mathbb N,\ S_n\succ0\right)
\iff \mathrm{RH}.
\]

The same statement holds for the centered Xi reciprocal-moment matrices

\[
H_n(i,j)=\operatorname{Re} M_{i+j}.
\]

The source identity `analyticTraceMoments_normalizedPrimeArchSource` gives `S_n = H_n`
entrywise and unconditionally.

The first nonempty level is already discharged:

\[
\det S_1=M_0>0.
\]

At the next level Lean proves the exact interface

\[
\det S_2=M_0M_2-M_1^2,
\]

and nonnegativity of this determinant is equivalent to the explicit theta-cusp sixth-moment
inequality `ThetaCuspSixthMomentHankelInequality`.  Hence the first genuinely open determinant is
the already isolated theta concentration problem at size two; higher sizes are generated by the
all-order cumulant recurrence.

## Strictness mechanism

Under RH, every reciprocal-square atom is positive.  Positivity is strict for every nonzero real
polynomial because the Xi divisor support is infinite while the reciprocal-square map has fibres of
size at most two: equal coordinates arise only from identical zeros or functional-equation partners.
Consequently, a nonzero polynomial cannot vanish at every atom.  Thus every finite moment matrix is
positive definite, not merely positive semidefinite.

Conversely, positive definiteness of all finite matrices makes every real-polynomial trace-Hankel
value nonnegative, so the existing infinite-spectrum separation theorem yields RH.

## Leading-minor reduction

Mathlib does not currently expose the required leading-principal-minor criterion in this form.  The
formal proof supplies it by induction.  Reindex `H_(n+1)` as an `H_n` plus one block, apply the
one-dimensional Schur complement, use positivity of `det H_n` and `det H_(n+1)` to make the Schur
scalar positive, and recover positive definiteness of the full block.  This is classical Sylvester
infrastructure and is not classified as new scientific knowledge.
