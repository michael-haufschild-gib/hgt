# Schwarzian projective erosion tower

- **ID:** `schwarzian-projective-erosion-tower`
- **Stage:** 3-formalized
- **Type:** THEOREM (paper) — `[PROVED HERE] [BRIDGE] [NOT NEW SCIENTIFIC KNOWLEDGE]`
- **Lane:** general hypertranscendence; projective differential invariants; translation orbits
- **Statement:** Iterated Schwarzian reduction of a maximally translation-free differential
  indeterminate produces an infinite strictly descending tower whose every level remains maximally
  translation-HT and whose finite-jet intersection is only the base field.

## Goal

Identify whether an unpointed maximally HT carrier has a finite projective core.  A positive answer
would leave open a finite projective or canonical-system normalization as a hidden generative
handle.  A negative answer would prove that every finite projective reduction remains on the HT
side of the wall and that only an infinite-depth constraint can survive all reductions.

## Setup

Let `(K,D)` be a differential field of characteristic zero.  Let `A` be a nonempty index set and

`F_0=K<Y_a : a in A>`

the differential rational field on a differentially algebraically independent family.  Write

`S(X)=D^3 X / D X - (3/2)(D^2 X / D X)^2`

for the Schwarzian differential rational operator.  Recursively define

`Y_a^[0]=Y_a`, `Y_a^[n+1]=S(Y_a^[n])`,

and

`F_n=K<Y_a^[n] : a in A>`.

For a nonbase differential rational function `R` in finitely many of the original generators,
write `depth_Y(R)` for the largest original jet order occurring in a reduced rational expression.

## Theorem `[PROVED HERE]`

1. For every `n`, the family `{Y_a^[n]}` is differentially algebraically independent
   over `K`.
2. `F_0 sup F_1 sup F_2 sup ...` is strictly descending.
3. If `R in F_n \ K`, then `depth_Y(R)>=3n`.  More precisely, if `R` has differential
   order `r` as an element of the differential rational field generated by `Y^[n]`, then its order
   in the original variables is `3n+r`.
4. `intersection_(n>=0) F_n=K`.
5. If `A` is a translation orbit and `Y_a` is maximally translation-HT, then every
   Schwarzian iterate is maximally translation-HT and the inclusions commute with translation.

## Proof

### Highest-jet addition

Let `Q in K<X>` have exact differential order `d`, and let `R in K<Z>` have exact order `r`.
For every `j>=0`, `D^j Q` has exact order `d+j`, with

`partial_(X_(d+j)) D^j Q=partial_(X_d) Q != 0`.             (1)

If `Q` is differentially transcendental, substitution `Z |-> Q` is injective.  The chain rule at
the newest jet gives

`partial_(X_(d+r)) R(Q)`

` =(partial_(Z_r) R)(Q) partial_(X_d) Q != 0`.              (2)

Therefore

`ord_X R(Q)=d+r`.                                           (3)

For several independent coordinates, apply the same calculation to each active coordinate; jets
from different coordinates are disjoint, so cancellation cannot cross coordinate packets.  This is
the standard differential-Luroth highest-jet calculation.

### Schwarzian depth

The Schwarzian `S(X)` has exact order three and

`partial_(D^3 X) S(X)=1/DX != 0`.                           (4)

Repeatedly applying (3) gives

`ord_Y Y_a^[n]=3n`,                                        (5)

and, for every nonbase `R in F_n` of order `r` in the `n`th-level variables,

`depth_Y(R)=3n+r`.                                         (6)

Each `Y_a^[n]` is nonconstant in the differential indeterminate `Y_a`, hence differentially
transcendental.  Put `q=Y_a^[n]` and `s=Y_a^[n+1]`.  Then `q` is differentially algebraic over `s`
through

`2 (Dq) (D^3q)-3(D^2q)^2-2s(Dq)^2=0`.                      (7)

For any finite coordinate set, (7) makes the field at level `n` differentially algebraic over the
field generated by the corresponding level-`n+1` variables.  Differential transcendence degree is
therefore unchanged, proving differential algebraic independence at every level.

### Strict descent and intersection

The inclusion `F_(n+1) subset F_n` is immediate.  It is strict by (6): the element `Y_a^[n]` has
order zero in the level-`n` variables, whereas every nonbase element of `F_(n+1)` has level-`n`
order at least three.  Equivalently, the differential automorphism

`Y_a^[n] |-> Y_a^[n]+1`

for every `a` fixes every Schwarzian `Y_a^[n+1]` but moves `Y_a^[n]`.

Now let `R` lie in every `F_n`.  As an element of `F_0`, it uses finitely many original jets and has
some finite depth `q`.  If `R notin K`, (6) gives `q>=3n` for every `n`, impossible.  Hence

`intersection_n F_n=K`.                                    (8)

Finite support also rules out an expression using extraneous orbit coordinates: algebraic
independence makes dependence on each coordinate intrinsic.

Finally, if `Y_h=T_h f` is a full translation orbit, Schwarzian reduction commutes with translation.
The already-proved independence at every level gives maximal translation HT, and all field
inclusions are translation-stable. `QED`

## RH-route pressure test

The theorem excludes only implementations that claim a finite projective
differential-rational normalization of maximal translation HT yields the missing finite DA,
positive, or spectral core.  It does not exclude a canonical system built from additional Euler or
measure data, nor does it assert that the actual xi carrier has a maximally free translation orbit.

## Parent-theory and novelty verdict

This result is useful but does not pass the new-science gate.

- The one-step fact that a nonconstant differential rational function of a differential
  indeterminate remains differentially transcendental is ADH, Lemma 4.1.5.
- The exact order-addition calculation (1)--(3) is already the mechanism in D'Alfonso--Jeronimo--
  Solerno, Proposition 5, *Effective Differential Luroth's Theorem*:
  `https://arxiv.org/abs/1202.6344`.
- Schwarzian invariance and analytic iteration are classical.  Zemyan explicitly studies sequences,
  fixed points, and cycles of the Schwarzian operator:
  `https://doi.org/10.1090/S1088-4173-2011-00224-4`.

The infinite strict tower and intersection formula are immediate iterations of the sourced
highest-jet calculation.  They are classified as a bridge, not candidate new scientific knowledge.

### Generality of the base

The base is an arbitrary characteristic-zero differential field: the statements carry
`[Field K] [CharZero K] [Differential K]` and the ambient derivation is
`differentialPolynomialOverDerivation` extended to the fraction field.  Nothing in the proof
assumes the base derivation vanishes; where the original argument used the fact that a coordinate
derivation kills the constants, the derivation-stability and intertwining loci are replaced by
`derivStableField` and `twistedLeibnizKernel`, which allow the base to move and only require the
derivative of a base element to be a base element.

The generality is not vacuous: instantiating `K` as a free family jet field over `ℚ` gives a base
whose derivation is nonzero, and every theorem of the card holds there.
