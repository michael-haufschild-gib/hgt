## Paper proof

Let `r=(r0+R)/2`.  The inequalities `0<=r0<R` imply

```text
r0 < r < R,
0 < r.
```

Every entry `w` of `zs` satisfies `||w-rho||<=r0`, hence lies strictly inside the circle of radius
`r`.  On `ball rho R`, `SEMSplitData` supplies the factorization

```text
completedSEM N z = product_{w in zs}(z-w) u(z),
```

where `u` is analytic and nowhere zero.  Reindex the list product by `Fin zs.length`, assigning
multiplicity one to each entry.  The topological argument principle gives

```text
wind(gamma_SEM,0) = sum_{j : Fin zs.length} 1 = zs.length,
```

including repeated entries, which proves (1).

By definition, the left side of (3) is the constant jet `[C(zs.length)]`.  The already formalized
Fitting calculation for `semHoleDefectZ h` gives the same class, proving (3).  Applying the SEM
count-rigidity theorem shows that the source index is independent of the admissible annulus,
truncation, and factorization and equals `ord_rho(xi)` whenever a split is used to evaluate it.
