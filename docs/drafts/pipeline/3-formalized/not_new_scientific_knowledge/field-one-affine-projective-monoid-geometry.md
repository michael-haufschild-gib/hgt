## Definitions

Let `E_I=N^(I)` be finitely supported exponent vectors. Write
`T^e T^f=T^(e+f)`. Adjoin an absorbing zero to obtain the pointed
commutative monoid `A_I`.

A monoid ideal `P⊆A_I` contains zero and satisfies `a∈P ⇒ ab∈P`. It is
prime if it is proper and `ab∈P ⇒ a∈P or b∈P`.

For `S⊆I`, define

`P_S={0} ∪ {T^e | supp(e)∩S≠∅}`.

## Complete paper proof

### Freeness

Given a commutative monoid with zero `M` and a function `f:I→M`, define

`f̄(0)=0`,
`f̄(T^e)=∏_{i∈supp(e)} f(i)^(e_i)`.

Finite support makes the product finite. Exponent addition and the laws
`x^(m+n)=x^m x^n` show that `f̄` preserves multiplication, zero, and one.
Any morphism extending `f` must take `T^e` to the displayed product, so the
extension is unique. Thus `A_I` is the free commutative monoid with zero on
`I`.

### Contracted base extension

The contracted algebra kills the basis vector indexed by absorbing zero.
The remaining basis is indexed by `E_I`; multiplication adds exponents.
Therefore

`R[A_I]^c = R[E_I] ≃ R[T_i | i∈I]`

by the coefficient-preserving map `[e]↦T^e`. This is a semiring isomorphism
for every commutative semiring `R`, hence a ring isomorphism for every
commutative ring.

### Prime ideals

For every `S⊆I`, `P_S` is an ideal: multiplying `T^e` by `T^f` replaces
support by `supp(e+f)=supp(e)∪supp(f)`, so an intersection with `S`
persists. It is proper because `T^0=1` has empty support. It is prime:
if `T^(e+f)∈P_S`, then

`(supp(e)∪supp(f))∩S≠∅`,

so `supp(e)∩S≠∅` or `supp(f)∩S≠∅`.

Conversely, let `P` be prime and put

`S_P={i | T_i∈P}`.

If `T^e∈P`, write `T^e` as the finite product of its variable factors.
Repeated primality implies some `T_i∈P` with `e_i>0`; hence
`supp(e)∩S_P≠∅`. Conversely, if `i∈supp(e)∩S_P`, then `T_i∈P` divides
`T^e`, and ideal closure gives `T^e∈P`. Thus `P=P_(S_P)`.

The constructions `S↦P_S` and `P↦S_P` are inverse. Hence

`Spec A_I ≃ Set(I)`

as point sets. Moreover,

`P_S⊆P_T ↔ S⊆T`.

The forward implication tests the variables `T_i`; the reverse implication
uses the support-intersection definition. Since specialization in a prime
spectrum is inclusion of prime ideals, the specialization poset is the
Boolean lattice `Set(I)`. If `I` is finite of size `n`, this has `2^n`
elements.

### Projective spectrum

Give every variable degree one. The irrelevant ideal is generated by all
`T_i`. The homogeneous prime `P_S` contains the irrelevant ideal exactly
when `S=I`. Proj removes that one prime, so its points correspond to proper
subsets `S⊊I`, equivalently nonempty complements. For `|I|=n`, the number is
`2^n−1`.

This is the full underlying monoid-scheme point set. It differs from the
module/Tits rational-point functor, which gives `n` points for
`P^(n−1)(F₁)`. ∎
