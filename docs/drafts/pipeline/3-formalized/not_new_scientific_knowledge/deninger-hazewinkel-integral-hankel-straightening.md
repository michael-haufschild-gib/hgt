## Integral alternant construction

Fix `k >= 1` and increasing row indices `r_0 < ... < r_(k-1)`. In
`Z[x_0,...,x_(k-1)]` put

```text
A_r(x) = det(x_j^(r_i))_(i,j),
V(x)   = det(x_j^i)_(i,j).
```

The row-subtraction proof of Vandermonde divisibility works over every commutative ring and gives

```text
A_r = V Q_r                                                     (1)
```

for a polynomial `Q_r` with integer coefficients. No division in a coefficient ring occurs. Write

```text
Q_r = sum_p c_r(p) x^p,       c_r(p) in Z,                      (2)
```

where the sum is finite. Classically `Q_r` is the Schur polynomial belonging to `r`; the
coefficients grouped by permutation orbits are Kostka numbers. Grussler--Damm use this refinement
and Littlewood--Richardson cancellation to obtain nonnegative coefficients. Integral ideal
generation needs only `(1)--(2)`.

## Column-polarization lemma

Let `R` be any commutative ring and let `B : N × {0,...,k-1} -> R` be an arbitrary column-indexed
array. Define the additive column polarization of a monomial by

```text
P_B(x^p) = product_j B(p_j,j),                                  (3)
```

and extend it `Z`-linearly to all polynomials. Applying `P_B` to the alternant gives

```text
P_B(A_r) = det(B(r_i,j))_(i,j).                                 (4)
```

For a monomial multiple of the basic alternant, determinant multilinearity and the Leibniz formula
give

```text
P_B(x^p V) = det(B(p_j+i,j))_(i,j).                             (5)
```

Indeed, the term indexed by a permutation `sigma` on either side is

```text
sign(sigma) product_j B(p_j+sigma(j),j).
```

Applying the additive map `P_B` to `(1)`, then using `(2)`, `(4)`, and `(5)`, proves the universal
straightening identity

```text
det(B(r_i,j))
  = sum_p c_r(p) det(B(p_j+i,j)).                               (6)
```

This proof is division-free and is valid in every commutative ring. It also avoids a density or
algebraic-closure argument: `(6)` is obtained directly from an equality in the integer polynomial
ring.

## Hankel specialization

For an arbitrary sequence `a : N -> R` and arbitrary column indices `s_j`, set

```text
B(t,j) = a_(t+s_j).
```

Then `(6)` becomes

```text
det(a_(r_i+s_j))
  = sum_p c_r(p) det(a_(i+(s_j+p_j))).                           (7)
```

Every determinant on the right uses the consecutive row set `0,...,k-1`; only its columns are
shifted. Thus every Hankel `k`-minor belongs to the fixed-row minor ideal. The reverse containment
is tautological, hence the two ideals are equal over `Z` and after evaluation in every commutative
ring, including rings with nilpotents.

## Hostile audit

- **No field descent:** proof never proves an identity only after tensoring with `Q` or a field.
- **No hidden Schur premise:** `Q_r` is the quotient supplied by integral Vandermonde divisibility;
  tableau positivity is not used for ideal membership.
- **Repeated selectors:** increasing row/column hypotheses are unnecessary for ideal containment;
  if selectors repeat, determinant is zero and membership is immediate. Reordering distinct
  selectors changes only a unit sign.
- **Finite support:** `(2)` is the ordinary finite support of a multivariate polynomial, so `(6)`
  is a finite ideal combination.
- **Nilpotents:** every step is a polynomial identity over `Z`, hence survives arbitrary base
  change without reducedness.
