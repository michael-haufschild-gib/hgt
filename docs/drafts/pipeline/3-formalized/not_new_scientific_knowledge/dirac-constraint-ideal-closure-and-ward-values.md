# Dirac constraint-ideal closure and Ward values

- **ID:** `dirac-constraint-ideal-closure-and-ward-values`
- **Stage:** 3-formalized
- **Type:** `[BRIDGE] [FORMALIZATION] [HYPOTHESIS WEAKENING] [QUANTUM COSMOLOGY]`
- **Source:** DeWitt canonical quantum gravity; weakly commuting Dirac observables in constrained
  minisuperspace; `HTGeometry/FrozenConstraint.lean`.
- **Statement:** An observable preserves the physical kernel when its commutator with the
  constraint closes in the right ideal generated by that constraint. For a self-adjoint
  constraint, every physical state also annihilates the corresponding commutator expectation,
  giving a static Ward value relation.

## Lean value

The former theorem `preserves_physicalState_of_commute` required the strict operator equality
`C*A=A*C`. The sufficient condition is weakened to

`C*A = A*C + B*C`.

On a physical state `psi` with `C psi=0`, the additional term vanishes, so `C(A psi)=0`. For a
finite first-class family `C_i`, the analogous closure

`C_i*A = A*C_i + sum_j B_ij*C_j`

preserves the joint physical kernel. Strict commutation remains available as the `B=0` special
case, so existing consumers keep their original interface.

When `C` is a bounded self-adjoint operator on a Hilbert space, symmetry gives the static Ward
identity

`inner psi (C (A psi)) = 0`

for every physical `psi`. Consequently the expectation of `[C,A]` is zero. This converts an
operator constraint into a scalar value relation without introducing a time flow.

## Literature bridge

DeWitt's canonical quantum gravity makes primary and secondary constraints conditions on the
state vector, with the constraints alone governing finite-universe dynamics:
<https://doi.org/10.1103/PhysRev.160.1113>. Ashtekar--Tate--Uggla formulate minisuperspace
Dirac observables as phase-space functions that commute weakly with the scalar constraint:
<https://arxiv.org/abs/gr-qc/9302027>. The Lean closure equation is the exact finite algebraic
version of this weak commutation statement.
