# Cayley quadratic resolvent identity (Huo--Ren--Sabadini--Xu, Lemma 8.4)

- **ID:** `octonionic-riesz-dunford-2605-07183-lemma-8-4`
- **Stage:** `3-formalized/not_new_scientific_knowledge`
- **Type:** THEOREM (paper)
- **Source:** Huo--Ren--Sabadini--Xu, *Octonionic Riesz--Dunford functional calculus*, arXiv:2605.07183v1, Lemma 8.4, equations (8.4)--(8.6), p. 53--54.
- **Statement:** For all octonions `s q`, with `Q_s(q) = q^2 - 2 Re(s) q + |s|^2`,
  `L_(Q_s(q)) = (R_s - L_q)(R_(conj s) - L_q) + [L_q, R_(conj s)]`; hence its restriction to the associative subalgebra generated by `s,q` is the uncorrected product.

## Dependency-closed paper proof

For arbitrary `x`, expand the right-hand side.  By the Cayley conjugation identities,
`(x * conj s) * s = x * |s|^2`; this is valid because `s` and `conj s` generate an associative two-dimensional subalgebra.  Therefore

```text
(R_s - L_q)(R_(conj s) - L_q)(x) + [L_q, R_(conj s)](x)
  = x |s|^2 - (q x)s - q(x conj s) + q(q x)
      + q(x conj s) - (q x)conj s
  = (q^2 - 2 Re(s)q + |s|^2) x.
```

The last equality uses left alternativity `q(qx) = (q^2)x`,
`s + conj s = 2 Re(s)`, and centrality of real scalars.  These are all defining consequences of the concrete Cayley--Dickson octonion multiplication, so no premise or external analytic result is needed.  On the subalgebra generated by `s,q`, the associator term vanishes, yielding (8.6).
