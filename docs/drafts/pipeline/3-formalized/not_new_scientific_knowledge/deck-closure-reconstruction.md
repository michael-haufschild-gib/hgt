## Scope boundary

The topology here is the Krull topology on a Galois group.  Applying the same architecture to an
abelian multiplication tail requires the paper-level identification of the relevant differential
closure with the Manin kernel.  The Lean theorem does not pretend that Krull and Kolchin closures
are the same object.
