# Rank-four `A₃` simple-Weyl torus kernel

- **ID:** `steinberg-fin4-a3-coxeter-torus-kernel`
- **Stage:** 3-formalized
- **Type:** THEOREM (Lean); `[BRIDGE]`, not new scientific knowledge
- **Source:** Milnor, *Introduction to Algebraic K-Theory*, §9.11; classical Matsumoto-symbol route
- **Statement:** For every field `F`, the rank-four Steinberg kernel equals the subgroup generated by Steinberg symbols:
  `KTwo F (Fin 4) = steinbergSymbolSubgroup F (Fin 4)`.

## Goal

Close the finite type-`A₃` Weyl-elimination gap needed by the in-tree Milnor/Matsumoto bridge. This is not the SP-E analytic core and does not establish RH; it removes a concrete algebraic dependency rather than rebranding it as new knowledge.

## Paper proof

1. Modulo the full torus in the signed Weyl-word subgroup, the adjacent unit factors `w₀₁(1)`, `w₁₂(1)`, `w₂₃(1)` are involutions, obey the two braid relations, and commute at distance two. Disjoint commutation is derived from the presented Steinberg root relations.
2. Every directed unit Weyl factor reduces to these three classes by the exact triangle and reversal identities.
3. Positive words have the closed normal form `P R`, with `P = {1,a,b,ab,ba,aba}` and `R = {1,c,cb,cba}`. Inverses remain in the same monoid because the generators are involutions.
4. A diagonal signed-monomial image has identity permutation. In a `P R` representative, `P` fixes index `3`; only `R=1` can fix it, and then only `P=1` has identity permutation. Hence the quotient class is trivial.
5. A `K₂` element is a Weyl word, then a torus times a simple-Weyl factor. Its matrix identity and diagonal torus image force that simple factor to have diagonal image, hence it is toral. The existing base-torus normal form then puts the resulting toral `K₂` element in the symbol subgroup.
