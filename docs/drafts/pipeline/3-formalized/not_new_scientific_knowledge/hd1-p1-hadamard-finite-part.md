## Proof

[PROVED HERE]

HD1 gives the genus-one Hadamard log derivative

```text
xi'/xi(s) = b + sum_rho [1/(s-rho) + 1/rho].
```

For `|s|` below the first zero modulus,

```text
1/(s-rho) + 1/rho
  = -s/(rho(s-rho))
  = - sum_{m>=1} s^m rho^(-(m+1)).
```

Therefore the zero sum in the genus-one expansion contributes no constant term at `s=0`. The constant term of `xi'/xi` is exactly `b`, so the constant term of `-xi'/xi` is

```text
P_1 = -b.
```

This is a Hadamard finite part fixed by the canonical genus-one product, not the ordinary unpaired series `sum_rho rho^(-1)`.

For `k>=2`, the coefficient of `s^(k-1)` in `-xi'/xi` is

```text
P_k = sum_rho rho^(-k).
```

These sums are absolutely convergent. Indeed, the Riemann-von Mangoldt zero count gives `N(T)=O(T log T)`. On a dyadic shell `R <= |rho| < 2R`, the total absolute contribution for exponent `k` is

```text
O(R log R) * O(R^(-k)) = O((log R) R^(1-k)).
```

Over dyadic `R=2^m`, this is summable for every `k>=2`.

For `k=1`, the same bound gives shell size `O(log R)`, and the ordinary absolute series diverges. Symmetric pairings can define a conditional value, but HD1's canonical atlas coefficient is the genus-one finite part `-b`.

Using the completed-zeta expression at `s=0`,

```text
xi'/xi(0) = -1 - gamma/2 + log(2 sqrt(pi)),
```

so

```text
P_1 = -b = 1 + gamma/2 - log(2 sqrt(pi)).
```

Two remarks on the proof as written on the card.

* The card derives the `k ≥ 2` convergence from the Riemann–von Mangoldt count `N(T) = O(T log T)`
  by dyadic summation.  That route is available in the corpus (`RHTower.xi_zeroCount_growth`), but
  it is not needed: the corpus already carries `RHTower.xiSpectralPoint_inv_sq_summable`
  (`∑_ρ ‖ρ - 1/2‖^{-2} < ∞`, the convergence exponent of the genus-one product), and every zero
  satisfies `‖ρ‖ > 3` (`three_lt_norm_xiZero`, from `RHTower.four_lt_norm_xiSpectralPoint`), so
  `‖ρ‖^{-k} ≤ ‖ρ‖^{-2}` for all `k ≥ 2`.  The formalization takes this shorter route; the card's
  dyadic argument is correct but strictly stronger than what is used.
* The explicit constant is obtained without any `ζ'/ζ(0)` computation: the corpus definition
  `xi s = s(s-1)/2 · completedRiemannZeta₀ s + 1/2` gives `ξ(0) = 1/2` and `ξ'(0) = -Λ₀(0)/2`
  directly, hence `b = -Λ₀(0)` and `P_1 = Λ₀(0)`; mathlib's `completedRiemannZeta₀_zero` supplies
  `Λ₀(0) = (γ - log(4π))/2 + 1`, which is exactly `1 + γ/2 - log(2√π)`.

The expansion is stated on `‖s‖ ≤ 1` (any radius below the smallest zero modulus would do; the
corpus's verified zero-free interval gives `‖ρ‖ > 3`), with `ξ s ≠ 0` — automatic there, but kept
as an explicit hypothesis of the identity rather than a hypothesis of the card.
