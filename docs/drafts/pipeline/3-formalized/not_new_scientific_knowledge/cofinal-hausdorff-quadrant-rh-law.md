## Proof mechanism

For a cutoff `M`, set
```text
a_M(X) = X^M (R-X)^M,
t_M(n) = D_R(2M+n, 2M).
```
The exact shift identity is
```text
D_R^{t_M}(k,r) = D_R(2M+k, 2M+r).
```
Thus positivity on a cofinal quadrant makes every calibrated Hausdorff difference of `t_M`
nonnegative. The existing Hausdorff--Bernstein and finite-KMS closure theorems then make every
Hankel square of `t_M` nonnegative. The moment-functional multiplication law identifies this
with source trace--Hankel positivity restricted to the principal ideal generated by `a_M`:
```text
0 <= Re TraceHankel(a_M * p)  for every real polynomial p.
```

The trace-class Xi phase separator remains complete on this ideal. The only roots of `a_M` are
the real points `0` and `R`, so `a_M` is nonzero at every nonreal reciprocal-square Xi atom. A
phase-corrected separator can divide its target value by `a_M(lambda)` and produces the same
strictly negative limiting contribution at a hypothetical nonreal atom. Hence ideal-restricted
trace positivity excludes every nonreal reciprocal-square atom and forces RH.

## RH proof impact

The earlier residual criterion required positivity outside a finite `14 x 44` rectangle, which
still contained two infinite arms where only one index is large. This theorem proves that both
arms are logically redundant. No inequality with bounded `k` or bounded `r` is needed for the
remaining proof. It is enough to establish one uniform asymptotic statement in the deep cone
where both indices tend to infinity.

The theorem does not prove that deep-cone positivity. The unconditional RH obligation is now
the source-only asymptotic assertion
```text
exists M, forall k r >= M, 0 <=
  Re sum_q lambda_q^(k+1) (R-lambda_q)^r.
```

## Shifted-tail strengthening

The principal-ideal detector is stronger than the Hausdorff application. For every cutoff `M`,
define the even-shifted source tail
```text
m_M(n) = normalizedPrimeArchMoment (2*M+n).
```
Lean proves
```text
SequenceTraceHankelNonnegative m_M iff RH
```
for every `M`. Thus an arbitrary finite prefix of the source moment sequence may be discarded;
Hankel positivity of any one remaining even tail is sufficient and necessary.

The finite-system closure version is also exact:
```text
FinitePositiveAtomicLocalMomentClosure m_M iff RH.
```
Consequently a thermodynamic construction need only approximate the values `m_(2M+n)` for one
chosen cutoff. No matching condition on the earlier moments is required.

The operator-state consumer is correspondingly weakened. If one bounded complex self-adjoint
observable `A` and one state `Omega` satisfy
```text
<Omega, A^n Omega> = m_(2M+n)
```
for every `n`, then RH follows. This is a static vacuum-moment statement: it uses no Hamiltonian
flow and represents only the shifted tail, not the complete source sequence.
