## Theorem

Let `x : ι → E` be differentially algebraically independent over `F`.  For a resolution vector
`N : ι → ℕ`, define the observable field generated by the visible jets

```text
P_N = F(δ^n x_i | n < N_i).
```

Then each labelled jet is visible exactly at its assigned resolution,

```text
δ^n x_i ∈ P_N  iff  n < N_i,
```

and the whole resolution order is reconstructed from algebra inclusion:

```text
P_M ⊆ P_N  iff  M_i ≤ N_i for every i.
```

Thus `N ↦ P_N` is an order embedding.  This extends the single-source
`HypertranscendentalObservableNet` theorem from one hypertranscendental element to arbitrary
differentially independent families.

## Boundary attacks

1. **Flow attack.**  No one-parameter automorphism, Hamiltonian, state, or evolution equation
   occurs.  The derivation labels finite observations, and the theorem concerns only inclusion of
   their generated fields.
2. **Single-source duplication attack.**  A singleton family recovers the earlier HT observable
   net, but the new theorem has the full product resolution poset `(ι → ℕ)` and applies to joint
   differential matroids.  It is not obtained by applying the singleton theorem independently:
   membership must exclude algebraic recovery of one coordinate from all visible coordinates of
   every other clock.
3. **AQFT overclaim attack.**  The fields are commutative intermediate fields, not local
   C-star or von Neumann algebras.  The transferred structure is isotony plus order reflection;
   locality, modular flow, Haag duality, and holographic reconstruction are not claimed.
4. **RH circularity attack.**  The Xi-zero specialization uses only open-strip location,
   injectivity, and the Hurwitz differential-matroid theorem.  Since it does not see the
   transverse real part of a zero, it cannot imply RH without a new source-side coupling law.
