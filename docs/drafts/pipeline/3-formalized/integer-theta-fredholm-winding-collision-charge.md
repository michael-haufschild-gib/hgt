### 2. Newton–Girard pair-difference polynomial and confocal Zhukovsky winding dichotomy

For `s_n = max 6 n`, set `a_n = 1/2 - 1/(4 s_n)`, `b_n = 1/(2 s_n)`, `c_n = √(a_n² - b_n²) > 0`, `ρ_n = (a_n + b_n)/c_n > 1`, and `zhukovskyLoop n u = 1/2 + (c_n / 2)(ρ_n u + (ρ_n u)⁻¹)` on `UnitCircle`.
