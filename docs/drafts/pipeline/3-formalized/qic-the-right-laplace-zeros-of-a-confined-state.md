# Right Laplace zeros of a confined state

- **Stage:** 3-formalized
- **Source:** [QIC](../../../reports/rh-current-frontier-map.md#qic)

If k crossings precede a confined null state, its Laplace transform has at most ⌊k/2⌋ distinct zeros in the upper right quadrant. Each accounts for one conjugate pair. The third state can miss at most one such pair. Every null state has a nonzero simple-pole residue at some right ζ zero. [Rung bound](../../../../formal/GaloisForLFunctions/ExclusionOfTheCriticalState/Index/TheConfinedIndexBoundsInvisiblePairs.lean#L171) · [Actual residue](../../../../formal/GaloisForLFunctions/ExclusionOfTheCriticalState/Index/TheConfinedIndexBoundsInvisiblePairs.lean#L161)

Let Uv sum the real resolvent components with coefficients v, and let T multiply each coefficient by its rate. For confinement coefficient a and weighted inner product W, the weak equation gives Q(UTv,Uv) = −4a W(Uv,Uv). For a rate w set P±(z) = z² ± 2 Re(w)z + |w|². Expansion gives Q(UP₊v) − Q(UP₋v) = −32a Re(w)[W(UTv,UTv) + |w|²W(Uv,Uv)]. Dividing by P₊ and multiplying by P₋ removes w while preserving every other nonzero upper-quadrant coefficient. Eliminating all but one nonzero coefficient proves strict negativity on the full real span. Window recovery therefore supplies two negative directions per pair. Every larger ratio counts the current crossing as well, so these pairs cannot exhaust the right ζ divisor. [Resolvent elimination](../../../../formal/GaloisForLFunctions/ExclusionOfTheCriticalState/Index/TheRightLaplaceZerosOfAConfinedState.lean#L189) · [Strict count](../../../../formal/GaloisForLFunctions/ExclusionOfTheCriticalState/Index/TheConfinedIndexBoundsInvisiblePairs.lean#L90)

At fixed ratio, arbitrarily large negative window families would yield negative unit tests orthogonal to any finite list of earlier tests. An infinite orthonormal sequence contradicts confinement compactness. Thus each bounded range contains finitely many crossings. Simplicity gives one Laplace zero set per crossing, so a single finite exceptional set works for **every** state in that range. With infinitely many off-line zeros, every state has infinitely many distinct right residues.
