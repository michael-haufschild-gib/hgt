Dependency-closed paper proof selected (before project Lean):

Let X=C_b(R,C), with the actual supremum norm. For a regular parameter z
(z != 0 and XiC(z) != 0), let k be the original normalized theta density,
L_z(g)=integral exp(i*z*x) k(x) g(x), and C(z)=L_z(1), the literal flat
connection. Set c_z(g)=-L_z(g)/(z*C(z)), h=g+z*c_z(g), and

  R_z g(x)=c_z(g)+i*exp(-i*z*x)/k(x)
                       * integral_(x,infinity) exp(i*z*y) k(y) h(y) dy.

1. Bounded forcing pays every integral by the existing all-parameter theta
   density admission. The moment is a bounded linear functional. By construction
   L_z(h)=0. Reflection therefore rewrites the left tail as a right tail at -z.
2. The existing positive decreasing source ratio gives, without any variation
   assumption on g,
   |R_z g(x)-c_z(g)| <= ||h|| * forcedTailMass(z,x) on the right, and the
   corresponding -z,-x estimate on the left. Both tail masses tend to zero.
   Their monotonicity supplies a uniform global bound from the two values at 0.
   Thus R_z:X->X is bounded linear, with the actual common endpoint trace c_z(g).
3. Differentiating the original tail integral gives the literal equation
   A(R_z g)-z R_z g=g, where A f=i(f'+(k'/k)(f-trace(f))). On any compact
   interval, k'/k is bounded. Consequently the image of the unit ball has a
   common local derivative bound. Subtracting c_z(g) leaves uniformly vanishing
   tails. Compact-interval Arzela--Ascoli plus finite discretization of the
   vanishing tails gives relative compactness in the GLOBAL supremum norm.
   Adding back the one-dimensional trace part proves R_z is compact.
4. Existing `nativeHomogeneous_zero` uses only differentiability, a tail trace,
   boundedness and the actual ODE (not BV). It proves uniqueness on this whole
   bounded continuous domain. Thus these are actual source-defined inverses,
   not a finite-packet receiver or a spectral definition of an operator.
5. Fix z=i, regular unconditionally by `XiC_imaginary_ne_zero`. If R_i f=mu*f
   with mu != 0 and f != 0, then f is differentiable with a common trace and
   A f=(i+mu^(-1))*f. The native homogeneous classification forces
