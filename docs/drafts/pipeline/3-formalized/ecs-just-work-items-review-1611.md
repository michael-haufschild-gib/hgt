## E-J3 paper proof
Let S(ε) = Σ_q LF(z_q)LF(−z_q)e^(εz_q²) (summable for ε > 0, criticalState_hasSum_zeroPairing_heated with G = F) and S(ε) → −aW₈ (criticalState_tendsto_zeroNorm). Split the copies into on-line (Re z = 0) and off-line. For Re z = 0: −z = z̄, LF(z̄) = conj LF(z) (F real), z² = −(Im z)², so the term is e^(−ε(Im z)²)|LF(z)|² ≥ 0, ≤ |LF(z)|², increasing to |LF(z)|² as ε ↓ 0.
(i) If the off-line part tends to L, the on-line part R(ε) (real) tends to M = −aW₈ − L, so M is real. For a finite set T of on-line copies, Σ_T|LF|² = lim Σ_T e^(−ε γ²)|LF|² ≤ lim R(ε) = M; hence summable with Σ ≤ M; and Σ|LF|² ≥ R(ε) → M. So Σ_on |LF|² + L = −aW₈.
(ii) If the on-line values are square-summable, dominated convergence (Tannery) gives R(ε) → Σ_on|LF|², so the off-line part tends to −aW₈ − Σ_on|LF|².
(iii) With finitely many off-line copies the off-line part is a finite sum and tends to Σ_off LF(z)LF(−z).

E = L²(e^{−8u}du, u<0). For F ∈ E and Re z > −4, L F(z) = ⟪c_z, F⟫ + i⟪s_z, F⟫ with c_z = e^{(σ+8)u}cos τu, s_z = e^{(σ+8)u}sin τu ∈ E. ## E-J5(b) Galerkin convergence: paper proof
Let F be the critical state (null vector of Q_{W₀}), R₂ > W₀ the second critical ratio (no negative plane for Q_{R₂}), δ = a(W₀) − a(R₂) > 0, m = W₈(F).
1. Gap. For X ∈ H with W₈(F, X) = 0: Q_{R₂}(sF + tX) = t²Q_{R₂}(X) + s²(a(R₂) − a(W₀))m (F is null for Q_{W₀}, Q_R = Q_{W₀} + (a(R) − a(W₀))W₈). If Q_{R₂}(X) < 0 the plane span(F, X) is negative, so Q_{R₂}(X) ≥ 0, i.e. Q_{W₀}(X) ≥ δW₈(X).
2. Distance. For G with W₈(G) = m write G = αF + X, X ⊥ F. Q_{W₀}(G) = Q_{W₀}(X) ≥ δW₈(X), W₈(X) = (1 − α²)m, so |α| ≤ 1 and with s = sign α: W₈(G − sF) = W₈(X) + (1 − |α|)²m ≤ 2W₈(X) ≤ 2Q_{W₀}(G)/δ.
3. Probes. Given ε, put ε₁ = min(ε, 4ε/δ), η = ε₁δ/(4ma(W₀)), R = W₀(1 + η). The Pick blocks of Q_R have a negative vector for all large N; its probe sum P has Q_R(P) < 0. By 2, W₈(G − sF) ≤ ε₁/2 ≤ ε; and Q_{W₀}(G − sF) = Q_{W₀}(G) ≤ ε₁δ/4 ≤ ε since adding a multiple of F does not change Q_{W₀}. The approximant is sG, a combination of e_7, …, e_{N+6}.
