## Question

For static noncommuting local Hamiltonian dynamics, can one replace general recurrence upper bounds
by an exact asymptotic first-return law for the physical state orbit?

## Result

Let `n,q >= 2`, `D=q^n`, and take the full real coefficient space of arbitrary Hermitian onsite
terms and arbitrary Hermitian nearest-neighbour two-site terms on an open `n`-site `q`-level path.
On every nonempty preconnected open simple-spectrum chart, one conull set of Hamiltonians has the
following property.  For every normalized state cyclic for that Hamiltonian and every positive
post-exit cutoff `t0`, if

\[
 T_{H,\psi}(\delta)=\inf\{t\ge t_0:
 1-|\langle\psi,e^{-itH}\psi\rangle|^2<\delta\},
\]

then

\[
 \lim_{\delta\downarrow0}
 \frac{\log T_{H,\psi}(\delta)}{\log(1/\delta)}
 =\frac{D-2}{2}.
\]

The same Hamiltonian simultaneously has maximal projective rank `D-1`, discrete phase first-hit
exponent `D-1`, first-gap winding exponent `D-2`, every positive-weight all-replica collision floor,
the corresponding completed moment floors, and no nonzero exact projective return.

## First-principles chain

1. The full path-local coefficient family escapes every real affine spectral relation.
2. Its ordered gap-ratio map is analytic and nondegenerate on every simple-spectrum chart.
3. Kleinbock--Margulis extremality removes the very-well-approximable exceptional set.
4. Dirichlet approximation gives the matching upper first-hit exponent.
5. Strictly positive spectral weights make fidelity deficit quadratically equivalent to phase
   displacement in every direction.
6. Spectral decomposition identifies this weighted packet exactly with physical orbit survival
   fidelity for every cyclic normalized state.

No random matrix, chaos, mixing, spectral-genericity premise, computational assumption, or
time-averaging approximation enters the theorem.

## Literature boundary checked first

- Campos Venuti (2015) studies average spacing of fidelity-level crossings and explicitly
  distinguishes it from first recurrence; near exact return it uses a Gaussian approximation.
- Gupta--Short (2026) give deterministic Dirichlet upper bounds, including exponent `D-2` for
  continuous uniform recurrence, but no matching generic local-family lower law.
- Kotowski--Oszmaniec (arXiv:2601.10409v3, 5 August 2026) prove deterministic packing upper bounds
  and random diagonal lower bounds, and explicitly list tight recurrence bounds for physical
  dynamics generated by local noncommuting Hamiltonians as open.

Permitted priority claim: exact almost-everywhere physical survival-fidelity first-return exponent
for the full static one-dimensional onsite-plus-nearest-neighbour Hamiltonian family.  This is a
generic-family result, not a bound for every local Hamiltonian and not a finite-resolution
experimental timescale theorem.
