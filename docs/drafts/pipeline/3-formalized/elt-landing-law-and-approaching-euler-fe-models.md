### III. Unconditional refutation on the Functional-Equation half (`[PROVED HERE]`)

and `G(s) := cosh(s − 1/2) ∏'_{n=0}^∞ E_n(s)`.
1. **Convergence and holomorphy:** Write `E_n(s) = 1 + f_n(s)`. Since `‖α_n‖ = ‖conj α_n‖ ≥ γ_n` and `∑ 1/γ_n^2 < ∞` (from `1/γ_n → 0` and `∑ 1/γ_n < ∞`), on every ball `B(1/2, R)` one has `‖f_n(s)‖ ≤ (2 R^2 + R^4)/γ_n^2` eventually (`γ_n ≥ 1`), which is summable. 2. **Symmetry, reality, and exponential type (order 1):** Since `(1 − s − 1/2)^2 = (s − 1/2)^2`, `E_n(1 − s) = E_n(s)` and `G(1 − s) = G(s)`. Since `conj((s − 1/2)^2 / α_n^2) = (conj s − 1/2)^2 / (conj α_n)^2`, `E_n(conj s) = conj(E_n s)`, passing through `tprod` by `Complex.continuous_conj` to give `G(conj s) = conj(G s)`. Moreover, for all `x ≥ 0`, `1 + x^2 ≤ (1 + x)^2 ≤ (e^x)^2 = e^{2x}`; at `x = ‖s − 1/2‖/γ_n`, `‖1 − (s − 1/2)^2/α_n^2‖ ≤ 1 + (‖s − 1/2‖/γ_n)^2 ≤ exp(2‖s − 1/2‖/γ_n)`, so `‖E_n(s)‖ ≤ exp(4‖s − 1/2‖/γ_n)` and `‖P(s)‖ ≤ exp(4 S_γ ‖s − 1/2‖)` with `S_γ = ∑'_n 1/γ_n`. Multiplying by `‖cosh(s − 1/2)‖ ≤ e^{1/2} e^{‖s‖}` gives `‖G(s)‖ ≤ C exp(B ‖s‖)`.
3. **Zero configuration:** `G(s) = 0` iff `s = 1/2 + i t` with `cos t = 0` or `∃ n, s ∈ {1/2 ± δ_n ± i γ_n}`. Since `0 < δ_n < 1/2`, `δ_n → 0`, and `γ_n → +∞`, the strip `ZeroConfig` of `G` satisfies `ApproachesLine Z`, `(rightOf Z 0).Infinite`, and `¬LandingLaw Z`.
