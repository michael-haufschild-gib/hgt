# Möbius sums over integers coprime to a set of primes

- **ID:** MC-COPRIME-MOBIUS-ZERO-FREE
- **Stage:** 3-formalized
- **Type:** THEOREM (Lean) / NO-GO (STATUS CANNOT-488)
- **Source:** MC conjecture loop, cycle 152 (`1-in-progress/mc-conjecture-loop-2026-09-28.md`)
- **Statement:** Let `E` be a set of primes, `μ_E(n) = μ(n)` for `n` coprime to `E` and `0` otherwise, and `H_E(s) = Σ_{n E-smooth} n^{−s}`. Assume `(σ−1)H_E(σ) → 0` as `σ ↓ 1` (true when `Σ_{p∈E} 1/p < ∞`). If `Σ_{n≤x} μ_E(n) = O(x^θ)` with `0 ≤ θ < 1`, then `H_E(σ) < ∞` for every `σ > θ` and `ζ(s) ≠ 0` for every `Re s > θ`. Consequently `θ ≥ ½`.

## Proof
1. `Σ_{d|n} μ_E(d) = 1_{E-smooth}(n)`. Both sides are multiplicative and agree on prime powers (`sum_divisors_mobiusAF`). So `L(μ_E)·ζ = H_E` on `Re s > 1`.
2. Partial summation continues `F = L(μ_E)` to `Re s > θ` (the corpus `countDefectIntegral`).
3. Sparsity forces `F(1) = 0`: `F(σ) = (σ−1)H_E(σ)/((σ−1)ζ(σ)) → 0/1` (`continuation_one`).
4. `G = (F/(s−1))·(s−1)ζ` is holomorphic on `Re s > θ` and equals the nonnegative series `H_E` for `Re s > 1` (`regularized_eq_LSeries`).
5. Landau's summability transfer (`landau_local_summability_transfer`) on a closed disc centred at `3` of radius `3 − (θ+σ)/2` gives convergence of `H_E` at every real `σ > θ`.
6. By the identity theorem, `H_E = G = Fζ` on `Re s > θ`. There `H_E` is an absolutely convergent Euler product, `exp(Σ_p −log(1 − 1_E(p)p^{−s}))`, hence nonzero (`LSeries_smooth_ne_zero`). A zero of `ζ` with `Re > θ` would make `G = Fζ` vanish. So there is none.

## What is new and what is not
- For finite `E`, and for `Σ_{p∈E} p^{−½} < ∞`, the zero-inheritance half is classical: `H_E` converges on the critical line and the Littlewood argument goes through.
- The case needing Landau is `Σ_{p∈E} p^{−½} = ∞`, where `H_E` has its own singularity at or beyond `½` and could a priori cancel zeta zeros. The theorem shows the opposite. A Möbius bound `O(x^θ)` makes the deleted set thin at exponent `θ`, so `H_E` is regular and nonzero on `Re s > θ`, and nothing is cancelled.
- **Hilberdink–Neamah.** Their IJNT 16 (2020) theorem says that the two largest of the exponents `(α, β, γ)` of `(Π, N, M)` coincide and are `≥ ½`. They conjecture that there is no `[½,½,0]`-system; Broucke–Vindas (Math. Z. 2024, §3) record this as open. For systems generated by a set of rational primes with `Σ_{p∉G}1/p < ∞` (positive density `ρ`), the theorem gives `γ ≥ ½`. So the conjecture holds in this class, for every such system. A literature search found no statement of this case.
- It is elementary: Landau plus Hardy. This is a boundary result, not an RH producer.

## MC reading
A sieved Möbius function is a receiver with the same threshold as `M(x)`. Deleting primes can neither hide zeta zeros nor create cancellation beyond the zero abscissa, and the deletion is forced to be thin by the bound it is supposed to improve. This closes "sieve the Möbius function first" as an MC producer idea.

## Boundary: additions (open, reduced)
For generators `ℙ ∪ C` (integers added), `ζ_G = ζ·exp(P_C + R_C)` with `P_C = Σ_{c∈C} c^{−s} ≥ 0`. If `Σ_{c∈C} c^{−½} < ∞`, the same argument applies: `exp(P_C)` is continuous and nonzero on `Re s ≥ ½`. If `Σ_C c^{−½} = ∞`, `γ < ½` requires `Re P_C(σ+iγ) ≥ m_γ log(1/(σ−½)) − O(log γ)` at every critical zero, i.e. positive coherence of the added integers with the zeros. The explicit formula gives, for each integer `n`, `Σ_{γ} w(γ/T) n^{iγ} = −(T/√n)Δ_T(n) + O(log T)`, where `Δ_T(n)` is the prime-count excess in `n(1 ± 1/T)`. So `C` must sit on prime deficits at every scale `n/T`, with the mass coming from `n > T²`. That is short-interval prime statistics at pair-correlation range `α ≥ 2`, in sup norm: the same `α ≥ 1` wall as the HF lane (L111/L117). Unresolved.

## Generalization: multiplicative dampings (cycle 153)
- **Statement.** Let `f` be real on the primes with `|f(p)| ≤ 1`, and let `a(n) = μ(n)∏_{p|n}f(p)`. Assume the divisor sum `g(n) = ∏_{p|n}(1 − f(p)) ≥ 0` is sparse at 1, which holds when `Σ_p (1 − f(p))/p < ∞`. If `Σ_{n≤x} a(n) = O(x^θ)` with `0 ≤ θ < 1`, then `Σ_n g(n) n^{−σ} < ∞` for `σ > θ` and `ζ(s) ≠ 0` for `Re s > θ`; hence `θ ≥ ½`. Deleting a set of primes is the case `f = 1_{p∉E}`.
- **Key identity.** `g` has the multiplicative inverse `h(p^k) = (f(p) − 1)f(p)^{k−1}`, and `|h| ≤ g`. So `L(g)·L(h) = 1` wherever `L(g)` converges absolutely. This replaces the Euler product, since `g` is not completely multiplicative.
