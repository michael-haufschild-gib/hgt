### 1. Probe Gram matrices and Gershgorin diagonal dominance `[PROVED HERE]`
For $a, b : \mathrm{Fin}\,N \to \mathbb{Z}$, define the polarized real pairing (`probePairing`)
$$G(a, b) = \sum_{i, j < N} \operatorname{Re}(\mathrm{atomGram}\,N\,i\,j)\,a_i b_j = \frac{Q(a + b) - Q(a) - Q(b)}{2}, \qquad Q = \mathtt{integerProbe}\,N.$$
For a family $a : \mathrm{Fin}\,m \to (\mathrm{Fin}\,N \to \mathbb{Z})$, let $G_{r s} = G(a_r, a_s)$ and $\mathcal{G}(a) = (G_{r s})_{r, s < m}$ over $\mathbb{C}$ (`probeGramMatrix`).
- $\mathcal{G}(a)$ is real symmetric (hence Hermitian), satisfies $\operatorname{hermQuad}(\mathcal{G}(a), c) = Q(\sum_r c_r a_r)$ for $c \in \mathbb{Z}^m$ (`hermQuad_probeGramMatrix_int`), and has $\operatorname{hermNegIndex}(\mathcal{G}(a)) \le \operatorname{hermNegIndex}(\mathrm{atomGram}\,N)$ (`hermNegIndex_probeGramMatrix_le`).
- For $m = 2$, $\operatorname{hermNegIndex}(\mathcal{G}(a)) = 2 \iff G_{11} < 0 \land G_{22} < 0 \land G_{12}^2 < G_{11} G_{22}$ (`twoProbe_negDef_iff_det`).
- **Gershgorin pilot (`hermNegIndex_eq_of_gershgorin_row_lt_one`)**: if $G_{r r} < 0$ and $\sum_{s \neq r} |G_{r s}| / \sqrt{G_{r r} G_{s s}} < 1$ for every $r < m$, normalizing $y_r = \sqrt{-G_{r r}}\,z_r$ yields
  $$\operatorname{hermQuad}(-\mathcal{G}(a), z) = \sum_r \|y_r\|^2 - \sum_{r \neq s} \frac{G_{r s}}{\sqrt{G_{r r} G_{s s}}} \operatorname{Re}(\bar y_r y_s) \ge \sum_r \|y_r\|^2 \Bigl(1 - \sum_{s \neq r} \frac{|G_{r s}|}{\sqrt{G_{r r} G_{s s}}}\Bigr) > 0,$$
  whence $\operatorname{hermNegIndex}(\mathcal{G}(a)) = m$.
