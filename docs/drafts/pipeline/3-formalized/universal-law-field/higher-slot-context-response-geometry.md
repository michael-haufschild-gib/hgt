## Frozen setting

Fix a set of source letters `A`, a response set `Y`, and finite rooted ordered binary source trees

\[
 t ::= \operatorname{leaf}(a)\mid \operatorname{fork}(t_0,t_1).
 \tag{HCRG.1}
\]

A one-hole context is generated by

\[
 C ::= \square\mid \operatorname{fork}(C,t)
                  \mid \operatorname{fork}(t,C),
 \tag{HCRG.2}
\]

with plugging `C[t]`.  A scalar or structured source law is any response

\[
 r:\operatorname{Tree}(A)\to Y.
 \tag{HCRG.3}
\]

Define contextual equivalence

\[
 t\sim_r u
 \quad\Longleftrightarrow\quad
 r(C[t])=r(C[u])\quad\text{for every one-hole context }C.
 \tag{HCRG.4}
\]

The proposed canonical law-state object is

\[
 \operatorname{Syn}(r)=\operatorname{Tree}(A)/{\sim_r}.
 \tag{HCRG.5}
\]

This is the source-generated context-response quotient, not a fitted receiver.

## Frozen theorem

### Theorem A — contextual congruence and canonical branched realization

For every `r`, relation `(HCRG.4)` is an equivalence relation and a two-sided fork congruence:

\[
 t_0\sim_r u_0,\ t_1\sim_r u_1
 \Longrightarrow
 \operatorname{fork}(t_0,t_1)\sim_r\operatorname{fork}(u_0,u_1).
 \tag{HCRG.6}
\]

Consequently leaf formation, binary fork, and root response descend to `Syn(r)`.  The descended
process realizes `r`, every state is source-reachable, and complete context response separates its
states.

### Theorem B — unique marked minimal realization

A presentation of `r` consists of a carrier `X`, marked leaves `eta:A->X`, binary composition
`mu:X->X->X`, and reporter `q:X->Y`.  Tree evaluation is defined recursively.  It is:

- reachable when every `x:X` is the evaluation of a source tree;
- context-observable when equality of reported responses after every evaluated one-hole context
  forces equality of states;
- a realization of `r` when `q(eval(t))=r(t)` for every tree.

Every reachable, context-observable realization of `r` is uniquely equivalent to `Syn(r)` by a
bijection preserving every marked leaf, binary composition, and reporter.  Hence any two such
presentations of one complete response are uniquely marked-equivalent.

### Corollary C — withheld higher-slot prediction

Every response of a composite context assembled from leaves, forks, and one withheld subtree is
presentation-independent.  If calibrated route charts determine the contextual class of that
subtree, the response of every unmeasured outer context is forced.  Sequential word response and
parallel tensor response are restrictions of this branched law, not the general law itself.

## Proof

Write `C compose D` for the context satisfying

\[
 (C\circ D)[t]=C[D[t]].
 \tag{HCRG.7}
\]

It is defined recursively on `C`; induction gives `(HCRG.7)` and associativity.  Reflexivity,
symmetry, and transitivity of `sim_r` hold pointwise over contexts.

Suppose `t_0 sim_r u_0` and `t_1 sim_r u_1`.  For an arbitrary outer context `C`, apply the first
equivalence to the composite context

\[
 C\circ\operatorname{fork}(square,t_1)
\]

and the second equivalence to

\[
 C\circ\operatorname{fork}(u_0,square).
\]

This yields

\[
 r(C[\operatorname{fork}(t_0,t_1)])
 =r(C[\operatorname{fork}(u_0,t_1)])
 =r(C[\operatorname{fork}(u_0,u_1)]),
\]

proving `(HCRG.6)`.  Hence `fork` descends to `Syn(r)`.  The hole context shows that `r(t)=r(u)`
whenever `t sim_r u`, so root response descends too.  Leaves descend by quotient projection.

Every element of `Syn(r)` has a tree representative, hence is reachable.  Let `[t]` and `[u]` have
equal descended response after every descended context.  Evaluating representatives says exactly
that `r(C[t])=r(C[u])` for every syntax context `C`.  Thus `t sim_r u` and `[t]=[u]`; the canonical
realization is context-observable.  This proves Theorem A.

Now let `P=(X,eta,mu,q)` be a reachable, context-observable realization of `r`.  Define

\[
 Phi_P:Syn(r)\longrightarrow X,
 \qquad Phi_P([t])=eval_P(t).
 \tag{HCRG.8}
\]

If `t sim_r u`, then for every context `C`, realization gives

\[
 q(eval_C^P(eval_P(t)))=r(C[t])=r(C[u])
 =q(eval_C^P(eval_P(u))).
\]

Context observability of `P` gives `eval_P(t)=eval_P(u)`, so `(HCRG.8)` is well-defined.
Reachability makes `Phi_P` surjective.  Conversely, if `eval_P(t)=eval_P(u)`, applying every
evaluated context and using realization gives `r(C[t])=r(C[u])`; hence `t sim_r u`.  Therefore
`Phi_P` is injective.

Structural recursion immediately gives

\[
 Phi_P([leaf(a)])=eta(a),\qquad
 Phi_P(fork(x,y))=mu(Phi_P(x),Phi_P(y)),
\]

and the hole context gives `q Phi_P = response`.  Any other map preserving leaves and fork agrees
with `Phi_P` on every represented tree by induction, hence everywhere by reachability.  Thus
`Phi_P` is the unique marked process equivalence.  Composing `Phi_P^{-1}` with `Phi_Q` proves
Theorem B for any two minimal realizations.

Finally, every composite one-hole response is computed by the descended context action on
`Syn(r)`.  A marked equivalence preserves leaves and fork and therefore preserves context action by
induction on contexts.  It also preserves the reporter.  The response of every withheld outer
context is consequently independent of presentation, proving Corollary C. `[PROVED HERE]`

No topology, positivity, linearity, finiteness, or choice of coordinates is used.  Those become
doctrines on the reconstructed branched process rather than premises of reconstruction.
