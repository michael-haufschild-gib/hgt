## Formalized result

For every matrix over an arbitrary commutative ring, Lean proves the generalized Laplace
containments

```text
I_(r+s)(M) <= I_r(M) I_s(M),
I_(n*k)(M) <= I_n(M)^k.
```

The proof identifies the determinant alternating map with the exterior product of the two block
minor maps.  This avoids division and therefore works unchanged over rings with torsion and
nilpotents.

For Hazewinkel's universal Hankel matrix over `MvPolynomial ℕ ℤ`, with `J_n` generated by its
`(n+1)`-minors, specialization gives Deninger's exact Lemma 2.2:

```text
J_(n*k-1) <= J_(n-1)^k,    n >= 2, k >= 1.
```

For a ring map `f : A →+* B` with `(ker f)^k = 0`, Lean then proves:

```text
rank H(map f w) < n  ->  rank H(w) < n*k,
map f w has finite Hankel rank <-> w has finite Hankel rank.
```

The latter equality is the cartesian square in Proposition 2.1(c).  An explicit coefficientwise
lift proves surjectivity of the big-Witt map for every surjective coefficient map.  Combining it
with rank descent proves formal smoothness of `W_J`; subtype uniqueness proves the unique lifting
property of `W_J -> W`, i.e. Proposition 2.1(d).

`DeningerRationalWittHazewinkelHankel.lean` closes Proposition 2.1(a) without the
paper's reduction through a polynomial domain.  A normalized fraction `F=P/Q` yields an explicit
eventual coefficient recurrence with bound

```text
d = max (natDegree(P)+1) (natDegree(Q)).
```

Strong induction expresses every Hankel column in the span of the first `d` columns.  Every
`(d+1)`-minor then factors as a `(d+1) x d` matrix times a `d x (d+1)` matrix, whose determinant
vanishes over every commutative ring.  Thus the literal inclusion
`W_rat(A) -> W_J(A)` is proved even when `A` has nilpotents or zero divisors.

The same module proves the sharp kernel estimate in Proposition 2.10.  If `f : A -> B` has
`(ker f)^k=0` and a big-Witt vector maps to `1`, then every positive coefficient lies in `ker f`.
In each Leibniz monomial of a `(k+1)`-minor, at most one selected Hankel entry can have index zero;
the remaining at least `k` factors lie in `ker f`.  Repeated row or column selectors are handled
separately by alternatingness.  Lean concludes

```text
W(ker f) = W_J(ker f) = W_J^{<=k}(ker f).
```

For surjective `f`, the result is packaged with Hazewinkel-lift surjectivity as Proposition
2.10(1)'s exact-sequence statement.  Specialization to `A -> A/nilradical(A)` proves Proposition
2.10(2).
