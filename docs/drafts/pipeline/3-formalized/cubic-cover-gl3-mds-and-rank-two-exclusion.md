### 1. Binding-bin specialization, cubic square-row restriction, and norm-shell independence
1. *Unramified local specialization:* At any primary prime `π ∤ 6` and unramified row `u ∉ (π)` (`j = 0`), setting `X = 0` and `V = 0` gives `primeR π ηp 0 0 = 0`, annihilating all eight positive-`t` Gauss-sum blocks `baseSum` identically, and reduces the `t = 0` block `(1 − 0)⁻¹ + χ_π(u) Y (1 − χ_π(u) Y)⁻¹` to `(1 − χ_π(u) Y)⁻¹` (`‖Y‖ < 1`), the local Euler factor of `L^{(u)}(w, χ_u)`.
2. *Order mismatch (`n = 6` vs `n = 3`) and Hasse–Davenport obstruction:* By `idealRowHom_square`, `idealRowHom x (d²) = ringComplex (idealSymbol d x)`, restricting `idealRowHom` to the cubic symbol (`n = 3`) on square ideals `u = d²` (`N(d) ≤ U^{1/2} ≪ U^{21766/32589}`). On any finite group `G`, `φ⁶ = 1` and `φ³ ≠ 1` give `2 · #{g ∈ G : φ(g)³ = 1} = |G|` via multiplication by `g₀` with `φ(g₀)³ = −1`. At each primary prime `π ∤ 6`, `χ(4) G₁ G₂ = −π |π| Γ(π) ≠ 0` maps sextic–cubic Gauss products into the quadratic Gauss phase `Γ(π)`.
3. *Norm-shell linear independence:* If `∑_{n ∈ S} c_n n^{−σ} = 0` for all `σ > 0` across a finite nonempty set `S` of positive integers `n ≥ 1` with `m = min S`, multiplying by `m^σ` gives `c_m + ∑_{n ∈ S \ {m}} c_n (m/n)^σ = 0`; since `0 < m/n < 1` for `n ∈ S \ {m}`, letting `σ → +∞` forces `c_m = 0` and inductively `c_n = 0` for all `n ∈ S` (splitting into real and imaginary parts over `ℂ`).

### 2. Exact `W(A₂) ≅ S₃` scattering duality, Stirling cocycle, and two-variable convexity hull
1. *Weyl group and scattering duality:* On `ℝ²`, `w₁(σ₁, σ₂) = (1 − σ₁, σ₁ + σ₂ − ½)` and `w₂(σ₁, σ₂) = (σ₁ + σ₂ − ½, 1 − σ₂)` satisfy `w₁² = w₂² = id`, `w₁ w₂ w₁ = w₂ w₁ w₂ = w₀`, and `(w₁ w₂)³ = id`.
