# Theta threshold for ξ-divisible transforms

- **ID:** theta-threshold-xi-divisible-uniqueness
- **Stage:** 3-formalized
- **Type:** THEOREM (Lean)
- **Source:** HF card `hf-positive-hodge-attack/krein-producer-loops.md`, L45 (after L43 survivor 4 and MUST-478)
- **Statement:** If `|F(x)| ≤ C exp(−c e^{2|x|})` with `c > π` and `ξ` divides `M_F(s) = ∫F(x)e^{(s−½)x}dx` in the ring of entire functions, then `F = 0` a.e.; for every `c < π` Riemann's kernel `Φ` (with `M_Φ = ξ`) is a nonzero example.

## Goal
The radical of the Weil form is generated by Riemann's kernel `Φ` (`M_Φ = ξ` vanishes on the whole
zero divisor, MUST-478). The question is how fast a function can decay while its transform stays
divisible by `ξ`. The answer is exactly the theta rate: `Φ(x) ≍ e^{9|x|/2}exp(−πe^{2|x|})`, and
nothing with decay rate `c > π` is `ξ`-divisible. The zero divisor of `ζ` (with multiplicity) is a
uniqueness set for the class `{|F| ≤ Ce^{−ce^{2|x|}}}` if and only if `c > π`. So `Φ` is the extremal
radical vector, and the margin of any radical-type near-null Weil test is limited by the theta tail.

Not circular: no hypothesis on the location of zeros enters.

## Paper proof

Notation: `s = σ + it`, `ξ(s) = s(s−1)/2·π^{−s/2}Γ(s/2)ζ(s)`, `M_F(s) = ∫F(x)e^{(s−½)x}dx`.
Hypothesis: `M_F = ξ·h` with `h` entire.

**Step 1 (growth of `M_F`).** For `y > 0` and `c' > 0`, `e^u ≥ 1+u` applied to
`c'e^{2x} = (y/2)exp(2x − log(y/2c'))` gives `yx − c'e^{2x} ≤ (y/2)log(y/2c') − y/2`. Fix
`π < c' < c` and `δ = c − c'`. Then for `σ ≥ ½`, `y = σ − ½`:
`|M_F(s)| ≤ C·I_δ·exp(max(0, (y/2)log(y/2c') − y/2))`, with `I_δ = ∫e^{−δe^{2|x|}}dx`.
For `σ ≤ ½` the same holds with `y = ½ − σ`, using `x < 0`.

**Step 2 (Gamma floor).** Gauss' limit gives
`|Γ(x+iy)|/Γ(x) = lim_n Π_{k≤n}(x+k)/|x+k+iy|`. Each factor is increasing in `x > 0`, so for
`x ≥ 1`: `|Γ(x+iy)| ≥ Γ(x)|Γ(1+iy)|`. The reflection formula gives `|Γ(1+iy)|² = πy/sinh(πy)`.
Since `u/sinh u ≥ e^{−u}`, this yields `|Γ(x+iy)| ≥ Γ(x)e^{−π|y|/2}`.

**Step 3 (ξ floor for `σ ≥ 2`).** `|ζ(s) − 1| ≤ ζ(2) − 1 < 2/3`, so `|ζ(s)| ≥ 1/3`. Also
`|s(s−1)|/2 ≥ 1`. So `|ξ(s)| ≥ (1/3)π^{−σ/2}Γ(σ/2)e^{−π|t|/4}`. Binet's formula with a
nonpositive kernel gives `log Γ(a) ≥ (a−½)log a − a + ½log 2π`.

**Step 4 (right half-plane).** For `σ ≥ 2`, Steps 1 and 3 give
`log|h(s)| ≤ K + (σ/2)log(π/c') + ½log σ + π|t|/4`. On the real axis this is
`|h(σ)| ≤ K'e^{−ησ}` with `η = ¼log(c'/π) > 0`. In general `|h(s)| ≤ K''e^{(π/4)|s|}`.

**Step 5 (left half-plane).** `ξ(s) = ξ(1−s)` and `M_F(s) = M_{F⁻}(1−s)` with `F⁻(x) = F(−x)`. So
`h(s) = M_{F⁻}(1−s)/ξ(1−s)`, and Step 4 applies at `1−s` (`F⁻` has the same decay).

**Step 6 (strip).** Burnol's good heights (`exists_xi_horizontal_ratio_nat_bound`): for every large
`n` there is `T ∈ [n, n+1]` with `|ξ(σ ± iT)| ≥ T^{−M}|ξ(2 ± iT)|` for `σ ∈ [−1, 2]`. There
`|M_F| ≤ K` and, by Step 3, `|ξ(2±iT)| ≥ c e^{−πT/4}`. So `|h| ≤ K T^M e^{πT/4}` on the
horizontal sides of `[−1,2]×[−T,T]`, and Steps 4–5 bound the vertical sides. The maximum modulus
principle gives `|h(s)| ≤ A e^{τ|s|}` in the strip, hence globally.

**Step 7 (two-ray vanishing).** `h` is entire of exponential type, and it decays exponentially along
both real rays (Steps 4–5). The two-ray Paley–Wiener theorem
(`RHTower.eq_zero_of_two_ray_exponential_decay`) gives `h ≡ 0`. So `M_F ≡ 0`, the Fourier transform
of `F` vanishes, and `F = 0` a.e.

**Sharpness.** `M_Φ = ξ` (`riemannPhiTransform_eq_xi`, `h = 1`). Moreover
`|Φ(x)| ≤ C e^{|x|/2}(3e^{2|x|} + 2e^{4|x|})e^{−πe^{2|x|}}` (`norm_riemannPhiKernel_le`), which is
`≤ C_c e^{−ce^{2|x|}}` for every `c < π`.

**Remarks.**
- Complex shifts `Φ(x − w)` have `M = e^{w(s−½)}ξ` and decay rate `πe^{−2|Re w|}cos(2 Im w) < π`.
  The threshold is where the window of admissible shifts shrinks to a point.
- The boundary case `c = π` is open: `Φ` just misses it because of its polynomial prefactor.
