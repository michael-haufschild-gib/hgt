## Exact relation

Let `Phi_U` be the finite cyclic observable twirl, `P_U` the stationary-vector average, and let
`psi` satisfy `U psi = psi`.  For every bounded operator `X`, define

```text
D*_U(X) = Phi_U(X†X) - Phi_U(X)† Phi_U(X).
```

If `U` is an isometry of nonzero finite period, then

```text
Re <psi,D*_U(X)psi> = ||(1-P_U)X psi||².                 (1)
```

Hence this value is nonnegative and

```text
Re <psi,D*_U(X)psi> = 0
  iff P_U X psi = X psi
  iff (U-1)X psi = 0
  iff (U X-X U)psi = 0.                                  (2)
```

For self-adjoint `X`, `D*_U(X)` is definitionally identified with the corpus's previous
finite-clock Kadison defect.  Thus `(1)` and `(2)` strictly generalize the old API.

For a full clock generated by `U` and a subclock generated by `U^d`, the arbitrary-operator law of
total observability variance is

```text
Re <psi,D*_full(X)psi>
  = Re <psi,D*_sub(X)psi> + ||(P_sub-P_full)X psi||².     (3)
```

For a finite family of clocks, summing `(1)` gives a nonnegative master energy whose zero set is
exactly the physical kernel of the existing finite quantum master constraint, without assuming
`X` self-adjoint.
