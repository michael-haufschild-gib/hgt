## Exact relation

Let `e : E ->_F L` intertwine the derivations.  The embedding-covariance theorem gives

```text
e(P_N(x)) = P_N(e x).
```

Since a field homomorphism is injective, restriction produces a canonical algebra equivalence

```text
j_N : P_N(x) ~=_F P_N(e x).
```

For every `y` in `P_N(e x)` there is therefore a unique `z` in `P_N(x)` satisfying

```text
e z = y.
```

These local equivalences commute with the inclusions in the jet filtration: if `M <= N`, applying
`j_M` before inclusion or including first and applying `j_N` has the same value in `L`.

Thus global non-surjectivity of `e` creates no loss inside the clock-generated finite observable
slice.  The local inverse is available exactly where it is justified, rather than being assumed on
the whole target field.
