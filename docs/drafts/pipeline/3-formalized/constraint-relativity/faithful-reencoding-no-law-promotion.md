## Clone-conjugacy theorem

Let `X` be a set and `C` a clone of finitary operations on `X`. Let
`i : X -> Y` be injective and put `Y_0=i(X)`. For every `n`-ary `f in C`, define

\[
 (i_*f)(i(x_1),\ldots,i(x_n))=i(f(x_1,\ldots,x_n)).
 \tag{1}
\]

Then `i_*C` is a clone on `Y_0`, and

\[
 i_*:C\xrightarrow{\sim}i_*C
 \tag{2}
\]

is a clone isomorphism. Consequently:

1. `i` is an isomorphism between the original algebra and its encoded image;
2. a term identity holds before encoding exactly when it holds after encoding;
3. term-definable operations correspond bijectively;
4. congruence lattices correspond bijectively; and
5. every operation obtained only by transporting old operations through `i` has zero genuine
   law-promotion content.

### Proof

Injectivity gives a two-sided inverse `i^{-1}:Y_0 -> X`. Equation `(1)` is therefore

\[
 i_*f=i\circ f\circ(i^{-1})^n.
\]

Transport sends coordinate projections to coordinate projections and respects substitution:

\[
 i_*(f\circ(g_1,\ldots,g_n))
 =(i_*f)\circ(i_*g_1,\ldots,i_*g_n).
\]

It is bijective onto `i_*C`, proving `(2)`. Evaluation of every term commutes with `i`, so term
identities are preserved and reflected. A relation is a congruence before encoding exactly when
its transported relation is a congruence afterward. QED.

## Separating-feature corollary

Let `Phi:X -> product_j Y_j` be any jointly separating family of source features. If every
successor operation is defined by the intertwining law

\[
 \Phi\circ T=\widehat T\circ\Phi,
 \tag{3}
\]

then `Phi` is an injective encoding and every `widehat T` restricted to `Phi(X)` is conjugate to
`T`. Adding more separating coordinates can enrich observation and expose a useful boundary, but
it does not change the algebraic theory of the source action.

## Prime crossing-time application

For a bounded valuation vector `x=(x_p)_p`, let

\[
 M=\sup_px_p,
 \qquad \tau_p=M-x_p+1.
\]

The complete crossing-time profile recovers `x`, hence the profile map `Phi:x mapsto (tau_p)_p`
is injective. The reset-and-carry action of prime multiplication is defined precisely by

\[
 \Phi(px)=\widehat M_p(\Phi(x)).
\]

Therefore reset-and-carry is conjugate to the original prime-multiplication action on the profile
image. It is an informationally complete, source-natural coordinate law, but not a new operation
type generated by failure.

This does not diminish the shell theorem's valid content: first failure times reconstruct prime
factorization and expose boundary cells. It corrects only the stronger claim that the transported
action already proves event-driven law creation.
