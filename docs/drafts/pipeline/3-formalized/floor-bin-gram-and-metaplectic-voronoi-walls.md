## Proof

### 1. Floor-bin bilinear signed Gram identity and phase-blind obstructions
Let `B₀` and `M` be finite sets, `α : B₀ → ℂ`, `b : M → ℂ`, and `Φ : B₀ → M → ℂ`. Interchanging summation in `S(α, b) = ∑_{u ∈ B₀} α_u ∑_{m ∈ M} b_m Φ(u, m) = ∑_{m ∈ M} b_m (∑_{u ∈ B₀} α_u Φ(u, m))` and applying Cauchy–Schwarz on `M` yields
`‖S(α, b)‖² ≤ (∑_{m ∈ M} ‖b_m‖²) (∑_{m ∈ M} ‖∑_{u ∈ B₀} α_u Φ(u, m)‖²)`.
Expanding `‖∑_{u ∈ B₀} α_u Φ(u, m)‖² = ∑_{u₁, u₂ ∈ B₀} α_{u₁} conj(α_{u₂}) Φ(u₁, m) conj(Φ(u₂, m))`, interchanging with `∑_{m ∈ M}`, and splitting `u₁ = u₂` from `u₂ ∈ B₀ \ {u₁}` with `G_M(u₁, u₂) := ∑_{m ∈ M} Φ(u₁, m) conj(Φ(u₂, m))` gives
`∑_{m ∈ M} ‖∑_{u ∈ B₀} α_u Φ(u, m)‖² = ∑_{u ∈ B₀} ‖α_u‖² G_M(u, u) + ∑_{u₁ ∈ B₀} ∑_{u₂ ≠ u₁} α_{u₁} conj(α_{u₂}) G_M(u₁, u₂)`.

1. *Unimodular matched-phase saturation:* If `‖Φ(u, m₀)‖ = 1` for all `u ∈ B₀` at some `m₀ ∈ M` and `A₀ ≥ 0`, setting `α_u := A₀ conj(Φ(u, m₀))` gives `‖α_u‖ = A₀` and `∑_{u ∈ B₀} α_u Φ(u, m₀) = |B₀| A₀`, so `∑_{m ∈ M} ‖∑_{u ∈ B₀} α_u Φ(u, m)‖² ≥ |B₀|² A₀²`.
2. *Character-group Parseval enlargement:* For `B₀ ⊆ AddChar G ℂ` on a finite additive abelian group `G`, dual character orthogonality `∑_{ψ ∈ AddChar G ℂ} ψ(x) conj(ψ(y)) = |G| δ_{x, y}` and nonnegativity outside `B₀` give `∑_{ψ ∈ B₀} ‖∑_{x ∈ G} b_x ψ(x)‖² ≤ |G| ∑_{x ∈ G} ‖b_x‖²`, so Cauchy–Schwarz on `B₀` bounds `‖S(α, b)‖² ≤ |B₀| |G| A₀² ∑_x ‖b_x‖²`, recovering `R₀ = 1` when `|B₀| ≍ |G|`.
3. *Truncated-approximant completion convexity:* For `α₁ ∈ [0, 1]` and `ρ ∈ ℝ`, `E_rem = E_tri − α₁(ρ − 1)` and `E_complete = E_tri + (lx + ly − ℓ) + (1 − α₁)(ρ − 1)` satisfy `(1 − α₁) E_rem + α₁ E_complete = E_tri + α₁(lx + ly − ℓ)`, whence `max(E_rem, E_complete) ≥ E_tri + α₁(lx + ly − ℓ) ≥ E_tri` whenever `ℓ ≤ lx + ly`.
