# The forward monodromy group of the heat cover; conjugation of the zeros is a monodromy

- **Stage:** 3-formalized
- **Type:** THEOREM (Lean)
- **Question:** review-1211 §2.19 Q5 (the group generated by the monodromy and its relation to
  conjugation); criterion T3g (the classes of `c` and `r`).

`H_τ(z)` the heat family, `ρ = 1/2 + iz`. On the place `z`: `r : z ↦ −z`, `cr : z ↦ z̄`.
A *forward path* is a continuous `γ : [0,1] → {Re τ > 0}` that avoids the branch times.
`T_γ(z₀) = z₁` (*transport*): a continuous family of zeros over `γ` runs from `z₀` to `z₁`.

## Theorems

1. (Algebra of transports.) Along a forward path `T_γ` is a bijection from the zeros of
   `H_{γ(0)}` to the zeros of `H_{γ(1)}`. `T_{γ₁γ₂} = T_{γ₂} ∘ T_{γ₁}`, `T_{γ⁻¹} = T_γ⁻¹`,
   `T_const = id`, `T_γ(−z) = −T_γ(z)`, `T_{γ̄}(z̄) = conj T_γ(z)`.
2. (Group.) For a forward time `τ` off the branch times, the transports along the forward
   loops based at `τ` form a subgroup `G₊(τ)` of the permutations of the zeros of `H_τ`.
   Every element commutes with `r`.
3. (Conjugation is a transport.) Let `t, t'` be real, `γ` a forward path from `t` to `t'`, and
   all zeros of `H_{t'}` real. Then `T_{γ · γ̄⁻¹}(z₀) = z̄₀` for every zero `z₀` of `H_t`.
4. (Paths.) Two forward times off the branch times are joined by a forward path.
5. (Conjugation in the group.) For real `t > 0` off the branch times, `cr ∈ G₊(t)`.
6. (RH.) RH ⇔ `cr = 1` on the fibre over every real `t > 0` off the branch times.
7. (Base time.) If `δ` is a forward path from `τ` to `τ'` then `σ ↦ T_δ σ T_δ⁻¹` maps `G₊(τ)`
   onto `G₊(τ')`. Hence `G₊(τ) ≅ G₊(τ')` for all forward `τ, τ'` off the branch times.
8. (Hermite reflection as a transport.) Let `(τ₀, z₀)` be a collision of order `m`,
   `Re τ₀ > 0`, with sheets `Z_ρ(s)`, `ρ` a root of the profile. For small `r > 0` the circle
   `τ₀ + r²e^{2πis}` is a forward path and transports `Z_ρ(r)` to `Z_{−ρ}(r)`. Twice the circle
   transports `Z_ρ(r)` to itself.
9. (Branch points act.) Let `z₀` be a multiple zero of `H_{τ₀}`, `Re τ₀ > 0`. For every base
   time `τ` there are `σ ∈ G₊(τ)` and a zero `p` of `H_τ` with `σp ≠ p`; `σp = −p` if `z₀ = 0`,
   and `σp ≠ −p` if `z₀ ≠ 0`.
10. (Sign change.) For every base time, `G₊(τ)` contains an element which exchanges a zero
    `z ≠ 0` with `−z`. `G₊(τ) ≠ 1`.
11. (RH.) If every element of `G₊(τ)` maps every zero `z` into `{z, −z}`, then RH holds.

## Proof

1. Existence of lifts and bijectivity: forward tameness. Composition: concatenate the lifts.
   Symmetries: `H_τ(−z) = H_τ(z)`, `conj H_τ(z) = H_{τ̄}(z̄)`, and the branch times are stable
   under conjugation. The end is determined by the start (uniqueness of lifts).
2. Closed under products (concatenation), inverses (reversal), and contains the identity
   (constant loop). `T_γ(−z) = −T_γ(z)` and uniqueness give `σr = rσ`.
3. `T_γ(z₀) = z₁` is a zero of `H_{t'}`, so `z̄₁ = z₁`. `T_{γ̄}(z̄₀) = z̄₁ = z₁`, hence
   `T_{γ̄⁻¹}(z₁) = z̄₀`.
4. Arcs `τ + (τ'−τ)(s + iηs(1−s))`, `0 < η ≤ η₀`, lie in a box of forward times and meet
   only at their ends. The box contains finitely many branch times, the ends are not branch
   times, and each branch time lies on at most one arc: some arc avoids all of them.
5. 3 and 4 with `t' = 1/8`, where all zeros are real and simple.
6. ⇒: under RH all zeros of `H_t`, `t > 0`, are real. ⇐: if `Λ > 0`, `[Λ/4, Λ/2]` contains a
   time off the (finitely many) branch times; there `cr = 1` says that all zeros are real,
   so the time is `≥ Λ`.

7. For a loop `β` at `τ`, `δ⁻¹βδ` is a loop at `τ'` with transport `T_δ T_β T_δ⁻¹`. The
   inverse map comes from `δ⁻¹`. A path exists by 4.
8. The branch times are isolated in `Re τ > 0`, so a small circle avoids them. The lift is
   `Z_ρ(re^{πis})`: it is continuous, consists of zeros of `H_{τ₀+r²e^{2πis}}`, starts at
   `Z_ρ(r)` and ends at `Z_ρ(−r) = Z_{−ρ}(r)`.
9. A multiple zero is a collision of order `m ≥ 2`; the profile has `m` distinct real roots,
   so a root `ρ ≠ 0`. `Z_ρ(r) ≠ Z_{−ρ}(r)` for small `r ≠ 0`. At the centre
   `Z_{−ρ} = −Z_ρ`. If `z₀ ≠ 0`, `Z_ρ(r) + Z_{−ρ}(r) → 2z₀ ≠ 0`. Conjugate the circle by a
   forward path `δ` to `τ` (4): the loop `δ⁻¹·circle·δ` gives `σ` with `σ(T_δ z) = T_δ z'`;
   `T_δ` is injective and commutes with `z ↦ −z`.
10. 9 at a centre time: the centre value `H_τ(0)` has zeros, all in `Re τ > 0`.
11. If RH fails there is a multiple zero `z₀` at a real time `t > 0`. `H_t(0) ≠ 0` for real
    `t`, so `z₀ ≠ 0`, and 9 gives `σ, p` with `σp ∉ {p, −p}`.
