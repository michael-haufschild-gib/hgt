## The reframe (the field's nature, made precise)
A **generative founding principle** — a finite rule that propagates the object from initial data — **is**
an algebraic differential equation (or, in the field's idiom, a finite difference / difference-differential
equation). **Hypertranscendence is exactly the absence of such a rule.** Hölder 1887 (Γ satisfies no algebraic
differential equation; the transfer to `ζ/ξ/Λ` via `Λ=Γ·ζ` is the **differential independence `Γ⊥ζ` over
`ℂ(s)`** — Li–Ye import, `../2-fully-proven/gamma-zeta-differential-independence.md`, *not* a one-line
Hölder corollary) is therefore the field's **founding theorem, and it
is negative**: it certifies that **no generative rule exists.**

**Consequence (the field's nature).** A theory of hypertranscendental objects **cannot** be a theory of
generative rules — by definition there are none. It can only be:
- **(O) a theory of obstructions** — *why* no rule exists (hypertranscendence proofs), and
- **(V) a theory of relations among values** — transcendence theory = difference-Galois Siegel–Shidlovsky + DSS.

This **dissolves the "C5 = a generative keystone" framing** the charter/vision implicitly carried: there is
no generative keystone to find; seeking one is self-defeating.

## The structural principle (the genuine new content)
> **Obstruction theorems decompose → BRIDGE; value-relation theorems are irreducible → the native C5 is
> value-relational (DSS).**

**(O) decomposes.** An obstruction theorem says "the object satisfies no equation of **type T**." The types
T partition by **which generator** the rule uses, and each type is a single parent's domain:
- differential (`∂_s`) → differential Galois / **Hölder** (Source A);
- single/finite difference (`σ_∞`, one shift) → van der Put–Singer / Adamczewski–Faverjon (single-q);
- difference-differential (`σ,∂` finite) → Hardouin–Singer / ADH.
A *joint* obstruction ("no equation of any combined type") **decomposes** into the per-type obstructions when
the types are independent — which the field's own results show they are:
- **§59/G1** (no finite q-difference eqn): decouples to the single shift `s↦s+1` ⟹ **BRIDGE**.
- **#134** (no `(σ_p,∂_s)`-equation, the weld): reduces (R1 collapse + Kolchin) to `Γ_ℝ⊥ζ over ℂ(s)`, the
  classical two-function statement (Li–Ye import) ⟹ **BRIDGE**.
- **#132** (FE-symmetry obstruction): the defect `[χ]` is purely archimedean (Source A) ⟹ **BRIDGE**.
- **#133** (the generators `σ_p,∂_s` are Fourier-diagonal): no combination modes at the generator level ⟹
  the whole connection/obstruction layer is **BRIDGE**.
Every obstruction theorem tested came back BRIDGE, for one structural reason: **the obstruction splits by
generator-type, and each type is a parent.** (The "necessarily" is a strong principle, not a formal theorem —
a single non-decomposing obstruction would be a counterexample; none has appeared.)

**(V) is irreducible.** A value-relation theorem — DSS: *the values `{γ_n}` (equivalently `{π}∪{ζ(odd)}∪{γ_n}`,
#72) are ℚ-algebraically independent* — is a **single joint statement about all values at once**; it does
**not** split by generator-type. No single parent yields it: differential SS needs a differential equation
(none — hypertranscendental); single-q SS (Adamczewski–Faverjon) needs a single-q equation (none — G1, infinite
base). The independence is irreducibly joint. **This is where the native C5 lives.**

  structurally BRIDGE and should be banked/grade as such, not chased as C5.
