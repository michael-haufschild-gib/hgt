## 1. Frontier problem

The existing profile theorem classifies a finite simultaneous family by the linear span of its
valuation profiles.  The fusion theorem shows that one neutral source forces infinitely many new
HT layers.  Neither result classifies **all fields stable under repeated fusion**, identifies the
canonical invariant of such a field, or determines the asymptotic law of the differential rank
created along the valuation axis.

The proposed answer is not another independence criterion.  It is an exact algebraization of the
entire fusion-complete radial sector, followed by a conductor theorem for its Kolchin growth.

## 2. Profile algebra and arithmetic realization

Let

```text
P = t C[[t]]
```

and identify `u in P` with its arbitrary valuation profile

```text
u = sum_(e>=0) u_e t^(e+1).
```

Define the prime-radial source `S(u)` by

```text
S(u)(p^(e+1)) = u_e,
S(u)(n) = 0 away from positive prime powers.                 (1)
```

For `u,v in P`, define their same-prime fusion coefficientwise.  At any fixed output valuation
only finitely many input pairs contribute, so no analytic convergence or infinite summation is
involved.  The already-defined pure-layer fusion then gives

```text
S(u) boxdot S(v) = S(uv).                                   (2)
```

Thus multiplication in `P` is represented literally by prime-valuation fusion.

For a complex subspace `W <= P`, let

```text
K(W) = C<S(u) : u in W>_diff                                (3)
```

inside the arithmetic-function fraction field.  Fusion closure means that whenever `u,v in W`,
the exact fused carrier `S(uv)` belongs to `K(W)`.

## 3. Master conjecture: exact fusion algebraization

For arbitrary subspaces `U,W <= P` and every `u in P`,

```text
S(u) in K(W)       iff u in W,                              (4)
K(U) <= K(W)       iff U <= W,                              (5)
K(U) = K(W)        iff U = W.                               (6)
```

The map `W |-> K(W)` preserves arbitrary joins and every nonempty meet.  Consequently it is a
complete lattice embedding into the interval below the full radial-profile field.

This is the classification statement.  Differential-field generation, equality, intersection,

## 4. The conductor and quantized-capacity law

Let `0 != W <= P` be fusion closed.  Define its order spectrum

```text
Gamma(W) = {ord_t f : 0 != f in W} subset N_(>0).           (9)
```

Because `ord_t(fg)=ord_t f+ord_t g`, `Gamma(W)` is an additive semigroup.  Put

```text
d(W) = gcd Gamma(W).                                       (10)
```

Then there is a conductor `c(W)` such that

```text
n >= c(W) and d(W) divides n  =>  n in Gamma(W),            (11)
```

and no order outside `d(W)N` occurs.  Equivalently, the order spectrum is eventually the exact
arithmetic progression `d(W)N`.

Let

```text
W_>=N+1 = W intersect t^(N+1) C[[t]],
h_W(N) = dim_C (W / W_>=N+1).                              (12)
```

The initial-coefficient map on the valuation filtration shows, at every `N`,

```text
h_W(N)-h_W(N-1) = 1 if N in Gamma(W), and 0 otherwise.      (13)
```

Hence

```text
h_W(N) = # (Gamma(W) intersect [1,N]),                      (14)
```

and for every sufficiently large `N`,

```text
h_W(N+d(W))-h_W(N)=1.                                      (15)
```

In particular,

```text
lim_(N->infinity) h_W(N)/N = 1/d(W).                        (16)
```

The asymptotic fusion capacity is therefore quantized by one positive integer.  It cannot be an
irrational density or an irregular nonconvergent density.

## 5. Exact two-cutoff Kolchin law

Choose lifts `b_1,...,b_h` of a basis of `W/W_>=N+1`, and let `r` be a jet cutoff.  The relative
prime-clock correspondence makes their carriers jointly differentially independent over the tail
field `K(W_>=N+1)`.  Therefore the complete finite jet rectangle

```text
{D^k S(b_i) : 1 <= i <= h_W(N), 0 <= k <= r}
```

is algebraically independent over that canonical tail field, and its exact transcendence rank is

```text
H_W(N,r) = (r+1) h_W(N)
         = (r+1) # (Gamma(W) intersect [1,N]).              (17)
```

Combining `(15)` and `(17)` gives the **fusion--Kolchin conductor law**:

```text
H_W(N+d(W),r)-H_W(N,r)=r+1                                 (18)
```

for every jet cutoff `r` and all sufficiently large `N`.  Thus one new infinite-lifetime HT
channel crosses every eventual valuation period, and it contributes exactly one new algebraically
independent coordinate at each observed derivative order.

The bivariate normalized law is

```text
lim_(N->infinity) H_W(N,r)/((r+1)N) = 1/d(W).               (19)
```

This is not an analogy with a Hilbert function: `H_W` is the actual relative algebraic
transcendence rank of actual prime-supported differential jets over the exact high-valuation
carrier field.

Equivalently, if `m` is the least positive element of the normalized order semigroup and
`Ap(Gamma,m)` is its Apéry set, then the complete bivariate rank series is rational:

```text
sum_(N,r>=0) H_W(N,r) X^N Y^r
  = (sum_(a in Ap(Gamma,m)) X^a)
      / ((1-X)(1-X^m)(1-Y)^2).                             (20)
```

The numerator is finite and records every exceptional valuation gap.  The two denominator
directions have different meanings: `1-X^m` is forced by fusion and the conductor, whereas
`(1-Y)^2` is forced by the free differential-jet clock.

## 6. Completeness and realization

Every additive subsemigroup `Gamma <= N_(>0)` whose gcd is `d` and which is cofinite in `dN`
occurs.  Take the monomial subalgebra

```text
W_Gamma = span_C {t^n : n in Gamma} <= t C[[t]].            (21)
```

Its nonzero order spectrum is exactly `Gamma`, so the corresponding actual carrier field has
the rank surface `(17)`.  In particular every numerical-semigroup gap pattern, conductor, genus,
and multiplicity is realized by an unconditional prime-supported HT fusion sector.

For the source `t` itself, `Gamma=N_(>0)`, `d=1`, and

```text
H(N,r)=N(r+1).                                              (22)
```

This is the maximal free area law and recovers the neutral-source creation tower as the universal
period-one phase.

More strongly, a function `H : N x N -> N` is the two-cutoff relative Kolchin-rank law of a

```text
H(N,r) = (r+1) # (Gamma intersect [1,N]).                   (23)
```

This inverse clause is the anti-theatre core: the theorem classifies all possible rank surfaces,
not merely the asymptotics of a preselected example.
