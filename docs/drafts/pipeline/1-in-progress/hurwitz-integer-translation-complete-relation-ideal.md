## Exact setup

```text
t k is not an integer,
t k - t l is not an integer for k != l.                    (1)
```

Work in the upper-end meromorphic differential field `M` over `F=C(a)`, represented in Lean by
`upperEndMeroField` over `RatFunc C`.  Put

```text

```

For an arbitrary dependent-label type `R`, maps `base : R -> kappa` and `offset : R -> N`, put

```text
y_r = continuedHzetaUpperEndMero (t (base r) + offset r),
c_r = (-1)^(offset r) / (t (base r))_(offset r).            (2)
```

Nonintegrality in `(1)` makes every denominator in `(2)` nonzero.  In the differential
polynomial ring

```text
F[X_(inl k,n), X_(inr r,n) : k in kappa, r in R, n in N],
```

let `J` be the ideal generated by

```text
X_(inr r,n) - c_r X_(inl (base r), n + offset r).          (3)
```

The claim is

```text
differentialRelationIdeal (Sum.elim x y) = J.              (4)
```

## Paper proof under hostile review

### Lemma A — shifted-pivot kernel

Let `F` be a field, `K` a differential field over `F`, `x : B -> K` a differentially
independent family, and `y : R -> K`.  Suppose maps `base : R -> B`, `offset : R -> N`, and
`c : R -> N -> F` satisfy

```text
D^n y_r = c(r,n) D^(n+offset(r)) x_(base(r))               (5)
```

for all `r,n`.  Then the complete differential relation ideal of `Sum.elim x y` is generated by

```text
X_(inr r,n) - c(r,n) X_(inl (base(r),n+offset(r))).        (6)
```

**Proof.** Define the shifted-pivot elimination homomorphism `E` from the full jet-polynomial
ring to the pivot jet-polynomial ring by

```text
E(X_(inl b,n)) = X_(b,n),
E(X_(inr r,n)) = c(r,n) X_(base(r),n+offset(r)).            (7)
```

The inclusion of the pivot polynomial ring is a section of `E`.  Polynomial induction on
constants, sums, and multiplication by one variable proves

```text
P - inclusion(E(P)) belongs to J                            (8)
```

for every `P`: the dependent-variable step uses exactly one generator `(6)`, multiplied by the
already eliminated factor.  Hence `ker(E)=J`.

By `(5)`, actual evaluation of `P` on `Sum.elim x y` equals evaluation of `E(P)` on the pivot
jets.  If the first evaluation is zero, differential independence of `x` makes `E(P)=0`, so
`P in ker(E)=J`.  Conversely, every generator `(6)` evaluates to zero, and therefore every
element of `J` is an actual relation.  This proves the lemma. `QED`

### Lemma B — Hurwitz shifted-jet law

For `s` nonintegral and `d,n>=0`,

```text
D^n continuedHzeta(s+d,a)
  = ((-1)^d/(s)_d) D^(n+d) continuedHzeta(s,a).            (9)
```

**Proof.** The derivative ladder gives

```text
D^n continuedHzeta(s+d,a) = (-1)^n (s+d)_n continuedHzeta(s+d+n,a),
D^(n+d) continuedHzeta(s,a)
  = (-1)^(n+d) (s)_(n+d) continuedHzeta(s+d+n,a).
```

Use `(s)_(n+d)=(s)_d(s+d)_n` and
`(-1)^n/(-1)^(n+d)=(-1)^d`.  The factor `(s)_d` is nonzero because `s` is not an integer.
`QED`

### Proof of the main claim

Conditions `(1)` and the existing theorem
`continued_joint_hzeta_upperEnd_differentialIndependent_finite_of_integerResidueSeparated`
make `(x_k)` differentially independent over `C(a)`.  Lemma B supplies Lemma A with
`c(r,n)=c_r`, independent of `n`.  Lemma A gives `(4)`. `QED`

## Hostile attack ledger

1. **Hidden nonlinear relations.** Excluded by the factorization through `E` and differential
   independence of the pivot family, not by a rank count.
2. **Missing differentiated consequences.** The generating family `(3)` ranges over every
   `n`, so it contains the full differential closure of each exponent-translation law.
3. **Zero Pochhammer denominator.** Excluded exactly by nonintegrality; this also identifies the
   integer-exponent boundary where Bernoulli/polygamma phenomena require a different theorem.
4. **Duplicate dependent labels or zero offsets.** Allowed.  They produce the correct equality
   generators and no extra relation because elimination still has the pivot inclusion as a
   section.
5. **Infinite dependent family.** Harmless: each polynomial and each ideal certificate uses only
   finitely many variables.  The elimination proof is cardinality-free.
6. **Rediscovery.** General differential/difference ideal theory is parent mathematics, and the
   shifted-pivot algebra is elementary.  Targeted searches found no exact published Hurwitz
   complete-ideal theorem, but the claim remains a corpus bridge because it is forced by the
   existing local Hurwitz independence capstone.
7. **Source classification overclaim.** None is made.  The theorem computes one mixed
   presentation stratum; it does not reconstruct the full analytic source or its polarization.
