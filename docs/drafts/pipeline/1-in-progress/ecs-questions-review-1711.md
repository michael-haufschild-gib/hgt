### 1. Individual Profile Solution of E-Q1 (`hasBeyondTheWallPrimeContinuation_iff_vanish_leftZeros`)

Let $F \in \mathcal{H}$ (`CriticalHalfLineEnergyDomain F`).
1. **Necessity ($\Rightarrow$):** If $\Phi_F$ extends holomorphically from $\operatorname{Re} p < -1/2$ to $\operatorname{Re} p < 0$, then for every `q : XiZeroCopy` with $\operatorname{Re}(\text{centredZero } q) < 0$, `not_wallPrimeBalance_continues_of_seen_zero` (at $\delta = 0 \le 5/2$) forces $\mathcal{L}F(\text{centredZero } q) = 0$.
2. **Sufficiency ($\Leftarrow$):** Suppose $\mathcal{L}F(\text{centredZero } q) = 0$ whenever $\operatorname{Re}(\text{centredZero } q) < 0$. Let $f(p) = \xi(1/2 + p)$ and $g(p) = \text{clearedRemainder } F\, p$. Both $f$ and $g$ are entire, and $\operatorname{ord}_{p_0}(f) < \infty$ at every $p_0 \in \mathbb{C}$. Define
   $$Q(p) := \begin{cases} g(p)/f(p), & f(p) \neq 0, \\ \lim_{w \to p,\, w \neq p} g(w)/f(w), & f(p) = 0. \end{cases}$$
   At any $p_0$ with $\operatorname{Re} p_0 < 0$:
   - If $f(p_0) \neq 0$, then $f \neq 0$ near $p_0$, so $Q = g/f$ near $p_0$ and $Q$ is holomorphic at $p_0$.
   - If $f(p_0) = 0$, then $1/2 + p_0$ is a zero of $\xi$ with $\operatorname{Re}(1/2 + p_0) < 1/2$, hence $p_0 = \text{centredZero } q$ for some copy $q$ with $\operatorname{Re}(\text{centredZero } q) < 0$, so $\mathcal{L}F(p_0) = 0$. By `le_analyticOrderAt_clearedRemainder_of_laplace_eq_zero`, $m := \operatorname{ord}_{p_0}(f) \le \operatorname{ord}_{p_0}(g)$. Locally $f(w) = (w - p_0)^m f_1(w)$ with $f_1$ analytic and $f_1(p_0) \neq 0$, and $g(w) = (w - p_0)^m g_1(w)$ with $g_1$ analytic. On a punctured neighbourhood $U \setminus \{p_0\}$ where $f_1 \neq 0$, we have $f(w) \neq 0$ and $Q(w) = g(w)/f(w) = g_1(w)/f_1(w)$. Passing to the punctured limit gives $Q(p_0) = g_1(p_0)/f_1(p_0)$, so $Q \equiv g_1/f_1$ on $U$, which is holomorphic at $p_0$.
   On $\operatorname{Re} p < -1/2$, $f(p) \neq 0$, so $Q(p) = \text{globalRemainder } F\, p = J_{\ge 1}F(p) + \Phi_F(p)$. Since $J_{\ge 1}F$ (`archimedeanWallTail F`) is holomorphic on $\operatorname{Re} p < 5/2$, $H(p) := Q(p) - J_{\ge 1}F(p)$ is holomorphic on $\operatorname{Re} p < 0$ and equals $\Phi_F(p)$ on $\operatorname{Re} p < -1/2$.

### 3. Single-Quartet Secular Determinant, Two-Rung Rigidity, Wall Laws, and Chebyshev Equivalence
