# PTR finite-multimode distributional regularity

- **Stage:** conjecture; not a proved no-go.
- **Proof chain:** rotating-cylinder Maxwell source → infinite `(grade, spatial mode)` boundary map → prime conormal eigen-distribution → independent confinement → RH.
- **Hard obstacle attacked:** whether the exact conormal can be a singular Floquet trace when spatial profiles vary with grade, beyond the existing fixed-profile and finite-energy no-gos.
- **Corpus basis:** `PhotonicMultimodeGeometricFloquetRigidity` defines the three-operator modal recurrence but treats only separable profiles; `PhotonicConormalFiniteEnergyNoGo` excludes `ℓ²` output at every spectral parameter; `DeningerSmoothPeriodic.coeff_decay` supplies all-order decay for smooth periodic traces. The physical source [Mai--Yang--Wang, arXiv:2609.08748v1](https://arxiv.org/html/2609.08748v1), Eqs. (1)--(7), gives smooth travelling-wave dielectric, spatial overlaps and a finite displayed truncation, not an infinite trace theorem.
- **Frozen conjecture:** for any finite-dimensional spatial Galerkin space and nonzero drive, if its dielectric matrix is smoothly invertible at every time, every polynomial-growth bilateral Floquet solution of the exact Maxwell modal recurrence has rapidly decaying sideband coefficients. Hence no bounded finite-modal port of such a solution equals the nonzero prime conormal family on the critical line. This leaves an infinite-spatial-mode, singular-trace carrier; it does not kill full PTR.
- **Mechanism to test, not a proof:** polynomial-growth coefficients define a periodic distribution; the recurrence becomes a finite-dimensional second-order ODE with invertible smooth leading matrix. Distributional ODE regularity would make the solution smooth, contradicting nondecaying conormal coefficients. Verify recurrence order and interface trace before formalization; a counterexample with invertible dielectric would falsify the conjecture.
- **Qualifying result sought:** Lean-closed source-faithful finite-modal no-go with exact positive survivor (necessary unbounded spatial spectral escape), not another fixed-profile estimate.
