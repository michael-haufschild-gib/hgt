## 1. Exact abstract selector

### Theorem A: scalar maximality is boundary unitarity

`[PARENT THEOREM; DIRECT PROOF INCLUDED]`

\[
 \mathrm{ev}_z\text{ is maximal}
 \quad\Longleftrightarrow\quad
 |z_p|=1\text{ for every }p\in P.                         \tag{1}
\]

If \(|z_p|<1\), the one-coordinate contraction has a nontrivial unitary dilation.  Tensoring it
with the unchanged remaining coordinates gives a nontrivial dilation of \(\mathrm{ev}_z\), so the
representation is not maximal.

Conversely, suppose every \(z_p\) is unitary and a contraction \(T_p\) on
\(\mathbb C\oplus K\) dilates the scalar \(z_p\).  In block form,
\[
 T_p=
 \begin{pmatrix}
 z_p&a_p\\ b_p&C_p
 \end{pmatrix}.
\]
Contractivity applied to the distinguished unit vector and to the adjoint gives
\[
 1\geq |z_p|^2+\|b_p\|^2,\qquad
 1\geq |z_p|^2+\|a_p\|^2.
\]
Thus \(a_p=b_p=0\).  The scalar summand reduces every generator, so every dilation is trivial.
This proves `(1)`.

The coordinate defect
\[

maximality.
