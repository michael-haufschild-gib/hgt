## Goal

Remove the common compact sampler and continuous-observable model from the analytic Grassmann
theorem.  The intrinsic source of a bounded prime coefficient stream is its class in

`Q = (Primes → ℂ) / {finite-support streams}`.

Changing finitely many coefficients changes the analytic carrier by a finite sum of single-prime
exponentials.  After adjoining those exponentials to the base, the carrier depends only on its
class in `Q`.  The conjecture asserts that this quotient is not merely respected but recovered
exactly from the generated differential field.

## Exact conjecture

Fix a shift `a`.  Let `B_E(a)` be the differential subfield of the upper-end meromorphic field
generated over the embedded coordinate field `ℂ(s)` by the single-prime carriers at shift `a`.
For every bounded coefficient stream `c : Primes → ℂ`, let `D_a(c)` be its prime-supported
analytic Dirichlet carrier.

1. `D_a(c)` modulo `B_E(a)` depends only on the cofinite-tail class `[c] ∈ Q`.
2. For every family `c_i`, the carriers `D_a(c_i)` are differentially independent over `B_E(a)`
   iff the classes `[c_i]` are linearly independent in `Q`.
3. For source subspaces `U,W ≤ Q`, the generated fields satisfy
   `Φ_E(U) ≤ Φ_E(W) ↔ U ≤ W`, hence equality of fields iff equality of tail subspaces.
4. For arbitrary additional source vectors, the complete differential-relation ideal is generated
   by their prolonged tail-linear coordinate relations, with the finite-support residual of each
   relation appearing as a coefficient in `B_E(a)`.
5. The resulting Grassmann-field map has the same split all-jet decoder and maximal representable
   core as the common-sampler theorem.

## Positive law

Every bounded prime-supported HT field over the Euler exponential base must carry a unique
cofinite-tail source subspace, and every genuinely new relative HT direction must be a new class in
that quotient.

## Open core

Prove the analytic tail-independence equivalence in item 2.  A putative algebraic relation uses
only finitely many base generators.  Tail independence supplies a full-rank prime packet outside
that finite activity set.  The required bridge must combine analytic Dirichlet uniqueness with the
finite-prime Jacobian argument without importing the nonconvergent formal coefficient field into
the meromorphic field.

## RH pressure test

The theorem would classify arbitrary bounded prime-supported sources, not only sources sampled
from a common compact geometry.  Therefore every Euler-product route whose operations remain in
one valuation layer would have to expose a new cofinite-tail source class.  The zeta logarithm's
prime-power dilations live in different valuation layers, so they remain outside this no-hidden-
source conclusion and become the precise next structure to classify.
