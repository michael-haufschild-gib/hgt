# Remove raised elaboration budgets from the discharge dependencies

- **ID:** heartbeat-budget-removal-20261023
- **Stage:** 1-in-progress
- **Type:** THEOREM (Lean)
- **Statement:** Every module in the import closure of the premise-discharge modules elaborates
  at the default `maxHeartbeats`/`maxRecDepth`/`synthInstance` budgets.

## Goal
No `set_option maxHeartbeats|maxRecDepth|synthInstance.maxHeartbeats|synthInstance.maxSize` in the
closure. A proof that needs a raised budget is rewritten: explicit `nlinarith` products,
`simp only`, small named lemmas, reusable rewrites.

## Method
One file at a time, nearest dependencies first: read the declarations under the option and fix
the visible causes (implicit functions in reindexing lemmas over the copy equivalences,
`let`/`change` in long proofs, unguided `nlinarith`, large unfold lists), delete the option, then
check once with `lake --old env lean <file>`. Statements are unchanged, so dependents' oleans stay
valid.
