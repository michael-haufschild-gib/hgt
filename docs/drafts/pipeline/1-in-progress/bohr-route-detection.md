## Setup (exact objects)
- `lam ∈ W` (full cone).
- `G = 1/F_lam = c(s−1)e^P` on `Re s > ½`, with `P' = A − Φ_lam` (`exists_reciprocalZeta_primitive`).
- **Zeta quotient** `B := ζ·G`:
  - holomorphic on `Re s > ½`; `B = exp(−Σ(lam−Λ)(n)n^{−s}/log n) = Σ(1⋆μ_lam)(n)n^{−s}` on `Re s > 1`;
  - **its zeros in `Re s > ½` are exactly the zeros of ζ there**;
  - `B'/B = ξ'/ξ − Φ_lam`, so `Re B'/B ≤ Re ξ'/ξ`.
- **Bohr mechanism (L283):** a Dirichlet series bounded on a half-plane is almost periodic there.
  - An almost-periodic holomorphic function's zeros recur along relatively dense almost periods, giving `≫ T` zeros.
  - ζ has `o(T)` zeros right of any fixed line (`eventually_zeroCount_fixedSigma_le`).
  - So `B` bounded on `Re s > x` ⇒ ζ is zero-free on `Re s > x`.
- **Wall:** positivity bounds `|B|` from below relative to `ξ` (`log|B(σ)| ≥ log|ξ(σ)/ξ(2)| − C`), never from above. Upper control of `|B|` needs `μ_lam` to track ζ's zeros (uniqueness-strength).

## Milestones
1. **[Lean, in progress] Bohr's theorem, almost-periodicity form.**
   - A holomorphic function bounded on `Re s > x` and almost periodic on one line `Re s = u` is almost periodic on every closed strip in `(x, u]`. Proof: Hadamard three lines applied to `F(·+iτ) − F`.
   - Not in mathlib or the corpus; `DirichletBddHolo` has only the easy half.
2. **[Lean] Zero recurrence:** a holomorphic strip-almost-periodic function with a zero has a zero in `D(ρ₀+iτ, r)` for relatively dense `τ`. Proof: maximum modulus for `1/F(·+iτ)`.
3. **[Lean] Bohr zero-set principle:** a Dirichlet series bounded on `Re s > x > ½` whose zeros there are zeros of ζ has no zeros there.
4. **[Lean] Producer detection boundary:** `Θ ≤ max(½, σ_b(ζ/F_lam))` for every `lam ∈ W`. Hence RH ⟺ some producer has `σ_b(ζ/F_lam) ≤ ½`.
5. **Open core:** an upper bound for `|ζ/F_lam|` from positivity plus the Dirichlet structure. Candidates are tested in the loop below.
