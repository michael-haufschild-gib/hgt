# Absolute geometry of Spec ℤ: the arithmetic square, carries, and the surface

- **ID:** agz-absolute-geometry-of-spec-z
- **Stage:** 1-in-progress
- **Type:** THEOREM (paper) → Lean
- **Source:** `docs/reports/review-0911/fable.md` §9

- **Statement:** In Λ-geometry `Spec ℤ ×_{𝔽₁} Spec ℤ = Spec W(ℤ)` exists, is the union of the
  Frobenius graphs, and carries the prime part of Weil's off-diagonal exactly; neither Weil's nor
  Stepanov's argument runs on it, for reasons that are theorems.

## Notation

`𝒢` = integer sequences `(x_n)_{n≥1}` with `p^{v_p(n)+1} ∣ x_{pn} − x_n` for all primes `p`, `n ≥ 1`.
`(F_k x)_n = x_{kn}`. `(V_k x)_n = k x_{n/k}` if `k ∣ n`, else `0`. `e_d = V_d 1`. `w_n(x) = x_n`.
`J(m,n)` = ideal of `ℤ` generated by `{x_m − x_n : x ∈ 𝒢}`. `[a]_n = aⁿ`.

## Theorems

**A1 (ring).** `𝒢` is a subring of `ℤ^{ℕ₊}`; `F_k` is a ring endomorphism of `𝒢`, `V_k` an additive
endomorphism; `F_kF_l = F_{kl}`, `V_kV_l = V_{kl}`, `F_kV_k = k`,
`F_nV_m = g V_{m/g}F_{n/g}` (`g = gcd(m,n)`), `V_k(x)·y = V_k(x·F_k y)`.
*Proof.* Congruences are preserved by sums and by `xy − x'y' = x(y−y') + y'(x−x')`. For `F_k`:
`v_p(kn) ≥ v_p(n)`. For `V_k`: if `k ∣ n` the difference is `k(x_{pn/k} − x_{n/k})` and
`v_p(k) + v_p(n/k) + 1 = v_p(n) + 1`; if `k ∤ n`, `k ∣ pn` then `v_p(k) = v_p(n) + 1` and the term
`k x_{pn/k}` is divisible by `p^{v_p(n)+1}`; if `k ∤ pn` both terms vanish. The identities are
checked on components. ∎

**A2 (necklace decomposition).** `x ∈ 𝒢` iff there are integers `b_d` with
`x_n = Σ_{d∣n} d b_d` for all `n`; the `b_d` are unique. `e_de_{d'} = gcd(d,d') e_{lcm(d,d')}`.
*Proof.* (⇐) `x_{pn} − x_n = Σ_{d ∣ pn, d ∤ n} d b_d`, and such `d` have `v_p(d) = v_p(n)+1`.
(⇒) Define `b_n` by strong induction. With `y = x − Σ_{d∣n, d<n} b_d e_d ∈ 𝒢`, `y_k = 0` for all
proper divisors `k` of `n`; for each prime `p ∣ n`, `p^{v_p(n)} ∣ y_n − y_{n/p} = y_n`; hence
`n ∣ y_n`, and `b_n = y_n/n`. Uniqueness: triangularity. ∎

**A3 (cofreeness).** Let `A` be a commutative ring with ring endomorphisms `ψ_n` (`n ≥ 1`),
`ψ_1 = id`, `ψ_mψ_n = ψ_{mn}`, and `ψ_p(a) − a^p ∈ pA` for all primes `p`. For every ring
homomorphism `f : A → ℤ`, `f̂(a) = (f(ψ_n a))_n` is a ring homomorphism `A → 𝒢` with
`w_1 f̂ = f`, `f̂ψ_k = F_k f̂`, and it is the only one with these two properties.
*Proof.* Fix `p` and write `n = p^r m`, `c = ψ_m a`, `g_r = f ψ_{p^r}`. Claim: `p^{r+1} ∣
g_{r+1}(c) − g_r(c)` for all `c`. `r = 0`: `f(ψ_p c) = f(c)^p + p f(b) ≡ f(c)` (Fermat). Step:
`g_{r+1}(c) = g_r(ψ_p c) = g_r(c)^p + p g_r(b)` and `g_r(c) = g_{r−1}(c)^p + p g_{r−1}(b)`; by
induction `g_r ≡ g_{r−1} (mod p^r)` on all elements, so `g_r(c)^p ≡ g_{r−1}(c)^p (mod p^{r+1})` and
`p g_r(b) ≡ p g_{r−1}(b) (mod p^{r+1})`. Uniqueness: `h(a)_n = (F_n h(a))_1 = h(ψ_n a)_1 =
f(ψ_n a)`. ∎
`𝒢` itself is such a ring: `(x_{pn} − x_n^p)/p` satisfies the congruences (for `q ≠ p` divide by
`p`; for `q = p` use `x_{pn} ≡ x_n (mod p^{v+1}) ⇒ x_{pn}^p ≡ x_n^p (mod p^{v+2})`).

**A4 (graphs meet in the primes).** For `m ≠ n`,
`J(m,n) = (gcd{d : d divides exactly one of m, n})`. Explicitly: if `n = m p^j`, `j ≥ 1`, `p`
prime, then `J(m,n) = (p^{v_p(m)+1})`; if `m ∣ n` and `n/m` is not a prime power, or neither
divides the other, `J(m,n) = (1)`. In particular `#(ℤ/J(1,n)) = e^{Λ(n)}` for `n ≥ 2`.
*Proof.* `e_d` gives `d ∈ J` for `d` dividing exactly one. Conversely `x_m − x_n =
Σ_{d∣m, d∤n} d b_d − Σ_{d∣n, d∤m} d b_d` by A2. The gcd: if `n = m p^j`, the divisors of `n` not
dividing `m` are the `d` with `v_p(d) > v_p(m)`, all multiples of `p^{v_p(m)+1}`, which is one of
them. If two primes `p ≠ q` have `v_p(n) > v_p(m)`, `v_q(n) > v_q(m)` (or one each way), the
divisors `p^{v_p(m)+1}`, `q^{v_q(m)+1}` are coprime. ∎

**A5 (Weil's prime kernel).** For `m ≠ n`, `g = gcd(m,n)`:
`g · log #(ℤ/J(m/g, n/g)) = min(m,n)·Λ(max/min)` if `min ∣ max`, and `0` otherwise. Hence
`SurfaceOfSpecZ.frobeniusIntersection m n = min/(1 − (min/max)²) + g·log #(ℤ/J(m/g, n/g))`.
*Proof.* A4 with coprime arguments, and `frobeniusIntersection_eq`, `orbitIntersection_formula`. ∎

**A6 (constants).** `F_p x = x^p` for all primes `p` iff `x = [x_1]`. `[a] ∈ 𝒢`.
`[a][b] = [ab]`. The necklace coordinates of `[a]` are `M_d(a) = (1/d)Σ_{k∣d} μ(d/k) a^k`; for
`a = q` a prime power, `M_d(q)` is the number of monic irreducible polynomials of degree `d` over
`𝔽_q`.

**A7 (Adams ring).** `T` = subring generated by the `[a]`. The ideal generated by
`{x_n − x_1 : x ∈ T}` is `(gcd_a(aⁿ − a)) = (Π_{p−1 ∣ n−1} p)` for `n ≥ 2`.
*Proof.* `p ∣ aⁿ − a` for all `a` iff `a^{n−1} = 1` on `𝔽_p^×` iff `p − 1 ∣ n − 1` (cyclic);
`p² ∤ pⁿ − p`. ∎

**A8 (δ).** `δ_p x = (F_p x − x^p)/p ∈ 𝒢`. `δ_p(x+y) = δ_p x + δ_p y + C_p(x,y)`,
`pC_p(x,y) = x^p + y^p − (x+y)^p`. `δ_p(xy) = x^pδ_p y + y^pδ_p x + pδ_p xδ_p y`. On `ℤ`
(`δ_p a = (a − a^p)/p`): `v_p(δ_p a) = v_p(a) − 1` for `p ∣ a ≠ 0`.

**A9 (cost).** If `A` has Frobenius lifts, `f : A → ℤ`, `S` a finite set of primes, `a ∈ A` with
`f(a) ≠ 0` and `p^m ∣ f(a)` for `p ∈ S`, then `m·θ(S) ≤ log |f(a)|`, with equality iff
`f(a) = ±Π_{p∈S} p^m`. For `n ≥ 2` the fixed scheme of `ψ_n` on `f` contains `V(e^{Λ(n)})`.

**A10 (the restriction to the Frobenius graph).** `x_p = x_1^p + p(δ_p x)_1`. If `x_1 = 0` then
`(δ_p x)_1 = b_p(x)` and `v_p(x_{p^j}) ≥ m` iff `p^{m−1} ∣ b_p(x)` (`j ≥ 1`, `m ≥ 1`): first order
at every prime is the one condition `x_1 = 0`; the conditions of higher order at different primes
are divisibility conditions on independent coordinates.

**B1 (carry).** `log binom(a+b, a) = Σ_{k≥1} Λ(k)(⌊(a+b)/k⌋ − ⌊a/k⌋ − ⌊b/k⌋)`;
`v_p binom(a+b,a)` = number of carries (Kummer, Mathlib).

**B2 (window).** `Σ_{k≤N} Λ(k)⌊q{N/k}⌋ + Σ_{N<k≤qN} Λ(k)⌊qN/k⌋ = log((qN)!/(N!)^q)`. By the prime
number theorem the first sum is `c_q N + o(N)` with `c_q > 0`: a fixed positive proportion.

**D1 (jets).** `τ = (n^{−2})_n ∈ ℚ^{ℕ₊}`, `𝒜 = ℚ[τ]`. `F_kτ^j = k^{−2j}τ^j`;
`Σ_{j≥0} n^{−2j} = 1 + 1/(n²−1)` for `n ≥ 2`. On a weight line (`F_n = n^z`), `F_nV_n = n` forces
`V_n = n^{1−z}`.

**D2 (gluing).** For `m < n`: `Σ_{j≥0} m^{1+2j}n^{−2j} = m/(1−(m/n)²)`, the trace of
`V_mF_n` on the weights `−2j`. With A5:
`frobeniusIntersection m n = g·log#(ℤ/J(m/g,n/g)) + Σ_j m^{1+2j}n^{−2j}`. For `k ≥ 2`:
`frobeniusIntersection m (mk) = m·N(k)`.

**D3 (support).** Let `R ⊂ ℚ^{ℕ₊}` be a subring containing `e_k`, and `V : R → R` additive with
`V(x·F_k y) = V(x)·y` whenever `x, y, F_k y ∈ R`. Then `(V y)_n = 0` for `k ∤ n`.
*Proof.* `F_k e_k = k`, so `kV(y) = V(y·F_ke_k) = V(y)e_k` and `V(y)(e_k − k) = 0`; `(e_k)_n = 0`
for `k ∤ n`. ∎
Witt's `V_k` on `𝒢` satisfies the projection formula. Hence no Verschiebung with the projection
formula gives a nonzero number at `(2,3)`, where Weil's is `18/5`; and `kF_k^{-1}` on `𝒜` has
`V(1) = k ≠ e_k`.

**E1 (lattice).** The Teichmüller points `[1],…,[K]` are linearly independent over `ℤ`; the lattice
`L(A,K) = {Σ_{k≤K} c_k[k] : |c_k| ≤ A}` has `(2A+1)^K` elements, and `|x_n| ≤ K·A·Kⁿ` on it.

**E2 (forced zeros).** For a commutative ring `R`, ring homomorphisms `r_1, r_n : R → ℤ`,
`I = ker r_1`: `r_n(I^ℓ) = r_n(I)^ℓ`. On `𝒢`: `r_n(I^ℓ) = J(1,n)^ℓ`, and `e_p^ℓ ∈ I^ℓ` has
`n`-th component `p^ℓ` for `n = p^j`.
