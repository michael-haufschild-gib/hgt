# Prop-interface discharge worklist

Generated by the Lean environment audit described on the card
`prop-interface-discharge-audit.md`.  A row is a project `Prop`-valued definition that is
consumed as a hypothesis by at least one theorem in `HTGeometry`, `HilbertMetric`, or
`RHTower` and whose name occurs in the conclusion of **no** theorem anywhere in the corpus —
so nothing in the corpus ever establishes it, not even conditionally.

Both directions of the detector are approximations and each row is verified by hand when it
is worked:
- a hypothesis or conclusion is scanned for every project constant it mentions, at any depth,
  so existential producers (`∃ …, P …`) and `↔`-producers are counted as occurrences;
- an `↔`-characterization counts as an occurrence even though it exhibits no witness, so an
  interface can be absent from this table and still lack a realization
  (`PointFiniteFacetFamily` was such a case; it is now realized by
  `HTGeometry.PointFiniteFacetWitnesses`).
