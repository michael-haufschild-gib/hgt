## Conjecture

seemingly different Laplace kernel.  The proposed weld is to take a mixed source jet before scalar
observation.

Write the universal Route-P Hardy kernel as

```text

```

For `R>0` and positive real horizontal depth `a`, introduce the projective node

```text

```

Whenever `R a>=1/2`, this is an admissible inward node, and exactly

```text

```

Now form the half-weighted Hellinger kernel

```text

 = 1/(a+b)-1/[2(a+2b)]-1/[2(2a+b)]+1/[4(2a+2b)].       (168.2)
```

It is the Gram of `k_a-(1/2)k_{2a}` on the projectively rescaled Hardy carrier.  The half weight is
forced: differentiating the doubled node supplies a factor two, so

```text
-d/da [exp(-a r)-(1/2)exp(-2a r)]
  = r(exp(-a r)-exp(-2a r)).                             (168.3)
```

Consequently the mixed jet is exactly

```text

 = 2/(a+b)^3-2/(a+2b)^3-2/(2a+b)^3+2/(2a+2b)^3
```

Thus the cubic separator is an actual tangent Gram of the same Hardy source selected by Route P,
not an abstract positive kernel appended after the fact.

## Why this changes the bottleneck

Equation `(168.4)` supplies the missing algebraic second-variation landing: the cubic horizontal
charge is generated by differentiating a source-defined Hardy packet.  Projective scale `R`
separates positive real shifts while P-G160's unitary ordinate phase remains available for Bohr
dephasing.  A separate finite-`sigma` theorem would still be needed to identify these growing
projective nodes directly with P-G167's full-Euler zeta overlap; the two limiting operations may
not be interchanged silently.

The projective blow-up is necessarily nonuniform.  For every fixed `R`, some
`0<a<=1/2` has `Re u_R(a)<0`; hence no fixed scale keeps the complete strict-right strip in the
arithmetic inward chart.  The cubic boundary discontinuity is therefore the shadow of a scale
which must diverge at least like `1/a`, not a defect of the four-unit Hardy Gram itself.

This is not yet the required `N/4` theorem.  Remaining analytic statement must localize this mixed
jet on dyadic height blocks and compare its literal Euler and archimedean traces with the full zero
census.  In particular, it must prove an upper bound rather than assume one as receiver input.
