## Discriminator

For a tree `T`, the balanced partition is the characteristic function of the centered weighted
spin sum

```text
X_T = (1/2) sum_(v in T) sigma_v log p_v.
```

The positive Fortuin--Kasteleyn expansion resolves it as a convex mixture over bond clusters.  In
each bond configuration the variance is

```text
(1/4) sum_(clusters C) (sum_(v in C) log p_v)^2
  >= (1/4) sum_(v in T) (log p_v)^2
  >= |V_T| (log 2)^2 / 4.                         (1)
```

Thus locally uniform convergence to the pointed Xi germ, which transports the second derivative,
forces the vertex counts to remain uniformly bounded.  A uniformly bounded vertex count gives a
uniformly bounded finite spectral width for every derivative-moment sequence.  The theta-cusp
Fourier source has continuous infinite support and therefore every finite raw moment Hankel
determinant is strictly positive.  Fixed finite spectral width instead forces one of those
determinants to vanish, including after pointwise jet convergence.  This is the proposed
contradiction.

The decisive test is equation (1).  If the exact FK recursion proves it, the entire finite-tree
Lee--Yang limit route is false.  If it fails, retain the first negative covariance or cluster term
as the exact obstruction to the variance argument.

## Critical rescaling successor

The variance obstruction does not merely kill the unscaled model.  For a real scale `a`, put

```text

```

The exact chain rule and equation `(1)` give

```text

  >=a^2 |V_T| (log 2)^2/4.                              (2)
```

Consequently, if `B_(T_n,a_n)` converges locally uniformly to the pointed Xi germ, then

```text

```

Thus every unbounded-rank successor must be critically renormalized; a fixed scale or any scale
with `a_n^2 |V_(T_n)|` unbounded is excluded before using a Xi zero.  Equation `(3)` is a necessary
source scaling law, not an existence theorem and not an RH criterion.  It selects the only live
finite-source regime in which a nontrivial unbounded completion could still be built.  In
particular, if `|V_(T_n)| -> infinity`, then necessarily `a_n -> 0`; this consequence is also
formalized unconditionally.
