overstrong generic-Steiner equality by one exact object that contains both
geometry and dynamics.

controls \(z=(z_e)\), an observer site packet \(S\), and a control packet
\(P\), let
\[

 =
 \mathcal M_S^{\rm site}\mathcal M_P^{\rm control}E_x(z).
\]
Along a nonzero control ray \(z=g\xi\), let \(p_{x,S,P,\xi}\) be its unique
scalar Taylor series. Define the actual birth depth
\[

 \begin{cases}
 \operatorname{ord}p_{x,S,P,\xi},&R_{x,S,P}(g\xi)\not\equiv0,\\
 \infty,&R_{x,S,P}(g\xi)\equiv0.
 \end{cases}
\]

The exact universal law to prove is:
\[

 =
 \bigoplus_{\substack{P\ne\varnothing\\
                      P\ {\rm spatially\ indecomposable}\\
                      S\subseteq{\rm supp}(P)}}R_{x,S,P}(z),

 b_x(S,P;\xi)\ge |P|\ge\tau(S),

and, whenever the sector is active,
\[

\]
Thus a detuning in this sector becomes resolvable exactly on the scale
\[
 T(g)\asymp |g|^{-b_x(S,P;\xi)}.
