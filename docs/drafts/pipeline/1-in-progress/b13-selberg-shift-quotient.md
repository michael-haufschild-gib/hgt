# A nonnegative Euler logarithm with nonreal exceptional zeros

- **Stage:** 1-in-progress
- **Question:** Which pole restrictions matter in the meromorphic version of the model question B13-T8?

Let (Z) be the Selberg zeta of a compact surface with small positive Laplace eigenvalue. For real (h>0), set

`F(s) = Z(s+ih) Z(s−ih) / Z(s)²`.

The coefficient of the negative logarithmic derivative at length (L) is the positive length weight times (2(1-\cos(hL))). Each real exceptional zero (x) of (Z) gives zeros (x\pm ih) and a pole at (x). These are all off-line zeros and poles in the open strip. Reflection exchanges the two shifted numerator factors, giving the exact shifted Selberg functional equation.

This model allows poles inside the strip. A model holomorphic there requires a different cancellation.
