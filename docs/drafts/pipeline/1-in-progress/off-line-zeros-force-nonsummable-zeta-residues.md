# Off-line recurrence forces divergent zeta residue mass

- **Stage:** 1-in-progress
- **Type:** CONJECTURE
- **Wall:** Γ215; approximate arithmetic constituents.
- **Statement:** If a nonzero real-scale Wiener expansion has a zero in a strip about the critical line, the sum of `mρ ‖ζ(ρ)/ρ‖` over all its strip zeros diverges, without assuming purity.

## Connection

The pure case follows from the summable-pole jump law. An off-line zero recurs along a relatively dense set of heights, whereas off-line zeta zeros have density zero. A mean-square bound for zeta on a larger compact strip should strengthen zero avoidance to a fixed positive lower bound for zeta at sufficiently many recurrent zeros.

## Missing bridge

Prove that, outside an arbitrarily small proportion of heights, zeta is uniformly bounded below on a fixed compact set in `1/2 < Re s < 1` whenever a slightly larger compact set contains no zero. Needed inputs: mean-square control of compact suprema, propagation from the Euler region, and a local minimum bound. Reflection must handle left-side zeros.

No lower-bound premise may be added to the capstone. Until this bridge is proved, no contribution is claimed.
