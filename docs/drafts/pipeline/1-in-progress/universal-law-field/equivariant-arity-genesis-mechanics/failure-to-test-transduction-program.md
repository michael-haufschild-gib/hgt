## 1. Higher pivot

Repeatedly asking for a missing source-native map recreates the old bottleneck.  The higher problem
is to classify the possible **failure-to-test transducers** before trying to construct one in a
particular source.

A current observer identifies two source alternatives.  Their failure record carries a symmetry:
it may be oriented, unoriented, probabilistic, cyclic, or higher-ary.  A successor test must respect
or explicitly break that symmetry.  Therefore its output doctrine and minimum arity are not free
design choices.  They are constrained by the orbit type of the failure record.

The proposed mechanism is:

```text
failed distinction with isotropy
        -> equivariant successor test
        -> forced output orbit type / arity
        -> optional doctrine change if deterministic effectivity fails.
```

This is not a hidden universal object.  It is a law governing how one failed comparison can create
the type of its next comparison.

## 2. First closed calibration

Take one unoriented failed pair and one untouched background state.  The pair-swap fixes the
background.  A deterministic binary output whose two labels are swapped has no fixed point.
Consequently no equivariant deterministic binary successor exists.

Exactly three minimal repairs remain.

1. **Raise deterministic arity:** add a fixed background output beside the swapped output pair.
2. **Add orientation:** remove pair-swap from the admitted source symmetry and choose one binary
   side.
3. **Convexify:** keep binary endpoints but represent the fixed background by their symmetric
   mixture.

The Stage-2 theorem proves that any deterministic equivariant separator has three distinct output
values, that the ternary repair attains this bound, that every deterministic binary repair fails,
and that the rational convex repair has the unique fixed mixture (1/2).

## 3. Why this matters for the field

The theorem turns several recurrent corpus slogans into one mechanism.

- Orientation is not a decorative label; it can lower the minimum deterministic test arity.
- Positive convexification can restore equivariance without restoring a pure deterministic choice.
- Observer arity can be generated by a failure's isotropy rather than postulated.
- Changing doctrine is forced exactly when the current output category lacks the fixed orbit types
  required by source symmetry.

This does not prove that all positivity is phase erasure, or that every ternary observer is born
from an unoriented pair.  It supplies the smallest exact law in which those phenomena are different
repairs of the same formation obstruction.

## 4. General conjecture

Let a failure record be a marked finite (G)-set (X), and let a successor doctrine admit outputs
in a (G)-set (Y).  A deterministic successor test is a (G)-map (X\to Y).  The next field
target is an orbit-type calculus satisfying:

1. **isotropy monotonicity:** stabilizers can only grow under a deterministic equivariant test;
2. **arity lower bounds:** source orbit types force a minimum number of target orbit types;
3. **orientation exchange:** reducing source isotropy can lower minimum deterministic arity;
4. **convex repair:** barycentric completion may create required fixed points, with a measurable
   mixing cost;
5. **composition:** independent failures combine by a source-defined product or wreath law, and the
   resulting arity bound is not inserted afterward;
6. **history:** repeated orbit-type changes determine whether the test vocabulary terminates,
   recurs, or grows without bound.

The general programme fails if these clauses reduce to ordinary orbit-stabilizer theory with no
new composition or prediction across doctrine changes.

## 5. Hostile boundaries

1. A source containing only the swapped pair has no fixed background, so a binary equivariant
   separator exists.  The background fixed point is load-bearing.
2. A binary stochastic reporter evades deterministic impossibility because its probability simplex
   contains a fixed barycenter.  This is a doctrine change, not a counterexample.
3. A relation-valued or multivalued reporter may also evade the bound.  Its effectivity and cost
   must be proved separately.
4. An ordered pair supplies orientation and permits binary separation.  The theorem does not select
   an orientation.
5. Generic (G)-set and invariant-decision machinery is classical.  Field content can only come
   from composition, doctrine-change laws, and source-generated failure records.

## 6. Parent mathematics

- finite (G)-sets, orbit types, stabilizers, and equivariant maps;
- equivariant obstruction and fixed-point theory;
- invariant statistical decision theory and randomized tests;
- symmetry breaking, convexification, and barycentric fixed points;
- active learning and counterexample-guided refinement.

These are ingredients of the intended Frankenstein synthesis, not novelty claims.

## 7. Next falsifiable question

For two composable failure records, does minimal equivariant test arity obey a strict exchange law,
or can all apparent arity growth be eliminated by one convex doctrine change?  The next theorem must
classify this without selecting a target route or fitting an observer after the fact.

## 8. Composed-failure result and higher gate

ULF-EAG-2 answers the deterministic half.  For `n` independent inactive/unoriented coordinates,
contextwise resolution and equivariance force one two-point orbit for every nonempty support.  The
minimum response image is `2^(n+1)-1`; the canonical sharp reporter is support plus sign parity; and
two independent blocks generate a mixed sector of size

\[
 (2^{|A|}-1)(2^{|B|}-1).
\]

Lean closes support separation, the universal lower bound, exact canonical attainment, the
canonical support/parity fibres, and the mixed-channel count.  The general convex construction and
classification of every sharp reporter remain paper-only.

This closes arity composition, not law formation.  A palette of forced channels may still be inert.
The next gate is **semantic transport**:

> construct a certificate-bearing mutation in which a newly forced mixed support changes a later
> legal repair, reporter envelope, or admission decision, and prove the response was not present in
> either parent failure block.

If every mixed channel is removable by relabelling and never changes future executability, EAG is
only classical orbit bookkeeping and must not be promoted as field dynamics.
