# Bounded stretch for perfect restricted matchings

- **Stage** 1-in-progress

An odd-factor matching permits a different completion. Copy every moved pair of odd squarefree integers to their doubles. Pair each remaining odd nonunit \(m\) with \(2m\) by replacing an existing prime \(p\) with \(2p\). Reserve the odd integers \(3r_j\), where \(r_0=5\) and \(2r_j<r_{j+1}<4r_j\) are prime. Fix any former partners of these reserved integers before doubling. Pair \(2\) with \(15\) and \(6r_j\) with \(3r_{j+1}\) for all \(j\), replacing \(2r_j\) by \(r_{j+1}\). This absorbs the remaining vertex \(2\) on one infinite ray of logarithmic size. If the odd matching had density-one coverage and sublinear displacement, its completion keeps density-one short movement, has bounded multiplicative stretch at every vertex, and has no fixed squarefree nonunit. The odd matching can be built from the prime tables with bands above 2.
