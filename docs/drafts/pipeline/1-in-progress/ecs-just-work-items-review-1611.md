## E-J3 paper proof
Let S(ε) = Σ_q LF(z_q)LF(−z_q)e^(εz_q²) (summable for ε > 0, criticalState_hasSum_zeroPairing_heated with G = F) and S(ε) → −aW₈ (criticalState_tendsto_zeroNorm). Split the copies into on-line (Re z = 0) and off-line. For Re z = 0: −z = z̄, LF(z̄) = conj LF(z) (F real), z² = −(Im z)², so the term is e^(−ε(Im z)²)|LF(z)|² ≥ 0, ≤ |LF(z)|², increasing to |LF(z)|² as ε ↓ 0.
(i) If the off-line part tends to L, the on-line part R(ε) (real) tends to M = −aW₈ − L, so M is real. For a finite set T of on-line copies, Σ_T|LF|² = lim Σ_T e^(−ε γ²)|LF|² ≤ lim R(ε) = M; hence summable with Σ ≤ M; and Σ|LF|² ≥ R(ε) → M. So Σ_on |LF|² + L = −aW₈.
(ii) If the on-line values are square-summable, dominated convergence (Tannery) gives R(ε) → Σ_on|LF|², so the off-line part tends to −aW₈ − Σ_on|LF|².
(iii) With finitely many off-line copies the off-line part is a finite sum and tends to Σ_off LF(z)LF(−z).

## E-T1 paper proof (second critical state)
P(R): some plane of H is negative definite for Q_R (2×2 Gram A < 0, AC − B² > 0). P is monotone in R and open to the left (entries affine in a(R)). No negative plane for R ≤ W₀ (ground energy ≥ 0); negative planes at large R: E-J1 gives two negative squares of the confined Gram matrix of half-line tests; its entries are real, so a complex negative 2-plane contains x ≠ 0 with Σ x_s⟨F₁,H_s⟩ = 0, and Re x or Im x is a real negative vector X ⊥ F₁ (F₁ the ground minimizer, μ₁ < 0); span(F₁, X) is negative. R₂ := inf{R : P(R)} ≥ W₀ and P(R₂) fails. Without a negative plane through F₁: μ₁ ⟨F₁,X⟩² ≤ Q(X). Hence the orthogonal energy at R₂ is ≥ 0; it is ≤ 0 by unit vectors of the negative planes at R₂ + 1/n orthogonal to F₁ (W₈ bounded by coercivity). It is attained (window approximation + compactness; orthogonality passes to L² limits). The zero-energy orthogonal minimizer K satisfies Q(K + cG) ≥ μ₁c²⟨F₁,G⟩², so Q(K, G) = 0 for all G: a null vector. R₂ > W₀ because at W₀ a zero-energy unit profile is a minimizer, hence ±F₁, not orthogonal to F₁.

## E-J2 paper proof (k-th critical state)
For a null vector Φ of Q_S and any G ∈ H, Q_R(Φ, G) = (a(R) − a(S))W₈(Φ, G). Hence for W₈-orthogonal null vectors Φ_i (ratios R_i) and Z ⊥ all Φ_i: Q_R(Z + Σc_iΦ_i) = Q_R(Z) + Σc_i²(a(R) − a(R_i))W₈(Φ_i) (Finset induction with the two-term expansion). If Q_R ≥ 0 on the complement, decomposing X = Y + Σc_iΦ_i (c_i = W₈(Φ_i, X)/W₈(Φ_i)) gives Q_R(X) ≥ Σ(a(R) − a(R_i))W₈(Φ_i, X)²/W₈(Φ_i) on all of H; a unit K ⊥ Φ with Q_R(K) = 0 then satisfies Q_R(K + cG) ≥ c²·(that sum at G), so Q_R(K, G) = 0: K is a null vector. Extension of a ladder: A = {t > R_m : Q_t < 0 somewhere on the complement} is up-closed (Q_t decreases in t) and open to the left (Q_t(X) continuous in t); r = inf A ∉ A, so the floor holds up to r. ## E-J9 paper proof
The Hardy datum of F⁺ is −a⁻¹ times the damped archimedean profile plus the L² series of the damped prime data e^{−x}Λ(n)n^{−½}F(x − log n) minus the two charge features. Each term has L² norm ≤ Λ(n)n^{−3/2}·‖e^{−u}F‖₂, summable; on (0, X) the L¹ norms are ≤ √X times the L² norms, so the pointwise series converges absolutely a.e. (Tonelli), and an L² series equals its pointwise sum a.e. (a subsequence of partial sums converges a.e.). Multiplying by e^x gives −aF⁺(x) = J⁺(x) + Σ Λ(n)n^{−½}F(x − log n) − LF(½)e^{−x/2} − LF(−½)e^{x/2}; the last term is ∫_{y>x}F(x−y)e^{y/2}dy (polarWallTerm_eq_continuumMainTerm). ## E-J4 for two arbitrary profiles: paper proof
Notation: τ_R f(u) = f(u + R); k_ε the heat kernel, ∫k_ε(y)e^{−zy}dy = e^{εz²}; c(s) = ∫F(t)G(t − s)dt; W(F, H) the bare-form formula (gamma − prime + charges) for any H with the needed integrability; S_ε = Σ_z LF(z)LG(−z)e^{εz²}.

## E-J9 asymptotics paper proof
ŜF(−t) = Σ_n Λ(n)n^{−½} A_t(log n) with A_t(L) = ∫_{u>−L} e^{−t(L+u)}F(u)du (unfold the Lévy head at p = −t; F = 0 on u ≥ 0). Translating u = v − L and scaling v = s/t: tA_t(L) = ∫_{s>0} e^{−s}F(s/t − L)ds.
(i) Cauchy–Schwarz: A_t(L)² ≤ (∫_{u>−L} e^{−t(L+u)}du)(∫ e^{−t(L+u)}F²) = t^{−1}m_t(L). m_t(L) → 0 by dominated convergence (weight ≤ 1, → 0 pointwise on u > −L), and for t ≥ 8, e^{−t(L+u)} ≤ e^{−8L}e^{−8u} on u > −L, so √t|A_t(log n)| ≤ n^{−4}(∫F²e^{−8u})^{½}. Σ Λ(n)n^{−½−4} < ∞; Tannery gives √t·ŜF(−t) → 0.
(ii) If F is right-continuous at −L and |F(u)| ≤ Ce^{cu}, c > ½: for t ≥ 2c, |e^{−s}F(s/t − L)| ≤ Ce^{−cL}e^{−s/2}; dominated convergence gives tA_t(L) → F(−L), and |tA_t(log n)| ≤ 2Cn^{−c}; Σ Λ(n)n^{−½−c} < ∞, Tannery.
(iii) JF(−t) = Σ_k LF(2k+½)/(2k+½+t) (hasSum_levyHead_resolvents at p = −t). With 0 ≤ t/(2k+½+t) ≤ 1 → 1, Tannery gives the limit when Σ|LF(2k+½)| < ∞. For the state b_k = LF(½)LF(2k+½) > 0 (criticalState_laplace_half_mul_pos): summable ⇒ limit Σ b_k > 0; not summable ⇒ the partial sums exceed any C, each finite sum Σ_{k<N} b_k t/(2k+½+t) → Σ_{k<N} b_k, and the full series dominates every finite one.
Sharpness (*reading*, not formalized): for F(u) ≈ (u + log 2)^{−α} just right of −log 2 with α < ½ (in L² and in the Gamma domain), tA_t(log 2) ≈ Γ(1 − α)t^α; so t^γ·ŜF(−t) → 0 fails for every γ > ½ and the exponent in (i) is optimal on H.
