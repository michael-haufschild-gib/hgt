# Integral opposing sections on actual hyperelliptic curves

For $y^2=f(x)$ squarefree of odd degree over a finite field of odd characteristic, write $q$ for the field size and $F$ for an unnormalised Frobenius root. Its integral characteristic polynomial $A(T)=a+TB(T)$ has $a\ne0$. Therefore $F[-B(F)]=a$ on every root. For an integral section $P(T)=\sum_{j=0}^m u_jT^j$, the reversed polynomial $V(T)=\sum_{j=0}^m u_jq^jT^{m-j}$ satisfies $V(F)=F^m\overline{P(F)}$, since $F\bar F=q$. At any prescribed positive lag $L$, choose $Q(T)=a^{L+m}[-B(T)]^{L+m}V(T)$. Then $F^LP(F)Q(F)=a^{2(L+m)}|P(F)|^2$. The positive constant clears all denominators. Summing the pole-subtracted extension counts with the coefficients of $P,Q$ should give this identity on the actual curve. The kernel consists of the sections vanishing on all distinct Frobenius roots.
