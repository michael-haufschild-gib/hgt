## Exact candidate

For a finite nonempty set `S` of distinct integers at least two, put

```
d_n(s) = xi(s) * exp(-s log n),
D_S = zeros(xi) union union_(n in S) zeros(1+d_n),
U_S = C minus D_S,
V = C minus {0,-1}.
```

Fix a basepoint of `U_S`. The marked functions give a map
`d_S : U_S -> V^S` and hence a homomorphism
`mu_S : pi_1(U_S) -> pi_1(V^S) = product_(n in S) F(a_n,b_n)`.
Here `a_n` winds around zero and `b_n` around minus one. Write
`ab : product F(a_n,b_n) -> Z^(S x {a,b})` for abelianization.

For each removed point `r`, let `v_r` be its vector of vanishing orders:
the `a_n` coordinate is `ord_r(xi)` for every n, and the `b_n` coordinate is
`ord_r(1+d_n)`. Orders of nonvanishing functions are zero. Let `L_S` be the
integer subgroup generated by every `v_r`.

**C1:** `image(mu_S) = ab^(-1)(L_S)` for every such S.

The definition retains auxiliary-divisor intersections and all multiplicities;
it assumes neither simplicity nor RH. Changing connecting paths conjugates
the image, while the proposed right side is normal, so the assertion is independent
of that choice. `D_S` is discrete: each defining entire function is nonzero as a
function, and S is finite. The usual punctured-plane generators show
`ab(image(mu_S))=L_S`. C1 asks for the additional inclusion of the full ambient
commutator subgroup; that inclusion is not a consequence of the abelian equality.

## Exact cubic obstruction on the normalized source cover

This is a dependency-closed paper reduction for any nonconstant entire function d,
not a proof of the actual Xi no-lift assertion. Put

```
pi : X -> C = normalization of y^2=d(d+1),
tau(s,y)=(s,-y),
u=1+2d+2y.
```

The finite normalized cover is allowed to be disconnected. The coordinate y is
holomorphic on X and `u*tau(u)=1`. In particular u is a holomorphic unit even
above multiple zeros of either factor. The exact equivalence is

```
exists entire h, (h^3-3h-2)/4=d
  iff exists holomorphic unit v on X, v^3=u
  iff wind(u o gamma) belongs to 3Z for every closed loop gamma in X.
```

**Forward proof.** For a cubic lift h, the identity
`(h^2-1)^2*(h^2-4)=16d(d+1)` holds. The meromorphic function
`q=4y/(h^2-1)` on X satisfies `q^2=h^2-4`. Thus q has no poles, by the
local order of a square, and extends holomorphically through the apparent
denominator zeros. Also `tau(q)=-q`. Set `v=(h+q)/2`. Then
`v*tau(v)=1`, `v+v^(-1)=h`, and `v-v^(-1)=q`. Consequently

```
v^3+v^(-3)=h^3-3h=2+4d,
v^3-v^(-3)=q*(h^2-1)=4y,
```

so `v^3=u`.

**Reverse proof, including descent.** If `v^3=u`, then
`c=v*tau(v)` is tau-invariant and satisfies `c^3=1`. It descends to a
holomorphic function on C, hence is one constant cube root of unity, also when
X is disconnected. Set `w=c*v`. Then `w^3=u` and `w*tau(w)=c^3=1`.
The function `h=w+w^(-1)` is tau-invariant and descends holomorphically to C.
At a ramification point this follows from the even power series in a local
double-cover coordinate; at an unramified point the two local values agree.
Now `h^3-3h=u+u^(-1)=2+4d`, proving the cubic identity.

**Topological step.** Apply the covering-space lifting criterion for
`C* -> C*, z |-> z^3` separately on each connected component of X. Its
fundamental-group image is `3Z`. A continuous lift of a holomorphic map through
this covering is holomorphic by the local inverse charts. No compactness,
growth estimate, simplicity hypothesis or square-class premise is used.

On the regular locus, direct differentiation gives

```
dlog u = d'(s)/y ds.
```

This differential extends holomorphically over X because u is a unit. Define
`kappa_n : pi_1(X_n) -> Z/3` as winding of u_n modulo three, componentwise,
for `d=d_n`. The **OPEN CORE** is to exhibit an actual source loop with
`kappa_n(gamma) != 0`, or to prove this homomorphism vanishes and produce the
entire cubic lift. Naming this class does not evaluate it.

**Updated status:** the entire-lift alternative is now excluded in Lean.
Combined with the dependency-closed paper equivalence above, this forces a
loop with nonzero mod-three winding. The normalized-cover equivalence and
this topological transport have not yet been formalized, and the proof does

### Reflection audit: rational normalization and exact cancellation

The exact source relation is
`d_n(1-s)=n^(2s-1)*d_n(s)`. It preserves the zero divisor of d_n but does
not preserve the other branch divisor `d_n=-1`. Therefore reflection does
not automatically act on X_n or its winding class. Any use of reflection
requires an actual correspondence between the distinct normalized covers;
a same-cover involution would be an extra, unproved assertion.

There is nevertheless an exact correspondence. Write `z=s-1/2`, `L=log n`,
`A=exp(-2Lz)`, `x=h(s)`, `y=h(1-s)`. A hypothetical lift satisfies
`P(x)=A*P(y)`. This plane cubic has its fixed node at `x=y=-1`.
Away from that node set `t=(x+1)/(y+1)`. Its rational normalization is

```
x=(2t^3-3At+A)/(t^3-A),
y=(3t^2-t^3-2A)/(t^3-A),
x+1=3t(t^2-A)/(t^3-A),
y+1=3(t^2-A)/(t^3-A).
```

These follow by substituting `x+1=t(y+1)` into
`(x-2)(x+1)^2=A(y-2)(y+1)^2`. The quotient t extends meromorphically
through the simultaneous zeros: their orders agree since A is a unit.
For a nonconstant lift the exceptional identity `t^3=A` cannot hold
identically, since the displayed undivided relations would force `t^2=A`
and therefore `t=A=1`, contrary to nonconstant A.

Put `r=exp(-2Lz/3)` and `v=t/r`. If `v(z)^3=1`, cancellation in the
displayed equations requires `t^2=A` as well as `t^3=A`, hence `t=A=1`.
Consequently

```
v^(-1)({1,omega,omega^2}) subset {pi*i*k/L : k in Z},
omega=exp(2*pi*i/3).
```

Each such preimage is simple. Indeed t is finite and nonzero there, and
`t^3-A=0` with `t=A=1`. If its derivative also vanished, then
`3t'=A'`, whereas `(t^2-A)'=2t'-A'=-A'/3 != 0`; y would have a pole.
Thus `v^3-1` has a simple zero. This is an exact necessary condition;
it neither asserts that every lattice point occurs nor fixes its label.


`3rv*y=x*(v^3+2)-2*(v^3-1)` exhibits that extension since rv is then one.

### Finite rational test: ternary fiber degree restriction (formalized)

Use the lattice coordinate `w=Lz/(pi*i)`. Cancellation says that a preimage
of `omega^j` is an integer congruent to j modulo three. Suppose the normalized
parameter is a nonconstant rational map `V : P1 -> P1` of degree N and
`V(infinity)` is not a cube root of unity. Then the following exact necessary
condition holds:

```
N = 3^e for some integer e >= 0.
```

Proof: each of the three fibers has N finite integer points, counted with
multiplicity. Let A_j be its monic root polynomial. These belong to Z[X].
Writing V as a quotient shows the three A_j are linearly dependent over C.
Since their coefficients are integers, they have a nonzero primitive integer
linear relation `c_0 A_0+c_1 A_1+c_2 A_2=0`. Reduce modulo three. At least
one coefficient survives, and the root congruences give a dependence among

```
X^N, (X-1)^N, (X+1)^N in F_3[X].
```

Evaluation at 0,1,-1 shows that N must be odd and the three coefficients
must be equal and nonzero. Thus
`X^N+(X-1)^N+(X+1)^N=0`. Comparing coefficients implies
`binom(N,j)=0 mod 3` for every positive even j with j <= N.
Since N is odd, binomial symmetry gives the same vanishing for every
interior odd j by replacing j with N-j. All interior binomial coefficients
therefore vanish modulo three. The standard prime-power criterion already
appears in this toolchain as `eq_pow_multiplicity_of_choose_modEq_zero_nat`
in `Mathlib/Data/Nat/Choose/Lucas.lean`, namespace `Choose`; its exact signature
has now been verified and used in the completed formalization. For a direct paper proof,
write N in base three. Frobenius gives the polynomial identity
`(1+X)^N=product_i (1+X^(3^i))^(digit_i(N))`. If any digit is two,
the coefficient at the positive even index `2*3^i` is nonzero. If two
digits are one, the coefficient at `3^i+3^k` is nonzero. The digits must
therefore consist of exactly one one, proving `N=3^e`.

### Joint-cover genus audit

For pairwise distinct nonzero constants a_1,...,a_k, the normalization of
the fiber product `a_i*P(x_i)=y` is connected of degree 3^k over P1_y.
At zero the monodromy is a tuple of transpositions; at -a_i it is a
transposition in coordinate i alone. In each coordinate those two
transpositions differ. Their commutator supplies a three-cycle supported
in coordinate i, so these generators contain every S3 factor. Thus the
joint monodromy is S3^k. The exact ramification defects are
`(3^k-1)/2` at zero, `3^(k-1)` at each -a_i, and `2*3^(k-1)` at
infinity. Riemann--Hurwitz gives

```
g = ((2*k-5)*3^(k-1)+3)/4, k >= 1.
```

In particular three channels have genus three. This is classical branch
bookkeeping, not a new rigidity theorem. [Ding--Zieve](https://arxiv.org/abs/2103.07921)
and [Pakovich](https://arxiv.org/html/2408.10874v2) supply the fiber-product
parent theory. No positivity-based orbifold criterion is imported.
For actual exponential marks the coefficients vary with s, so a section
is not an entire map into one fixed compact curve. The constant section
with source zero also survives at every level. Genus alone therefore
does not establish the required section obstruction.

Forward/backward mark collisions satisfy exactly
`n^s=m^(1-s)` iff `s=(log m+2*pi*i*k)/log(n*m)`.
Equal marks collide on the critical line; unequal marks have additional
