# Square section bounds on sparse conductors

Let $q_n$ be the ordinary rational generator of $nD_n$ and $Q_n$ the signed degree. Can one conductor per short interval recover the width? For any set $E$ with gaps $O(n^\theta)$, $\theta<1$, a uniform lower bound $Q_n\ge -C(n+1)^{2s}$ on $E$ suffices. In particular RH would follow from $\log q_n\le Cn^2$ at only the perfect $k$th powers for any fixed $k\ge1$.

Write $w$ for the actual zero width. The two long traces in $Q_n$ vary by $O(n^{2w+\theta-1})$ across a gap, by the first absolute spectral moment and the difference of the logarithmic lags. The short trace stays bounded. Thus the same lower bound holds at every integer with exponent $2t=\max(2s,2w+\theta-1)$. The all-conductor criterion gives $w\le t$. If $w>s$, then $t<w$, a contradiction. The diagonal contact error divided by $n^2$ is uniformly bounded, so the argument applies to the actual rational generators. Off RH, every $\theta<1$ consequently admits arbitrarily late intervals of length $n^\theta$ on which all the generators exceed any prescribed fixed exponential allowance. The known cofinal existence of sections does not bound the gaps between successful conductors.
