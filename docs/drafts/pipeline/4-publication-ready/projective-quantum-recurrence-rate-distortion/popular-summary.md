# Popular summary

## Headline

**Quantum systems may follow the same “water-filling” rule used to compress
information when they find their way home.**

## Summary

A closed quantum system can, in principle, return close to an earlier state.
The obvious question is: how long must we wait?

The new result says size alone is not the answer. Each occupied energy level
has a weight, and a requested accuracy decides which weights matter. The
optimal rule resembles pouring water across uneven columns: important
coherences rise above the water line and must be synchronized; sufficiently
weak ones fall below it and cost nothing in the leading information budget.
That is exactly the mathematical “reverse water-filling” rule used in lossy
data compression.

The strengthened result does not rely on inventing a single worst-case
spectrum. It bounds what fraction of all phase spectra can return by any
chosen deadline. Its guarantee for every spectrum can also ignore a
low-weight tail: ignored levels consume part of the allowed error but add no
factor to the clock. The overhead follows the levels that must be
synchronized, not every level present.

There is a second twist. A quantum system has no single observer-independent
return clock. A chosen state or measurement sees a network connecting energy
levels. The number of independent phases that must line up is the number of
visible levels minus the number of disconnected pieces of that network.

This does not solve cosmology or prove that the universe repeats. It gives a
testable law for closed quantum systems: change the prepared weights or change
what is observed, and the guaranteed recurrence budget changes in a precise
way.

## One-sentence video pitch

**How long until a quantum system repeats itself? The answer is encoded not
only in its size, but in a hidden network of coherences—and the waiting-time
budget obeys the same water-filling mathematics as data compression.**
