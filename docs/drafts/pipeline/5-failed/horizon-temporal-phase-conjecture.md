# Failed route: a horizon changes the dimension of time

- **ID:** `horizon-temporal-phase-conjecture`
- **Status:** `RETIRED — BOTH UNIVERSAL DIRECTIONS FALSIFIED; MODEL CORE PRIOR ART`
- **Parent:** `../1-in-progress/observer-dependent-temporal-dimension.md`
- **Frozen headline:** “A black hole forms when time becomes infinitely
  dimensional for outside observers.”

## Frozen conjecture

In every UV-complete compact-boundary holographic theory in a strict
semiclassical large-\(N\) limit, every centred nonconserved simple probe
reaching a nonextremal horizon was conjectured to have atomless connected
boundary-time spectrum, while the corresponding horizonless phase was
conjectured to have pure-point spectrum. A separating-family transition was
also conjectured to characterize horizon formation conversely.

This was a genuine proof-route-blind conjecture: evidence suggested it, but no
proof route was known. Its quantifiers were frozen before literature and
counterexample attack.

## Fatal counterexamples

1. **Horizonless continuum.** Superstring theory on
   AdS\(_3\times S^3\times T^4\) with generic NS--NS flux has a spacetime CFT
   containing an \(\mathcal N=4\) Liouville factor and the associated
   long-string continuum. Global AdS\(_3\) is horizonless and its boundary
   spatial circle is compact. Compact boundary plus absence of a horizon
   therefore does not force pure-point probe spectra.
2. **Horizon with an undamped mode.** Stationary nonextremal Kerr--AdS black
   holes possess superradiant onset curves with real zero-damping modes;
   black-resonator branches emerge from those onsets. The universal claim
   that every nonconserved horizon-coupled probe is atomless is false.
3. **Prior-art collision.** The large-\(k\) AdS\(_3\)/CFT\(_2\)
   Hawking--Page transition from oscillatory normal-mode response to
   exponentially relaxing quasinormal-mode response was established in 2003.
   Rephrasing that model result as a change of temporal dimension is not a
   new horizon-discovery law.

## Strongest positive salvage

For the selected large-\(k\) AdS\(_3\)/CFT\(_2\) response, the known
Hawking--Page oscillatory/decaying transition combines with the exact spectral
return theorem as follows:

```text
oscillatory normal-mode response -> pure-point return phase;
decaying quasinormal response    -> atomless zero-density return phase.
```

This is a clean calibration of observer-dependent return type in a
holographic model. It is not a universal horizon criterion and is not new
parent physics. Formalization is required only if this model calibration is
retained in a later manuscript; it cannot serve as novelty anchor.

## Closure

The conjecture must not be retroactively weakened by adding stability,
Einstein-gravity, no-long-string, nonmarginality, or generic-probe clauses.
Those would define a different theorem candidate whose proof route is already
suggested by the known Hawking--Page calculation.
