- **Scope:** Retires the literal fixed-period, stroboscopic Maxwell-cell return as a producer of the zeta-valued PTR response; does not retire PTR's nonlocal Mellin or rotating-cylinder branches.
- **Chain tested:** temporal-Maxwell slab cell → repeated parabolic transfer → claimed source-derived `photonicReturn(s)` → defect confinement → RH.
- **Corpus basis:** `PhotonicTemporalMaxwellSlabRealization` realizes the prime cyclic cell as source-free temporal Maxwell transfer. `PhotonicParabolicReturn` proves `U^n` is parabolic but obtains `photonicReturn(s)₀₀ = ζ(s)` only after inserting the Mellin weight `(n+1)⁻ˢ`. `PhotonicPrimeClockDeningerLatticeNoGo` already excludes one clock or any finite disjoint clock array from carrying every prime lattice.
- **New exact obstruction (Lean):** For every period `T>0` and **every** map `G : ℂ → Mat₂(ℂ)`—no linearity, continuity, or analyticity assumption—`G(exp(-Ts))` cannot equal `photonicReturn(s)` throughout `Re s>2`. The first entry would make ζ periodic under `s ↦ s+2πi/T`. Analytic continuation away from its shifted pole and its nonzero residue at `s=1` forbid that period. Certificate: [`PhotonicFixedClockReturnNoGo.lean`](../../../../formal/GaloisForLFunctions/RHTower/PhotonicFixedClockReturnNoGo.lean), `ptr_fixed_clock_factor_photonic_return_no_go`.
- **Within-cycle boundary (Lean):** Even if the readout depends on `s` beyond `exp(-Ts)`, a return holomorphic throughout `Re s>0` cannot equal `photonicReturn` on `Re s>2`. The identity theorem would carry its ζ diagonal toward `s=1`, where the source return stays regular but ζ has residue one. Certificate: same file, `ptr_right_halfplane_holomorphic_photonic_return_no_go`. This is a function-class no-go; the literal slab's causal Laplace-port holomorphy is not yet formalized.
- **Positive survivor / sharpened burden:** Any direct causal Laplace-port realization must create a genuine pole at `s=1`; nonperiodic but right-half-plane-holomorphic within-cycle data cannot suffice. Logarithmic retiming of the `n`-history or an all-prime/infinite-clock source could change the convergence abscissa; the arithmetic all-prime occupation/Euler product is already in the corpus. A literal Maxwell port with that singularity, independent defect confinement, and the rotating-interface conormal law remain open. Merely realizing the parabolic cell does not supply the Mellin weighting.
