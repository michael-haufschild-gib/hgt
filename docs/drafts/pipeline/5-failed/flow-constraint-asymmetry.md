## Theorem (the flow/constraint asymmetry)

The **same** prime base behaves **oppositely** on the two axes — this is the precise mechanism of "constraint
not flow":

> **(Flow axis — primes INERT.)** The difference generators `p^{-s}` are **D-finite**: each solves the
> first-order linear ODE `y' = −(log p)·y`, so `difference-trdeg(ℂ(s, {p^{-s}}_p) / ℂ(s)) = 0`. Adjoining the
> whole prime-exponential field adds **no** differential-transcendence. Hence any *flow* (differential /
> difference-differential, "no algebraic equation") question about `Λ=Γ·ζ` reduces to the archimedean factor
> alone (Hölder on `Γ`) — the primes contribute nothing. **⟹ every flow-framed weld is BRIDGE** (Professor's
> `lambda-…` weld proof; and G1, the cross-term #132, generators #133 — all flow-framed, all BRIDGE).
>
> **(Constraint axis — primes LOAD-BEARING.)** The frequencies `{log p}` are **ℚ-linearly independent**
> (#1, Lean), so the relation lattice `Λ_M ⊆ ℤ^{(P)}` of the multipliers is **trivial** and
> `corank(Λ) = rank(ℤ^{(P)}/Λ_M) = ∞`. The infinitely many primes are **irreducibly present** in the
> constraint (corank / non-holonomicity, G3): no finite sub-base captures it.

**Same base: D-finite generators (flow-inert) vs ℚ-independent frequencies (constraint-loaded).** This is why
the native content is the **constraint** (corank, non-holonomicity), not the **flow** (the differential
equation) — the user's epigraph, as a mechanism.

### Proof
**(flow-inert).** `y = p^{-s} = e^{-(log p)s}` ⟹ `y' = −(log p)y`: a first-order linear ODE over `ℂ` with
constant coefficient `log p`. So each `p^{-s}` is differentially algebraic over `ℂ(s)` (indeed D-finite,
order 1). A field generated by countably many differentially-algebraic elements has difference-trdeg 0 over
the base; so `difftrdeg(ℂ(s,{p^{-s}})/ℂ(s)) = 0`. Therefore for the differential/diff-diff question, the
prime exponentials are inert — the transcendence-degree is unchanged by adjoining them, and the only
differential-transcendence is `Γ`'s (Hölder). ∎
**(constraint-loaded).** The multiplier relation lattice is `Λ_M = { m ∈ ℤ^{(P)} : Σ_p m_p log p = 0 }`. By
the ℚ-linear independence of `{log p}` (#1, `logPrime_no_rat_relation`), `Λ_M = {0}`, so
`ℤ^{(P)}/Λ_M = ℤ^{(P)}` has infinite rank: `corank(Λ) = ∞`. Each prime is a free generator of the lattice —
removing any finite set leaves infinite corank. So the primes are load-bearing for the constraint. ∎
