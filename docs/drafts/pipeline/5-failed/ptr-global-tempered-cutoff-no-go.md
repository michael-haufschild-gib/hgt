# PTR global tempered-cutoff formulation: no-go

- **Chain attacked:** source rotating-cylinder material law → all-grade Maxwell/interface relation → prime conormal landing → confinement → RH. This retires only the attempted everywhere-defined, continuous multiplier on the full tempered-distribution field space.
- **Exact theorem:** [Lean](../../../../formal/GaloisForLFunctions/RHTower/PhotonicCylinderDistributionCutoffNoGo.lean) proves no continuous `T : 𝓢'(ℝ,ℂ) → 𝓢'(ℝ,ℂ)` agrees on point masses away from a sharp interface with the source's cylinder indicator in a local normal chart. `δ_x` is continuous as `x→0`; from one side its image must tend to zero, from the other to `δ_0≠0`. No choice of value at the interface repairs this.
- **Positive survivor:** the existing [literal material-overlap operator](../../../../formal/GaloisForLFunctions/RHTower/PhotonicRotatingCylinderMaterialOverlap.lean) remains bounded on `L²`. The source-faithful distributional Maxwell problem must specify a restricted field/trace domain, a non-continuous action, or separate interior/exterior distributions with explicit transmission data. The latter is the active [Cauchy-data relation](../1-in-progress/ptr-calderon-boundary-reframe.md). This obstruction identifies a **domain/interface** problem, not a missing bound.
- **Limits:** the Lean theorem is a local normal-chart model and does not prove a two-dimensional Maxwell equation, transmission regularity, prime conormal exclusion, or full PTR failure. Its underlying sharp-cutoff distribution fact may be classical; no literature-novelty claim follows from this lemma alone. It eliminates a proposed formulation, not the physical source.
