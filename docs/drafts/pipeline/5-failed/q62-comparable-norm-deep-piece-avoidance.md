## GBExt mechanism — VALIDATED (2026-07-03, sharpening after reading `W4LinWinding`)

uses the one the gap regime does NOT:

  equipotential `{G_{c₂} > G_{c₂}(0)}`, where `bottcherCoord c₂` is GLOBALLY single-valued. This is
  exactly what fails at comparable norms: the `c₁`-deep pieces live near `K₁` (small radius), inside

- **Winding-0-by-containment mechanism (THIS route).** A loop hugging `P_k(p)` in a small disk `D`
  with `D ∩ K₂ = ∅` has `φ₂` single-valued on `D` because `D` is simply connected and disjoint from
  `K₂` — `bottcherCoord c₂` is locally defined on `D ⊆ escapeOpen c₂` and has no monodromy on a
  `K₂`-null-homotopic loop, REGARDLESS of Green level. So `GBExt` survives even though `Ext` dips into
  `c₂`'s near region. ✔ This is a valid, distinct mechanism — the reason the route can reach comparable
  norms where the far-region floor cannot.

## REFUTATION (2026-07-03 — the route is dead; the reason sharpens OP16-A)
Pursuing the section structure (`SectionTower.TowerSection`) refutes the route in ALL its forms
(deep-piece, small-loop-around-0, filament-hugging). The obstruction:

`TowerSection c₁ rlo rhi` carries `wind : ∫ (T(circleMap 0 r θ))⁻¹ · deriv T · … = 2πi` — the image
loop `T∘circle` has **unit winding around the ORIGIN `0`** (the critical point of `z ↦ z²+c₁`). This
is structural: it is how the non-square witness `F` gets its odd winding.

Consequences that kill the winding-0 idea:
1. A unit-winding-around-`0` loop cannot live on a single deep lobe. Below the critical level
   `G_{c₁}(0)`, `φ_{c₁}` is injective only on individual figure-8 lobes, and `0` is the figure-8 NODE
   — on every lobe's boundary, never interior. A section loop confined to a lobe winds `0` around
   `0`, violating `wind`. So a valid section loop must be in the **far region** `{G_{c₁} > G_{c₁}(0)}`
   (an annulus around ∞) and be its `π₁`-generator.
2. That generator necessarily encircles the ENTIRE bounded sub-critical region
   `{G_{c₁} ≤ G_{c₁}(0)} ⊇ K₁ ∪ {0}` (winding is constant `= 1` on the whole bounded complementary
   component). For comparable norms `K₂ ⊂ ball(0, √‖c₂‖+1)` overlaps `c₁`'s sub-critical ball
   `≈ ball(0, √‖c₁‖)`, so `K₂ ∩ {G_{c₁} < G_{c₁}(0)} ≠ ∅` generically, and the loop winds `= 1`
   around those `K₂`-points. Winding ≠ 0 ⟹ `GBExt`-by-containment is impossible.

So the ONLY surviving `GBExt` mechanism is far-region single-valuedness (loop above BOTH critical
levels), which is exactly the gap-bound construction (`‖c₂‖ ≲ ‖c₁‖/400`, card
`norm-bounded-tower-mixed-pair-far.md` addendum 8). **Conclusion:** comparable-norm q62 cannot be
closed by re-routing loops inside the Böttcher-tower / winding framework at all. It genuinely needs
OP16-A's enclosure resolved by a DIFFERENT structure (not this tower). Net gain: OP16-A is sharpened
from "steer the tower piece off `K₂`" to the precise impossibility "no unit-winding-around-`0` loop
avoids the sub-critical `K₂`-mass" — the tower framework is provably exhausted for comparable norms.
