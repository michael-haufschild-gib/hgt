## 2. General diagonal-intervention classification

For a scalar sequence `m=(m_p)`, let

\[
 M_m:X\longrightarrow X,
 \qquad
 (M_mx)_p=m_px_p.
\tag{5}
\]

### Theorem 2.1

1. `M_m` descends to an endomorphism of `Q` iff `m in ell^infinity(P)`.
2. When it descends, it is injective on `Q` iff there are a finite set `F subset P` and
   `epsilon>0` such that
   \[
   |m_p|\ge\epsilon\qquad(p\notin F).
   \tag{6}
   \]
3. If `m_p=1` outside a finite set, the induced map on `Q` is exactly the identity.
4. If `m_p -> 0`, the induced map is noninjective.

### Proof

If `m` is bounded, multiplication preserves `ell^1`. Conversely, if `m` is unbounded, choose
distinct `p_n` with `|m_(p_n)|>=n^3`. Put

\[
 x_{p_n}=\frac1{n^2}\frac{\overline{m_{p_n}}}{|m_{p_n}|},
 \qquad x_p=0\text{ otherwise}.
\tag{7a}
\]

Then `x in ell^1`, but `|m_(p_n)x_(p_n)|>=n`, so `mx notin ell^1`.

Assume `(6)`. If `mx in ell^1`, then

\[
 \sum_{p\notin F}|x_p|
 \le\epsilon^{-1}\sum_{p\notin F}|m_px_p|<\infty.
\tag{7}
\]

The coordinates on finite `F` are summable, so `x in I`; the quotient map is injective.
Conversely, if no cofinite lower bound exists, choose distinct `p_n` with
`|m_(p_n)|<=2^(-n)` and put `x_(p_n)=1`. Then `x notin I` but `mx in I`, so the quotient map is
not injective. This proves 1 and 2.

For 3, `(M_m-1)x` has finite support for every raw `x`, hence lies in `I`. For 4, use the same
subsequence construction as above. QED.

The cofinite condition is sharp: finitely many zero coordinates disappear in the quotient because
every finite-support sequence belongs to `I`.

## 3. Raw Kummer--Gamma flow

Define, for real `t`,

\[

\tag{8}

### Theorem 3.1

   \[
   G_sG_t=G_{s+t},\qquad G_t^{-1}=G_{-t}.
   \tag{9}

2. Its coordinatewise infinitesimal generator is
   \[
   \left.\partial_tG_t\right|_{t=0}=M_{-2\log p},

   exactly twice the signed Kummer prime period `-log p`.
3. `G_t` descends to `Q` iff `t>=0`. For `t>0` the induced quotient map is surjective and
   noninjective; at `t=0` it is the identity; for `t<0` it is inadmissible.
4. Its physical finite holonomy on `F_t` is
   \[
   \boxed{G_tF_t-F_t=F_{-t}-F_t=\beta_t.}

   \]

### Proof

Equations `(9)` and `(10)` are coordinatewise. For `t>=0`, `p^(-2t)` is bounded, so Theorem 2.1

Finally,

\[

\tag{12}

which proves `(11)`. QED.

\[

\[

\[
