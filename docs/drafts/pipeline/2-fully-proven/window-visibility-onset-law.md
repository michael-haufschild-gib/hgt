- **Dilation left-continuity (`[TemperedConfig Z]`):** If `WindowPositiveAt Z a'` holds for all `0 ≤ a' < a` (`a > 0`), then for any `C²` test `f` with `tsupport f ⊆ [-a, a]`, the dilates `f_n(u) = f((1 + 1/(n+1)) u)` have `tsupport f_n ⊆ [-(a/(1 + 1/(n+1))), a/(1 + 1/(n+1))] ⊂ (-a, a)`.
