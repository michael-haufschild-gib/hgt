   - *Mertens/floor piece:* Set $K_N := \lfloor N / \exp(\sqrt{\log N}) \rfloor$. For $N$ large enough (or directly splitting at $m \le \sqrt{N}$: on $1 \le n \le m$, $N/n \ge \sqrt{N}$ gives $|e(N/n) - r_n| \le \frac{2 C_0}{\log N}$, contributing $\le \frac{4 C_0^2}{(\log N)^2} \sum_{n=1}^m \frac{\tilde{c}_m(n)^2}{n} \le \frac{4 C_0^2}{\log N}\|v_m\|^2$; on $m < n \le N$, `wiener_lorentzian_sum_le` and complete-period grouping of $\tilde{c}_m^2$ give $\frac{1}{\log N}\sum_{n=m+1}^N \operatorname{rem}(N/n)^2 \frac{\tilde{c}_m(n)^2}{n} \le \frac{C_0^2(3 + 4\pi^2)}{\log N}$).

   Dividing by $\log N$ gives $\|P_N v_m - (\log N - E_{\mathrm{arith}}(m)) v_m\| \le C_{p,1}\frac{1 + \log m}{\sqrt{\log N}}$. Since $E_{\mathrm{arith}}(m) = \log m + \operatorname{tameDifferent}(m) - \gamma \ge \log m - \gamma$,
   $$\operatorname{renormalizedPrimeEnergy}_N(v_m) \ge (\log m - \gamma)\|v_m\|^2 - C_{p,1}\frac{1 + \log m}{\sqrt{\log N}}\|v_m\|.$$

2. **Two-pole kernels ($A_{\mathrm{pole}}$ and $A_{\mathrm{poleErr}}$).** For $m \ge 2$, $\tilde{c}_m$ is $m$-periodic of period mean $0$ (`periodMean_normalizedRamanujanMode_mul`) and period $L^1$ norm $\sum_{r=0}^{m-1}|\tilde{c}_m(r)| \le m$ (`sum_range_abs_normalizedRamanujanMode_le`), so $|\sum_{j \in [l, k)} \tilde{c}_m(j)| \le m$ for all $l \le k$. ### Theorem 2 (Coercivity on $(V_{\lfloor N^\theta \rfloor})^\perp$ for $0 < \alpha < \frac{1}{16}$)

First derive the $D_0$-free reverse confinement gap (`poleDefect_ge_of_mem_conductorSubspace_orthog`): let $C_{\mathrm{conf}} > 0$ be the constant of `exists_quantitative_exponential_conductor_cutoff_of_poleDefect_le`. For $Q \ge 2$, $N \ge 2$, and $z \in V_Q^\perp \setminus \{0\}$, $\hat{z} := z/\|z\|$ has $\|\hat{z}\| = 1$ and $P_{V_Q}\hat{z} = 0$. Applying quantitative confinement to $\hat{z}$ at $\eta = \frac{1}{2}$ produces $R \ge 2$ with $\log R \le 8 C_{\mathrm{conf}}(\operatorname{poleDefect}_N(\hat{z}) + 1)$ and $\|\hat{z} - P_{V_R}\hat{z}\|^2 \le \frac{1}{2}$. Since $\|\hat{z} - P_{V_Q}\hat{z}\|^2 = 1 > \frac{1}{2}$, monotonicity of $V_R$ forces $Q < R$, hence
$$\operatorname{poleDefect}_N(z) \ge \Big(\frac{\log Q}{8 C_{\mathrm{conf}}} - 1\Big)\|z\|^2.$$
Now let $0 < \theta < 1$ and $0 < \alpha < \frac{1}{16}$, and set $Q_N := \lfloor N^\theta \rfloor$. By `exists_completeWeil_matrix_polynomial_reserve`, there exist $b > 0$ and $B > 0$ such that eventually $\operatorname{completeWeilEnergy}(\varphi_0, c, N, z) \ge \frac{b}{c^7}\operatorname{poleDefect}_N(z) - B c^9 \|z\|^2$. For $z \in V_{Q_N}^\perp$, $\frac{\log Q_N}{8 C_{\mathrm{conf}}} - 1 \ge \frac{\theta \log N}{16 C_{\mathrm{conf}}}$ eventually, while $B c^9 \le B (\log N)^{9\alpha} \ll \frac{b \theta}{32 C_{\mathrm{conf}}} (\log N)^{1 - 7\alpha} \le \frac{b \theta \log N}{32 C_{\mathrm{conf}} c^7}$ because $16\alpha < 1$. Thus $\operatorname{completeWeilEnergy}(\varphi_0, c, N, z) \ge \frac{b \theta}{32 C_{\mathrm{conf}}} \frac{\log N}{c^7}\|z\|^2$. Any subspace $U \le E_N$ on which $\operatorname{completeWeilEnergy}(\varphi_0, c, N, \cdot) \le 0$ satisfies $U \cap V_{Q_N}^\perp = \{0\}$, so $\dim_{\mathbb{R}} U \le \dim_{\mathbb{R}} V_{Q_N} \le \lfloor N^\theta \rfloor$.

### Theorem 3 (Optimal Self-Absorbing Tail Confinement $\log R' \le C_{16} c^{16} + \log Q_1$)

Given a unit vector $\hat{z} \in V_{Q_1}^\perp$ with $\operatorname{completeWeilEnergy}(\varphi_0, c, N, \hat{z}) \le 2\kappa + 2$, polynomial defect reserve gives $\operatorname{poleDefect}_N(\hat{z}) \le K_{\mathrm{coef}} c^{16}$ (`K_coef := (B + 2\kappa + 2)/b`). Apply `exists_quantitative_exponential_conductor_cutoff_of_poleDefect_le` at constant $\eta := \frac{1}{4}$: this gives $R_0 \ge 2$ with $\log R_0 \le 64 C_{\mathrm{conf}}(K_{\mathrm{coef}} c^{16} + 1)$ and $\|\hat{z} - P_{V_{R_0}}\hat{z}\|^2 \le \frac{1}{4}$. Set
$$R_{\mathrm{abs}} := \Big\lceil \exp\!\Big(8 C_{\mathrm{conf}}\Big(\frac{B + C_{\mathrm{cross}}^2}{b} c^{16} + 1\Big)\Big) \Big\rceil + 2, \qquad R' := \max(R_0, \max(Q_1, R_{\mathrm{abs}})).$$
Then $\log R' \le C_{16} c^{16} + \log Q_1$ for an explicit constant $C_{16} > 0$. Writing $\hat{z} = u + w$ with $u := P_{V_{R'}}\hat{z} \in V_{R'} \cap V_{Q_1}^\perp$ and $w := \hat{z} - u \in V_{R'}^\perp$:
- $\|w\|^2 \le \|\hat{z} - P_{V_{R_0}}\hat{z}\|^2 \le \frac{1}{4}$, so $\|u\|^2 = 1 - \|w\|^2 \ge \frac{3}{4}$ and $\|u\| \le 1$.
- Since $w \in V_{R'}^\perp$ and $R' \ge R_{\mathrm{abs}}$, the $D_0$-free reverse gap gives $\operatorname{poleDefect}_N(w) \ge \frac{B + C_{\mathrm{cross}}^2}{b} c^{16}\|w\|^2$. Therefore
  $$\operatorname{completeWeilEnergy}(\varphi_0, c, N, w) \ge \frac{b}{c^7}\operatorname{poleDefect}_N(w) - B c^9 \|w\|^2 \ge C_{\mathrm{cross}}^2 c^9 \|w\|^2 \ge C_{\mathrm{cross}}^2 c^6 \|w\|^2.$$
- Whenever $(1 + \log R')^2 \le \sqrt{\log N}$ and $(R')^6 \le N$, `exists_completeWeilMatrix_orthog_cross_le` gives $2|\langle W_{c,N} u, w \rangle| \le 2 C_{\mathrm{cross}} c^3 \|u\|\|w\| \le 1 + C_{\mathrm{cross}}^2 c^6 \|w\|^2$.
Combining the two inequalities yields $\operatorname{completeWeilEnergy}(\varphi_0, c, N, w) + 2\langle W_{c,N} u, w \rangle \ge -1$, hence $\operatorname{completeWeilEnergy}(\varphi_0, c, N, u) \le 2\kappa + 3$.

### Theorem 4 ($D_0$-Free High-Band Coercivity, Arbitrary-Root Upward Split, and Positivity for $0 < \alpha < \frac{1}{64}$)

1. **Arbitrary-root harmonic-quotient upward bound (`exists_completeWeil_uniform_conductor_residual_bound_root`).** For every integer $k \ge 2$ (specifically $k = 64$), splitting the affine shell source in `GrowingConductorShellsHaveUniformHarmonicBounds` at $Y_N := \exp((\log N)^{1/k})$ invokes `exists_conductor_uniform_affineShellCorrection_linear_log_rate` with exponent $k A$ and order $k$, yielding $(\log Y_N)^k = \log N$ on quotients $\ge 2 c Y_N$ and tail logarithm $1 + \log(4 c Y_N) \le 5 c (\log N)^{1/k}$, hence
   $$\|W_{c,N} v_m - E_m(c) v_m\|^2 \le K_k m^4 \Big(\frac{c^5}{\log N} + c^{10}\Big(\frac{\log N}{N}\Big)^2 + \frac{c^3}{(\log N)^{1 - 1/k}}\Big)$$
   eventually for all $0 < m \le (\log N)^A$ and $1 \le c$.

2. **$D_0$-free prime-packet coercivity on $y = \sum_{m=1}^{R'} b_m v_m$ ($b_m = 0$ for $m \le Q_1$).** For any coefficients $c_m, d_m$ on $[1, R']$ ($R'^2 \le N$), polarization with the parallelogram law $\sum(c'_m + d'_m)^2 + \sum(c'_m - d'_m)^2 = 4$ applied to `abs_norm_sum_normalizedRamanujanHorizonVector_sq_sub_le` gives

   Applying this to $c_m = b_m E_{\mathrm{arith}}(m)$ and $d_m = b_m$ (where $\log Q_1 - 1 \le E_{\mathrm{arith}}(m) \le 2(1 + \log R')$ on $\operatorname{supp}(b)$) and combining with `exists_fullPrimeMatrix_packet_residual_norm_le` ($\|P_N y - \sum b_m(\log N - E_{\mathrm{arith}}(m)) v_m\| \le 2 C_{\mathrm{pr}}\|y\|$ when $(1 + \log R')^2 \le \sqrt{\log N}$) and upper Riesz $\|y\|^2 \le \frac{3}{2}\sum b_m^2$ yields
   $$\operatorname{renormalizedPrimeEnergy}_N(y) \ge \Big(\frac{2}{3}\log Q_1 - (2 + 2 C_{\mathrm{pr}})\Big)\|y\|^2.$$

3. **Explicit rational exponent $\alpha < \frac{1}{64}$.** Fix $0 < \alpha < \frac{1}{64}$ and set $Q_1(N) := \lfloor (\log N)^{(17/2)\alpha} \rfloor$, $k := 64$. Across $1 \le c \le (\log N)^\alpha$:
   - *Low-band eigenvalue and decoupling budget:* $Q_1^5 c^{14} \cdot \operatorname{rate}_{64}$ has leading $\log N$-exponents $\frac{85}{2}\alpha + 19\alpha - 1 = \frac{123}{2}\alpha - 1 < \frac{123}{128} - 1 = -\frac{5}{128} < 0$ and $\frac{85}{2}\alpha + 17\alpha - \frac{63}{64} = \frac{119}{2}\alpha - \frac{63}{64} < \frac{119}{128} - \frac{126}{128} = -\frac{7}{128} < 0$.
   - *Confinement scale:* $\log R' \le C_{16}(\log N)^{16\alpha} + \frac{17}{2}\alpha \log\log N$ with $16\alpha < \frac{1}{4}$, so $(1 + \log R')^2 / \sqrt{\log N} \ll (\log N)^{32\alpha - 1/2} \to 0$ and $(R')^6 \le N$.
   - *Intermediate-band overlap:* $\frac{c^4}{\sqrt{Q_1}} \ll (\log N)^{4\alpha - (17/4)\alpha} = (\log N)^{-\alpha/4} \to 0$.
   - *High-band coercivity:* $\frac{1}{2}(\frac{2}{3}\log Q_1 - (2 + 2 C_{\mathrm{pr}})) - \log c \ge (\frac{17}{6} - 1)\alpha \log\log N - O(1) = \frac{11}{6}\alpha \log\log N - O(1) \to +\infty$.
   By `matrix_posDef_of_uniform_conductor_budget`, $\operatorname{spectralFloorWeilMatrix}(c, N)$ is positive definite on all vectors eventually, yielding $\operatorname{PosDef}$ of $\operatorname{completeWeilMatrix}(\varphi_0, c, N)$, the $\frac{\kappa}{2 c^7}\|x\|^2$ floor, literal $\operatorname{weilQuad} \ge 0$, zero-mass-loss $\operatorname{poleDefect}$ reserve, and (combining $[1, \lfloor (\log N)^9 \rfloor]$ from $\operatorname{PosDef}$ with $[\lceil (\log N)^9 \rceil, \lfloor N^\theta \rfloor]$ from Theorem 1 at $A = 9 > 8\alpha$) emptiness of nonpositive conductors across the entire interval $[1, \lfloor N^\theta \rfloor]$ for every $0 < \theta < \frac{1}{2}$ and $0 < \alpha < \frac{1}{64}$.
