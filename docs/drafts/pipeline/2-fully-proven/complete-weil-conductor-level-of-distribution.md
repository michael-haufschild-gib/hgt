## Complete Paper Proof (`[PROVED HERE]`)

Fix $0 < \theta < 1/2$ and set $M = M_N := \lfloor N^\theta \rfloor$. For $N$ sufficiently large, $2 \le M$ and $M^2 \le N$. Write $\tilde{c}_m(n) := c_m(n)/\sqrt{\varphi(m)}$ and $v_m(n) := \tilde{c}_m(n)/\sqrt{n \log N}$ on $\{1,\dots,N\}$.

### 1. Exact prime-power Gram locality and two-sided whole-prefix Riesz frame (`0 < θ < 1/2`)

1. **Lower Riesz frame.** By `ramanujanPoleProfile_family_squareRoot_lower`, for $M \ge 2$ and $N \ge 2$,
   $$\sum_{n=1}^N \left(\sum_{m=1}^M a_m \frac{\tilde{c}_m(n)}{\sqrt{n}}\right)^2 \ge \bigl(\log(N+1) - 2\log M\bigr)\sum_{m=1}^M a_m^2 \ge (1 - 2\theta)(\log N)\sum_{m=1}^M a_m^2.$$
   Dividing by $\log N$ yields $\|( \sum_{m=1}^M a_m v_m )\|^2 \ge (1 - 2\theta)\sum_{m=1}^M a_m^2$. In particular $\{v_1,\dots,v_M\}$ is linearly independent over $\mathbb{R}$ and $\dim_{\mathbb{R}} V_M = M$.

2. **Exact Gram decomposition and upper Riesz frame.** Using Kluyver's identity $c_m(n) = \sum_{d\mid\gcd(m,n)} d\,\mu(m/d)$ (`ramanujanLagCoefficient_eq_gcd_divisor_sum`), for $1 \le m,l \le M$ with $ml \le M^2 \le N$, every pair $d\mid m$, $e\mid l$ satisfies $L := \operatorname{lcm}(d,e) \le ml \le N$ and $de/L = \gcd(d,e)$, so
   $$\sum_{n=1}^N \frac{c_m(n)c_l(n)}{n} = \sum_{d\mid m}\sum_{e\mid l} \gcd(d,e)\,\mu(m/d)\,\mu(l/e)\,H_{\lfloor N/\operatorname{lcm}(d,e)\rfloor}.$$
   By `abs_harmonic_sub_log_sub_eulerMascheroni_le` and elementary floor-log comparison on $1 \le L \le N$, $H_{\lfloor N/L\rfloor} = (\log N + \gamma) - \log L + \eta(N,L)$ with $|\eta(N,L)| \le 3 L / N$. Expanding $\gcd(d,e) = \sum_{g\mid\gcd(d,e)} \varphi(g)$ and $\log\operatorname{lcm}(d,e) = \log d + \log e - \log\gcd(d,e)$:
   - Since $\sum_{u\mid k}\mu(k/u) = \delta_{k,1}$ and $\sum_{u\mid k}(\log u)\mu(k/u) = \Lambda(k)$, the $(\log N + \gamma)$ term equals $\delta_{m,l}\varphi(m)(\log N + \gamma)$.
   - Writing $n\log n = \sum_{g\mid n}\psi(g)$ by Möbius inversion ($\psi(m) = \sum_{d\mid m} d(\log d)\mu(m/d) = \varphi(m)(\log m - \operatorname{tameDifferent}(m))$ with sign convention $-\log\operatorname{lcm} = -\log d - \log e + \log\gcd$, giving diagonal $-\varphi(m)(\log m - \operatorname{tameDifferent}(m))$), the $\log\gcd(d,e)\gcd(d,e)$ term vanishes off the diagonal $m = l$, while the $-\log d\,\gcd(d,e)$ and $-\log e\,\gcd(d,e)$ terms vanish unless $l\mid m$ or $m\mid l$, where for $l < m$ ($l\mid m$) they evaluate to $-\varphi(l)\Lambda(m/l)$.
   Dividing by $\sqrt{\varphi(m)\varphi(l)}\log N$ yields
   $$\langle v_m, v_l \rangle = \delta_{m,l}\left(1 + \frac{\gamma - \log m + \operatorname{tameDifferent}(m)}{\log N}\right) - \frac{1}{\log N}\left(\mathbf{1}_{l\mid m,\,l<m}\sqrt{\frac{\varphi(l)}{\varphi(m)}}\Lambda(m/l) + \mathbf{1}_{m\mid l,\,m<l}\sqrt{\frac{\varphi(m)}{\varphi(l)}}\Lambda(l/m)\right) + E_{m,l}.$$
   - Diagonal: since $\operatorname{tameDifferent}(m) = \sum_{p\mid m}\frac{\log p}{p-1} \le \sum_{p\mid m}\log p \le \log m$ (`Real.log_le_sub_one_of_pos`), $-\log m + \operatorname{tameDifferent}(m) \le 0$, so the diagonal is at most $1 + \gamma/\log N \le 2$ for $\log N \ge 1$.
   - Prime-power off-diagonal $K_{m,l}$: weighted Schur with $w_m = m^{-1/2}$ gives, for $l = m p^k \le M$, $\sqrt{m/(mp^k)}\sqrt{\varphi(m)/\varphi(mp^k)}\Lambda(p^k) = \frac{\Lambda(p^k)}{p^{k/2}\sqrt{p^{k-1}(p-1)}} \le \sqrt{2}\frac{\Lambda(p^k)}{p^k}$ (sum over $p^k \le M$ at most $\sqrt{2}\log M$), and for $l = m/p^k$ ($p^k\mid m$), $\sqrt{p^k}\frac{\Lambda(p^k)}{\sqrt{p^{k-1}(p-1)}} = \sqrt{\frac{p}{p-1}}\Lambda(p^k) \le \sqrt{2}\Lambda(p^k)$ (sum over $d\mid m$ equal to $\sqrt{2}\log m \le \sqrt{2}\log M$). Thus $\|K\|_{\mathrm{op}} \le \sqrt{2}\frac{\log M}{\log N} \le \sqrt{2}$.
   - Remainder $E_{m,l}$: $\gcd(d,e)|\eta(N,\operatorname{lcm}(d,e))| \le 3 de/N$, so $|E_{m,l}| \le \frac{3}{N\log N} f(m)f(l)$ where $f(m) := \varphi(m)^{-1/2}\sum_{d\mid m} d|\mu(m/d)|$. By multiplicativity over $p^e \parallel m$, $f(p^e)^2 = p^e \frac{(p+1)^2}{p(p-1)} \le p^e (1 + 7/p)$ since $(p+7)(p-1) - (p+1)^2 = 4(p-2) \ge 0$ for $p \ge 2$. Hence $f(m)^2 \le m\sum_{r\mid m}\mu(r)^2 7^{\omega(r)}/r$, and summing $m = rk \le M$ gives
     $$\sum_{m=1}^M f(m)^2 \le M^2 \sum_{r=1}^M \frac{\mu(r)^2 7^{\omega(r)}}{r^2} \le M^2 \prod_{p\le M}\left(1 + \frac{7}{p^2}\right) \le e^7 M^2.$$
     Thus $\|E\|_{\mathrm{op}} \le \frac{3 e^7 M^2}{N\log N} \le \frac{3 e^7}{\log N} \le 1$ for $\log N \ge 3 e^7$.
   Combining all three pieces gives the uniform upper Riesz frame bound $\|\sum_{m=1}^M a_m v_m\|^2 \le 5 \sum_{m=1}^M a_m^2$ for all $M^2 \le N$ and $\log N \ge 3 e^7$ (and in particular $\|v_m\|^2 \le 5$ for each $1 \le m \le M$).

3. **Divisor-totient packet envelope.** By Hölder's formula (`sieveLagMultiplier_eq_moebius_totient_quotient`), for $d = \gcd(m,n)$ and $r = m/d$, $\tilde{c}_m(n)^2 = \mu(r)^2 \varphi(m)/\varphi(r)^2 \le \varphi(d)\,\mu(r)^2 r/\varphi(r)^2$ (using $\varphi(dr) \le r\varphi(d)$). Since $p/(p-1)^2 \le 4/p$ for every prime $p \ge 2$ ($4(p-1)^2 - p = 4p^2 - 9p + 4 > 0$), $\mu(r)^2 r/\varphi(r)^2 \le \mu(r)^2 4^{\omega(r)}/r$. Injecting subsets $(S_1,S_2) \subseteq \operatorname{primeFactors}(r)^2$ into $(Icc\,1\,M)^4$ via $(S_1\cap S_2, S_1\setminus S_2, S_2\setminus S_1, \operatorname{primeFactors}(r)\setminus(S_1\cup S_2))$ yields $\sum_{r=1}^M \mu(r)^2 4^{\omega(r)}/r \le H_M^4 \le (1 + \log M)^4$. Using $\sum_{d\mid n}\varphi(d) = n$, for every $n \ge 1$ and $M \ge 1$:
   $$\sum_{m=1}^M \tilde{c}_m(n)^2 \le n(1 + \log M)^4.$$

### 2. Unconditional level of distribution for `fullPrimeMatrix` (`0 < θ < 1/2`)

By `OneArithmeticRemainderControlsEveryRamanujanResidual.lean`, for $n \in [1,N]$, $|p_m(n)| \le \frac{1}{\sqrt{n\log N}}(A_{m,n} + B_{m,n})$ with $A_{m,n} = \operatorname{primeMertensRemainderProfile}(\lfloor N/n\rfloor)|\tilde{c}_m(n)|$ and $B_{m,n} = |\operatorname{poleProfileCorrection}(\tilde{c}_m,\lfloor N/n\rfloor,n) + (\log m + \operatorname{tameDifferent}(m))\tilde{c}_m(n)|$.
- **Mertens piece $A_{m,n}$:** By `exists_primeMertensRemainder_log_envelope`, $\operatorname{primeMertensRemainderProfile}(y) \le C_0/(1 + \log y)$.
  - For $1 \le n \le M$: $\lfloor N/n\rfloor \ge \lfloor N/M\rfloor \ge \sqrt{N}/2$, so $1 + \log\lfloor N/n\rfloor \ge \frac{1}{3}\log N$. Summing over $m \le M$ via §1.3 gives $\frac{1}{\log N}\sum_{n=1}^M \frac{9 C_0^2}{(\log N)^2}(1 + \log M)^4 \le C_1 M \log N$.
  - For $M < n \le N$: $n > m$ for every $m \le M$. On $m < n \le \min(2m,N)$, $\sum_n \tilde{c}_m(n)^2/n \le \frac{1}{m}\sum_{r=0}^{m-1}\tilde{c}_m(r)^2 = 1$, contributing $C_0^2/\log N$. For $k \ge 2$, on $B_k = [km+1,\min((k+1)m,N)]$, every $n \in B_k$ and every $u$ in the disjoint previous full period $P_k = [(k-1)m+1,km] \subseteq [1,N]$ satisfy $u \le km < n \le (k+1)m \le 3u$, hence $1 + \log\lfloor N/u\rfloor \le 3(1 + \log\lfloor N/n\rfloor)$ and $\frac{1}{km} \le \frac{1}{u}$. Periodicity $\sum_{r=0}^{m-1}\tilde{c}_m(r)^2 = m$ bounds the sum over $k \ge 2$ by $9 C_0^2 \sum_{u=1}^N \frac{1}{u(1+\log\lfloor N/u\rfloor)^2} \le 18 C_0^2(1 + 2\pi^2)$ (`wiener_constant_kernel_sum_le`). Dividing by $\log N$ and summing over $m \le M$ gives $O(M/\log N)$.
- **Prime-tower tail $B_{m,n}$:**
  - For $1 \le n \le \lfloor N/m\rfloor$: `abs_normalizedRamanujan_correction_le` gives $B_{m,n} \le 4\sqrt{\varphi(m)}\log m/\lfloor N/n\rfloor \le 8\sqrt{m}(\log m) n/N$. Summing $B_{m,n}^2/n$ over $n \le N/m$ gives $\frac{64 m(\log m)^2}{N^2}\sum_{n\le N/m} n \le \frac{64(\log m)^2}{m} \le 64(\log m)^2$.
  - For $\lfloor N/m\rfloor < n \le N$: $y = \lfloor N/n\rfloor \in \{1,\dots,m-1\}$. By `TheRamanujanPrimeCorrectionHasAUniformTail.lean`, $B_{m,n} \le T_m(y,n) := \sum_{t > y} \mu_m(t)(|\tilde{c}_m(nt)| + |\tilde{c}_m(n)|)$, where $\mu_m(t) = \sum_{p\in\operatorname{primeFactors}(m)}\operatorname{localMangoldtMass}(p,t)$ and $T_m(y,\cdot)$ is $m$-periodic. For any $t \ge 1$ and $g = \gcd(m,t)$, multiplication by $t/g$ permutes $\mathbb{Z}/(m/g)\mathbb{Z}$, so $\sum_{r=0}^{m-1}\tilde{c}_m(rt)^2 \le g\sum_{s=0}^{m-1}\tilde{c}_m(s)^2 = gm$. Moreover, at $p^e \parallel m$, $\sum_{k\ge 1}\frac{\log p}{p^k}\gcd(m,p^k) = (\log p)(\sum_{k=1}^e 1 + \sum_{k>e} p^{e-k}) \le 2 e\log p$, so $\sum_{t\ge 1}\mu_m(t)\gcd(m,t) \le 2\log m$. Cauchy–Schwarz over $t > y$ gives $\frac{1}{m}\sum_{r=0}^{m-1} T_m(y,r)^2 \le (8\log m)\sum_{t>y}\mu_m(t)$. Covering $I_y = (\lfloor N/(y+1)\rfloor, \lfloor N/y\rfloor]$ (where $1/n \le (y+1)/N$) by $\le \frac{N}{my(y+1)} + 2$ periods of length $m$ and summing $1 \le y < m$:
    - $\sum_{y=1}^{m-1}\frac{1}{y}\sum_{t>y}\mu_m(t) \le \sum_{p\mid m}(\log p)\sum_{k=1}^\infty \frac{1+k\log p}{p^k} \le 3\sum_{p\mid m}\log p \le 3\log m$ (using $\log p \le p - 1$),
    - $\sum_{y=1}^{m-1}\frac{2m(y+1)}{N}\sum_{t>y}\mu_m(t) \le \sum_{y=1}^{m-1}\frac{2m(2y)}{N}\frac{2\log m}{y} \le \frac{8m^2\log m}{N} \le 8\log m$ for $m^2 \le N$.
    Multiplying by $8\log m / \log N$ gives $O((\log m)^2/\log N) = O(\log N)$ per $m$.
Hence $\sum_{m=1}^M \|p_m\|^2 \le C_p M\log N$.

### 3. Complete-Weil residual bounds and Q3 at RH-complete overlap

By `completeWeilMatrix_ramanujan_residual_eq_at_every_overlap`, $(W_{N,c} - E_m(c))v_m = -p_m + s_m + c_m - x_m + q_m + (y_m + z_m) - u_m$. For $c \ge 1$, $c/N \le 1/3$, $\log N \ge 3e^7$, $M = \lfloor N^\theta\rfloor$ ($M^2 \le N$), using $\|v_m\|^2 \le 5$:
1. **Self error $s_m$:** $|e_{\mathrm{self}}| \le \frac{e^{1/2}}{2}\frac{c}{N}$, so $\|s_m\|^2 \le C_s c^2/N^2 \le C_s c^2$.
2. **Center error $c_m$:** At $m = 1$, $\|c_1\|^2 \le C c^2/\log N$ (`exists_centerError_uniform_conductor_bound`). For $2 \le m \le M$, `fullWeilCenterMatrix` splits into two rank-1 pole products (Frobenius norm squared $O(c^2\log N)$), the $(n+j)^{-1}$ collar (AM-GM gives Frobenius norm squared $O(c^2)$), and $H_{n,j} = \frac{\alpha_c}{2N}\frac{\sqrt{nj}}{|n-j|}\mathbf{1}_{j\ne n}$. Writing $\sqrt{j}v_m(j) = \sqrt{N}u_m(j)$ with $\|u_m\|^2 = \frac{1}{N\log N}\sum_{j=1}^N \tilde{c}_m(j)^2 \le \frac{2}{\log N}$ (by $m$-periodicity and $m \le N$) and $\sqrt{n/N} \le 1$, triangle inequality over offsets $h = |n - j| \in [1,N]$ gives $\|H v_m\| \le |\alpha_c| H_N \|u_m\|$, so $\|H v_m\|^2 \le C c^2\log N$. Thus $\|c_m\|^2 \le C_c c^2\log N$.
3. **Separated cross error $x_m$:** By `abs_separatedCrossError_le`, $|X_{n,j}| \le K_0 (c/N)^2 \max(n,j)^2/|n-j|^2 \le K_0 c^2/|n-j|^2$ ($j \ne n$). Offset triangle inequality ($\sum_{h\ge 1} h^{-2} \le 2$) gives $\|X x\|^2 \le 16 K_0^2 c^4 \|x\|^2$.
4. **Pole moment error $q_m$:** Frobenius norm squared of `fullWeilPoleErrorMatrix` is $O(c^4\log N/N^2) \le C_q c^4$, so $\|q_m\|^2 \le C_q c^4 \|v_m\|^2$.
5. **Near-center vector $z_m$:** By `abs_nearCenter_entry_le`, entries in `nearRowIndices c N n` ($|j - n| \le \lceil 2ec\rceil$) are $O(c)$, so offset triangle inequality gives $\|z_m\|^2 \le C_z c^4 \|v_m\|^2$.
6. **Near-Gamma downward vector $y_m$:** Splitting into interior near-row terms and exterior downward terms (`NearGammaDownwardCancellationHasPolynomialGrowth.lean`):
   - The first two interior pieces have entries $O(c)$ on $|j - n| \le \lceil 2e^2 c\rceil$, giving $O(c^4\|v_m\|^2)$.
   - The divisor-jet piece acts on $w_m(j) = \mathbf{1}_{j \ge N/(2e^2 c)} \operatorname{ramanujanLogDivisorJet}(m,j)/\sqrt{\varphi(m)j\log N}$ by a near-row kernel of offset width $O(c)$ and entry bound $1$, hence operator norm $O(c)$. When $4e^2 c m \le N$, covering $[N/(2e^2 c),N]$ by period-$m$ blocks $B_k = [km,(k+1)m)$ ($k \ge k_0 := \lfloor N/(4e^2 c m)\rfloor \ge 1$) and applying `sum_range_ramanujanLogDivisorJet_sq` and `sum_vonMangoldt_sq_mul_totient_le` ($\sum_{r=0}^{m-1}\operatorname{jet}^2 \le 2m\varphi(m)(\log m)^2$) with $\sum_{k=k_0}^{\lceil N/m\rceil} 1/k \le C(1 + \log c)$ gives $\|w_m\|^2 \le C(1+\log c)(\log m)^2/\log N \le C(1+\log c)\log N$, hence $\|Q w_m\|^2 \le C_y c^2(1+\log c)\log N$.
   - For the exterior downward piece on $n \in [N - B, N]$ and $\ell \in (N, N + B]$ ($B = \lceil ec\rceil$), Cauchy–Schwarz over $k\mid\ell$ ($\sum_{k\mid\ell}\Lambda(k) = \log\ell$) and §1.3 ($\sum_{m=1}^M \tilde{c}_m(\ell/k)^2 \le (\ell/k)(1 + \log M)^4$) give $\sum_{m=1}^M \|y_{m,\mathrm{ext}}\|^2 \le C_{\mathrm{ext}} c^3 (\log N)^5$.
7. **Upward prime residual $u_m$:**
   - On $[h/c,1]$ ($1 \le h < \lceil c\rceil$), $|u|^{-1} \le c$ and $|\operatorname{shellAutocorr}\,\varphi\,u| \le \int\varphi^2$, so `completedShellCorrectionBudget` $\le 4c^2$ ($c \ge 1$), giving $(\operatorname{shellCorrection}\,\varphi\,c\,m)^2\|v_m\|^2 \le 80 c^4$.
   - For `upwardPrimeVector`, weighted Schur with $w_n = n^{-1/2}$ has row sum $\le C_1 c$ (`up_row_le` at $w = c/N \le 1$) and column sum at $j$: for $T = kn \ne j$ with $|\log T - \log j| \le c/N$, $|T - j| \le \lceil ec\rceil$, $\sqrt{j/T} \le e^{1/2}$, and $\sum_{k\mid T}\Lambda(k) = \log T \le \log(2N)$, giving column sum $\le C_2 c\log N$. Hence $\|\operatorname{upwardPrimeVector}\,\varphi\,c\,N\,x\|^2 \le C_{\mathrm{up}} c^2(\log N)\|x\|^2$.
8. **Denominator lower bound:** By `completedConductorEnergy_log_lower`, $E_m(c) \ge \log m + \operatorname{selfFP}(c) - 4c^2$ with $|\operatorname{selfFP}(c)| = O(1 + \log c) \le C c^2$. Whenever $c_N^2(1 + \log c_N)/\log N \to 0$, for $m \in [\lceil M/2\rceil, M]$ eventually $E_m(c_N) \ge \frac{\theta}{2}\log N$, so $\sum_{m=1}^M E_m(c_N)^2 \ge \frac{\theta^2}{16} M(\log N)^2$, whereas $\sum_{m=1}^M \|r_m\|^2 = O(M(\log N + c_N^2(1+\log c_N)\log N + c_N^4) + c_N^3(\log N)^5) = o(M(\log N)^2)$. This proves Q3.

### 4. Conductor-average positivity, `o(M)` census, and `κ(W_{N,c_N}|_{V_M}) = o(M)`

1. **Conductor-average positivity and census:** Writing $\langle W v_m, v_m\rangle = E_m \|v_m\|^2 + \langle r_m, v_m\rangle$: by `ramanujanPoleProfile_gram_error_le_nat`, $|\|v_1\|^2 - 1| = O(1/\log N)$, and in fact by §1.2 every $1 \le m \le M$ satisfies $\|v_m\|^2 \ge 1 - \theta - O(1/\log N) \ge 1 - 2\theta$ (`half_sum_sq` / §1.1 on $e_m$). Thus $\langle W v_m, v_m\rangle \ge (1 - 2\theta)E_m - \sqrt{5}\|r_m\|$. Averaging over $1 \le m \le M$: $\frac{1}{M}\sum_{m=1}^M E_m \ge \frac{\theta}{4}\log N$ (using $E_m \ge -C c_N^2$ for $m < M/2$ and $E_m \ge \frac{\theta}{2}\log N$ for $m \ge M/2$), while $\frac{1}{M}\sum_{m=1}^M \|r_m\| \le (\frac{1}{M}\sum \|r_m\|^2)^{1/2} = o(\log N)$, so $\frac{1}{M}\sum_{m=1}^M \operatorname{completeWeilEnergy}\,\varphi\,c_N\,N\,v_m \to +\infty$. Chebyshev's inequality on $\{m \le M : \operatorname{completeWeilEnergy}\,\varphi\,c_N\,N\,v_m \le 0\}$ (noting that for $m \ge M^\eta$ eventually $(1-2\theta)E_m > 0$, so nonpositivity forces $\|r_m\| \ge \frac{1-2\theta}{\sqrt{5}}E_m \ge c_\eta\log N$) shows $\#\{m \le M : \operatorname{completeWeilEnergy}\,\varphi\,c_N\,N\,v_m \le 0\} / M \to 0$.
2. **Sublinear negative index on $V_M$:** Let $U \subseteq V_M$ satisfy $\operatorname{completeWeilEnergy}\,\varphi\,c_N\,N\,x \le 0$ for all $x \in U$. Given $\varepsilon \in (0,1)$, set $\delta = \varepsilon/2$ and $M_0 = \lfloor\delta M\rfloor$. By rank-nullity on the low-conductor coordinate projection $V_M \to \mathbb{R}^{M_0}$, $\dim U \le M_0 + r$ where $r = \dim(U \cap V_{(M_0,M]})$. Choose an orthonormal basis $b^{(1)},\dots,b^{(r)}$ of the coefficient image of $U \cap V_{(M_0,M]}$ in $\mathbb{R}^{(M_0,M]}$, and set $x^{(i)} = \sum_{m=M_0+1}^M b^{(i)}_m v_m \in U$. For $m \in (M_0,M]$, splitting primes $p\mid m$ at $\sqrt{2\log N}$ gives $0 \le \operatorname{tameDifferent}(m) \le 3\sqrt{\log N}$, so $E_m = E_* + \Delta_m$ with $E_* = \log(M_0+1) + \gamma + \operatorname{selfFP}(c_N) \ge \frac{\theta}{2}\log N$ and $|\Delta_m| \le \log(1/\delta) + 3\sqrt{\log N} + 4c_N^2 = o(\log N)$. By §1.1–1.2, $\langle \sum_m b^{(i)}_m E_m v_m, x^{(i)}\rangle \ge (1-2\theta)E_* - 5\max|\Delta_m| \ge \frac{1-2\theta}{2}E_*$ eventually. Since $\langle W x^{(i)}, x^{(i)}\rangle \le 0$, Cauchy–Schwarz over $m$ gives $\frac{(1-2\theta)^2}{4}E_*^2 \le \sum_{m=M_0+1}^M \langle r_m, x^{(i)}\rangle^2$. Summing over $i = 1,\dots,r$ and applying Bessel's inequality in coefficient space together with dual upper frame Bessel ($\sum_{i=1}^r \langle y, x^{(i)}\rangle^2 \le \sum_{m=1}^M \langle y, v_m\rangle^2 \le 5\|y\|^2$) gives $r \cdot \frac{(1-2\theta)^2}{4}E_*^2 \le 5\sum_{m=1}^M \|r_m\|^2 = o(M(\log N)^2)$, whence $r \le \frac{\varepsilon}{2}M$ eventually and $\dim U \le \varepsilon M$.
