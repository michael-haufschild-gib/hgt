# Global confining gap, boundary outerness, and Lipschitz parameter response

- **ID:** global-confining-transverse-gap-and-response
- **Stage:** 2-fully-proven
- **Type:** THEOREM (paper)
- **Target:** B16, B17; universal regularity, boundary outerness, causal cyclicity, transverse spectral gap, and `C^{1,1}_{\mathrm{loc}}` parameter response of the attained half-line ground state at every positive ratio `R > 0`.
- **Statement:** At every ratio `R > 0`, any normalized minimizer `F_R` of `criticalHalfLineFullEnergy R` has positive square mass on every terminal interval `(-d, 0)`, zero-free Laplace transform on the closed right half-plane `Re z ≥ 0`, outer Cayley–Laplace multiplier, and reflected state cyclic for causal translations on `L²(0, ∞)`. The shifted form `Q_R(G) := E_R(G) - λ(R) ∫ G²` (`λ(R) := criticalHalfLineGroundEnergy R`) satisfies `Q_R(G_⊥) = Q_R(G)` on `G_⊥ = G - (∫ F_R G) F_R` and obeys `γ_R ∫ G_⊥² e^{-8u} ≤ Q_R(G)` for some `γ_R > 0`. Consequently `λ ∈ C^{1,1}_{\mathrm{loc}}(0, ∞)` and `μ(t) := λ(t⁻¹) ∈ C^{1,1}_{\mathrm{loc}}(0, ∞)` with `λ'(R) = -(a(R)/R) W_8(F_R)` and `μ'(t) = a(1) W_8(F_{t⁻¹})`, while `R ↦ ±F_R` (in the `L²(e^{-8u})` norm), `R ↦ W_8(F_R)`, and `R ↦ ±∫ F_R · polarSourceProfile` are locally Lipschitz on `(0, ∞)`.

## Proof

Fix `R > 0` and let `F = F_R` satisfy `IsHalfLineEnergyMinimizer R F`, so `F ∈ CriticalHalfLineEnergyDomain`, `∫ F² = 1`, and `E_R(F) = λ(R)` (`exists_criticalHalfLineGroundEnergy_minimizer`).

1. **Terminal endpoint mass (`IsHalfLineEnergyMinimizer.endpoint_mass_pos`).** Suppose `∫_{-d}^0 F² = 0` for some `d > 0`. Replacing `F` by `G = 1_{(-∞, -d/2)} F` preserves domain membership, `∫ G² = 1`, and `E_R(G) = λ(R)`. Since `G(u - d/2)` vanishes on `[0, ∞)` and `∫ G(u - d/2)² = ∫ G² = 1`, `criticalHalfLineFullEnergy_comp_add_right` gives
   $$E_R(G(\cdot - d/2)) = \lambda(R) + a(R)\bigl(e^{-4d} - 1\bigr) W_8(G) < \lambda(R)$$
   because `a(R) > 0`, `e^{-4d} < 1`, and `W_8(G) ≥ ∫ G² = 1`, contradicting `λ(R) ≤ E_R(G(\cdot - d/2))`.

2. **Closed right-half-plane Laplace zero-freeness, outerness, and cyclicity (`IsHalfLineEnergyMinimizer.closedRightHalfPlaneLaplace_ne_zero`, `laplaceMultiplier_outer`, `causalCyclicSubspace_eq_top`).** Open right-half-plane nonvanishing `Re z > 0` holds by `IsHalfLineEnergyMinimizer.complexLaplace_ne_zero`. For `z = i 2π b` (`b ∈ ℝ`), assume `negativeHalfLineLaplace (cx F) (modulatedLaplaceRate 0 b) = 0`, and set `H := realUndampedCausalConvolution b F ∈ CriticalHalfLineEnergyDomain`. By `gammaFourierPair_realUndampedCausalConvolution`, `gammaFourierPair F H r = 0` for all `r ∈ ℝ`, so `‖𝓕(cx(F + H)) ξ‖ = ‖𝓕(cx(F - H)) ξ‖` for all `ξ ∈ ℝ`. Applying `integral_conj_mul_translate_eq_of_fourier_norm` at lag `0` yields `∫ (F + H)² = ∫ (F - H)²`, hence `∫ F H = 0`. Thus the eigenvalue term `λ(R) ∫ F H` in `hF.weakEquation hR hH` vanishes: `criticalHalfLineMixedEnergy R F H = 0`. By `arithmetic_mixed_realUndampedCausalConvolution_eq_zero` and `pole_mixed_realUndampedCausalConvolution_eq_zero`, the Gamma, prime, and polar mixed terms vanish, leaving `a(R)(4/π) ∫ ‖causalLaplaceWeighted (4/π) (modulatedCausalConvolution 0 b (cx F))‖² = 0`. Since `a(R)(4/π) > 0`, the undamped convolution vanishes a.e., whence `cx F = 0` a.e. by `fourier_undampedCausalConvolution_mul` and Fourier uniqueness (`ae_eq_zero_of_fourierIntegral_eq_zero`), contradicting `∫ F² = 1`. Combining closed-RHP nonvanishing with step 1 yields `IsOuterDiskMultiplier` via `isOuter_negativeHalfLineLaplaceDiskMultiplier`, and Paley–Wiener transport (`causalCyclicSubspace_eq_top_of_outerLaplace`) yields `causalCyclicSubspace = ⊤`.

3. **Neutral projection and positive eighth-exponential transverse gap (`shiftedEnergy_neutralPart`, `transverse_L2_gap`, `transverse_exponential_gap`, `controls_neutralPart`).** Define `Q_R(G) := E_R(G) - λ(R) ∫ G² ≥ 0` (`criticalHalfLineGroundEnergy_mul_mass_le_all`). Expanding `E_R(G - c F)` and `∫ (G - c F)²` at `c = ∫ F G` and substituting `E_R(F) = λ(R)`, `∫ F² = 1`, and `criticalHalfLineMixedEnergy R F G = λ(R) c` (`weakEquation`) gives `Q_R(G_⊥) = Q_R(G)`.
   Suppose no `δ > 0` satisfies `δ ∫ G² ≤ Q_R(G)` on `{G : ∫ F G = 0}`. Normalization produces `G_n` with `∫ G_n² = 1`, `∫ F G_n = 0`, and `Q_R(G_n) < 1/(n+1)`, so `E_R(G_n) < λ(R) + 1/(n+1)`. By `criticalHalfLineFullEnergy_coercive_remainder`, `(a(R)/2) W_8(G_n) ≤ E_R(G_n) + B ≤ λ(R) + 1 + B`, bounding `W_8(G_n) ≤ M`. Applying `exists_window_energy_recovery` at tolerance `e_n = 1/(n+1)` supplies smooth compactly supported negative-half-line profiles `H_n` with `∫ H_n² ≤ 1`, `∫ (H_n - G_n)² < e_n`, `W_8(H_n) ≤ 2M`, and `E_R(H_n) < E_R(G_n) + e_n < λ(R) + 2 e_n`. Since `λ(R) ∫ H_n² ≤ E_R(H_n)` and `∫ H_n² → 1`, squeeze gives `E_R(H_n) → λ(R)`. By `exists_domain_limit_of_smooth_energy_limit`, a subsequence `H_{s(n)}` converges in `L²` and `L¹` to `K ∈ CriticalHalfLineEnergyDomain` with `∫ K² = 1` and `E_R(K) ≤ λ(R)`, so `IsHalfLineEnergyMinimizer R K`. `L²` convergence passes `∫ F G_n = 0` to `∫ F K = 0`, contradicting `K = ±F` a.e. (`halfLineEnergyMinimizer_unique_up_to_sign`). Interpolating `δ ∫ G² ≤ Q_R(G)` with `(a(R)/2) W_8(G) ≤ Q_R(G) + (B + |λ(R)|) ∫ G²` yields `γ_R > 0` with `γ_R W_8(G) ≤ Q_R(G)` for `∫ F G = 0`, hence `γ_R W_8(G_⊥) ≤ Q_R(G)` for all `G`.

4. **Quadratic tangent, `C¹` differentiability, and optimal local Lipschitz response (`quadratic_tangent`, `hasDerivAt_criticalHalfLineGroundEnergy_all`, `minimizer_lipschitz_stability`).** Fix `R > 0` with unit minimizer `F` (`w := W_8(F) ≥ 1`, gap `γ = γ_R > 0`). For any unit `G` and `S > 0`, let `η := a(S) - a(R)`, `c := ∫ F G`, `N := G_⊥`, `m := ∫ N² = 1 - c²`, `n := W_8(N) ≥ m`, `q := ∫ N F e^{-8u}`. Then
   $$E_S(G) - \lambda(R) = Q_R(G) + \eta\bigl(n + 2 c q + (1 - m) w\bigr) \ge \gamma n + \eta\bigl(n + 2 c q + (1 - m) w\bigr).$$
   Completing the weighted square `0 ≤ W_8(N + (2 η c / γ) F) = n + (4 η c / γ) q + (4 η² c² / γ²) w` shows that for `|η| ≤ γ / (2(1 + w))`, `E_S(G) ≥ λ(R) + η w - (2 w / γ) η²`, while testing `F` gives `λ(S) ≤ E_S(F) = λ(R) + η w`. Hence `|λ(S) - λ(R) - w(a(S) - a(R))| ≤ (2 w / γ)(a(S) - a(R))²`. Applying `hasDerivAt_of_quadratic_comparison` to `a'(R) = -a(R)/R` gives `HasDerivAt λ (-(a(R)/R) W_8(F)) R`, and composing with `t ↦ t⁻¹` gives `HasDerivAt μ (a(1) W_8(F_{t⁻¹})) t`.
   Now let `H` be any unit minimizer at `S > 0`. Adding `Q_R(H) = E_R(H) - λ(R)` and `0 ≤ Q_S(F) = E_S(F) - λ(S)` and using `E_R(H) - E_S(H) = -η W_8(H)` and `E_S(F) - E_R(F) = η W_8(F)` yields the exact symmetric identity
   $$Q_R(H) + Q_S(F) = \eta\bigl(W_8(F) - W_8(H)\bigr), \qquad \gamma n \le Q_R(H) \le |\eta| \, |W_8(H) - W_8(F)|.$$
   Choose `σ ∈ {1, -1}` with `σ c = |c| ≥ 0`, and set `D := H - σ F = N + (c - σ) F`, `d := W_8(D)`. Since `|c - σ| = 1 - |c| ≤ (1 - |c|)(1 + |c|) = 1 - c² = m ≤ n`, we have `(c - σ)² ≤ n²`. For `|η| ≤ min(γ / (4(1 + w)), γ / (12 w))`, the crude bound `γ n ≤ |η|(3w + 2n)` already gives `n ≤ (6w/γ)|η| ≤ 1/2 ≤ 1`, so `(c - σ)² ≤ n` and `d ≤ 2n + 2(c - σ)² w ≤ 2(1 + w)n`. Moreover `H² - (σ F)² = D(2 σ F + D)`, so weighted Cauchy–Schwarz gives
   $$|W_8(H) - W_8(F)| = \left|\int D(2\sigma F + D)e^{-8u}\right| \le 2\sqrt{w}\sqrt{d} + d.$$
   Combining `d / (2(1 + w)) ≤ n` with `γ n ≤ |η|(2\sqrt{w}\sqrt{d} + d)` gives
   $$\frac{\gamma}{2(1 + w)} d \le 2\sqrt{w}|\eta|\sqrt{d} + |\eta| d.$$
   Since `|η| ≤ γ / (4(1 + w))`, subtracting `|η| d` yields `(γ / (4(1 + w))) d ≤ 2\sqrt{w} |η| \sqrt{d}`, hence
   $$\sqrt{d} \le \frac{8(1 + w)\sqrt{w}}{\gamma}\,|a(S) - a(R)|, \qquad d \le \frac{64(1 + w)^2 w}{\gamma^2}\,|a(S) - a(R)|^2,$$
   and consequently `|W_8(H) - W_8(F)| ≤ L |a(S) - a(R)|` and `|∫ H · polarSourceProfile - σ ∫ F · polarSourceProfile| ≤ L_p |a(S) - a(R)|`. Since `R ↦ a(R) = a(1)/R` is smooth on `(0, ∞)`, `R ↦ W_8(F_R)`, `λ'`, and `μ'` are locally Lipschitz on `(0, ∞)`.
