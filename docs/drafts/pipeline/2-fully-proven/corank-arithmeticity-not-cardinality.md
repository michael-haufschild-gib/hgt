## §1 The continuation block of a finite Beurling system `[PROVED HERE]`

Let `B = {g_1,…,g_r}` be **generalized primes** (reals `g_i > 1`, multiplicatively independent), with
generalized zeta `ζ_B(s) = ∏_{i=1}^{r} (1 − g_i^{-s})^{-1}`. Write `L_i = log g_i`.

**Pole and Laurent block at `s=0`.** Each factor `1 − g_i^{-s} = 1 − e^{-sL_i} = sL_i\,(1 − sL_i/2 + sL_i^2/12 − …)`
(an `e^{sL_i}` Bernoulli expansion), so
```
   ζ_B(s) = s^{-r} · ( ∏_i L_i )^{-1} · ( 1 + c_1 s + c_2 s^2 + … ),     c_1 = (1/2)·e_1(L),  c_2 = (…)·e_1(L)^2 + (…)·e_2(L) + (…)ΣL_i^2, …
```
where `e_k(L)` are the elementary symmetric functions of `L_1,…,L_r` and every `c_k ∈ ℚ[L_1,…,L_r]^{S_r}`
(symmetric, rational-coefficient). Numerically certified: leading coefficient `ζ_B(s)·s^r → 1/∏L_i` to
rel.err `~10^{-12}` for `B = {2,3}, {2,3,5}, {e,π}, {e,π,√2 e}`, and `c_0 = 1/2` for `r=1`.

Hence the **continuation block** `T_0(ζ_B) := ℚ̄`-field generated by the Laurent coefficients satisfies
```
   T_0(ζ_B) = ℚ̄( e_1(L), …, e_r(L) )  ⊆  ℚ̄(L_1,…,L_r).
```

**trdeg = corank ⟺ value-independence.** The multiplier group is `⟨g_1,…,g_r⟩`, so
`corank(Λ_B) = dim_ℚ span{L_i} = r` (multiplicative independence ⟹ `{L_i}` ℚ-linearly independent).
The general upper bound (sibling card §3) gives `trdeg_ℚ̄ T_0 ≤ r`. The lower bound is exact:
```
   trdeg_ℚ̄ T_0(ζ_B) = r   ⟺   {L_1,…,L_r} are algebraically independent over ℚ,
```
because symmetric functions `e_1,…,e_r` of algebraically independent elements are themselves algebraically
independent (the `L_i` are the roots of `X^r − e_1 X^{r-1} + … ± e_r`, algebraic of degree `r` over
`ℚ(e_1,…,e_r)`, so `trdeg ℚ(e)=trdeg ℚ(L)=r`). ∎

## §2 The free witness `B_free` `[PROVED HERE]`

Choose the generalized primes so that `{L_i}` are **algebraically independent**.
- **Explicit, `r=2`:** `L_1 = π, L_2 = e^{π}` (Nesterenko 1996: `π, e^{π}` algebraically independent).
  `g_1 = e^{π} ≈ 23.14`, `g_2 = e^{e^{π}}`. Then `trdeg T_0(ζ_{B_free}) = 2 = corank`, **unconditional**.
- **Explicit, `r=3`:** add `L_3` with `{π, Γ(1/4), e^{π}}` algebraically independent (Nesterenko).
- **All finite `r` (and `r=∞`):** a countable algebraically independent subset of `(0,∞)` exists
  (ℝ has transcendence degree continuum over ℚ; pick inductively, with `L_i → ∞` so the `g_i` are a valid
  increasing generalized-prime sequence). Non-constructive but rigorous.

So for **every** `r ≤ ∞`, there is a Beurling system with `corank = trdeg = r`, the identity **proven**.

## §2bis The dependent witness `B_dep` — the identity is FALSE at fixed native invariants `[PROVED HERE]`

Take `B_dep = {g_1, g_2} = {e^{L_1}, e^{L_1^2}}` for any transcendental `L_1 > 1` (e.g. `L_1 = π`,
`g_1 = e^{π}`, `g_2 = e^{π^2}`). Then `L_2 = L_1^2`.
- `{L_1, L_2} = {L_1, L_1^2}` is **ℚ-linearly independent** (`aL_1 + bL_1^2 = 0` with `(a,b)≠0` forces
  `L_1 = -a/b ∈ ℚ`, impossible) ⟹ **corank `= 2`**, same flat abelian rank-2 `G_L`, Frobenius-less.
- but `{L_1, L_2}` is **algebraically dependent** (`L_2 - L_1^2 = 0`) ⟹ by §1,
  `trdeg T_0(ζ_{B_dep}) = trdeg_ℚ̄ ℚ̄(L_1, L_1^2) = 1 < 2 = corank`.

So `B_dep` and `B_free(r=2)` have **identical native invariants** (corank 2, `dim G_L = 2`, flat, additive,
Frobenius-less) but `trdeg = 1` resp. `2`. **`trdeg = corank` is therefore NOT a function of the native
invariants** — it is determined entirely by the algebraic-(in)dependence of the multiplier-logs, a
value-arithmetic datum the native invariants cannot see. ∎

**Structural inventory of `B_free` (all native invariants):** corank `= r`; difference-Galois group a
rank-`r` torus, `dim G_L = r`; generators `{σ_i : x_i ↦ g_i^{-1}x_i}` commute (flat, `F_{ij}=0`); additive
Euler product (`log ζ_B = Σ_i Σ_{k≥1} g_i^{-ks}/k`, no complementarities); **no single Frobenius** (no one
`g` with all `g_i ∈ g^{ℤ}` — `r` independent generators). For `r=∞`: corank `=∞`, no Frobenius — *exactly
the two features the corpus blamed for the ℚ wall* — yet `trdeg = ∞` is a theorem here.

## §3 The arithmetic system `M_S` and the separation theorem `[PROVED HERE / one isolated CONJECTURE]`

Let `S = {p_1,…,p_r}` be the first `r` rational primes, `M_S` the truncated Euler system
`ζ_S(s) = ∏_{p∈S}(1−p^{-s})^{-1}`, `L_i = log p_i`. Its structural inventory is **identical to `B_free`'s**:
corank `= r` (`{log p}` ℚ-linearly independent, unique factorization, ledger
`linearIndependent_log_primes` #121), `dim G_L = r`, flat commuting `σ_p`, additive Euler product, no single
Frobenius. By §1, `trdeg T_0(ζ_S) = r ⟺ {log p_1,…,log p_r}` algebraically independent.

> **[CONJECTURE] (the isolated ℚ wall).** `trdeg_ℚ̄ T_0(ζ_S) = r` for all `r` — equivalently `{log p}` are
> algebraically independent. **Open for every `r ≥ 2`** (it implies, e.g., that `(log 2)(log 3)` is
> irrational, itself unknown); a special case of Schanuel / the four-exponentials circle. Left open here.

**The separation theorem `[PROVED HERE]`.** Fix `r = 2` (hence all `r ≥ 2`). The three systems `B_free`,
`B_dep`, `M_S` are **pairwise indistinguishable by every native difference-Galois invariant** (corank `2`,
`dim G_L = 2`, flat abelian rank-2, additive Euler, Frobenius-less). Yet `trdeg(continuation) = 2` for
`B_free` (§2) and `= 1` for `B_dep` (§2bis). Therefore **`trdeg` is not a function of the native invariants**,
and **no theorem of the form "native-invariant hypotheses ⟹ trdeg = corank" can exist** — `B_dep` is an
explicit counterexample with the same hypotheses and `trdeg < corank`. (This is the airtight form: the
obstruction is not merely "no *known* structural proof" but "no *possible* one," because the target universal
is outright false.) Consequently the value of `trdeg T_0(ζ_S)` for the arithmetic system `M_S` — i.e. whether
`{log p}` are algebraically independent (the isolated conjecture) — is **undecidable from the native
invariants** and is **irreducibly value-arithmetic**: the only datum that separates `B_free` (`trdeg=2`) from
`B_dep` (`trdeg=1`), and hence fixes `M_S`, is the algebraic-(in)dependence of the *specific* multiplier-logs,
visible **only** in the arithmetic nature of the multipliers, never in a native invariant. ∎

(all three blocks share corank, `dim G_L`, holonomy type). This corroborates §3; it is not a proof of the
ℚ conjecture (absence of a *low-height* relation is evidence, not a transcendence theorem).
