2. $\sum_{j, k} c_j c_k \le (K + 1)^{2r} N$;
3. For every $\varphi : \mathbb{Z} \to \mathbb{R}$, $\sum_{j, k} c_j c_k \varphi((j : \mathbb{Z}) - (k : \mathbb{Z})) = \sum_{s \in \text{Icc } (-n) n} R(s) \varphi(s)$;
4. $R(0) = 1$ and $0 \le R(s) \le 1$ for all $s \in \mathbb{Z}$;
5. For every $\ell : \text{Fin } r$, $t \in \mathbb{Z}$, and $\tau > 0$: if $|t| \le N$ and $2(K + 1)^{2r}|t| \le \tau^2 N$, then $|(q_\ell : \mathbb{Z}) + t| \le n$ and $R((q_\ell : \mathbb{Z}) + t) \ge 1 - 2\alpha - \tau$.

*Proof.* Set $n := K r Q + N \ge 1$, $W(u) := \mathbf{1}_{0 \le u < N}$ on $\mathbb{Z}$, and for $0 \le k \le K$, $G_k(m) := \sum_{v \in \{0,\dots,k\}^r} W(m - \sum_\ell v_\ell q_\ell)$. For $k \le K$, $G_k$ is supported in $I_0 := [0, n) \cap \mathbb{Z}$, $\|G_0\|_2^2 = N \ge 1$, and by Cauchy–Schwarz $\|G_k\|_2^2 \le (k + 1)^{2r} N$ while $\sum_{m \in I_0} G_k(m) = (k + 1)^r N$. If $\|G_{k+1}\|_2^2 > (1 + \alpha)\|G_k\|_2^2$ held for all $k < K$, induction would give $(1 + \alpha)^K N < \|G_K\|_2^2 \le (K + 1)^{2r} N$, contradicting $(K + 1)^{2r} \le (1 + \alpha)^K$. - Properties (1)–(4) follow from $\sum_j c_j^2 = 1$, $(\sum_j c_j)^2 = (k+1)^{2r} N^2 / \|G_k\|_2^2 \le (K + 1)^{2r} N$, fiber grouping by $s = j - j' \in [-n, n]$, and Cauchy–Schwarz $R(s) \le \|\tilde{c}\|_2^2 = 1$.
- Since $0 \le G_k(m) \le G_{k+1}(m)$ and $0 \le G_k(m - q_\ell) \le G_{k+1}(m)$ with all functions supported in $I_0$, $(B - A)^2 \le B^2 - A^2$ ($0 \le A \le B$) gives $\|G_{k+1} - G_k\|_2^2 \le \alpha \|G_k\|_2^2$ and $\|G_{k+1} - G_k(\cdot - q_\ell)\|_2^2 \le \alpha \|G_k\|_2^2$, whence $\|G_k - G_k(\cdot - q_\ell)\|_2^2 \le 4\alpha \|G_k\|_2^2$, i.e. $2 - 2 R(q_\ell) \le 4\alpha \implies R(q_\ell) \ge 1 - 2\alpha$.
- For any $t \in \mathbb{Z}$, $\sum_{w \in \mathbb{Z}} (W(w) - W(w + t))^2 \le 2|t|$ (by translation symmetry to $t \ge 0$ and $\sum_w W(w)W(w+t) \ge \max(0, N - t)$). Cauchy–Schwarz across $\{0,\dots,k\}^r$ gives $\sum_{u \in \mathbb{Z}} (G_k(u) - G_k(u + t))^2 \le 2(K + 1)^{2r}|t|$, so $(R(s) - R(s + t))^2 \le \sum_u (\tilde{c}(u) - \tilde{c}(u + t))^2 \le 2(K + 1)^{2r}|t| / N$. #### Theorem B.3 (Quantitative `Δ`-Free Collective Half-Pole Collar Forcing)
Define for $\kappa, d, M, r \in \mathbb{N}$ and $T \in \mathbb{R}$:

$$\exists \ell : \text{Fin } r,\quad \operatorname{Re}\rho_\ell \le 1 - \text{halfPoleCollarWidth}(\kappa, d, M, r, T).$$

     Hence $\text{RHS} \cdot h \le \pi\kappa + \frac{1}{16} + \frac{33}{64} = \pi\kappa + \frac{37}{64}$.
   - **Each zero $\rho_\ell$:** let $\alpha_\ell := \delta + (1 - \operatorname{Re}\rho_\ell) \in [\delta, \delta + \eta]$ and $J_\ell := \lceil L \alpha_\ell / h \rceil \ge 1$.
