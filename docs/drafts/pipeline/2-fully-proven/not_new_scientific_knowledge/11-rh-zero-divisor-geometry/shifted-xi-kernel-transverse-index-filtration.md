# Shifted-xi kernel recovers the transverse off-line divisor filtration

- **ID:** shifted-xi-kernel-transverse-index-filtration
- **Stage:** 2-fully-proven/not_new_scientific_knowledge
- **Type:** THEOREM (paper) -- scientifically non-new bridge
- **Statement:** `[PROVED HERE; BRIDGE; NOT NEW SCIENTIFIC KNOWLEDGE]` For all nonexceptional
  shifts `omega>0`, the negative index of the Hermite--Biehler kernel generated by
  `E_omega(z)=xi(1/2+omega-iz)` equals the total multiplicity of zeta zeros in
  `Re rho>1/2+omega`, with both sides allowed to be infinite. Thus the full horizontal filtration
  of the off-line divisor is the negative-index filtration of one global, no-jet kernel.

## Goal

Replace local collision jets and finite-exception Weil matrices by an invariant built from the
entire divisor. The invariant should remain meaningful when infinitely many off-line zeros exist
and should distinguish their horizontal distance from the critical line.

## Setup

Let `xi` be Riemann's entire xi function and, for `omega>0`, put

```text
E_omega(z)=xi(1/2+omega-iz),
E_omega#(z)=conjugate(E_omega(conjugate(z)))
           =xi(1/2-omega-iz).
```

The last equality uses reality and `xi(s)=xi(1-s)`. Define the meromorphic inner quotient

```text
Theta_omega(z)=E_omega#(z)/E_omega(z)
```

and its generalized de Branges kernel on the upper half-plane

```text
S_omega(z,w)=i/(z-conjugate(w))
  * (1-Theta_omega(z)conjugate(Theta_omega(w))).
```

Let `kappa(omega)` be the number of negative squares of this kernel, with value `infinity` if the
negative index is unbounded.

Call `omega` exceptional if `E_omega` and `E_omega#` have a common nonreal zero. Equivalently,
there are two xi zeros with the same ordinate and real parts separated by `2 omega`. The exceptional
set is at most countable.

## Candidate theorem

For every nonexceptional `omega>0`,

```text
kappa(omega)
= sum_(xi(rho)=0, Re rho>1/2+omega) multiplicity(rho),        (T)
```

where equality includes the value `infinity`.

For exceptional `omega`, the same formula holds after deleting the common divisor of `E_omega`
and `E_omega#`; equivalently, horizontally paired zeros separated by `2 omega` cancel from both the
meromorphic quotient and the index.

Consequently, at nonexceptional shifts where the right side is finite, the discrete measure of
horizontal displacements is recovered from the index step function:

```text
-d kappa(omega)
= sum_(Re rho>1/2) multiplicity(rho)
    delta_(Re rho-1/2)(d omega).                              (F)
```

The reflected left-half zeros contain the same information by the functional equation.

## Paper proof

`[PROVED HERE; NOVELTY UNVERIFIED]`

If `rho=beta+i gamma` is a zero of `xi`, then the corresponding zero of `E_omega` is

```text
z_rho=-gamma+i(beta-1/2-omega).
```

Therefore `z_rho` lies in the open upper half-plane exactly when

```text
beta>1/2+omega.                                              (1)
```

The centered function `Xi(z)=xi(1/2-iz)` is of Cartwright class: it has exponential type, and
Stirling's formula gives exponential decay on the real axis up to polynomial factors, hence the
Cartwright logarithmic integral is finite. Since `E_omega(z)=Xi(z+i omega)`, the shifted function is
of bounded type in both half-planes. Hence `Theta_omega=E_omega#/E_omega` is meromorphic of bounded
type in the upper half-plane and has unimodular boundary values almost everywhere.

Its mean type has no denominator contribution. Indeed, on the positive imaginary axis,

```text
Theta_omega(iy)=xi(1/2-omega+y)/xi(1/2+omega+y),
```

and Stirling's formula together with `zeta(y+c)->1` shows that this ratio has only polynomial decay.
Thus `lim_(y->infinity) y^(-1)log|Theta_omega(iy)|=0`; there is no growing singular exponential
factor. The canonical bounded-type factorization therefore has the form

```text
Theta_omega = constant * B_zero/B_pole,
```

after canceling the common inner divisor. The denominator Blaschke product has one zero, with the
same multiplicity, for every uncancelled zero of `E_omega` in the upper half-plane.

If `B_pole` has finite degree `kappa`, the classical Krein--Langer/generalized-Schur factorization
theorem says that the kernel

```text
i(1-Theta(z)conjugate(Theta(w)))/(z-conjugate(w))
```

has exactly `kappa` negative squares. Conversely, a generalized Schur function with finite negative
index `kappa` can have only a finite denominator Blaschke product of degree `kappa`. Hence an
infinite set of poles forces infinite negative index. Combining this factorization theorem with
`(1)` proves `(T)`. Formula `(F)` is the Stieltjes derivative of the cumulative counting function
whenever it is locally finite.

## Entry interpretation

For a deformation `xi_t`, an off-line pair at horizontal distance `a(t)` contributes one negative
square to every shifted kernel with `0<omega<a(t)` and none for `omega>a(t)`. As the pair enters the
critical line, its entire negative-index step shrinks toward `omega=0` and disappears there.

Thus entry is not blocked by a local discriminant alone. It requires loss of a whole interval of
negative-square data in the global kernel filtration. This is an infinite-divisor constraint and
uses no derivatives at the zero.

## Euler-data realization

In a sufficiently high upper half-plane both shifted arguments lie in the Euler-product region, so
`Theta_omega` is determined there by the quotient of the two shifted completed Euler products. Its
meromorphic continuation determines `S_omega` everywhere. Hence `(T)` identifies an exact object
through which the infinite Euler data encodes the transverse divisor count:

```text
shifted Euler quotient -> generalized inner kernel -> negative index
                       = off-line zeros beyond omega.
```

This does not yet provide a positive estimate on the kernel from the zeta Euler factors. Such an
estimate would be a genuine exclusion theorem.

## Known parents

- Weil positivity and Bombieri's finite-truncation theorem already relate negative eigenvalues to
  off-line zeros. Bombieri explicitly treats the case of finitely many off-line exceptions and
  encounters a limiting linear-dependence obstruction beyond it.
- Suzuki (2012) studies exactly
  `Theta_omega(z)=xi(1/2-omega-iz)/xi(1/2+omega-iz)` and proves that absence of zeros in
  `Re s>1/2+omega_0` is equivalent to meromorphic innerness of `Theta_omega` for every
  `omega>omega_0`. Thus the zero-versus-no-zero endpoint of the proposed filtration is already
  known; only the exact generalized negative-index count could be new.
- Generalized Hermite--Biehler/Krein--Langer theory already identifies the number of negative
  squares with upper-half-plane zeros of an entire denominator after common-divisor cancellation.
- Alpay--Rovnyak, *Loewner's theorem for kernels having a finite number of negative squares*,
  Proc. Amer. Math. Soc. 127 (1999), 1109--1117, DOI
  `10.1090/S0002-9939-99-04618-3`, records both the generalized Schur factorization parent and the
  independence of the negative-square count from the holomorphic sampling region.
- Shifted Hermite--Biehler functions and translates of zeta/L-functions are established subjects.
- The exact `omega`-filtration `(T)`--`(F)` follows directly from these parents and is retained only
  as source-transport infrastructure.
