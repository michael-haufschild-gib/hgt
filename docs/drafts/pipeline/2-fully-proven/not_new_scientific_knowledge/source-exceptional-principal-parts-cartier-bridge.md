## Theorem

Let `R` be a commutative domain and let `x` be nonzero. Put

\[
R_x=R[x^{-1}],\qquad P_x=R_x/R,
\]

where `R` denotes the image of the localization map. Define

\[
\partial_x:R\longrightarrow P_x,\qquad
r\longmapsto [r/x].
\tag{1}
\]

Then

\[
\ker\partial_x=xR
\quad\text{and hence}\quad
R/(x)\xrightarrow{\;\sim\;}\operatorname{im}\partial_x.
\tag{2}
\]

If `R` is a local analytic domain and `x=t^m u` with `u` a unit, the same layer is

\[
\operatorname{im}\partial_x\cong R/(t^m).
\tag{3}
\]

Thus its length is `m` whenever the usual one-dimensional length is defined. Multiplying
`1/x` by a unit, in particular the factor `1/2` in the completed exceptional section
`1/(2 Xi)`, does not change the generated layer.

## Proof

If `r=xa`, then

\[
[r/x]=[a]=0\quad\text{in }R_x/R,
\]

so `xR` lies in the kernel.

Conversely, suppose `[r/x]=0`. Then `r/x` is the image of some `a` in `R_x`. Multiplying by
`x` gives equality of the images of `r` and `xa`. Since `x` is nonzero and `R` is a domain,
the localization map `R -> R_x` is injective. Hence `r=xa`. This proves the kernel identity.
The first isomorphism theorem gives `(2)`. If `x=t^m u`, multiplication by `u` identifies
`(x)` with `(t^m)`, proving `(3)`.
