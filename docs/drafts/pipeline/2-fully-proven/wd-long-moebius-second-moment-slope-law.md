### Theorem 1 (Prefix-amplified sawtooth zero floor and sparse sharp-Möbius criteria)
Let $S \subset \mathbb{N}_+$ be finite, $y_1 \ge 1$, and $a : \mathbb{N} \to \mathbb{R}$ satisfy $\sum_{d \in S,\, d \mid n} a(d) = \mathbf{1}_{n=1}$ for all $1 \le n \le y_1$.
1. **Linearity up to $y_1$.** For $0 \le x < 1$, `sawtoothDefect_of_lt_one` gives $F(x) = x w$ with $w = \sum_{d \in S} a(d)/d$. For $1 \le x \le y_1$, writing $\{x/d\} = x/d - \lfloor x/d \rfloor$ and $\lfloor x/d \rfloor = \sum_{1 \le n \le \lfloor x \rfloor,\, d \mid n} 1$ yields
   $$F(x) = 1 + x w - \sum_{n=1}^{\lfloor x \rfloor} \sum_{d \in S,\, d \mid n} a(d) = 1 + x w - 1 = x w.$$
   Hence $g(u) := \operatorname{defectPull}(S, a, u) = w e^{u/2}$ for all $u \le L := \log y_1$.
2. **Shifted Laplace split at $L = \log y_1$.** Let $\rho$ be a zero of $\zeta$ with $\frac{1}{2} < \operatorname{Re}\rho < 1$, and set $A = 2\operatorname{Re}\rho - 1 > 0$. By `integral_defectPull_mul_cexp`, $\int_{\mathbb{R}} g(u) e^{-(\rho - 1/2)u} \, du = 1/\rho$. Since $\int_{-\infty}^L w e^{(1-\rho)u} \, du = w y_1^{1-\rho}/(1-\rho)$ and $\int_{-\infty}^L \|g(u)\|^2 \, du = y_1 w^2$, Cauchy–Schwarz on $(L, \infty)$ against $\int_L^\infty e^{-Au} \, du = y_1^{-A}/A$ gives
   $$\operatorname{mollifierDefect}(S, a) \ge y_1 w^2 + A y_1^A \left\|\frac{1}{\rho} - \frac{w y_1^{1-\rho}}{1 - \rho}\right\|^2.$$
3. **Quadratic minimization in $\tilde{w} = |w| y_1^{1 - \operatorname{Re}\rho}$.** Since $y_1 w^2 = y_1^A \tilde{w}^2$, setting $a_1 = \|1/\rho - w y_1^{1-\rho}/(1-\rho)\|$ and $\varepsilon = \|1 - \rho\|^{-1}$ gives $\|\rho\|^{-1} \le a_1 + \tilde{w}\varepsilon$ and $A(a_1 + \tilde{w}\varepsilon)^2 \le (\tilde{w}^2 + A a_1^2)(1 + A\varepsilon^2) = (\tilde{w}^2 + A a_1^2)\|\rho\|^2 \varepsilon^2$ using $\|\rho\|^2 = \|1-\rho\|^2 + A$. Multiplying by $y_1^A / (\|\rho\|^2 \varepsilon^2)$ yields $\frac{A\|1-\rho\|^2}{\|\rho\|^4} y_1^A \le \operatorname{mollifierDefect}(S, a)$.
4. **Consequences for `sharpCoeff`.** Taking $S = \{1,\dots,y\}$, $y_1 = y$, and $a = \mu$ (`sharpCoeff`), any cofinal subsequence bound $\operatorname{mollifierDefect}(\{1,\dots,y\}, \mu) \le C y^{2\beta + \eta}$ along $\exists^\infty y$ forces $2\operatorname{Re}\rho - 1 \le 2\beta + \eta$ for every zero $\rho$, hence $\operatorname{XiZeroHalfPlaneBound}(\beta)$ when $\eta \to 0^+$ (and $\operatorname{RiemannHypothesis}$ at $\beta = 0$). Moreover, Plancherel (`mollifierDefect_eq`) gives $I(\theta, T) \le 2(T - 1) + 4\pi(\frac{1}{4} + T^2)\operatorname{mollifierDefect}(\{1,\dots,\lfloor T^\theta \rfloor\}, \mu)$ for all $T \ge 1$.

### Theorem 2 (All-$\theta$, all-$T$ upper bound without crossing $\operatorname{Re} s = \frac{1}{2}$)
Assume $\operatorname{XiZeroHalfPlaneBound}(\beta)$ with $\beta \in [0, \frac{1}{2}]$, so $\Theta_\zeta \le \frac{1}{2} + \beta$.
1. **Left-line Abel bound on $\sigma_1 = \frac{1}{2} - \delta \in [\frac{1}{4}, \frac{1}{2})$.** Given $\varepsilon \in (0, 1]$, `mobiusMertens_subpower_zetaZeroAbscissa` supplies $C_0 \ge 0$ with $\|M(k)\| \le C_0(k+1)^{1/2+\beta+\varepsilon}$ for all $k$. Summation by parts (`Finset.sum_range_by_parts`) on $M_X(\sigma_1 + i\tau)$ with `norm_cpow_unit_diff_le` gives, for $\alpha = \beta + \delta + \varepsilon > 0$,
   $$\|M_X(\sigma_1 + i\tau)\| \le C_1 (1 + |\tau|) X^{\beta + \delta + \varepsilon} \qquad (X \ge 1,\ \tau \in \mathbb{R}),$$
   bounding $\sum_{k=1}^{X-1} k^{\alpha - 1} \le (1 + \alpha^{-1}) X^\alpha$ (directly for $\alpha \ge 1$, and by MVT telescoping of $x^\alpha$ for $0 < \alpha < 1$).
2. **Pole-cleared strip bound.** Since $\sigma_1 < \frac{1}{2} < 1$, $\zeta(\sigma_1 + it)$ is continuous on $|t| \le 2$ and satisfies $\|\zeta(\sigma_1 + it)\| \le 2 + 8|t|$ on $|t| \ge 2$ (`norm_riemannZeta_le_quarter`), giving $\|\operatorname{mobField}(X, \sigma_1 + it)\| \le C_2 (1 + |t|)^2 X^{\beta + \delta + \varepsilon}$ for all $t \in \mathbb{R}$.
3. **Unit-window $L^2$ three-lines bound.** Apply `integral_normSq_le_of_three_lines` on $[\sigma_1, 3]$ at $\sigma = \frac{1}{2}$ to $F(z) = \operatorname{mobWindowField}(X, 8, \tau, z)$ on $[\tau - \frac{1}{2}, \tau + \frac{1}{2}]$ ($\tau \in \mathbb{R}$). On $\operatorname{Re} z = \sigma_1$, $\int_{\mathbb{R}} \|F(\sigma_1+it)\|^2 \, dt \le C_3 (1 + |\tau|)^4 X^{2(\beta + \delta + \varepsilon)}$. On $\operatorname{Re} z = 3$, `integral_mobWindowField_three_le` gives $\le C_R X^{-2}$. With $\lambda = \frac{\delta}{5/2 + \delta}$, the interpolated $X$-exponent is $\frac{5\beta + 3\delta + 5\varepsilon}{5/2 + \delta} \le 2\beta + \frac{6}{5}\delta + 2\varepsilon$. On $\operatorname{Re} z = \frac{1}{2}$, $\|(z-1)/z\| = 1$ identically for all $t \in \mathbb{R}$ and $\|\operatorname{nearLineGauss}(8, \tau, \frac{1}{2}+it)\|^2 \ge \frac{1}{2}$ on $[\tau - \frac{1}{2}, \tau + \frac{1}{2}]$, so for all $\tau \in \mathbb{R}$ and $X \ge 1$,
   $$\int_{\tau - 1/2}^{\tau + 1/2} \left\|\zeta(\tfrac{1}{2}+it) M_X(\tfrac{1}{2}+it) - 1\right\|^2 dt \le C_{\delta,\varepsilon} (1 + |\tau|)^4 X^{2\beta + \frac{6}{5}\delta + 2\varepsilon}.$$
4. **Parameter specialization.** Summing unit windows over $[1, \lceil T \rceil]$ for $T \ge 2$ yields $\int_1^T \|\zeta M_X - 1\|^2 \, dt \le C'_{\delta,\varepsilon} T^5 X^{2\beta + \frac{6}{5}\delta + 2\varepsilon}$. For any $\theta > 0$, choosing $\delta = \min(\frac{1}{4}, \frac{1}{2\theta})$ and $\varepsilon = \min(1, \frac{1}{5\theta})$ gives $(\frac{6}{5}\delta + 2\varepsilon)\theta \le 1$, so at $X = \lfloor T^\theta \rfloor$, $I(\theta, T) \le C_\theta T^{6 + 2\beta\theta}$ for all $T \ge 2$.
5. **Immediate corollaries.** Setting $\beta = 0$ gives `RiemannHypothesis → ∀ θ > 0, ∃ C ≥ 0, ∀ T ≥ 2, I(θ, T) ≤ C T^6`. Combined with `riemannHypothesis_of_cofinal_moebius_mollifier`, `route-wd.md` §1 is unconditionally equivalent to `RiemannHypothesis`, and any sparse $(\theta, T)$ bound with arbitrary $K \ge 0$ self-improves unconditionally to all $\theta > 0$, all $T \ge 2$, and $K_0 = 6$. Setting $\beta = \frac{1}{2}$ gives the unconditional bound $I(\theta, T) \le C_\theta T^{6 + \theta}$.

### Theorem 3 (Sharp bootstrap lower slope $2 \cdot \operatorname{zetaZeroWidth}$)
Suppose $\beta \in [0, \frac{1}{2})$ and there exists $K \ge 0$ such that for arbitrarily large $\theta > 0$, some $C_\theta \ge 0$ satisfies $I(\theta, T) \le C_\theta T^{K + 2\beta\theta}$ for unboundedly many $T$. Assume for contradiction $\beta < \delta_* := \operatorname{zetaZeroWidth} \le \frac{1}{2}$, and set $\varepsilon = \frac{\delta_* - \beta}{10} > 0$.
1. **Top-of-spectrum zero and test field.** Select a nontrivial zero $\rho_0 = \frac{1}{2} + \delta_0 + i\gamma_0$ with $\gamma_0 > \frac{11}{2}$ (`riemannZeta_ne_zero_of_im_sq_le` gives $\gamma_0^2 > 32$) and $\delta_0 > \delta_* - \frac{\varepsilon}{4}$. Choose integer $B \ge 4$ with $\frac{4}{B - 1/2} \le \frac{\varepsilon}{10}$ and radius $r = \min(\frac{\delta_0}{2}, \frac{\varepsilon}{20}, \frac{1}{8})$. For $X \ge 2$, set $R_X = \frac{4\varepsilon}{\delta_0}\log X$ and
   $$F_X(z) = \exp\!\left(\frac{(z - i\gamma_0)^2}{64}\right) \exp\!\left(-\frac{R_X}{z - \frac{1}{2} + \delta_0}\right) \operatorname{mobField}(X, z).$$
2. **Center lower bound.** On $\operatorname{Re} z \ge \frac{1}{2}$, $\operatorname{Re}(z - \frac{1}{2} + \delta_0) \ge \delta_0 > 0$, so $|\exp(-R_X/(z - \frac{1}{2} + \delta_0))| \le 1$ everywhere on the strip $[\frac{1}{2}, B]$. At $z = \rho_0$, $\operatorname{mobField}(X, \rho_0) = (1 - \rho_0)/\rho_0 \ne 0$, $|\exp((\rho_0 - i\gamma_0)^2/64)|^2 \ge 1$, and $2 R_X \operatorname{Re}(1/(2\delta_0 + i\gamma_0)) = \frac{8\varepsilon}{\delta_0}\log X \cdot \frac{2\delta_0}{4\delta_0^2 + \gamma_0^2} \le \frac{1}{2}\varepsilon \log X$ since $\gamma_0^2 > 32$, giving $\|F_X(\rho_0)\|^2 \ge c_{\rho_0} X^{-\varepsilon/2}$. By `norm_sq_value_mul_area_le_integral_ball_local` and `setIntegral_reProdIm_eq_iterated_of_continuousOn` on $[\beta_0 - r, \beta_0 + r] \times [\gamma_0 - r, \gamma_0 + r]$, some $\sigma_* \in [\beta_0 - r, \beta_0 + r]$ satisfies $\frac{\pi r}{2} c_{\rho_0} X^{-\varepsilon/2} \le \int_{\gamma_0 - r}^{\gamma_0 + r} \|F_X(\sigma_* + it)\|^2 \, dt$.
3. **Boundary bounds and contradiction.**
   - On $\operatorname{Re} z = \frac{1}{2}$: on $[1, T]$ and (by conjugate symmetry) $[-T, -1]$, the integral is $\le 8 I(\theta, T) + 8T \ll_\theta X^{2\beta + \varepsilon} \le X^{2\delta_0 - 17\varepsilon}$ once $(K+1)/\theta \le \varepsilon$; on $[-1, 1]$, $|\exp(-R_X/(\delta_0 + it))|^2 = \exp(-2 R_X \delta_0/(\delta_0^2 + t^2)) \le X^{-4\varepsilon}$ while Theorem 2 applied unconditionally at $\delta_* = \operatorname{zetaZeroWidth}$ gives $\int_{-1}^1 \|\operatorname{mobField}(X, \frac{1}{2}+it)\|^2 \, dt \le C_{\mathrm{boot}} X^{2\delta_* + \varepsilon/4} \le C_{\mathrm{boot}} X^{2\delta_0 + 3\varepsilon/4}$, yielding $\le 2 C_{\mathrm{boot}} X^{2\delta_0 - 13\varepsilon/4}$; on $|t| > T$, Gaussian decay $e^{-(T-\gamma_0)^2/64} X^2 \le 1$ for large $T$. Thus $S_L \le C_L X^{2\delta_0 - 3\varepsilon}$.
   - On $\operatorname{Re} z = B \ge 4$: for $n > X$, $n^{-B} \le X^{-(B-3)} n^{-3}$, so `norm_LSeries_le_of_vanishing_head` gives $\|\operatorname{mobField}(X, B+it)\| \le 2 X^{2-B}$, whence $S_R \le C'_B X^{-2B+4}$.
   - Applying `integral_normSq_le_of_three_lines` on $[\frac{1}{2}, B]$ at $\sigma_*$ gives $X$-exponent $(1 - \lambda_*)(2\delta_0 - 3\varepsilon) + \lambda_*(-2B + 4) \le 2\delta_0 - 3\varepsilon - 2(\sigma_* - \frac{1}{2}) + \frac{3}{B - 1/2} \le -\frac{13}{5}\varepsilon < -\frac{1}{2}\varepsilon$, contradicting $X^{-\varepsilon/2} \ll X^{-13\varepsilon/5}$ as $T \to \infty$.

## Residual Obstruction to Unconditional $\beta = 0$ Closure
