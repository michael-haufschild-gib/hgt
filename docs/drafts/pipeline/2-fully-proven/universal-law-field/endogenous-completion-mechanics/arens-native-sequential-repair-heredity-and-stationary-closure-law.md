## 1. Setup

Let

\[
 X=\{\infty\}\sqcup\{b_n:n\in\mathbb N\}
   \sqcup\{a_{n,m}:n,m\in\mathbb N\}.
 \tag{AS.1}
\]

Declare `U subset X` open when both conditions hold:

1. if `b_n in U`, then some `M` satisfies `a_(n,m) in U` for every `m>=M`;
2. if `infinity in U`, then some `N` satisfies `b_n in U` for every `n>=N`.

Leaves are therefore isolated.  Let

\[
 A=\{a_{n,m}:n,m\in\mathbb N\},
 \qquad B=\{b_n:n\in\mathbb N\}.
 \tag{AS.2}
\]

For `C subset X`, write

\[
 S(C)=\{x:\text{there is a sequence in }C\text{ converging to }x\}
 \tag{AS.3}
\]

for native sequential closure.

## 2. Main theorem

### Theorem 2.1 -- two-generation native repair

The declared open sets form a topology on `X`, and

\[
 \boxed{S(A)=A\cup B,}
 \tag{AS.4}
\]

\[
 \boxed{S(S(A))=X,}
 \tag{AS.5}
\]

while

\[
 \boxed{\overline A=\overline{S(A)}=X.}
 \tag{AS.6}
\]

The repair layers are exactly

\[
 S(A)\setminus A=B,
 \qquad
 S^2(A)\setminus S(A)=\{\infty\}.
 \tag{AS.7}

Moreover, the second repair is hereditarily generated by the first: the sequence `(b_n)` lies
entirely in `S(A)\setminus A` and converges to `infinity`.  No sequence lying entirely in `A`
converges to `infinity`.

Thus one fixed topology supplies a non-idempotent operational repair whose first outputs create the
next legal witness, although ordinary closure semantics is stationary from stage zero.

## 3. Proof

### 3.1 Topology axioms

The empty set and `X` satisfy both eventual-tail conditions.

Let `U,V` be open.  If `b_n in U intersect V`, choose row thresholds `M_U,M_V`; the threshold
`max(M_U,M_V)` works for the intersection.  If `infinity in U intersect V`, choose branch
thresholds `N_U,N_V`; `max(N_U,N_V)` works.  Hence finite intersections are open.

For a union of open sets, membership of either `b_n` or `infinity` in the union is witnessed by one
member of the family.  The corresponding threshold for that member also works for the union.
Arbitrary unions are open.  The prescription therefore defines a topology.

### 3.2 First-generation limits

Every point of `A` lies in `S(A)` by its constant sequence.  For fixed `n`,

\[
 a_{n,0},a_{n,1},a_{n,2},\ldots\longrightarrow b_n
 \tag{AS.8}
\]

because every neighbourhood of `b_n` contains a tail of the `n`th row.  Therefore

\[
 A\cup B\subseteq S(A).
 \tag{AS.9}
\]

It remains to exclude `infinity`.  Let `(x_k)` be any sequence in `A`, and write
`x_k=a_(n_k,m_k)`.

If some row `n` occurs for infinitely many `k`, consider

\[
 U=X\setminus\bigl(\{b_n\}\cup\{a_{n,m}:m\in\mathbb N\}\bigr).
 \tag{AS.10}
\]

This is an open neighbourhood of `infinity`: it contains every branch except `b_n`, and contains
every leaf on every retained branch.  Infinitely many `x_k` lie outside `U`, so the sequence does
not converge to `infinity`.

Otherwise every row occurs only finitely often.  For each `n`, let `c(n)=0` when row `n` never
occurs, and otherwise choose

\[
 c(n)=1+\max\{m_k:n_k=n\}.
\]

Then

\[
 V=\{\infty\}\cup B\cup\{a_{n,m}:m\ge c(n)\}
 \tag{AS.11}
\]

is open: it contains every branch and a tail of every row.  It contains none of the terms `x_k`.
Again the sequence does not converge to `infinity`.  These two exhaustive cases prove
`infinity notin S(A)`, and `(AS.4)` follows from `(AS.9)` because `X` has no other points.

### 3.3 Second-generation limit

Every neighbourhood of `infinity` contains all `b_n` beyond some finite index.  Hence

\[
 b_n\longrightarrow\infty.
 \tag{AS.12}
\]

The sequence lies entirely in `B=S(A)\setminus A`, so `infinity in S(S(A))`.  All other points
already lie in `S(A)`, and sequential closure is extensive by constant sequences.  Therefore
`S(S(A))=X`, proving `(AS.5)` and `(AS.7)`.

### 3.4 Stationary ordinary closure

Every branch `b_n` is a sequential limit of leaves, hence belongs to `closure(A)`.  Let `U` be an
open neighbourhood of `infinity`.  It contains some branch `b_n`; because it is open, it then
contains a tail of the `n`th leaf row.  Thus every neighbourhood of `infinity` meets `A`, so
`infinity in closure(A)`.  Consequently `closure(A)=X`.

Since `A subset S(A) subset X`, monotonicity of closure gives

\[
 X=\overline A\subseteq\overline{S(A)}\subseteq X.
\]

This proves `(AS.6)` and completes the theorem.  `square`

## 4. Mechanism extracted

Define the native failure and repair operations

\[
 F(C)=S(C)\setminus C,
 \qquad P(C)=C\cup F(C)=S(C).
 \tag{AS.13}
\]

The theorem gives

\[
 F(A)=B,
 \qquad F(P(A))=\{\infty\},
 \qquad F(P^2(A))=\varnothing.
 \tag{AS.14}
\]

This supplies five laws independent of the word presentation:

1. **Native repair:** one pre-existing topology determines every legal convergence test.
2. **Repair internality:** admitted limits become legal entries of future histories.
3. **Failure heredity:** the next failure has a witness entirely in the preceding repair layer.
4. **Semantic/operational separation:** ordinary closure is fixed while sequential executability
   changes.
5. **Formation rank:** least sequential generation depth is information discarded by ordinary
   closure.

Unlike ULF-LSM-1, no pair of alternating repair operators is supplied.  One topology and one native
operation `S` generate both layers.
