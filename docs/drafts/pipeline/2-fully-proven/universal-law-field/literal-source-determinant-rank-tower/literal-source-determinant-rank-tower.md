## Theorem

For every `n : Nat`:

1. `(x_j)_(j<n)` is linearly independent over `k`, hence over `C`.
2. `dim_C S_n = n`.
3. `S_n` is a strict subspace of `S_(n+1)`.
4. `dim_C Q_n = 1`.
5. `xbar_n ≠ 0` and `Q_n = C xbar_n`; hence `det(Q_n) = exteriorPower^1 Q_n`
   is a canonical line generated by `xbar_n`.
6. `det(S_n) = exteriorPower^n S_n` is one-dimensional, while functorial exterior
   transport from `S_n` cannot surject onto `det(S_(n+1))` in degree `n+1`.
7. Prefix tower never stabilizes: for every `N`, `S_N ≠ S_(N+1)`; consequently there is no finite
   stage containing every literal source channel.

## Proof

Set `x : Nat → E` as above.  Corpus theorem
`rankTwelveFiniteAbscissaSource_relativeDifferentialIndependent` gives differential independence of
`x` over `k`.  Differential independence implies ordinary linear independence over `k`; restriction
of scalars along `C → k`, then restriction along injection `Fin n → Nat`, proves item 1.

The synthesis map

`F_n : C^(Fin n) → E`, `F_n(c) = sum_(j<n) c_j x_j`,

has range exactly `S_n`.  Item 1 makes `F_n` injective.  Rank-nullity therefore gives

`dim_C S_n = dim_C C^(Fin n) = n`,

proving item 2.

Every generator `x_j` with `j<n` also occurs among first `n+1` generators, hence
`S_n ≤ S_(n+1)`.  If equality held, item 2 would give `n = n+1`, impossible.  Equivalently,
linear independence says `x_n` is not in span of its predecessors.  This proves item 3.

The quotient dimension formula for finite-dimensional spaces gives

`dim_C Q_n = dim_C S_(n+1) - dim_C S_n = (n+1)-n = 1`,

proving item 4.  If `xbar_n=0`, then `x_n` lies in `S_n`, contradicting linear independence.
Thus `xbar_n` is nonzero.  Every nonzero vector in a one-dimensional space spans it, proving item
5.  Since first exterior power is canonically the original space, its determinant increment is a
line with canonical generator `xbar_n`.

Item 2 and `choose(n,n)=1` give `dim det(S_n)=1`.  Apply
`RankJumpDeterminantCreation` to injective inclusion `i_n`, using dimensions `n` and `n+1`.
At old degree `n`, old determinant volume survives injectively inside an `(n+1)`-dimensional
carrier.  At new degree `n+1`, old exterior source has dimension zero while target determinant is a
line, so induced map is not surjective.  This proves item 6 and shows why moving determinant
history requires quotient increments rather than an ordinary directed system of top wedges.
