# Frozen pre-run protocol: Which zeros are joined by lifting closed target loops?

Status: numerical discovery, no Lean builds. User broadened scope to zeta landscape; no claim of a closed HB proof gap is needed for admission.

Question: Which zeros are joined by lifting closed target loops?
Competing explanations: target motion only rearranges nearby zeros; or finite critical values and the asymptotic value 1 produce nonlocal or path-dependent connectivity. Neither finite endpoint map was derived in the prediction pass. Generic local square-root branching and the far-right approximation zeta(s)-1 ~ 2^(-s) are derived implementation controls, not discoveries.

Literal objects: zeta(s), its first/second derivatives, cached zero ordinates at 240 digits. No physical terms are omitted because this is not a physical-action experiment. SS/SV/VV identification, corrections, contacts, boundary terms and extinction remain unaddressed.

Portfolio: 64 positive zeros with circle w=1-exp(2pi i u); first 16 additionally reverse circle, small circle .35(1-exp(2pi i u)), and ellipses 1-cos(2pi u)-i b sin(2pi u), b=.5,1.5. 128 paths total.

All discovery at 50 digits. Predictor/corrector, residual below 1e-35, predicted motion <=.22, accepted motion <=.3 and correction <=.06, refinement down to 1e-8 of path parameter. Guards and failed starts are retained. Critical branches start 1e-5 away in relative target value. Endpoint assigned to nearest cached positive zero with distance reported, never forced to be a zero. Validation will tighten step and increase precision before accepting surprises.

Two-job pilot is part of the same wall clock; 14 workers with native threads one. Whole process deadline 585s + cleanup below10s; code checks575s. Partial output is preserved. Deterministic, no RNG seed needed. Cache provenance and exact package versions captured by guard. No remote deletion before verified download.

Discriminants: endpoint labels and distances, pair adjacency, path shape/reversal differences, critical-value distance to1, derivative minima, residuals, failed lifts. A solver jump can mimic monodromy: refinement plus independent continuation is required. No global RH or novelty claim from finite data.

Whole-route consequence: determines whether inverse-value geometry offers a new organization of actual zeros worth studying, independently of known HB identification/selection obstructions. Positive salvage: isolate finite graph components or failure boundaries even if the initial neighboring-only explanation survives.

Prior audit: shared ledger search found no inverse-zeta/critical-value/monodromy entry; current deep and hybrid corpus searches are partial and did not return a directly applicable inverse-zeta graph result. This is not an exhaustive novelty audit.
