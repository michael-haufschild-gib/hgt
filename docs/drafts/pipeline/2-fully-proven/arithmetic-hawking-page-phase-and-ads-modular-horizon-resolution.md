## Proof

Let `K := criticalAliasCoefficient 1 > 0`, `a(R) = K / R`, `λ(R) := criticalHalfLineGroundEnergy R`, and `μ(t) := confiningHalfLineGroundEnergy t = λ(t⁻¹)` for `R, t > 0`.

1. **Strict exponential-mass excess and two-sided secant bounds (`one_lt_exponential_mass_of_unit_domain`, `confiningHalfLineGroundEnergy_secant_bounds`).** Let `F ∈ CriticalHalfLineEnergyDomain` satisfy `∫ F² = 1`. Since `F(u) = 0` for `u ≥ 0`, `F(u)²(e^{-8u} - 1) ≥ 0` for all `u ∈ ℝ` with strict positivity wherever `F(u) ≠ 0` and `u < 0`. If `W_8(F) := ∫ F² e^{-8u} = 1`, then `∫ F²(e^{-8u} - 1) = 0`; nonnegativity and integrability give `F(u)²(e^{-8u} - 1) = 0` a.e., hence `F = 0` a.e. (`e^{-8u} > 1` on `(-∞, 0)`), contradicting `∫ F² = 1`. Thus `W_8(F) > 1`.
   For `0 < t₁ < t₂` with unit minimizers `F₁` at `t₁⁻¹` and `F₂` at `t₂⁻¹`, optimality and `E_{t⁻¹}(G) = E_0(G) + K t W_8(G)` give
   $$\mu(t_2) - \mu(t_1) \ge E_{t_2^{-1}}(F_2) - E_{t_1^{-1}}(F_2) = K(t_2 - t_1)W_8(F_2),$$
   $$\mu(t_2) - \mu(t_1) \le E_{t_2^{-1}}(F_1) - E_{t_1^{-1}}(F_1) = K(t_2 - t_1)W_8(F_1),$$
   with strict inequalities because `F₁` cannot minimize at `t₂⁻¹` and `F₂` cannot minimize at `t₁⁻¹` (`halfLineEnergyMinimizer_ratio_unique`). Since `W_8(F₂) > 1`, we obtain unconditionally
   $$0 < K < K W_8(F_2) < \frac{\mu(t_2) - \mu(t_1)}{t_2 - t_1} < K W_8(F_1).$$
   In particular `μ` is strictly increasing on `(0, ∞)` and `λ` is strictly decreasing on `(0, ∞)`.

2. **Resolution of (1) & (2): Coupling-endpoint sign and Legendre-intercept identification.** Applying step 1 to `t₁ = e^u < t₂ = e^u + e^v` gives
   $$\text{confiningCoexistenceSource}(u, v) = \frac{\mu(e^u + e^v) - \mu(e^u)}{e^v} > K W_8(F_{(e^u + e^v)^{-1}}) > K > 0$$
   for all `u, v ∈ ℝ`. By `endpoint_gap`, `confiningSourceEnergy z (e^u + e^v) - confiningSourceEnergy z (e^u) = e^v (\text{confiningCoexistenceSource}(u, v) - z)`. Hence for every `z ≤ K` (including `z = 0` and all `z ≤ 0`), `confiningSourceEnergy z (e^u) < confiningSourceEnergy z (e^u + e^v)` at every scale `(u, v) ∈ ℝ²`, unconditionally under both `RH` and `¬RH`: the weak-confinement (larger-`R`) endpoint always strictly wins below `z = K`, and the strong-confinement endpoint wins above `confiningCoexistenceSource u v`.
   Define the bare unconfined Weil energy `bareHalfLineEnergy F := E_R(F) - a(R) W_8(F)` (`= archForm F - primeSum F + 2 coshHalfMoment F ^ 2 - 2 sinhHalfMoment F ^ 2`, independent of `R`). Fixing `R > 0` with unit minimizer `F_R` and setting `z_R := K W_8(F_R) = μ'(R⁻¹)`, for every `s > 0` with `s ≠ R⁻¹` (`s⁻¹ ≠ R`), strict non-optimality of `F_R` at `s⁻¹` gives `μ(s) < E_{s⁻¹}(F_R) = bareHalfLineEnergy F_R + K s W_8(F_R)`, so
   $$\text{confiningSourceEnergy } z_R \, s = \mu(s) - z_R s < \text{bareHalfLineEnergy } F_R = \text{confiningSourceEnergy } z_R \, (R^{-1}).$$
   Thus `s = R⁻¹` is the unique strict global maximizer of `s ↦ confiningSourceEnergy z_R s` on `(0, ∞)`, with maximum value `bareHalfLineEnergy F_R`. Under `RH`, `exists_window_energy_recovery` (which bounds `W_8(H_k) ≤ 2 W_8(G)`) applied as `R → ∞` (`a(R) → 0`) together with `0 ≤ weilQuad H` (`riemannHypothesis_iff_windowThreshold_eq_top`) gives `0 ≤ bareHalfLineEnergy G` for all `G ∈ CriticalHalfLineEnergyDomain`, hence `E_R(F_R) ≥ a(R) W_8(F_R) > K / R > 0` and `0 ≤ confiningSourceEnergy z_R (R⁻¹)` for all `R > 0`. Conversely, if `0 ≤ bareHalfLineEnergy F_R` for all `R > 0`, then `λ(R) = bareHalfLineEnergy F_R + a(R) W_8(F_R) > 0` for all `R > 0`, which implies `RH` by step 3.

3. **Occupation Hawking–Page transition on `{∫ G² ≤ 1}`.** For any `R > 0` and `G ∈ CriticalHalfLineEnergyDomain` with `m := ∫ G² ∈ [0, 1]`, if `m = 0` then `Q_R(G) = E_R(G) ≥ 0` and `(a(R)/2) W_8(G) ≤ E_R(G)` (`criticalHalfLineFullEnergy_coercive_remainder`), so `E_R(G) ≥ 0` with equality iff `G = 0` a.e.; if `m > 0`, homogeneity gives `E_R(G) ≥ m λ(R)` with equality iff `m^{-1/2} G` is a unit minimizer at `R`, i.e. `G = ±√m F_R` a.e.    $$\inf\bigl\{E_R(G) : G \in \text{CriticalHalfLineEnergyDomain},\, \textstyle\int G^2 \le 1\bigr\} = \min(0, \lambda(R)).$$
   - **Under `RH` (`W = ⊤`):** For every `R > 0`, `bareHalfLineEnergy F_R ≥ 0` gives `λ(R) ≥ a(R) W_8(F_R) > K / R > 0`, so `min(0, λ(R)) = 0` and `G = 0` a.e. is the unique global minimizer on `{∫ G² ≤ 1}` at every `R > 0`.
