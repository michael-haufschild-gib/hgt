### Theorem 1 (Refutation of unrestricted A10 and Unconditional Collar Gårding) `[PROVED HERE]`

**(a) Failure of unrestricted A10.** Set `z_N = (e₁ - √2 e₂) / √3 ∈ (conductorSubspace 1 N)ᗮ`. For `N > 4 c_N`, `w_N = c_N / N < (log 2)/2`, so the uncentred test `f_N = atomicTest N z_N (atomDilate φ w_N)` is supported in `[0, 2]` with disjoint atoms. By `weilQuad_centredAtomicTest`, `weilQuad(centredAtomicTest φ z_N c_N N) = weilQuad(f_N)`. On `[0, 2]`, `archForm(f_N) ≤ C₁ w_N log(1/w_N)`, `|primeSum(f_N)| ≤ C₂ w_N`, and `|poleTerm(f_N)| ≤ C₃ w_N²`. Rescaling to `U_N = normalizedCentredAtomicTest φ z_N c_N N = (√N / c_N) centredAtomicTest φ z_N c_N N` gives `‖U_N‖_{L²}² = (∫ φ²)/c_N`, `weilQuad(U_N) ≤ C (log N)/c_N`, and on `[−log N, −log N + w_N]` (`n = 1`), `W₈(U_N) ≥ (e⁻⁸ ∫ φ² / (3 c_N)) N⁸`. Normalizing `Ũ_N = U_N / ‖U_N‖_{L²}` gives `‖Ũ_N‖_{L²} = 1`, `weilQuad(Ũ_N) + B ‖Ũ_N‖_{L²}² ≤ C' log N + B`, and `W₈(Ũ_N) ≥ (e⁻⁸ / 3) N⁸`, contradicting `weilQuad(Ũ_N) + B ‖Ũ_N‖_{L²}² ≥ a W₈(Ũ_N)` for every `a > 0` and `B ∈ ℝ`.

**(b) Unconditional Collar Atomic Gårding.** Let `y` be supported on `Ioc M N` and `U_y = normalizedCentredAtomicTest φ y c_N N`, `f_y = centredAtomicTest φ y c_N N = (c_N / √N) U_y`.
1. *Interpolated Lévy bound:* Splitting `levyEnergy h` at `0 < t₀ ≤ 1` and integrating by parts twice on `|u| ≥ t₀` gives `levyEnergy h ≤ 2 t₀² ∫ (h')² + (78 / t₀) ∫ h²`.
2. *Dyadic collar archimedean reserve at arbitrary `R > 0`:* In the dyadic shell partition `f_y = ∑_k χ_k f_y`, `F_k = I_{S_k} f_y`, `R_k = χ_k f_y - F_k`, retain `-C₀ ∫ F_k²` in the shell reserve instead of bounding `∫ F_k²` by `(1 + 2 e c_k) w_N ∫ φ² ∑_{S_k} y_n²`. Since `∫ F_k² ≤ 2 ∫ (χ_k f_y)² + 2 ∫ R_k²` and `∑_k χ_k² ≤ 9`, summing over `k` yields `-18 C₀ ∫ f_y² - o_N(1) w_N S₇(y)` where `S₇(y) = topCollarSeventhMass M N y`. Applying the interpolated Lévy bound to `R_k` at `t₀ = √(c_N / N)` turns `∑_k levyEnergy(R_k)` into `O((c_N² / N + c_N (c_N / N)^{3/2}) S₇(y)) = o((L / c_N⁷) w_N S₇(y))`. Thus eventually `archForm(U_y) ≥ (d₀ / R) W₈(U_y) - B₁ ‖U_y‖_{L²}²` (`d₀ > 0`), using `W₈(U_y) ≤ C_φ S₇(y) / ∫ φ²` (`normalized_tail_exponential_mass_le`).
3. *Prime and pole absorption:* By `exists_abs_primeSum_le_exponential_mass` on `U_y` (supported in `[−log(linearDefectCutoff c_N), 1]`, shifted by `-1` via `weilQuad_translate`), `|primeSum(U_y)| ≤ (d₀ / (4 R)) W₈(U_y) + B₂(R) ‖U_y‖_{L²}²`. For the negative `sinh(u/2)` pole square, splitting `∫ U_y(u) sinh(u/2) du` at `-Y_R` bounds `(∫_{u < -Y_R} |U_y| e^{-u/2})² ≤ (∫ U_y² e^{-8u})(∫_{u < -Y_R} e^{7u}) = (e^{-7 Y_R} / 7) W₈(U_y) ≤ (d₀ / (4 R)) W₈(U_y)`, while `(∫_{-Y_R}^1 |U_y| |sinh(u/2)|)² ≤ C(Y_R) ‖U_y‖_{L²}²`. Combining gives `weilQuad(U_y) + B_R ‖U_y‖_{L²}² ≥ (d₀ / (2 R)) W₈(U_y)`.

### Theorem 2 (Discrete and Continuum Logarithmic Window Confinement) `[PROVED HERE]`

**(a) Discrete support non-escape at length `(1/8) log R + O(1)`.** Let `K₁ > 0` be the certified critical multiple of `exists_tiltedUnitSpline_completeWeilEnergy_ge_spectral_floor_at_critical_multiple`, and set `Λ_R = ⌈(R + 1)^{1/8} / K₁ + 2⌉`. Put `N' = ⌊N / Λ_R⌋` and `c'_N = c_N N' / N`. Then `c'_N / N' = c_N / N` and eventually `1 ≤ c'_N ≤ 2 K₁ (log N')^{1/8}`. For any `x` with `x_n = 0` on `(⌊N / Λ_R⌋, N]`, `atomicTest N x (atomDilate φ (c_N / N)) = atomicTest N' x (atomDilate φ (c'_N / N'))`, so `⟨B_N x, x⟩ = ⟨B_{N'}(c'_N) x', x'⟩ ≥ (κ₀ / (2 (c'_N)⁷)) ‖x‖² > 0` for `x ≠ 0`. Consequently every nonzero `x` with `⟨B_N x, x⟩ ≤ 0` satisfies `∃ n ∈ Ioc ⌊N / Λ_R⌋ N, x_n ≠ 0`.

**(b) All-space window-localized Gårding and `L¹`/`L²` precompactness.** Decompose `x = y + u₀ + u₁ + w` orthogonally with `Q₁ = ⌊L^{13/32}⌋`, `Q₂ = ⌊N^{5/12}⌋`, `y ∈ V_{Q₁}`, `u₀ ∈ V_{Q₁}^⊥ ∩ V_{Q₂}`, `u₁ ∈ V_{Q₂}^⊥` supported in `[1, M]`, and `w ∈ V_{Q₂}^⊥` supported in `Ioc M N`. Split `w = w_{sub} + w_{win}` across `Ioc M ⌊N / Λ'_R⌋` and `Ioc ⌊N / Λ'_R⌋ N` where `log Λ'_R = O(log R + 1)`.
1. *All-ratio three-band complement reserve:* Because `c_N^8 ≤ (R + 1) L` implies `c_N ≤ L^{65/512}` eventually, the middle-conductor (`u₀`) and separated-prefix (`u₁`) bands retain `≳ (L / c_N⁷)(‖u₀‖² + ‖u₁‖²)` and pay all cross terms with `w`. On `w`, replacing `farLinearConstant · c_N · S₇(w)` by Collar Atomic Gårding (Theorem 1(b)) plus the prefix pole defect gives `(1 / c_N)⟨B_N(u₀ + u₁ + w), u₀ + u₁ + w⟩ + B₁(R) ‖W_N‖_{L²}² ≥ a₁(R) (W₈(W_N) + S₇(w) + (‖u₀‖² + ‖u₁‖²)/c_N)`. Since `‖W_{sub,N}‖_{L²}² ≤ e (Λ'_R)^{-8} W₈(W_{sub,N}) ≤ C (Λ'_R)^{-8} S₇(w)`, taking `(Λ'_R)^8 ≥ 4 C B₁(R) / a₁(R)` absorbs `B₁(R) ‖W_{sub,N}‖_{L²}²` into `(a₁(R)/2) S₇(w)`, leaving `+ 2 B₁(R) ‖W_{win,N}‖_{L²}²`.
2. *Low-packet residual coupling at every `R > 0`:* Write `y = ∑_{m ≤ Q₁} b_m v_m`. By `eventually_completeWeil_low_packet_signed_approx`, `(1/c_N)⟨B_N y, y⟩ ≥ (1/(2 c_N)) ∑_{m ≤ Q₁} E_m b_m² - C_{pole} b₁² / L`. Couplings of `y` with `u₀, u₁` and prefix `primeDefect` decay as `O_R(L^{-1/8})`. For `⟨r_m, w⟩` (`r_m = (B_N - E_m I) v_m`):
   - *Above overlap (`c_N < m ≤ Q₁`):* `eventually_upper_critical_packet_residual_mass_le` bounds `∑_{c_N < m ≤ Q₁} ‖r_m‖² / (c_N E_m) ≤ L^{-1/64}`.
   - *Below overlap, large conductor (`m₀(R) < m ≤ c_N`, `m₀(R) = ⌈C₀ R² + 2⌉`):* `exists_completeWeil_dualSeventh_conductor_residual_log_free` bounds `(c_N⁷ / L) ∑_{m₀ < m ≤ c_N} D₇(M, N; r_m) / E_m ≤ C R² ∑_{m > m₀} m^{-5} ≤ a₁(R)/16`.
   - *Sub-collar (`Ioc M ⌊N / Λ'_R⌋`) for `1 ≤ m ≤ m₀(R)`:* On `n ≤ N / Λ'_R`, `(n/N)⁷ ≤ (Λ'_R)^{-6} (n/N)`, so the log-free channel bounds gain `(Λ'_R)^{-6}`; choosing `Λ'_R ≳ (R + 2)^{1/2} m₀(R)` (so `log Λ'_R = O(log R + 1)`) makes `(c_N⁷ / L) ∑_{m=1}^{m₀(R)} D₇(M, ⌊N / Λ'_R⌋; r_m) / E_m ≤ a₁(R)/16`.
   - *Terminal window (`Ioc ⌊N / Λ'_R⌋ N`) for `1 ≤ m ≤ m₀(R)`:* By `complete_terminal_conductor_pair_eq_channels`, `tendsto_complete_terminal_nonpolar_above_half`, and `tendsto_complete_terminal_pole`, for `m ≥ 2` the nonpolar `O(c_N / √(n L))` profiles of `u₃` and `u₆₇` cancel and the remaining terminal pairing tends to `0`, while for `m = 1` the polar profile is Lipschitz on `[−log Λ'_R, 0]`, so `abs_integral_normalizedCentredAtomicTest_mul_sub_le` bounds `⟨r_1, w_{win}⟩² / (c_N E_1) ≤ C_R ‖W_{win,N}‖_{L²}² + o_N(1) ‖w_{win}‖²`.
   Combining yields the All-Space Window-Localized Gårding inequality:
   `(1 / c_N)⟨B_N x, x⟩ + B_R ‖W_{win,N}‖_{L²}² + C_{pole} b₁² / L ≥ a_R (W₈(W_N) + S₇(w) + (1/c_N) ∑_{m ≤ Q₁} E_m b_m² + (‖u₀‖² + ‖u₁‖²)/c_N)`.
   On `(conductorSubspace 1 N)ᗮ`, `b₁ = 0`, so every nonzero `x` with `⟨B_N x, x⟩ ≤ 0` has `‖W_{win,N}‖_{L²} > 0`, bounded `W₈(W_N)` and `weilQuad(W_N)` (when normalized to `‖W_{win,N}‖_{L²} = 1`), hence precompactness in `L²(ℝ)` (`PhysicalAndFourierTailsGiveCompactness` + `BoundedWeilEnergyUpgradesL1LimitsToStrongLimits`) and in global `L¹(ℝ)` (by Cauchy–Schwarz against `e^{4y}` on `(-∞, -Y)` using `supp(W_N) ⊂ (-∞, 1]`).

### Theorem 4 (Discrete Critical Positivity Threshold Law) `[PROVED HERE]`

2. *Lower bound on `R_c^⊥(ζ)`:* Fix `a ≥ 2` with `ZetaWindowPositive a` and `0 < R < c₁' e^{(13/4)a}`.
