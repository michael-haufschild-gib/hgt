### Theorem 0 (Sharp Two-Sided Prefix–Collar Schur Decoupling) `[FORMALIZED: PrefixCollarSchurObstructionAndFarDecoupling]`

Formalized unconditionally in `CriticalArithmeticCorrelationTheory.PrefixCollarSchurObstructionAndFarDecoupling`: (a) `tendsto_prime_quasimode_prefix_collar_schur_ratio`, `not_naive_physical_prefix_collar_schur_decoupling`; (b) `exists_far_prefix_collar_schur_decoupling_below_ratio`, `exists_far_prefix_collar_schur_decoupling`. Combined with the finite-conductor collar reduction and the `m = 1` polar retention law in `CriticalArithmeticCorrelationTheory.FiniteConductorCollarReductionAndPolarDecoupling.complete_prefix_and_low_packet_collar_resolution`.

**(a) `4 / 13` physical-tearing obstruction on `(conductorSubspace Q₁ N)ᗮ`.** Let `q_N` be the least prime `> Q₁`; by Bertrand's postulate (`Nat.exists_prime_lt_and_le_two_mul`), `Q₁ < q_N ≤ 2 Q₁`, so `log q_N = (13/32) log L + O(1)` and `q_N / c_N → ∞`. Set `v = normalizedRamanujanHorizonVector q_N N` and `z_N = P_{(V_{Q_1})ᗮ} v`. Since `q_N > Q₁`, for every `1 ≤ m ≤ Q₁`, `gcd(q_N, m) = 1` and `|⟨v, v_m⟩| = O(√(q_N m) / L)`, whence `‖z_N - v‖ = O(Q₁^2 / L) = O(L^{-3/16})` and replacing `v` by `z_N` changes `⟨B_N ·, ·⟩` on `z_N, p_N, y_N` by `O(c_N Q₁^4 / L^2) = o(1 / c_N)`. Because `D = linearDefectCutoff c_N = ⌈max 3 (256 e^2 c_N)⌉₊`, `log D = log c_N + O(1) = (1/8) log L + O_R(1)` and `c'_M := c_N M / N = (1 / (256 e^2)) + o(1) < 1`. For `v` (`c_{q_N}(n) = q_N - 1` on `q_N ∣ n` and `-1` otherwise):
1. Consecutive multiples of `q_N` in `[1, N]` have log-spacing `≥ q_N / N > c_N / N`, so the `q_N ∣ n` spike component has pairwise disjoint atoms across all of `[1, N]` and is a `+log q_N` translate of the unit horizon vector at `N / q_N`, while the `-1` background has mass `O(1 / q_N)` and energy `O_R((log c_N) / q_N) = o(1)`.
2. At full horizon `N` (`c_N < q_N`), `⟨B_N z_N, z_N⟩ = log q_N - log c_N + O_R(1) = (9/32) log L + O_R(1)`.
3. On the separated prefix `[1, M]` (`c'_M = c_N M / N = O(1) < 1`), `⟨B_N p_N, p_N⟩ = log q_N - log c'_M + O_R(1) = (13/32) log L + O_R(1)`.
4. On the collar `Ioc M N`, `‖y_N‖^2 = (log D) / L + O(1/L) = ((1/8) log L + O_R(1)) / L`, `‖U_{y_N}‖_{L²}^2 = (I₂ / c_N) ‖y_N‖^2 = o(1 / c_N)`, prime shifts `k ≤ D` contribute `O((log D)^2 / L) → 0`, and disjoint self-archimedean energy gives `⟨B_N y_N, y_N⟩ = L ‖y_N‖^2 + O_R(1) = (1/8) log L + O_R(1)`.
5. Polarization gives `2 ⟨B_N y_N, p_N⟩ = ⟨B_N z_N, z_N⟩ - ⟨B_N p_N, p_N⟩ - ⟨B_N y_N, y_N⟩ = -(1/4) log L + O_R(1)`, so `|weilBilin U_{y_N} U_{p_N}|^2 / (weilQuad U_{p_N} · (weilQuad U_{y_N} + B_R ‖U_{y_N}‖_{L²}^2)) → (1/8)^2 / ((13/32)(1/8)) = 4 / 13 > 0`.

**(b) Literal `o(1)` Schur decoupling on the far-conductor prefix.** Let `p ∈ (conductorSubspace R₁ N)ᗮ` vanish on `Ioc M N` and let `y` vanish on `[1, M]`. Since `p` vanishes on `Ioc M N` and `⟨p, v_1⟩ = 0`, `prefixPoleMoment M p = 0`, and by `poleDefect` lower bound on `(V_{R_1})ᗮ` (`R₁ = ⌊N^θ⌋₊`), `poleDefect M p ≥ (θ L / D - 1) ‖p‖^2`, whence `weilQuad U_p ≥ (I₂ / c_N) (c₀ θ L) ‖p‖^2` and `‖U_p‖_{L²}^2 = (I₂ / c_N) ‖p‖^2 ≤ C₀ (θ L)^{-1} weilQuad U_p`. On `y`, Collar Atomic Gårding (`exists_collar_atomic_garding_below_ratio`) gives `κ_R S₇(y) + a_R W₈(U_y) ≤ weilQuad U_y + B_R ‖U_y‖_{L²}^2`. Across the ordered cutoff `M`:
1. `|archBilin(U_p, U_y)| ≤ 2π ‖U_p‖_{L²} ‖U_y‖_{L²}` (`TouchingSupportsHaveBoundedGammaInteraction`) `≤ C₁ (θ L)^{-1/2} √(weilQuad U_p) √(weilQuad U_y + B'_R ‖U_y‖_{L²}^2)`.
2. Since `⟨p, v_1⟩ = 0`, `|I_-(U_p)| = O((c_N / N) √N ‖p‖) = o((θ L)^{-1} √(weilQuad U_p))`, while `|I_+(U_p)| = O((D L)^{-1/2} √(c_N) ‖U_p‖_{L²})` and `|I_±(U_y)| ≤ C_R √(W₈(U_y) + ‖U_y‖_{L²}^2)`, so `|poleBilin(U_p, U_y)| = o_N(1) √(weilQuad U_p) √(weilQuad U_y + B'_R ‖U_y‖_{L²}^2)`.
3. For prime shifts across `M` (`U_p(u) U_y(u + log k)`), `two_mul_abs_integral_mul_atomicTest_le` and `translate_masses_le` with `prefixPoleMoment M p = 0` bound `|primeBilin(U_p, U_y)|` by `C √(c_N^{-1} primeDefect M p) √(c_N S₇(y)) = O_R((c_N^8 / (θ L))^{1/2} / L^{3/8}) √(weilQuad U_p) √(κ_R S₇(y)) = o_N(1) √(weilQuad U_p) √(weilQuad U_y + B_R ‖U_y‖_{L²}^2)`.
Summing (1)–(3) yields `|weilBilin U_y U_p|^2 ≤ ε · weilQuad U_p · (weilQuad U_y + B_R ‖U_y‖_{L²}^2)` eventually for every `ε > 0`.

### Theorem 2 (Discrete Confinement and All-Space Window-Localized Gårding) `[PROVED HERE]`

**(a) Discrete support non-escape at length `(1/8) log R + O(1)`.** Let `K₁ > 0` be the certified multiple of `exists_tiltedUnitSpline_completeWeilEnergy_ge_spectral_floor_at_critical_multiple`, set `Λ_R = ⌈(R + 1)^{1/8} / K₁ + 2⌉₊`, `N' = ⌊N / Λ_R⌋₊`, and `c'_N = c_N N' / N`. **(b) All-space window-localized Gårding at every `R > 0`.** Orthogonally decompose `x = y + u₀ + u₁ + w` with `y = ∑_{m=1}^{Q₁} b_m v_m ∈ V_{Q₁}`, `u₀ ∈ (V_{Q₁})ᗮ ∩ V_{Q₂}` (`Q₂ = ⌊L^{5/8}⌋₊`), `u₁ ∈ (V_{Q₂})ᗮ ∩ V_{R₁}`, and `w ∈ (V_{R₁})ᗮ`, and split `w = w_p + w_y` at `M`.
