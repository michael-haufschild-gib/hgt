## Theorem

Let `C` be the complex numbers with trivial derivation, let `y` be differentially transcendental
over `C`, and put

```text
F = C<y>.
```

For a rational map `R in C(z)` of degree at least two, differential substitution defines an
injective endomorphism

```text
Phi_R : F -> F,
Phi_R(delta^j y) = delta^j(R(y)).
```

Define the stable observable field

```text
Tail(R) = intersection over n >= 0 of Phi_R^n(F).
```

Then:

1. `Tail(R) != C` if and only if there are an integer `k > 0`, a nonzero rational
   `k`-differential `q(z)(dz)^k` on the projective line, and `lambda in C^*` such that

   ```text
   R^*(q(z)(dz)^k) = lambda q(z)(dz)^k.
   ```

2. Equivalently, `R` preserves a parabolic orbifold and is, up to projective conjugacy, a power,
   Chebyshev, or Lattes map.

3. If `k` is minimal and

   ```text
   Q_R = q(y) (delta y)^k,
   ```

   then the full tail is

   ```text
   Tail(R) = C<Q_R>.
   ```

The scalar `Q_R` is itself hypertranscendental over `C`.  Thus every scale is again a free
hypertranscendental field, while the intersection of all scales is either trivial or one free
field carried by the orbifold current.

## Proof

### 1. Every nonconstant stable core is projective

The stable-core theorem in
`scalar-differential-inversive-core-projective-law.md` applies to `Phi_R`.  If `Tail(R)` is
nonconstant, differential Luroth gives a differentially transcendental `u` such that

```text
Tail(R) = C<u>.
```

The restriction of `Phi_R` to the tail is an automorphism.  Differential-order additivity and its
inverse force this automorphism to have order zero, so there is an `M in PGL_2(C)` with

```text
Phi_R(u) = M(u).                                             (1)
```

This turns the infinite intersection into a finite-order differential semiconjugacy.

### 2. The Schwarzian makes the Malgrange envelope proper

For a nonconstant differential rational function `v`, write

```text
S(v) = v'''/v' - (3/2)(v''/v')^2.
```

Because `u` is differentially transcendental, `u'` is nonzero.  The projective chain rule and the
fact that the coefficients of `M` are differential constants give

```text
S(M(u)) = S(u).
```

Since `Phi_R` commutes with the derivation, (1) therefore implies

```text
Phi_R(S(u)) = S(Phi_R(u)) = S(M(u)) = S(u).                 (2)
```

The invariant `S(u)` is nonconstant.  Otherwise `S(u)=c in C` would be the nonzero differential
equation

```text
2 u' u''' - 3 (u'')^2 - 2 c (u')^2 = 0,
```

contradicting the differential transcendence of `u`.

If `u` has order `m`, then `S(u)` is a nonconstant rational differential invariant on the
`(m+3)`-frame space of the projective line.  Equation (2) is a nonzero differential equation
satisfied by the prolonged rational map.  In the terminology of Casale and Casale--Roques, the
Malgrange differential envelope of `R` is therefore nontrivial.  Casale's classification theorem
now forces `R`, up to homography, to be a monomial, a Chebyshev polynomial, or a Lattes map.

This proves the difficult implication

```text
Tail(R) != C  ==>  R is parabolic-orbifold exceptional.     (3)
```

Garofali's classification identifies the same exceptional list with rational maps admitting a
parallel meromorphic tensor.

### 3. Differential fixed fields on an exceptional cover

It remains to compute the whole tail rather than merely construct one element of it.  Use the
standard exceptional presentation

```text
G --A--> G
|        |
pi       pi
v        v
P1 --R--> P1,                                                (4)
```

where `G` is `G_m` or an elliptic curve, `A` is an affine isogeny, and `pi` is the quotient by a
finite orbifold group `H`.  Let `p` be a differential-generic path on `G`, and let

```text
L = C<p>.
```

Choose a nonzero translation-invariant one-form `omega` on `G` and set

```text
v = omega_p(delta p).
```

The finite jet field of a path on a one-dimensional group has translation coordinates

```text
C(G)(v, v', ..., v^(r)).                                    (5)
```

at order `r`.  Hence the full translation-invariant differential field is exactly

```text
L^G = C<v>.                                                  (6)
```

Indeed, translation fixes all the velocity jets in (5), while a rational function of the base
point fixed by the Zariski-dense translation action is constant.  Applying this after extending
scalars by the algebraically independent velocity jets proves (6) at every finite order.

For `f_n = pi composed with A^n`, separability of `f_n` gives

```text
C<f_n(p)> = L^(Gamma_n),                                    (7)
```

where `Gamma_n` is its finite deck group.  To see that differentiating introduces no extra
algebraic degree, adjoin `p` to `C<f_n(p)>`: the first derivative of `f_n(p)` recovers the invariant
velocity after `p` is adjoined, and the higher derivatives then recover all higher velocity jets.
Thus the differential extension has the same degree and deck automorphisms as the algebraic cover
`f_n`.

The groups `Gamma_n` contain the translation kernels of `A^n`.  Their union is infinite and hence
Zariski dense in the one-dimensional connected algebraic group `G`.  Every element of `L` uses
only finitely many jets, so its stabilizer is Zariski closed.  Therefore

```text
intersection_n L^(Gamma_n) = L^(G semidirect H)
                            = C<v>^H.                       (8)
```

The group `H` acts on `omega` through a finite character.  Let `k` be the order of its image.  It
acts on every velocity jet by `v^(j) |-> zeta v^(j)`, and

```text
C<v>^H = C<v^k>.                                             (9)
```

For completeness, at jet order `r` the fixed field of this scalar `mu_k` action is generated by
`v^k` and `v^(j)/v`.  Successive derivatives of `v^k`, divided by `v^k`, recover
`v^(j)/v` triangularly.  Taking the union over `r` proves (9).

Finally the minimal parallel tensor `q(z)(dz)^k` is characterized, up to a nonzero scalar, by

```text
pi^*(q(z)(dz)^k) = omega^k.
```

Consequently its evaluation on the source jet satisfies

```text
Q_R = q(y)(delta y)^k = v^k
```

under the identification `y=pi(p)`.  Equations (7)--(9) prove

```text
Tail(R) = C<Q_R>.                                            (10)
```

This also proves the exceptional implication and the exact-tail assertion.

### 4. Direct inclusion and positive-order erasure

Independently of the cover computation, `R^*q = lambda q` gives

```text
Phi_R(Q_R) = lambda Q_R,
```

so `C<Q_R>` is contained in `Tail(R)`.  The first two elementary signatures are

```text
R(z) = z^d:      Q_R = delta y / y,
R(z) = T_d(z):   Q_R = (delta y)^2 / (y^2 - 1).
```

For every differential rational substitution of positive differential order `r`, order additivity
gives

```text
ord_y(Phi_R^n(a)) = ord_y(a) + n r
```

for nonconstant `a`; hence its stable observable field is `C`.  The rational-map case has order
zero and is the only place where a topological orbifold residue can survive.

`Phi_R^n(F)` is the algebra of finite-order observations available after `n` applications of the
same local coarse-graining.  Generic rational dynamics loses every nonconstant observation in the
infinite-depth tail.  Exceptional dynamics retains exactly an orbifold current.  The surviving

This is a zero-one law for information horizons.  Infinite-depth memory is absent generically; if
it exists, the memory is precisely the quotient of translation velocity by the finite holonomy of
a parabolic orbifold.

## 2026-08-16 — a Casale-free route to the hard direction, and the exact gap in it

The only paper-level input left in this card is step 2, where Casale's classification is quoted.
The following is a completely elementary chain that reaches the *tensor* half of item `(1)` — i.e.
`Tail(R) != C` implies `R` preserves a nonzero rational `k`-differential up to a scalar — using only
machinery the corpus already owns, together with one named gap.  Recording it so the next pass does
not have to rediscover it.

**Steps that are already corpus-formalized.**

1. `Tail(R) != C` gives `Tail(R) = C<u>` by `differentialLuroth`, and `u` is hypertranscendental
   (`differentialRational_noDAShadow`).
2. `Phi_R` restricts to a *bijection* of `Tail(R)`, because the intersection defining the tail is
   decreasing: `Phi_R(Tail) = intersection_(n>=1) Phi_R^n F = Tail`.  So `Phi_R|_Tail` is a
   differential automorphism of a free differential field on one generator, and
   `MutualGeneratorMobius`/`algEquiv_generator_mobius_of_mem` give `M in PGL_2(C)` with
   `Phi_R(u) = M(u)`.
3. Conjugating `u` by a Moebius map replaces `M` by a conjugate, so over `C` one may assume
   `M(u) = alpha u` or `M(u) = u + 1`.
4. `ord_y(u) = 0` is impossible: it would give `u . R = M . u` in `C(y)`, and comparing degrees
   `deg u * deg R = deg u` forces `deg R = 1`.  So `m := ord_y(u) >= 1`.

**The new step.**  Apply the top coordinate derivation `pd_m = ∂/∂y_m`, using the principal-symbol
identity now available as `HTGeometry.pd_differentialJet_top`
(`JetPrincipalSymbolExtraction.lean`): since `Phi_R(y_l) = delta^l R(y)` has `pd_m`-derivative `0`
for `l < m` and `R'(y)` for `l = m`, the chain rule gives

```text
pd_m(Phi_R v) = Phi_R(pd_m v) * R'(y)     for every v of order <= m.
```

With `w := pd_m u != 0` and `lambda := alpha` (resp. `1`) this reads

```text
Phi_R(w) * R'(y) = lambda * w.                                      (T1)
```

**The descent.**  If `ord_y(w) = nu >= 1`, write `w = P/Q` in lowest terms as a rational function of
`y_nu` over `C(y_0,...,y_(nu-1))`, with `y_nu`-degrees `a` and `b` and leading coefficients `p_a`,
`q_b`.  Because `Phi_R(y_nu) = R'(y) y_nu + (terms in y_0..y_(nu-1))`, the substitution preserves
the `y_nu`-degree and multiplies the leading coefficient of a degree-`c` polynomial by `R'^c`.
Comparing leading coefficients in `(T1)` gives

```text
Phi_R(s) * R'(y)^(e') = lambda * s,     s := p_a/q_b,  e' = e + a - b,
```

with `ord_y(s) <= nu - 1`.  Iterating down to order zero produces `s_0 in C(y)^x`, `e_0 in Z` and
`lambda_0 in C^x` with

```text
s_0(R(y)) * R'(y)^(e_0) = lambda_0 * s_0(y).                        (T2)
```

If `e_0 != 0` then `s_0 (dz)^(e_0)` is an `R`-invariant tensor (invert it if `e_0 < 0`), which is
exactly item `(1)`.

**The gap.**  `(T2)` with `e_0 = 0` says `s_0 . R = lambda_0 s_0`, and comparing degrees forces
`s_0` constant and `lambda_0 = 1` — no information.  So the descent as stated can terminate
vacuously.  Two ways out are visible and neither has been checked:

* keep the whole `y_nu`-divisor rather than only the leading coefficient — the substitution moves
  the roots by `rho |-> (Phi_R(rho) - L)/R'`, and the multiset identity
  `sigma(roots P) + roots Q = roots P + sigma(roots Q)` is extra information the leading-coefficient
  comparison throws away;
* for `R` a *polynomial* of degree `d` with leading coefficient `c`, the substitution is graded:
  it multiplies total jet degree by exactly `d`, with top form `y_0 |-> c y_0^d`,
  `y_j |-> c d y_0^(d-1) y_j` for `j >= 1`, and the top-form comparison in `(T1)` reduces to the
  identity `d * P(dy) Q(y) = lambda P(y) Q(dy)` between polynomials in `y_1, y_2, ...` alone.  That
  identity is very rigid and may already force the classification for polynomials.

**Why this matters for the two dependent cards.**  `floquet-orbifold-tail-emergence` needs only
`Tail(z^2+1) = C` and `Tail((z-1)^2) = C`.  Given the tensor half above, those follow from an
elementary orbit argument that needs no classification: the functional equation
`q(R(z)) R'(z)^k = lambda q(z)` gives, at every point `a`,

```text
e_a * ord_(R(a))(q) + k * [a is a critical point, with its multiplicity] = ord_a(q).
```

For `R = z^2+1` the only finite critical point is `0`, so `ord_a(q) = ord_(R(a))(q)` for `a != 0`
and `ord_0(q) = 2 ord_1(q) + k`.  The forward orbit `0 -> 1 -> 2 -> 5 -> 26 -> ...` is infinite and
`ord` is constant along it, so `ord_1(q) = 0` and `ord_0(q) = k != 0`; then `ord` is constant along
the *backward* orbit of `0`, which is infinite, so `q` has infinitely many zeros or poles — absurd.
The same argument kills `(z-1)^2` after translating its critical point to the origin.

### 2026-08-16 (later) — the gap has a normal form: the pole multiset is `sigma`-stable

The leading-coefficient descent above throws away exactly the information that repairs it.  Here is
the repaired step, still elementary and still inside the corpus's machinery.

Start from `(T1)`: `Phi_R(w)·R'(y) = lambda·w`, `w != 0`, `nu := ord_y(w) >= 1`.  Apply `pd_nu` to
both sides.  Since `R'(y)` does not involve `y_nu`, and since `pd_nu(Phi_R v) = Phi_R(pd_nu v)·R'`
for `v` of order `<= nu` (`HTGeometry.pd_differentialJet_top`), this gives

```text
Phi_R(pd_nu w)·R'^2 = lambda·pd_nu w .
```

Dividing by `(T1)` and writing `v := pd_nu w / w` — the logarithmic derivative in the *top jet
variable* — the eigenvalue cancels:

```text
Phi_R(v)·R'(y) = v ,        v != 0 ,        ord_y(v) <= nu .        (T3)
```

`v != 0` because `pd_nu w = 0` would contradict `ord_y(w) = nu`.

Now `(T3)` is rigid, because `v` is a logarithmic derivative: over the field
`F := C(y_0, ..., y_(nu-1))` write `w = c·prod_i (y_nu - r_i)^(m_i)` with distinct `r_i` in an
algebraic closure of `F` and `m_i` nonzero integers.  Then

```text
v = sum_i m_i / (y_nu - r_i) .
```

Since `Phi_R(y_nu) = R'(y)·y_nu + L` with `L` of order `< nu`, substituting and multiplying by `R'`
gives

```text
Phi_R(v)·R' = sum_i m_i / (y_nu - sigma(r_i)) ,
   sigma(r) := (Phi_R(r) - L) / R' .
```

Comparing with `v` and using uniqueness of the partial-fraction decomposition over `F`:

> **the finite multiset `{(r_i, m_i)}` is invariant under `sigma`.**

That is the missing rigidity, and it survives the passage back to `F`.  `sigma` is the twist of the
injective endomorphism `Phi_R` by the affine change `t |-> (t - L)/R'`, so it is injective; a finite
`sigma`-stable multiset is therefore permuted.  Since `sigma` commutes with the `F`-conjugation
action only after `Phi_R` is applied to `F` as well, the invariant statement to use is the one about
*coefficients*, not roots: writing

```text
w = c · P(y_nu) / Q(y_nu) ,     P, Q in F[T] monic and coprime,
```

the multiset identity says exactly that the monic polynomial `P·Q` in `F[T]` obeys

```text
(P·Q)^(Phi_R) (R'·T + L)  =  R'^(deg(P·Q)) · (P·Q)(T) ,
```

an identity between polynomials whose coefficients lie in `F`, i.e. have order `<= nu - 1`.
Comparing coefficients of `T^c` gives, for each `c`, a relation of the shape `(T1)` one order lower,
with the *computable* eigenvalue `R'^(deg(P·Q) - c)` — so the exponent on `R'` is never lost, which
is precisely what the old leading-coefficient descent could not guarantee.

At `nu = 0` the relation `(T3)` reads `s(R(y))·R'(y) = s(y)` with `s in C(y)^x`.  That *is* an
invariant `1`-differential; the `e_0 = 0` degeneration of the old descent cannot occur here, because
`(T3)` carries the exponent `1` on `R'` by construction rather than by accident.

**What is left to check.**  That the coefficient relations above are not all vacuous — i.e. that at
least one coefficient of `P·Q` is nonconstant, or else that `P·Q = T^(deg)` and the relation becomes
`R'^deg · T^deg = R'^deg T^deg`, in which case `w` is a monomial `c·y_nu^(a-b)` in `y_nu` and `(T1)`
reduces directly to `Phi_R(c)·R'^(1 + a - b) = lambda·c` with `c in F`, i.e. `(T1)` one order lower
with exponent `1 + a - b`.  Both branches decrease `nu`; the surviving obligation is to rule out
`1 + a - b = 0` in the monomial branch, which is the same arithmetic accident as before but now
isolated to a single, completely explicit case.

**The monomial branch is almost always empty.**  `Phi_R(y_nu) = delta^nu(R(y_0))`, so

```text
nu = 1 :  Phi_R(y_1) = R'(y_0)·y_1 ,                       L = 0 ;
nu = 2 :  Phi_R(y_2) = R''(y_0)·y_1^2 + R'(y_0)·y_2 ,      L = R''(y_0)·y_1^2 ;
```

and in general `L` is a nonzero polynomial in `y_1, ..., y_(nu-1)` as soon as `R'' != 0`, i.e. as
soon as `R` is not affine.  If `w = c·y_nu^k` is a monomial with `k != 0`, then `(T1)` requires
`(R'·y_nu + L)^k` to be proportional to `y_nu^k`, which forces `L = 0`.  Hence for a non-affine `R`
the monomial branch survives only at `nu = 1`, where `(T1)` becomes

```text
Phi_R(c)·R'^(k+1) = lambda·c ,     c in C(y_0)^x .
```

If `k + 1 != 0` this is an invariant `(k+1)`-differential and the card's item `(1)` is proved.  If
`k + 1 = 0`, i.e. `w = c/y_1`, then `c(R(y_0)) = lambda·c(y_0)`, so `c` is constant and `lambda = 1`
by degree comparison; but `w = pd_1 u` with `u` in the *rational* jet field, and `pd_1 u = c/y_1`
has no rational primitive in `y_1`.  Contradiction.

So for non-affine `R` the descent has exactly two exits, an invariant tensor or a contradiction, at
every stage except the passage `nu -> nu - 1` through the coefficient identity, which is the single
remaining bookkeeping step.

### `(T1)` and `(T3)` are formalized — and the relative constant-kernel lemma was not needed

The gap flagged in the previous section turned out to be avoidable.  What the chain rule really
needs is the *total* derivative formula on a finite jet slice, not a characterisation of the
elements of a given order.

Every element of `JetField C Unit` lies in `jetObservableField C y_0 N` for **some** `N`
(`exists_jetObservableField_of_mem_differentialAdjoin`, since
`differentialAdjoin C {y_0} = ⊤`).  On that slice the two maps

```text
v |-> pd_M (Phi_R v)          and       v |-> Σ_(l ≤ N) Phi_R(pd_l v) · pd_M(delta^l R(y_0))
```

are both `Phi_R`-twisted derivations agreeing on the coordinates `y_0, ..., y_N` and on constants,
so their equalizer is an intermediate field containing the slice (`substitutionChainField`).  The
triangularity already proved — `pd_M(delta^l R(y_0)) = 0` for `l < M`, `= R'(y_0)` for `l = M` —
then collapses the sum as soon as `v` has order at most `M`:

```text
pd_jetSubstitution_top :
  (∀ j > M, pd_j v = 0)  ⇒  pd_M (Phi_R v) = Phi_R (pd_M v) · R'(y_0) .
```

That is `(T1)`'s chain rule, unconditionally.  Two consequences, also formalized:

```text
pd_commutator, pd_comm                coordinate partials commute
pd_order_le                           pd_M preserves "order at most M"
pd_eigen_of_jetSubstitution_eigen     (T1):
    Phi_R u = lam·u,  ord u ≤ M   ⇒   Phi_R(pd_M u)·R'(y_0) = lam·pd_M u
eigen_logDeriv_pd_of_jetSubstitution_eigen   (T3), for M ≥ 1:
    Phi_R( pd_M(pd_M u) / pd_M u ) · R'(y_0) = pd_M(pd_M u) / pd_M u
```

The hypothesis `M ≥ 1` in `(T3)` is exactly the card's `m = ord_y(u) ≥ 1`: it is what makes
`pd_M(R'(y_0)) = 0`, so that the derivative factor is a `pd_M`-constant and the eigenvalue can
cancel.  The normalization lemma `eigen_logDeriv_of_chain_rule` was correspondingly weakened to
require the chain rule only at the eigenvector itself.

**What is left of the hard direction.**  Only the descent recorded above: from `(T3)` at order
`nu`, the coefficient identity `(P·Q)^(Phi_R)(R'·T + L) = R'^(deg)·(P·Q)(T)` in `F[T]`, the
`sigma`-stable pole multiset, and the explicit `nu = 1` branch (where `L = 0` and
`coeff_eigen_pow_of_comp_scale` applies directly).  No missing infrastructure remains between the
card's setup and that descent.

### The Euler dichotomy at order one

`Phi_R` scales the first jet coordinate *exactly*: `delta(R(y_0)) = R'(y_0)·y_1`, with no lower-order
remainder, because `L = 0` at `nu = 1`.  Formalized as

```text
substitutionJet_one        delta(R(y_0)) = y_1 · R'(y_0)
jetSubstitution_jet_one    Phi_R(y_1) = y_1 · R'(y_0)
```

(the proof is the corpus's `freeCoordinate_chainRule` on the one-coordinate slice: the total
derivative of an order-zero element is `y_1` times its `pd_0`).

Consequently the Euler operator `E = y_1·pd_1` is intertwined by `Phi_R` up to the derivative
factor, and the *logarithmic* Euler derivative of a `(T3)`-eigenvector is a genuine invariant:

```text
jetSubstitution_eulerQuotient :
  v != 0,  ord v ≤ 1,  Phi_R(v)·R'(y_0) = v
    ⇒  Phi_R( y_1 · pd_1 v / v ) = y_1 · pd_1 v / v
mem_orbifoldTail_of_fixed :
  Phi_R g = g  ⇒  g ∈ Tail(R)
```

The computation is three lines once the chain rule is available: `Phi_R v = v/R'`, hence
`pd_1(Phi_R v) = pd_1 v / R'`, hence `Phi_R(pd_1 v) = pd_1 v / R'^2`, and the two factors `R'`
cancel against `Phi_R(y_1) = R'·y_1` in the quotient.

**The dichotomy this produces.**  Write `g := y_1·pd_1 v / v ∈ Tail(R)`, of order at most one.

* If `g` is nonconstant, `Tail(R)` contains a nonconstant element of order at most one.
* If `g ∈ C`, then `pd_1 v / v = g / y_1`; a rational function of `y_1` has logarithmic derivative
  `Σ m_i/(y_1 - r_i)` with `m_i` integers, so all `r_i = 0`, `g = Σ m_i` is an integer, and
  `v = c·y_1^g` with `c ∈ C(y_0)`.  Substituting into `(T3)` gives
  `Phi_R(c)·R'^(g+1) = c` — an invariant `(g+1)`-differential unless `g = -1`, and `g = -1` is
  impossible because `v` is the principal symbol `pd_1 u` of a rational `u` and `pd_1 u = c/y_1`
  has no rational primitive in `y_1`.

Only the partial-fraction step of the second bullet is not yet formalized; the first bullet is the
statement `mem_orbifoldTail_of_fixed` applied to `jetSubstitution_eulerQuotient`, both proved.

### Invariant differentials and the easy half of item (1), concretely

The card's item `(1)` has two halves.  The "if" half — an invariant tensor forces a nonconstant
tail — was proved in the 2026-08-14 pass, but only against abstract stand-ins for the substitution.
It is now proved for `Phi_R` itself, together with the predicate it is about.

```text
IsInvariantDifferential R hR k q lam :
    q != 0,  ord q = 0,  Phi_R(q)·R'(y_0)^k = lam·q            (k : ℤ)

invariantCurrent k q = q · y_1^k                                (the current q·(dy)^k)

    Phi_R (q·y_1^k) = lam · (q·y_1^k)
adjoin_le_orbifoldTail_of_isInvariantDifferential
differentialAdjoin_le_orbifoldTail_of_isInvariantDifferential :
    lam != 0  ⇒  C⟨q·y_1^k⟩ ≤ Tail(R)
```

The current, not the differential itself, is the eigenvector: `Phi_R(y_1) = y_1·R'(y_0)` supplies
exactly the `k`-th power of the derivative factor that the invariance relation carries.  That is
why the tail sees `q·(dy)^k` and not `q`.

The **order-zero exit** of the descent is proved too:

```text
isInvariantDifferential_pd_of_order_zero_eigen :
    ord s = 0,  pd_0 s != 0,  Phi_R s = lam·s
      ⇒  IsInvariantDifferential R hR 1 (pd_0 s) lam
```

This is `(T1)` at `M = 0`: differentiating an order-zero eigen-relation produces an invariant
`1`-differential, with the *same* eigenvalue.  In particular the degenerate branch of the descent —
`Phi_R(s) = s` with `s` of order zero — does **not** need the degree argument `deg(s∘R) = deg s·deg R`
that the card's step 4 quotes: if `s` is nonconstant then `pd_0 s != 0` and the invariant
`1`-differential is `pd_0 s` itself.  That removes the last place where a composition-degree theory
for rational functions would have been required.

### The descent is formalized, and it closes at order one

`formal/GaloisForLFunctions/HTGeometry/TwistedScalingDescent.lean` and
`formal/GaloisForLFunctions/HTGeometry/JetSubstitutionDescent.lean`, both unconditional and
axiom-clean, wired into the `HTGeometry` umbrella.

**The generic machinery.**  For a ring endomorphism `Phi` of a field `K` and an *affine* `T` in
`K[X]`, the twisted substitution `twistComp Phi T P = (P^Phi) . T` preserves degrees and multiplies
leading coefficients:

```text
natDegree_twistComp     deg ((P^Phi) . T) = deg P
leadingCoeff_twistComp  lc ((P^Phi) . T) = Phi(lc P) * lc(T)^(deg P)
exists_scalars_of_twisted_cross :
   P, Q nonzero and coprime,  mu, nu nonzero,
   (P^Phi . T) * mu * Q = nu * P * (Q^Phi . T)
     ⇒ ∃ c, d nonzero,  P^Phi . T = c*P,  Q^Phi . T = d*Q,  c*mu = nu*d
coeff_eigen_of_twistComp_scale :   (pure scaling T = rho*X)
   P^Phi . T = c*P  ⇒  Phi(P_j) * rho^j = c * P_j   for every j
```

That is the card's "coprimality splits the cross identity", in a form that does not mention jets.

**The jet-side slicing.**  `jetPrefixField C M` is the subfield generated by `y_0, …, y_(M-1)`, and
the corpus's support-kernel theorem identifies it with the elements of order below `M`:

```text
mem_jetPrefixField_iff   v ∈ jetPrefixField C M  ↔  ∀ j ≥ M, pd_j v = 0
transcendental_jet_over_jetPrefixField    y_M is transcendental over it
jetPrefixField_succ                       jetPrefixField C (M+1) = (jetPrefixField C M)⟮y_M⟯
jetSubstitution_mem_jetPrefixField        Phi_R preserves it
jetSubstitutionPrefix                     the restriction Phi_R|_(jetPrefixField C M)
```

The substitution is *affine* in the top coordinate, with the remainder one order lower:

```text
substitutionShift R M   := delta^M(R(y_0)) - R'(y_0)*y_M
substitutionShift_mem_jetPrefixField   ord (substitutionShift R M) ≤ M - 1     (M ≥ 1)
substitutionAffine R hM := C R'(y_0) * X + C (substitutionShift R M)
jetSubstitution_aeval :  Phi_R (P(y_M)) = (twistComp Phi_R|_prefix (substitutionAffine) P)(y_M)
```

**The descent.**  With `SubstitutionEigen R hR M kappa w lam` the relation
`w != 0`, `ord w ≤ M`, `Phi_R(w)·R'^kappa = lam·w` — so that
`IsInvariantDifferential R hR k q lam` is literally `SubstitutionEigen R hR 0 k q lam` —

```text
exists_coprime_slicing (M ≥ 1) :
   w = P(y_M)/Q(y_M) with P, Q coprime over the prefix field, and
   P^Phi . T = c*P,  Q^Phi . T = d*Q,  c*R'^kappa = lam*d
substitutionEigen_leadingRatio :
   SubstitutionEigen (M-1) (kappa + deg P - deg Q) (lc P / lc Q) lam
exists_substitutionEigen_pred :  the same, existentially
exists_isInvariantDifferential_of_substitutionEigen :
   iterating down to order zero,
   SubstitutionEigen M kappa w lam  ⇒  ∃ k q, IsInvariantDifferential R hR k q lam
exists_isInvariantDifferential_of_eigen :
   Phi_R u = lam·u,  u != 0,  ord u ≤ M,  lam != 0
     ⇒  ∃ k q, IsInvariantDifferential R hR k q lam
```

So *every* finite-order eigenvector of `Phi_R` already carries an invariant differential with the
same eigenvalue.  The only thing the leading-coefficient descent cannot control is whether the
weight `k` it lands on is zero.

**Order one is closed.**  At `M = 1` the remainder vanishes — `substitutionShift_one : L = 0`, i.e.
`Phi_R(y_1) = R'(y_0)·y_1` exactly — so the substitution is a *pure scaling* and every coefficient,
not only the leading one, satisfies an eigen-relation:

```text
substitutionEigen_coeffRatio :
   substitutionShift R M = 0,  P^Phi . T = c*P,  P_i != 0,  P_j != 0
     ⇒ SubstitutionEigen (M-1) (j - i) (P_j / P_i) 1
```

Together with the order-zero exit these exhaust the cases:

```text
exists_nonzero_isInvariantDifferential_of_order_one :
   ord u ≤ 1,  u not a constant,  lam != 0,  Phi_R u = lam·u
     ⇒ ∃ k != 0, ∃ q, ∃ mu != 0,  IsInvariantDifferential R hR k q mu
exists_nonzero_isInvariantDifferential_of_pd_one_ne_zero :  the same with pd_1 u != 0
exists_differentialAdjoin_invariantCurrent_le_orbifoldTail :
   ... and C⟨q·y_1^k⟩ ≤ Tail(R)
```

The case analysis is exactly the one recorded above, now checked: the leading ratio `s = lc P/lc Q`
gives weight `deg P - deg Q`; if that is nonzero the tensor is produced; if it is zero then
`Phi_R(s) = lam·s` with `s` of order zero, so either `pd_0 s != 0` and
`isInvariantDifferential_pd_of_order_zero_eigen` gives weight `1`, or `s` is a constant, `lam = 1`,
and a non-leading coefficient of `P` or `Q` gives a nonzero weight with eigenvalue `1`; and if both
`P` and `Q` are monomials of the same degree then coprimality forces both to be constants, so
`u = s` is a constant, excluded.

**What is left.**  Only the weight-zero exit above order one.  At level `M ≥ 2` the remainder `L`
is nonzero, so only the *leading* coefficients satisfy per-coefficient relations, and the descent
can land on `k = 0` with a constant `s`.  The route out is the normalization noted earlier: the
next-to-leading coefficient of the split relation is exactly a solution of the affine equation
`Phi_R(t) - R'·t = -L` (take `t = P_(a-1)/(a·P_a)`, legitimate whenever `deg P ≥ 1`), and in the
translated coordinate `z = y_M + t` the substitution becomes the pure scaling `z ↦ R'·z`, so the
full coefficient analysis applies at every order.  The residual configuration is then the explicit
family `w = e·z^(-kappa)` with `e` a constant — which at `kappa = 0` is excluded by nonconstancy,
which is precisely why order one closes.  Ruling it out for `kappa != 0` is the single remaining
step of the Casale-free route.
