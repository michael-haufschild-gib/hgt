### 1. `SL(2, ℂ)` metric-measure geometry of `ℍ³`, geodesic stabilizer rigidity, and free-space Robin constant
1. **Upper half-space model, Hermitian matrix embedding, and triangle inequality.**
   Define `H3 := {(z, t) ∈ ℂ × ℝ : 0 < t}` with vertical geodesic points `degPoint t := (0, t)` (`t > 0`), `natPoint n := (0, n)` (`n ≥ 1`), chordal invariant
   `h3Cosh p q := 1 + (‖p.z − q.z‖² + (p.t − q.t)²) / (2 p.t q.t) ≥ 1`,
   and geodesic distance `h3Dist p q := arcosh(h3Cosh p q) ≥ 0`. Clearly `h3Dist p q = 0 ↔ h3Cosh p q = 1 ↔ p = q`, `h3Dist p q = h3Dist q p`, and `h3Dist (degPoint t) (degPoint u) = |log u − log t|` since `cosh |log u − log t| = 1 + (u − t)² / (2 t u)` (`cosh_log_sub_log`).
   Embed `p = (z, t) ∈ H3` into `M₂(ℂ)` by
   `toHermMat p := !![(‖z‖² + t²) / t, z / t; conj z / t, 1 / t]`.
   Entry `(1, 1)` determines `t = ((toHermMat p 1 1).re)⁻¹` and entry `(0, 1)` determines `z = (toHermMat p 0 1) * t`, so `toHermMat` is injective, `det(toHermMat p) = 1`, and
   `Re Tr(toHermMat p * adjugate(toHermMat q)) = ((‖p.z‖² + p.t²) + (‖q.z‖² + q.t²) − 2 Re(p.z * conj q.z)) / (p.t q.t) = 2 * h3Cosh p q`.
   For `g = !![a, b; c, d] ∈ SL(2, ℂ)` (`a d − b c = 1`), `denom g p := ‖c p.z + d‖² + ‖c‖² p.t² > 0` (vanishing forces `c = 0` since `p.t > 0`, hence `d = 0`, contradicting `a d − b c = 1`). Defining
   `h3Act g p := (((a p.z + b) conj(c p.z + d) + a conj(c) p.t²) / denom g p, p.t / denom g p)`,
   direct `2 × 2` multiplication and Lagrange's identity `(‖a z + b‖² + ‖a‖² t²)(‖c z + d‖² + ‖c‖² t²) − ‖(a z + b) conj(c z + d) + a conj(c) t²‖² = ‖a d − b c‖² t² = t²` yield
   `toHermMat (h3Act g p) = g * toHermMat p * gᴴ`.
   Injectivity of `toHermMat` gives `h3Act 1 p = p` and `h3Act (g₁ * g₂) p = h3Act g₁ (h3Act g₂ p)`. Since `adjugate(g M gᴴ) = adjugate(gᴴ) adjugate(M) adjugate(g)` and `adjugate(g) g = (det g) • 1 = 1`, cyclicity of trace gives `h3Cosh (h3Act g p) (h3Act g q) = h3Cosh p q` and `h3Dist (h3Act g p) (h3Act g q) = h3Dist p q`.
   For any `q = (z, t) ∈ H3`, `b_q := !![√t, z / √t; 0, 1 / √t] ∈ SL(2, ℂ)` satisfies `h3Act b_q (degPoint 1) = q`. Applying `b_q⁻¹` reduces `h3Dist p r ≤ h3Dist p q + h3Dist q r` to `q = o := degPoint 1`. Writing `C(p) := h3Cosh p o = (‖p.z‖² + p.t² + 1) / (2 p.t)` and `X(p) := (Re p.z / p.t, Im p.z / p.t, (‖p.z‖² + p.t² − 1) / (2 p.t))`, polynomial algebra gives `C(p)² − (X₁(p)² + X₂(p)² + X₃(p)²) = 1` and `h3Cosh p r = C(p) C(r) − ∑_{i=1}^3 X_i(p) X_i(r)`. By 3-term Cauchy–Schwarz, `−∑ X_i(p) X_i(r) ≤ √(C(p)² − 1) √(C(r)² − 1) = sinh(h3Dist p o) sinh(h3Dist o r)`, so `h3Cosh p r ≤ cosh(h3Dist p o + h3Dist o r)` and monotonicity of `arcosh` yields `h3Dist p r ≤ h3Dist p q + h3Dist q r`.

2. **`SL(2, ℂ)`-invariance of hyperbolic volume `h3Measure`.**

### 2. Finite-covolume thin–thick dichotomy and parabolic cusp divergence (No-go for B118)
1. **Scale-invariant hyperbolic ball volume.**
   For `ρ > 0`, set `δ(ρ) := min(1 / 2, √((cosh ρ − 1) / 4)) > 0`. For every `t > 0`, every `p = (x + i y, u)` in the Euclidean box `Q(t, δ) := [−δ t, δ t] × [−δ t, δ t] × [(1 − δ) t, (1 + δ) t]` has `u ≥ t / 2 > 0` and
   `h3Cosh (degPoint t) p − 1 = (x² + y² + (u − t)²) / (2 t u) ≤ 3 δ² t² / t² = 3 δ² < 4 δ² ≤ cosh ρ − 1`,
   so `Q(t, δ) ⊆ {p ∈ H3 : h3Dist (degPoint t) p < ρ}`. On `Q(t, δ)`, `u ≤ (3 / 2) t`, so `u⁻³ ≥ (8 / 27) t⁻³`, while the Euclidean volume of `Q(t, δ)` is `(2 δ t)³ = 8 δ³ t³`. Thus `h3Measure {p : h3Dist (degPoint t) p < ρ} ≥ (64 / 27) δ(ρ)³ > 0` independent of `t > 0`.

2. **Thin–thick dichotomy on finite-covolume Kleinian quotients.**
   Let `Γ ≤ SL(2, ℂ)` carry `DiscreteTopology Γ` and admit a measurable set `F ⊆ H3` with `h3Measure F < ⊤` and `∀ p : H3, ∃ γ : Γ, γ • p ∈ F`. Let `Γ_ℓ := {γ ∈ Γ : ∀ t > 0, γ • degPoint t = degPoint t}` be the pointwise vertical-geodesic stabilizer subgroup. By Section 1.3, `Γ_ℓ` maps into the compact set `{!![a, 0; 0, a⁻¹] : ‖a‖ = 1} ⊆ SL(2, ℂ)`, so `Subgroup.tendsto_coe_cofinite_of_discrete` forces `Γ_ℓ` to be finite of cardinality `M := Nat.card Γ_ℓ ≥ 1`. Since `SL(2, ℂ)` is second-countable and `Γ` is discrete, `Γ` is countable.
   Let `S ⊆ ℕ` be infinite with `∀ n ∈ S, 0 < n`, and let `ε > 0`. Suppose for contradiction that:
   (i) `{n ∈ S : ∃ γ : Γ, γ ∉ Γ_ℓ ∧ h3Dist (natPoint n) (γ • natPoint n) < ε}` is finite, so an infinite subset `S₁ ⊆ S` satisfies `∀ n ∈ S₁, ∀ γ : Γ, h3Dist (natPoint n) (γ • natPoint n) < ε → γ ∈ Γ_ℓ`; and
   (ii) there exists `R > 1` such that `∀ m ∈ S, ∀ n ∈ S, R < (n : ℝ) / m → ∀ γ : Γ, ε ≤ h3Dist (natPoint m) (γ • natPoint n)`.
   Choose inductively `n₀ < n₁ < ⋯` in `S₁` with `(n_{k+1} : ℝ) / n_k > R` for all `k` (hence `(n_j : ℝ) / n_i > R` for all `i < j`). Set `B_k := {p ∈ H3 : h3Dist (natPoint n_k) p < ε / 2}` and `E_k := (⋃ γ : Γ, γ • B_k) ∩ F`.
   - *Disjointness across `k`:* If `x ∈ E_i ∩ E_j` (`i < j`), then `x = γ₁ • p₁ = γ₂ • p₂` with `p₁ ∈ B_i, p₂ ∈ B_j`, so `h3Dist (natPoint n_i) ((γ₁⁻¹ * γ₂) • natPoint n_j) ≤ h3Dist (natPoint n_i) p₁ + h3Dist p₂ (natPoint n_j) < ε`, contradicting (ii). Thus `(E_k)_{k ∈ ℕ}` are pairwise disjoint measurable subsets of `F`.
   - *Uniform lower bound on `h3Measure E_k`:* Every `τ ∈ Γ_ℓ` fixes `natPoint n_k` and preserves `h3Dist`, hence satisfies `τ • B_k = B_k`. Grouping the countable cover `B_k = ⋃ γ : Γ, B_k ∩ (γ⁻¹ • F)` by left cosets `c ∈ Γ / Γ_ℓ` (choosing a section `rep : (Γ ⧸ Γ_ℓ) → Γ`, where `γ = rep c * τ` has `(rep c * τ)⁻¹ • F = τ⁻¹ • (rep c)⁻¹ • F` and `τ • (B_k ∩ τ⁻¹ • (rep c)⁻¹ • F) = B_k ∩ (rep c)⁻¹ • F`, and `(rep c) • (B_k ∩ (rep c)⁻¹ • F) = ((rep c) • B_k) ∩ F ⊆ E_k`): if `x ∈ ((rep c₁ • B_k) ∩ F) ∩ ((rep c₂ • B_k) ∩ F)`, then `h3Dist (natPoint n_k) (((rep c₁)⁻¹ * rep c₂) • natPoint n_k) < ε`, so `(rep c₁)⁻¹ * rep c₂ ∈ Γ_ℓ` by (i), hence `c₁ = c₂`. Countable additivity on pairwise disjoint coset pieces and `SL(2, ℂ)`-invariance of `h3Measure` yield
     `c₀ ≤ h3Measure B_k ≤ M * ∑' c : Γ ⧸ Γ_ℓ, h3Measure (((rep c) • B_k) ∩ F) ≤ M * h3Measure E_k`,
     where `c₀ := (64 / 27) δ(ε / 2)³ > 0`.
   Summing over `k < K` gives `K * c₀ ≤ M * ∑_{k < K} h3Measure E_k ≤ M * h3Measure F < ⊤` for every `K ∈ ℕ`, a contradiction.
   Consequently, if `S = {p : p.Prime}`, then in Branch (ii)'s negation any `Γ`-invariant kernel `K_X : H3 → H3 → ℝ` satisfying a Newtonian lower bound `K_X p q ≥ c₁ / d_Γ(p, q) − C₁` (`c₁ > 0`, `d_Γ(p, q) = inf_{γ ∈ Γ} h3Dist p (γ • q)`) exceeds any prescribed bound along prime pairs `(p, q)` of arbitrarily large ratio `q / p > R`, whereas `archProfile (log(q / p)) → 0` as `q / p → ∞`.

3. **Parabolic cusp harmonic divergence and exact horospherical zero-mode at `s = 1 / 2`.**
   - For `ω ∈ ℂ \ {0}`, `parabolicSL2 ω := !![1, ω; 0, 1] ∈ SL(2, ℂ)` satisfies `(parabolicSL2 ω)^k = !![1, k ω; 0, 1]`. For any `t, u > 0` and `k ≥ 1`, `d_k := h3Dist (degPoint t) ((parabolicSL2 ω)^k • degPoint u) > 0` satisfies `cosh d_k = 1 + (k² ‖ω‖² + (t − u)²) / (2 t u) ≤ M k²` with `M := 1 + (‖ω‖² + (t − u)²) / (2 t u) > 0`. Comparison with the divergent harmonic series yields `¬ Summable (fun k : ℕ => hyperbolicGreen (1 / 2) (h3Dist (degPoint t) ((parabolicSL2 ω)^k • degPoint u)))`.
   - For `t, u > 0`, `r ≥ 0`, set `horoDist t u r := arcosh(1 + (r² + (t − u)²) / (2 t u))`. For `s ≠ 1` and `r > 0`, `horoDist t u r > 0` and `F(r) := −(t u / (2 (s − 1))) exp(−(s − 1) * horoDist t u r)` has derivative `F'(r) = 2π r * hyperbolicGreen s (horoDist t u r)`. By `integral_Ioi_of_hasDerivAt_of_nonneg`, for any cusp covolume `Λ_area > 0` and `s > 1`,
     `Λ_area⁻¹ * ∫ r in Ioi 0, 2π r * hyperbolicGreen s (horoDist t u r) = min(t, u)^s max(t, u)^{2 − s} / (2 (s − 1) Λ_area) =: cuspZeroMode Λ_area s t u`.
     The function `s ↦ (s − 1) * cuspZeroMode Λ_area s t u` is real-analytic on `ℝ`, uniquely fixing `cuspZeroMode Λ_area (1 / 2) t u = −min(t, u)^{1/2} max(t, u)^{3/2} / Λ_area`: at `(1, n)` it tends to `−∞` as `−n^{3/2} / Λ_area`, and on the diagonal `(n, n)` it equals `−n² / Λ_area`, with `|cuspZeroMode Λ_area (1 / 2) n n| / log n = n² / (Λ_area log n) → +∞`.

### 3. Pure trivial-zero jet Cauchy determinant and causal Taylor-jet Hilbert carrier (B115)
1. **Pure jet decomposition and nonsingular Cauchy blocks.**
   Define `jetKernel m n := min (m : ℝ) n ^ 3 / (max (m : ℝ) n ^ 2 − min (m : ℝ) n ^ 2)` and `jetProfile d := exp(−5 d / 2) / (1 − exp(−2 d))`. For `0 < m, 0 < n, m ≠ n`, `archKernel m n = min (m : ℝ) n + jetKernel m n`, `jetKernel m n = √(m n) * jetProfile |log n − log m|`, and `HasSum (fun k : ℕ => exp(−(2 (k + 1) + 1 / 2) d)) (jetProfile d)` (`d > 0`).
   For `0 < m < n`, `jetKernel m n = m³ / (n² − m²)`. Hence on any block `m, n : Fin r → ℕ` with `m` and `n` injective, `0 < m i`, and `∀ i j, m i < n j`,
   `Matrix.of (fun i j => jetKernel (m i) (n j)) = Matrix.diagonal (fun i => (m i : ℝ) ^ 3) * HTGeometry.cauchyMatrix (fun i => −(m i : ℝ) ^ 2) (fun j => (n j : ℝ) ^ 2)`,
   whose determinant is `(∏ i, (m i : ℝ) ^ 3) * (HTGeometry.cauchyMatrix (−m²) (n²)).det ≠ 0` by `HTGeometry.det_cauchyMatrix`. Partitioning `Nat.nth Nat.Prime` into `P(0), …, P(r−1)` and `P(r), …, P(2r−1)` (`r = r' + 1`) proves `¬ ∀ p q, p.Prime → q.Prime → p ≠ q → jetKernel p q = ∑ k : Fin r', u k p * v k q` for every finite rank `r'`, and `¬ ∀ p q, p.Prime → q.Prime → p ≠ q → frobeniusIntersection p q − min (p : ℝ) q = ∑ k : Fin r', u k p * v k q`.

2. **Causal monomial Hilbert bundle on `L²(0, ∞)` (`causalJetWave`).**
   For `a > 0` and `k ∈ ℕ`, define `causalJetWave a k : ℝ → ℝ` by `(Ioc 0 a).indicator (fun x => √(4 k + 1) * (x / a) ^ (2 * k))`.
   - *Exact Gram law:* For `a, b > 0` and `k ∈ ℕ`, `(Ioc 0 a) ∩ (Ioc 0 b) = Ioc 0 (min a b)`. On `(0, min a b]`, the product `causalJetWave a k x * causalJetWave b k x = (4 k + 1) * x^{4k} / (a b)^{2k}` is the derivative of `G(x) := x^{4k + 1} / (a b)^{2k}`, with `G(0) = 0` and `G(min a b) = min(a, b)^{4k + 1} / (min(a, b) max(a, b))^{2k} = min(a, b) * (min(a, b) / max(a, b))^{2k}`.
