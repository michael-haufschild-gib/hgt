$$G(a, b) = \sum_{i, j < N} \operatorname{Re}(\mathrm{atomGram}\,N\,i\,j)\,a_i b_j = \frac{Q(a + b) - Q(a) - Q(b)}{2}, \qquad Q = \mathtt{integerProbe}\,N.$$

  via $2 \|y_r\| \|y_s\| \le \|y_r\|^2 + \|y_s\|^2$ and symmetry of $|G_{r s}| / \sqrt{G_{r r} G_{s s}}$, whence $\operatorname{hermNegIndex}(\mathcal{G}(a)) = m$.
