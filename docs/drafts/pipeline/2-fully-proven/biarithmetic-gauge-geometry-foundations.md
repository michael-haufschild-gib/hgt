### Theorem I (Unitary Prime-Gauge Blindness vs. Catalan–Bézout Successor Rigidity) `[PROVED HERE]`
1. **Prime Gauge Torus and Multiplicative Lift:** Let $\Omega_{\mathcal{P}}$ be the group of prime phase assignments $\omega : \mathbb{N} \to \mathbb{C}$ satisfying $\|\omega(p)\| = 1$ for every prime $p$ and $\omega(n) = 1$ for non-primes, with completely multiplicative extension $\chi_\omega(n) = \prod_{p \in n.\text{primeFactors}} \omega(p)^{v_p(n)}$ for $n \ge 1$ ($\chi_\omega(0) = 0$). For $m, n \ge 1$, unique factorization gives $\chi_\omega(m n) = \chi_\omega(m)\chi_\omega(n)$ and $\|\chi_\omega(n)\| = 1$. At $\omega_{\mathbf{1}}(p) = 1$, $\chi_{\mathbf{1}}(n) = 1$; at $\omega_{\boldsymbol{-1}}(p) = -1$, $\chi_{\boldsymbol{-1}}(n) = (-1)^{\Omega(n)}$ is Liouville's function $\lambda(n)$; at $\omega_\gamma(p) = p^{i\gamma}$, $\chi_{\omega_\gamma}(n) = n^{i\gamma}$ for $n \ge 1$.
2. **Unitary Multiplicative Blindness:** For any $\psi : \mathbb{N} \to \mathbb{C}$, define $(U_\omega \psi)(n) = \chi_\omega(n)\psi(n)$. Since $\|\chi_\omega(n)\| = 1$ for $n \ge 1$, $\|U_\omega \psi(n)\| = \|\psi(n)\|$, so every diagonal potential $\sum_{n=1}^X d(n) \|\psi(n)\|^2$ is strictly $U_\omega$-invariant, while for every multiplicative ratio shift $m \ge 1$ and $a \ge 1$,
   $$\overline{(U_\omega \psi)(a)}\, (U_\omega \psi)(a m) = \overline{\chi_\omega(a)}\,\chi_\omega(a)\,\chi_\omega(m)\,\overline{\psi(a)}\,\psi(a m) = \chi_\omega(m)\,\overline{\psi(a)}\,\psi(a m).$$
   Thus replacing $\psi$ by $U_{\overline{\omega}} \psi$ maps the $\omega$-twisted ratio correlation $\sum_{m=2}^X w(m)\chi_\omega(m)\sum_{a=1}^X \overline{\psi(a)}\psi(am)$ bijectively onto the untwisted Euler correlation $\sum_{m=2}^X w(m)\sum_{a=1}^X \overline{\phi(a)}\phi(am)$ with identical norm profile $|\phi(n)| = |\psi(n)|$. Likewise, for real sign gauges $\sigma : \mathbb{N} \to \{\pm 1\}$ ($\chi_\sigma(n) \in \{\pm 1\}$), $\chi_\sigma(a)\chi_\sigma(b) = \chi_\sigma(ab)$ makes **both** ratio correlations $\chi_\sigma(m)\psi(a)\psi(am)$ and product correlations $\chi_\sigma(ab)\psi(a)\psi(b)$ unitarily equivalent to the Euler vacuum ($\sigma \equiv +1$) via $\phi(n) = \chi_\sigma(n)\psi(n)$! Hence no operator built purely from diagonal weights (including `archReflectedDiagWeight`), horizon cutoffs `[1, X]`, and multiplicative ratio/product shifts can ever separate $\zeta$ from its Liouville twin $\lambda$!
3. **Successor Connection and Catalan Reconstruction:** Define the successor gauge connection $A_\omega(n) := \overline{\chi_\omega(n)}\chi_\omega(n+1)$ ($n \ge 1$). Then $A_\omega(n) = 1$ for all $1 \le n \le N$ iff $\chi_\omega(n) = \chi_\omega(1) = 1$ for all $1 \le n \le N+1$ (by induction on $n$), which holds iff $\omega(p) = 1$ for every prime $p \le N + 1$ (since $\chi_\omega(p) = \omega(p)$ for $p \le N+1$, and conversely every $n \le N+1$ has prime factors $\le N+1$). On the Catalan–Bézout quartet $\{1, 2, 3, 4\}$ ($N = 3$), $A_\omega(2) = \overline{\omega(2)}\omega(3)$ and $A_\omega(3) = \overline{\omega(3)}\omega(2)^2$. Multiplying gives $A_\omega(2)A_\omega(3) = |\omega(3)|^2 \overline{\omega(2)}\omega(2)^2 = |\omega(2)|^2 \omega(2) = \omega(2)$ and $A_\omega(2)^2 A_\omega(3) = \overline{\omega(2)}^2 \omega(2)^2 \omega(3)^2 \overline{\omega(3)} = \omega(3)$, reconstructing $(\omega(2), \omega(3))$ algebraically from two consecutive successor steps!

### Theorem II (Quantitative Baker-Free Diophantine Repulsion of the Liouville Vacuum off the Kronecker Line) `[PROVED HERE]`
1. **Parity-Separated Integer Power Gap:** For any integers $a, b \ge 1$, $2^a$ is even and $3^b$ is odd, so $2^a \ne 3^b$ and $|3^b - 2^a| \ge 1$ in $\mathbb{Z}$. For any positive reals $X \ne Y$ with $|X - Y| \ge 1$: if $X > Y \ge 1$, then $X \ge Y + 1$, so $\log(X/Y) = \log(1 + (X-Y)/Y) \ge \log(1 + 1/Y)$. Using $\log(1 + u) \ge u / (1 + u)$ for $u > 0$ (since $e^{u/(1+u)} \le \frac{1}{1 - u/(1+u)} = 1 + u$ by $e^{-t} \ge 1 - t$ at $t = u/(1+u)$), $\log(1 + 1/Y) \ge \frac{1/Y}{1 + 1/Y} = \frac{1}{Y + 1} \ge \frac{1}{X} \ge \frac{1}{X + Y}$. Symmetrically if $Y > X \ge 1$, $|\log X - \log Y| \ge \frac{1}{X + Y}$. Thus for all $a, b \ge 1$,
   $$|b \log 3 - a \log 2| \ge \frac{1}{3^b + 2^a}.$$
   If $a = 0$ and $b \ge 1$, $|b \log 3| \ge \log 3 > \frac{1}{3^b + 1}$; if $b = 0$ and $a \ge 1$, $|a \log 2| \ge \log 2 > \frac{1}{1 + 2^a}$. For signed odd integers $u, v \in \mathbb{Z}$ (`Odd u`, `Odd v`), if $u$ and $v$ have opposite signs then $|u \log 2 - v \log 3| = |u|\log 2 + |v|\log 3 \ge \log 2 + \log 3 > \frac{1}{2^{|u|} + 3^{|v|}}$; if they have the same sign, $|u|, |v| \ge 1$ gives $|u \log 2 - v \log 3| = ||u|\log 2 - |v|\log 3| \ge \frac{1}{2^{|u|} + 3^{|v|}}$.
2. **Cosine Distance to $-1$:** For any real $x \in \mathbb{R}$, let $k = \lfloor x / (2\pi) \rfloor \in \mathbb{Z}$, so $\theta := x - (2k + 1)\pi \in [-\pi, \pi]$. Since $1 + \cos x = 1 - \cos \theta = 2 \sin^2(\theta/2)$ and $|\sin y| \ge \frac{2}{\pi}|y|$ for $|y| \le \pi/2$ (by concavity of $\sin$ on $[0, \pi/2]$), we have:
   $$1 + \cos x \ge \frac{2}{\pi^2} \theta^2 = \frac{2}{\pi^2} \bigl(x - (2k + 1)\pi\bigr)^2,$$
   where $u := 2k + 1$ is an **odd integer** satisfying $|u| \le \frac{|x|}{\pi} + 1$ (since $|(2k+1)\pi - x| \le \pi$).
3. **Explicit All-Height Repulsion Bound:** Given any $\gamma \in \mathbb{R}$, apply step 2 to $x_2 = \gamma \log 2$ and $x_3 = \gamma \log 3$, obtaining odd integers $u_2, u_3$ with $|u_2| \le \frac{|\gamma|\log 2}{\pi} + 1$, $|u_3| \le \frac{|\gamma|\log 3}{\pi} + 1$, and $\delta_j := x_j - u_j \pi$ satisfying $1 + \cos x_j \ge \frac{2}{\pi^2} \delta_j^2$. Note the exact elimination of $\gamma$:
   $$(\log 3)\delta_2 - (\log 2)\delta_3 = (\log 3)(\gamma\log 2 - u_2\pi) - (\log 2)(\gamma\log 3 - u_3\pi) = \pi (u_3 \log 2 - u_2 \log 3)!$$
   By Cauchy–Schwarz, $(\delta_2^2 + \delta_3^2)((\log 3)^2 + (\log 2)^2) \ge ((\log 3)\delta_2 - (\log 2)\delta_3)^2 = \pi^2 (u_3 \log 2 - u_2 \log 3)^2$. Since $(\log 2)^2 + (\log 3)^2 < 1^2 + (3/2)^2 < 4$ and $|u_3 \log 2 - u_2 \log 3| \ge \frac{1}{2^{|u_3|} + 3^{|u_2|}}$, while $2^{|u_3|} \le 2 \cdot e^{(|\gamma|\log 3 \log 2)/\pi} \le 2 e^{|\gamma|/2}$ and $3^{|u_2|} \le 3 \cdot e^{(|\gamma|\log 2 \log 3)/\pi} \le 3 e^{|\gamma|/2}$ (as $\frac{\log 2 \cdot \log 3}{\pi} < \frac{0.7 \times 1.1}{3.14} < \frac{1}{4}$, so square is $< e^{|\gamma|/2}$!), we have $2^{|u_3|} + 3^{|u_2|} \le 5 e^{|\gamma|/4}$ and $(2^{|u_3|} + 3^{|u_2|})^2 \le 25 e^{|\gamma|/2}$! Combining:
   $$(1 + \cos(\gamma \log 2)) + (1 + \cos(\gamma \log 3)) \ge \frac{2}{\pi^2}(\delta_2^2 + \delta_3^2) \ge \frac{2}{\pi^2} \cdot \frac{\pi^2}{4 \cdot 25 e^{|\gamma|/2}} = \frac{1}{50} e^{-|\gamma|/2}!$$
   Consequently, if $(1 + \cos(\gamma\log 2)) + (1 + \cos(\gamma\log 3)) \le \varepsilon$ ($0 < \varepsilon < 1/50$), then $|\gamma| \ge 2 \log\!\left(\frac{1}{50\varepsilon}\right)$!

### Theorem III (Disproof of `CoupledRigid`, Chirality Law, Lattice-Decay Separation, and `CentralVanishingCeiling`) `[PROVED HERE]`

   $$\operatorname{Re}\!\left(-\frac{W_\beta'}{W_\beta}(\sigma + iu)\right) = \int_0^\infty e^{-(\sigma - 1/2)t} \cdot 2(1 - \cos(\beta t)) \cos(tu)\, dt.$$

### Theorem IV (Polar-Neutral Rank-One Collapse & Exact Euclidean Cell-Remainder Subdivision) `[PROVED HERE]`
1. **Polar-Neutral Collapse of Lattice Reflected-Diagonal Surplus:** Define the polar amplitude $s(n) = \frac{n - 1}{\sqrt{n}}$ ($n \ge 1$). Then $\frac{1}{2}\bigl(\sum_{n=2}^X s(n) q(n)\bigr)^2 = \sum_{n=2}^X \frac{(n-1)^2}{2n} q(n)^2 + \sum_{a \in [2,X]} \sum_{b \in [2,X] \setminus \{a\}} \frac{(a-1)(b-1)}{2\sqrt{ab}} q(a) q(b)$. Whenever $\sum_{n=2}^X s(n) q(n) = 0$ (the codimension-1 polar-neutral hyperplane), adding the off-diagonal polar cross-terms to $\sum_{n=2}^X \text{archReflectedDiagWeight}(n) q(n)^2$ cancels $\frac{(n-1)^2}{2n}$ identically and leaves $-\sum_{n=2}^X \frac{n^3}{n^4 - 1} q(n)^2 \le 0$!
2. **Exact Logarithmic Cell Subdivision & Telescoping:** Let $w(n) = \log(n+1) - \log n$ ($n \ge 1$). For any integers $a, m \ge 1$, telescoping gives $\sum_{r=0}^{m-1} w(am + r) = \log(am + m) - \log(am) = \log((a+1)m) - \log(am) = \log(a+1) - \log a = w(a)$. For a finitely supported cell sequence $c : \mathbb{N} \to \mathbb{R}$, the exact continuum correlation of $F(x) = c_{\lfloor e^x \rfloor}$ at shift $\log m$ equals $\sum_{a=1}^X c_a \sum_{r=0}^{m-1} w(am+r) c_{am+r} = \sum_{a=1}^X w(a) c_a c_{am} + \sum_{a=1}^X c_a \sum_{r=1}^{m-1} w(am+r)(c_{am+r} - c_{am})$.
3. **Biarithmetic Sobolev Bound on the Euclidean Remainder:** For $1 \le r < m$ and $a \ge 1$, $c_{am+r} - c_{am} = \sum_{j=0}^{r-1} (c_{am+j+1} - c_{am+j})$. By Cauchy–Schwarz,
   $$(c_{am+r} - c_{am})^2 \le \left(\sum_{j=0}^{r-1} \frac{1}{am+j}\right)\left(\sum_{j=0}^{r-1} (am+j)(c_{am+j+1} - c_{am+j})^2\right) \le \frac{1}{a} \sum_{j=0}^{m-1} (am+j)(c_{am+j+1} - c_{am+j})^2,$$
   since $\sum_{j=0}^{r-1} \frac{1}{am+j} \le \frac{r}{am} \le \frac{1}{a}$. Since $w(a) = \log(1 + 1/a) \le 1/a$, we have $w(a) \le \sqrt{w(a)} / \sqrt{a} \le \sqrt{w(a)}$ and $(w(a)/\sqrt{a})^2 = w(a)^2 / a \le w(a) / a^2 \le w(a)$. Applying Cauchy–Schwarz over $a \in [1, X]$ and using disjointness of $\{am + j : 0 \le j < m\}$ across distinct $a \ge 1$ (by uniqueness of Euclidean quotient $\lfloor k/m \rfloor = a$!) yields:
   $$\left|\sum_{a=1}^X c_a \sum_{r=1}^{m-1} w(am+r)(c_{am+r} - c_{am})\right| \le \left(\sum_{a=1}^X w(a) c_a^2\right)^{1/2} \left(\sum_{k=m}^{mX+m-1} k (c_{k+1} - c_k)^2\right)^{1/2},$$
   completely independent of $m \ge 2$ and $X$!
