1. ## Approach

### Theorem A (8-Channel Bilinear Conductor Residual and Positivity on Fixed Packets & Polylogarithmic Subspaces Below $1/8$) `[PROVED HERE]`
Let $\varphi \in C^2(\mathbb{R})$ be supported in $[0, 1]$ with $\int \varphi^2 > 0$. Fix $A \ge 0$ and integer $k \ge 1$. For $N \ge 16$ with $\log N \ge 1$, $1 \le m \le (\log N)^A$ with $m^4 \le N$, $1 \le l$ with $l^4 \le N$, and $c \ge 1$ with $4(e + 3)^2 c^2 \le N$, decompose $r_m := W_{\varphi,c,N} v_{m,N} - E_\varphi(c, m) v_{m,N}$ via `completeWeilMatrix_ramanujan_residual_eq_at_every_overlap` into its eight explicit-formula channels and pair each channel against $v_{l,N}(n) = (\log N)^{-1/2} \tilde{c}_l(n)/\sqrt{n}$ ($|\tilde{c}_l(n)| \le \sqrt{l}$, $\|v_{l,N}\| \le 5$):
1. **Prime residual:** By `abs_ramanujanPrimeResidual_le`, $|r_m^{(1)}(n)| \le (\log N)^{-1/2} \cdot 4\sqrt{m}(1 + \log m) \operatorname{primeMertensRemainderProfile}(N/n)/\sqrt{n}$. Fourth-order Taylor domination $\exp(-c_M \sqrt{L})(1 + L)^2 \le 1 + 24/c_M^4$ applied to `exists_global_mertensDeviation_exp_sqrt_log_bound` gives $\operatorname{primeMertensRemainderProfile}(y) \le C_M / (1 + \log y)^2$, so `wiener_constant_kernel_sum_le` yields $|\langle r_m^{(1)}, v_{l,N}\rangle| \le C_1 \sqrt{ml}(1 + \log m)/\log N$.
2. **Self-energy error:** $|e_{\mathrm{self}}(\varphi, c, N)| \le \frac{1}{2} e^{1/2} c / N$ and $\|v_{m,N}\|\|v_{l,N}\| \le 25$ yield $|\langle r_m^{(2)}, v_{l,N}\rangle| \le C_2 \sqrt{ml}\, c / N$.
3. **Complete center residual ($\alpha_c = \operatorname{completeWeilPoleShift}(\varphi, c)$, $|\alpha_c| \le c$):**
   - For $m = 1$: `(r_1^{(3)})_n = (\log N)^{-1/2} (\alpha_c/N) \sqrt{n} B_N(n)` with $\sum_{n=1}^N B_N(n)^2 \le 6N$ (`HarmonicCenterBoundaryBounds`), so $\sqrt{n}$ cancels $1/\sqrt{n}$ in $v_{l,N}(n)$ and Cauchy–Schwarz gives $|\langle r_1^{(3)}, v_{l,N}\rangle| \le \sqrt{6} |\alpha_c| \sqrt{l}/\log N$.
   - For $m \ge 2, l = 1$: Hermitian symmetry of `fullWeilCenterMatrix` plus $|\langle v_{m,N}, v_{1,N}\rangle| \le 2\sqrt{m}(1 + \log m)/\log N$ (`abs_sum_Icc_normalizedRamanujanMode_div_le_sqrt_log`) gives $|\langle r_m^{(3)}, v_{1,N}\rangle| \le (\sqrt{6} + 2)|\alpha_c|\sqrt{m}(1 + \log m)/\log N$.
   - For $m \ge 2, l \ge 2$: write $v_{m,N} = \beta_m v_{1,N} + u_m$ and $v_{l,N} = \beta_l v_{1,N} + u_l$ via $P_1 = (\operatorname{conductorSubspace} 1 N).\operatorname{starProjection}$, where $|\beta_m| \le 2\sqrt{m}(1 + \log m)/\log N$ (since $\|v_{1,N}\|^2 = H_N/\log N \ge 1$) and $u_m, u_l \in V_{\max(m,l)} \cap V_1^\perp$. Normalized polarization of `abs_fullWeilCenterMatrix_self_inner_le_of_mem_conductorSubspace` on $V_{\max(m,l)} \cap V_1^\perp$ gives $|\langle C_{\alpha_c} u_m, u_l\rangle| \le 600 |\alpha_c| \frac{1 + \log\max(m,l)}{\log N}\|u_m\|\|u_l\| \le 30000 |\alpha_c| \sqrt{ml}(1 + \log m)/\log N$ (using $1 + \log\max(m,l) \le (1 + \log m)(1 + \log l)$ and $1 + \log l \le 2\sqrt{l}$), while the rank-1 boundary terms satisfy $|\beta_m \langle C_{\alpha_c} v_{1,N}, v_{l,N}\rangle| + |\beta_l \langle u_m, r_1^{(3)}\rangle| \ll |\alpha_c| \sqrt{ml}(1 + \log m)/\log N$.
4. **Separated cross error:** Pointwise row bound $|r_m^{(4)}(n)| \le (\log N)^{-1/2}(32 K_0 \sqrt{m} c \sqrt{n}/N + 4 K_0 \sqrt{m} c^2 / N)$ paired with $(\log N)^{-1/2} \sqrt{l}/\sqrt{n}$ sums to $\le 40 K_0 \sqrt{ml}\, c / \log N$.
5. **Rank-2 pole error:** Pointwise identity $|r_m^{(5)}(n)| \le (\log N)^{-1/2} C_p (c/N)^2 (\sqrt{n}|S_m| + |T_m|/\sqrt{n})$ with $|S_m| \le \sqrt{m}(1 + \log N)$ and $|T_m| \le \sqrt{m} N$ pairs with $v_{l,N}$ to $O(\sqrt{ml}\, c^2 / N)$.
6. **Near-gamma downward source:** The near-band row satisfies $|r_{m,\mathrm{near}}^{(6)}(n)| \le (\varphi(m)\log N)^{-1/2} \cdot 2 e R_c K_{m,c} \sqrt{n}/N$ with $K_{m,c} \ll \varphi(m)(1 + \log m)(1 + \log c)$, pairing to $O(\sqrt{ml}(1 + \log m) c(1 + \log c)/\log N)$; the exterior row is supported on $|S| \le (e + 2)c$ indices $n \ge N - \operatorname{linearPrimeStrip}(c) \ge N/2$ with amplitude $O(\sqrt{m}\, c \log N / \sqrt{N \log N})$, pairing to $O(\sqrt{ml}\, c^2 / N)$.
7. **Near-center row:** Vanishes for $N/n \ge R_c + 1$ and satisfies $|r_m^{(7)}(n)| \le (\log N)^{-1/2} B_{m,c}/\sqrt{n}$ ($B_{m,c} \ll \sqrt{m}\, c(1 + \log c)$) on $N/(R_c + 1) < n \le N$, pairing via quotient-harmonic summation to $O(\sqrt{ml}\, c(1 + \log c)^2/\log N)$.
8. **Upward prime defect:** Decomposes into (a) logarithmic-minus-linearized ($L^2$ norm $O(\sqrt{m}\, c^5 (\log N)^{1/2}/N)$, Cauchy–Schwarz gives $O(\sqrt{ml}\, c^5 (\log N)^{1/2}/N)$), (b) linearized-minus-reciprocal ($O(\sqrt{m}\, c / \sqrt{N \log N})$ on $(B, N]$ and $O(\sqrt{m}\, c^2 \sqrt{\log N}/N)$ on $[1, B]$, pairing to $O(\sqrt{ml}\, c/\log N + \sqrt{ml}\, c^3 \log N / N)$), and (c) reciprocal-minus-shell-correction (two shifted rows bounded by $O(c / (\log N \sqrt{n}))$ for $N/n \ge 2c\exp((\log N)^{1/k})$ and $O(\varphi(m) c / \sqrt{n})$ globally, divided by $\sqrt{\varphi(m)\log N}$ and paired via quotient-harmonic summation to $O(\sqrt{ml}\, c(1 + \log c)(\log N)^{1/k}/\log N)$).

For $\varphi_0 = \operatorname{tiltedUnitSpline}$, $E_{\varphi_0}(c, m) \ge \kappa_0 \min(1, (m/c)^7)$ (`tiltedUnitSpline_completedConductorEnergy_ge_conductor_scale`) and $E_{\varphi_0}(c, m) \ge \kappa_0 / c^7 =: 2s$. Setting $\tilde{E}_m := E_{\varphi_0}(c, m) - s \ge \frac{1}{2} E_{\varphi_0}(c, m)$, any $y = \sum_{m=1}^{Q_1} a_m v_{m,N} \in V_{Q_1}$ satisfies:
- $\sum_{m=1}^{Q_1} \frac{m(1 + \log m)^2}{E_{\varphi_0}(c,m)} \le \frac{4 c^7}{\kappa_0} \sum_{m \ge 1} m^{-5} + \frac{Q_1^2 (1 + \log Q_1)^2}{\kappa_0}$ and $\sum_{l=1}^{Q_1} \frac{l}{E_{\varphi_0}(c,l)} \le \frac{2 c^7}{\kappa_0} + \frac{Q_1^2}{\kappa_0}$.
- Symmetrically rescaling $b_m := \sqrt{\tilde{E}_m}\, a_m$, the Gram deviation is $O\big(c^{11/2}(1 + \log Q_1)^{3/2}/\log N\big)\sum b_m^2$ and the bilinear residual form is bounded by $2\Big(\sum_{m,l \le Q_1} \frac{|\langle r_m, v_l\rangle|^2}{E_m(c) E_l(c)}\Big)^{1/2} \sum b_m^2 \ll \big(c^8 + c^{9/2} Q_1(1 + \log Q_1) + c Q_1^2(1 + \log Q_1)\big)(1 + \log c)^2 (\log N)^{1/k - 1} \sum b_m^2$.
- Whenever $0 < \alpha < 1/8$, fixed packets ($Q_1 = M_0$ constant) satisfy $\langle W_{\varphi_0,c,N} y, y\rangle \ge \frac{\kappa_0}{2 c^7}\|y\|^2$, and growing subspaces $Q_1 = \lfloor (\log N)^q \rfloor$ with $\frac{9}{2}\alpha + q < 1$ and $\alpha + 2q < 1$ satisfy the strengthened floor
  $$\langle (W_{\varphi_0,c,N} - s I) y, y\rangle \ge \frac{1}{4}\sum_{m=1}^{Q_1} E_{\varphi_0}(c, m) a_m^2 \ge 0.$$

### Theorem B (Homogeneous Four-Band Orthogonal Decomposition and Unconditional All-Vector Weil Positivity Below $1/9$) `[PROVED HERE]`
Fix $0 < \alpha < 1/9$ and set $q := \frac{1}{2}(3\alpha + \frac{1}{3}) \in (3\alpha, \frac{1}{3})$, $Q_1 := \lfloor (\log N)^q \rfloor$, $R_0 := \lfloor \exp((\log N)^{1/2}) \rfloor$, and $R_1 := \lfloor N^{\theta_1} \rfloor$ for a small absolute constant $\theta_1 \in (0, 1/4096)$.
1. **Sharpened mid-band overlap ($c^{3/2}(1 + \log c)/\sqrt{Q_1}$):** In `midBandMeanSum`, summing $\sum_{n > \lfloor N/(R_c + 1)\rfloor}^{N-h} 1/n \le C(1 + \log c)$ harmonically (instead of bounding card by $N$ against $O(c/N)$) and retaining $Q_1 \le 4 e^2 c \varphi(t)^2 \implies 1/\varphi(t) \le 2 e \sqrt{c}/\sqrt{Q_1}$ (without squaring $c$) sharpens the mid-band overlap bound from $O(c^3/\sqrt{Q_1})$ to $O(c^{3/2}(1 + \log c)/\sqrt{Q_1})$, which vanishes because $q > 3\alpha$.
2. **Sharpened nonprime cross operators on $V_R$ ($R^6 \le N$):**
   - Applying $(\max(n, j))^2 \le 2 j^2 + 2|n - j|^2$ (`(n - 2j)^2 + (n - j)^2 \ge 0`) and `finite_weighted_schur_row_potential` + `sum_linear_moment_sq_le_four_div_log` gives $|\langle \operatorname{separatedCrossErrorMatrix}(\varphi_0, c, N) u, w\rangle|^2 \le C_{\mathrm{sep}} \frac{c^4}{\log N}\|u\|^2\|w\|^2$.
   - Keeping the conductor-independent near-center/scalar-gamma rows ($O(c^4(1 + \log c)/\log N \cdot \|u\|^2)$) unmerged from the divisor-jet row ($O(c^2(1 + \log M)^2(1 + \log c)/\log N \cdot \|u\|^2)$) before applying `conductor_packet_sq_le_logarithmic_weight` replaces $c^4(1 + \log R)(1 + \log c)/\log N \cdot G$ by $\frac{c^4(1 + \log c)}{\log N}\|u\|^2 + \frac{c^2(1 + \log R)(1 + \log c)}{\log N} G$.
3. **Homogeneous three-band coercivity on $V_{Q_1}^\perp$:** Every $z \in V_{Q_1}^\perp$ decomposes orthogonally via nested `starProjection`s as $z = u_0 + u_1 + w$ with $u_0 \in V_{R_0} \cap V_{Q_1}^\perp$, $u_1 \in V_{R_1} \cap V_{R_0}^\perp$, $w \in V_{R_1}^\perp$, and $\|z\|^2 = \|u_0\|^2 + \|u_1\|^2 + \|w\|^2$:
   - On $u_0 = \sum_{m=1}^{R_0} a_0(m) v_{m,N}$: $1 + \log R_0 \asymp (\log N)^{1/2}$, so $c^2(1 + \log R_0)(1 + \log c)/\log N \to 0$ and $c^{3/2}(1 + \log c)/\sqrt{Q_1} \to 0$; 2-homogeneous scaling yields $\operatorname{completeWeilEnergy}(u_0) \ge \frac{1}{8} E(a_0) + \big(\frac{1}{4}\log Q_1 - \log c - C_{\mathrm{coerc}}\big)\|u_0\|^2$.
   - On $u_1 = \sum_{m=1}^{R_1} a_1(m) v_{m,N}$: `primePacket_energy_ge_adjunction_and_log_of_orthogonal` gives $\operatorname{renormalizedPrimeEnergy}(u_1) \ge \frac{1}{8} E(a_1) + (\frac{1}{4}\log R_0 - C_0)\|u_1\|^2$ while the remaining quadratic channels satisfy $O(c^2(1 + \log c))\|u_1\|^2 \ll (\log N)^{1/2}\|u_1\|^2$ (since $2\alpha < 2/9 < 1/2$), yielding $\operatorname{completeWeilEnergy}(u_1) \ge \frac{1}{8} E(a_1) + \frac{1}{8}(\log N)^{1/2}\|u_1\|^2$.
   - On $w \in V_{R_1}^\perp$: `exists_completeWeilEnergy_asymmetric_two_region_reserve` yields $\operatorname{completeWeilEnergy}(w) \ge \frac{k_1}{4} P_w + \frac{b k_1}{2 c^7} S_w$ with $k_1 = \log R_1 / D - 1 \asymp \theta_1 \log N \gg c^9$.
   - Cross terms: $2|\langle W u_0, u_1\rangle|$ (`CompleteWeilSplitCrossBounds` at $R = R_0, M = N, s = t = \gamma = \frac{1}{32}(\log N)^{1/2}$) is absorbed by $\frac{1}{32} E(a_0) + \|u_0\|^2 + \frac{3}{32}(\log N)^{1/2}\|u_1\|^2$; $2|\langle W u_0, w\rangle|$ and $2|\langle W u_1, w\rangle|$ (paid at $s = k_1/16, t = \gamma = b k_1/(16 c^7)$ using the sharpened cross bounds above and small fixed $\theta_1$) are absorbed by $\frac{1}{32} E(a_0) + \|u_0\|^2 + \frac{1}{32} E(a_1) + \|u_1\|^2 + \frac{k_1}{8} P_w + \frac{3 b k_1}{8 c^7} S_w$.
   - Summing gives $\operatorname{completeWeilEnergy}(z) \ge (\kappa_0 + 2)\|z\|^2$ for every $z \in V_{Q_1}^\perp$.
4. **Global two-block Schur synthesis ($x = y + z$, $y \in V_{Q_1}$, $z \in V_{Q_1}^\perp$):**
   For $\tilde{W} := W_{\varphi_0,c,N} - s I$, orthogonality $z \in V_{Q_1}^\perp$ annihilates the diagonal part of $\langle \tilde{W} y, z\rangle$, leaving
   $$2|\langle \tilde{W} y, z\rangle| \le \frac{1}{4}\sum_{m=1}^{Q_1} E_{\varphi_0}(c,m) a_m^2 + 4\left(\sum_{m=1}^{Q_1} \frac{\|r_m\|^2}{E_{\varphi_0}(c,m)}\right)\|z\|^2.$$
   By Theorem 2 of `QuadraticOverlapConductorResiduals` and $E_{\varphi_0}(c,m) \ge \kappa_0 \min(1, (m/c)^7)$, $\sum_{m=1}^{Q_1} \frac{\|r_m\|^2}{E_{\varphi_0}(c,m)} \ll (c^9 + c^2 Q_1^2(1 + \log Q_1)^2)(1 + \log c)^3 (\log N)^{1/k - 1} \to 0$ since $9\alpha < 1$ and $2\alpha + 2q = 5\alpha + \frac{1}{3} < \frac{8}{9} < 1$. Combining with Theorem A on $y$ and Step 3 on $z$ yields $\langle \tilde{W} x, x\rangle \ge \frac{1}{2}\|z\|^2 \ge 0$, proving all-vector positivity and all spectral/geometric/edge corollaries for every $0 < \alpha < 1/9$.

## No-go closure (mandatory when falsified)
- **Exact killing theorem/mechanism:** Direct single-cutoff application of `HighConductorWeilCoercivity` at $R = \lfloor N^\theta \rfloor$ fails because $c^2(1 + \log R)(1 + \log c)/\log N \asymp \theta c^2(1 + \log c) \to \infty$, while direct application at $R = \lfloor \exp(c^9) \rfloor$ hits $c(1 + \log R)/\log N \asymp c^{10}/\log N$ ($\alpha < 1/10$).
- **Strongest positive survivor:** Telescoped intermediate cutoff $R_0 = \lfloor \exp((\log N)^{1/2}) \rfloor$ between $Q_1 = \lfloor (\log N)^q \rfloor$ and $R_1 = \lfloor N^{\theta_1} \rfloor$, combined with 8-channel bilinear conductor residuals weighted by $E_m(c)^{-1/2}$.
- **New insight:** Separating the polylogarithmic mid-band $V_{R_0} \cap V_{Q_1}^\perp$ (where $1 + \log R_0 = (\log N)^{1/2}$ keeps all $1/\log N$ errors $o(1)$) from the sub-polynomial band $V_{R_1} \cap V_{R_0}^\perp$ (where $\frac{1}{4}\log R_0 = \frac{1}{4}(\log N)^{1/2}$ dominates raw $O(c^2(1 + \log c))$ overlap and non-ratio costs directly) eliminates sublevel confinement without losing a single power of $c$ below the $1/9$ complement threshold.
