### 1. Antiunitary generator–correlation dichotomy and cross-horizon Hankel law
Let `H` be a complex Hilbert space with antiunitary involution `J : AntiunitaryInvol H`.
1. **Commuting positive-energy collapse.** Let `U : ℝ → (H →L[ℂ] H)` satisfy `J (U(a) (J x)) = U(a) x` for all `a ∈ ℝ`, `x ∈ H`, and let `P : H →L[ℂ] H` be self-adjoint (`star P = P`) with `0 ≤ Re ⟪x, P x⟫` and strong derivative `d/da|_{a=0} U(a) x = i P x` for all `x ∈ H`. Differentiating `J (U(a) (J x)) = U(a) x` at `a = 0` via real-linearity and continuity of `J` gives `-i J(P(J x)) = i P x`, i.e. `P (J x) = -J (P x)`. Hence for every `x ∈ H`,
   `0 ≤ Re ⟪J x, P (J x)⟫ = -Re ⟪J x, J (P x)⟫ = -Re ⟪P x, x⟫ = -Re ⟪x, P x⟫ ≤ 0`,
   so `⟪x, P x⟫ = 0` for all `x ∈ H`. Polarizing `star P = P` gives `P = 0`. Thus a nontrivial positive-energy unitary group cannot commute with `J`.
2. **Cross-horizon Hankel law.** Let `(H, M, ms)` be a `StandardForm M`, `S` a commutative monoid, and `U : S → (H →L[ℂ] H)` a unitary representation (`U(s * t) = U(s) * U(t)`, `star (U s) * U s = 1`, `U s * star (U s) = 1`) fixing `ms.Ω` (`U s ms.Ω = ms.Ω`) and inverted by `ms.J` (`ms.J.conjOp (U s) = star (U s)`). Then `(star (U t)) ms.Ω = (star (U t) * U t) ms.Ω = ms.Ω`. Setting `α_s(A) := U s * A * star (U s)`, for all `A₀, B₀ : H →L[ℂ] H` and `s, t ∈ S`:
   `ms.J.conjOp (α_t B₀) ms.Ω = ms.J (U t (B₀ ((star (U t)) ms.Ω))) = ms.J.conjOp (U t) (ms.J (B₀ ms.Ω)) = (star (U t)) (ms.J (B₀ ms.Ω))`.
   Applying `α_s A₀` and using `star (U s) * star (U t) = star (U t * U s) = star (U (s * t))` together with `(star (U s)) ms.Ω = ms.Ω` gives
   `⟪ms.Ω, α_s A₀ (ms.J.conjOp (α_t B₀) ms.Ω)⟫ = ⟪(star A₀) ms.Ω, (star (U (s * t))) (ms.J (B₀ ms.Ω))⟫`,
   which depends on `(s, t)` solely through the product `s * t`.

### 2. Positive classification of Partner-Hankel `∩` Hecke-isometric kernels (Square-class survivor)
1. **Square-class equivalence on `ℕ+`.** Call `K : ℕ+ → ℕ+ → α` *multiplicatively Hankel* if `∃ g : ℕ+ → α, ∀ m n, K m n = g (m * n)`, and *Hecke-dilation invariant* if `∀ p m n, K (p * m) (p * n) = K m n`. Then `K` satisfies both properties iff `∃ g : ℕ+ → α, (∀ p k, g (p ^ 2 * k) = g k) ∧ ∀ m n, K m n = g (m * n)`: if `K m n = g (m * n)` is Hecke-invariant then `g (p ^ 2 * k) = K p (p * k) = K 1 k = g k`; conversely `g ((p * m) * (p * n)) = g (p ^ 2 * (m * n)) = g (m * n)`.
   Writing `sqFreeCore (n : ℕ+) : ℕ+` for `∏ p ∈ (n : ℕ).primeFactors, p ^ ((n : ℕ).factorization p % 2)`, prime-factorization division `e_p = 2(e_p / 2) + e_p % 2` gives `n = (sqPart n) ^ 2 * sqFreeCore n` with `Squarefree (sqFreeCore n : ℕ)` and `sqFreeCore (p ^ 2 * k) = sqFreeCore k`. Hence `∀ p k, g (p ^ 2 * k) = g k` holds iff `g` factors through `sqFreeCore` (`∀ n, g n = g (sqFreeCore n)`).
2. **Nontrivial noncommutative `StandardForm` realization.** Let `H = EuclideanSpace ℂ (Fin 2 × Fin 2)` carry left matrix multiplication `M = (Set.range rightMul)′` (`M′ = Set.range rightMul` by finite-dimensionality / explicit `2 × 2` matrix units), cyclic separating tracial vector `Ω = (1 / √2) (e_{00} + e_{11})`, and `J(X)_{ij} = conj(X_{ji})`. For `χ₂(n) = (-1)^{(n : ℕ).factorization 2}` on `ℕ+`, conjugation `U(n)(X)_{ij} = χ₂(n)^{i.val + j.val} X_{ij}` is a multiplicative unitary representation fixing `Ω` with `J U(n) J = star (U(n))`, `U(2) ∉ M`, `U(2) ∉ M′` (strictly external, escaping Tomita central collapse), and `α_n(L_{A₀}) ∈ M` for `A₀ = E_{00} + E_{01}`. Its natural-cone kernel is `K(m, n) = (1 + χ₂(m * n)) / 2`, which is positive semidefinite, exact Hecke-dilation invariant (`K(pm, pn) = K(m, n)`), and nonconstant (`K(1, 1) = 1 ≠ 0 = K(1, 2)`).
3. **Constant collapse under continuous log-Toeplitz or positive Laplace structure.**
   - *Continuous log-Toeplitz:* Let `Φ : ℝ → β` (`T2Space β`) be continuous and satisfy `Φ(log(m / n)) = g(m * n)` for all `m, n : ℕ+`. For any `a, b : ℕ+`, `(a ^ 2) * (b ^ 2) = (a * b) * (a * b)` gives `Φ(2 log(a / b)) = g(a² b²) = g((ab)²) = Φ(0)`. Since `{2 log(a / b) : a, b ∈ ℕ+}` is dense in `ℝ` (`Rat.denseRange_cast` on `(0, ∞)` composed with the homeomorphism `x ↦ 2 log x`), continuity forces `Φ(y) = Φ(0)` for all `y ∈ ℝ`.
   - *Laplace / Euclidean positive energy:* Let `μ` be a finite positive measure on `ℝ` with `μ(Iio 0) = 0` and `g(n) = ∫ λ, exp(-λ log n) ∂μ`. If `g(4) = g(1)`, then `∫ λ in Ici 0, (1 - exp(-λ log 4)) ∂μ = 0`. On `[0, ∞)` the integrand is nonnegative and strictly positive on `(0, ∞)`, so `μ(Ioi 0) = 0` and `g(n) = g(1)` for all `n : ℕ+`.

### 3. Borchers `ax + b` spectral and Bohr-frequency rigidity
Let `(Δ, U)` be a strongly continuous unitary `BorchersPair H` (`Δ(s) U(a) Δ(-s) = U(e^{-2πs} a)`).
1. **Forced vacuum invariance and strict externality.** If `∀ s, Δ(s) Ω = Ω`, then `‖U(a) Ω - Ω‖ = ‖Δ(s)(U(a) Ω - Ω)‖ = ‖U(e^{-2πs} a) Ω - Ω‖ → 0` as `s → +∞`, so `U(a) Ω = Ω` for all `a ∈ ℝ`. In any `StandardForm M` with `∀ s, Δ(s) ms.Ω = ms.Ω`, separatingness of `ms.Ω` for `M` (and via `ms.J` for `M′`) gives `U(a) ∈ M ↔ U(a) = 1` and `U(a) ∈ M′ ↔ U(a) = 1`.
2. **Absence of nonzero eigenmodes and triviality on finite-dimensional subspaces (Graph/curve rung).**
   - Suppose `U(a) v = exp(i ω a) • v` for all `a ∈ ℝ` with `ω ≠ 0`. For `s ≠ 0`, `v_s := Δ(-s) v` satisfies `U(a) v_s = exp(i e^{-2πs} ω a) • v_s`. Setting `a₀ := π / ((1 - e^{-2πs}) ω)` gives `⟪v, v_s⟫ = ⟪U(a₀) v, U(a₀) v_s⟫ = exp(-iπ) ⟪v, v_s⟫ = -⟪v, v_s⟫`, so `⟪v, Δ(-s) v⟫ = 0` for all `s ≠ 0`. Letting `s → 0` yields `‖v‖² = 0`, hence `v = 0`.
   - Let `V ≤ H` be a finite-dimensional `ℂ`-subspace with `∀ a, ∀ v ∈ V, U(a) v ∈ V`. On `V`, `t ↦ U_V(t) ∈ (V →L[ℂ] V)` is norm-continuous, so `(1/ε) ∫_0^ε U_V(t) dt → 1` is a unit for small `ε > 0`. Hence every `x ∈ V` is `C¹` along `a ↦ U_V(a) x` with skew-adjoint generator `G = (U_V(ε) - 1) (∫_0^ε U_V(t) dt)⁻¹` (`⟪G x, y⟫ + ⟪x, G y⟫ = 0`). Both `ker G` and `(ker G)⊥` are `G`-invariant; if `ker G ≠ ⊤`, `Module.End.exists_eigenvalue` on `(ker G)⊥` gives `w ≠ 0` and `λ ≠ 0` with `G w = λ w`, hence `d/da (e^{-λa} U_V(a) w) = 0`, `U_V(a) w = e^{λa} w`, `Re λ = 0` by isometry, and `w = 0` by no-eigenmodes, contradiction. Thus `G = 0` and `U(a) v = v` for all `v ∈ V`. In particular, on any finite-dimensional representation of `QuadraticAlgebra ℝ (-q) t` (every graph black hole, damped or undamped) invariant under `U`, `U` acts trivially.
3. **Triviality of antiperiodic vectors and vanishing of alternating Cesàro Bohr averages.**
   - Suppose `U(τ₁) w = -w` with `τ₁ ≠ 0`; replacing `τ₁` by `|τ₁|` (since `U(-τ₁) w = -w`), assume `τ₁ > 0`, and set `T := 2 τ₁`, `ω := π / τ₁ > 0`. Then `U(t + T) w = w`. For each `k ∈ ℤ`, `w_k := ∫ t in 0..T, exp(-i k ω t) • U(t) w` satisfies `U(a) w_k = exp(i k ω a) • w_k` by `T`-periodicity; for `k ≠ 0`, `k ω ≠ 0` forces `w_k = 0`, while for `k = 0`, splitting `[0, 2τ₁] = [0, τ₁] ∪ [τ₁, 2τ₁]` and using `U(t + τ₁) w = -U(t) w` gives `w_0 = 0`. Thus `∫ t in 0..T, exp(-i k ω t) φ(t) = ⟪w, w_k⟫ = 0` for all `k ∈ ℤ`, where `φ(t) := Re ⟪w, U(t) w⟫` satisfies `φ(τ₁) = -‖w‖²` and `|φ(t)| ≤ ‖w‖²`. Since `Q_m(t) := ((1 - cos(ω t))/2)^m = sin(ω t / 2)^{2m}` lies in the span of `{exp(-i k ω t) : k ∈ ℤ}`, `∫ t in 0..T, Q_m(t) φ(t) = 0` for all `m ∈ ℕ`, which by strict peaking of `sin(ω t / 2)` at `t = τ₁` forces `‖w‖ = 0`, so `w = 0`.
   - For any `γ ≠ 0`, set `W := -U(π / γ)`. Both `ker(W - 1)` and `ker(star W - 1) = ker(-U(-π / γ) - 1)` are `{0}`, so `(LinearMap.range (W - 1))ᗮ = ⊥` and `range(W - 1)` is dense in `H`. For any `ψ ∈ H`, approximating `ψ` within `ε/2` by `(W - 1) x` and telescoping `∑_{k < K} W^k (W - 1) x = W^K x - x` gives `(1/K) ∑_{k < K} (-1)^k U(k π / γ) ψ → 0`, hence `(1/K) ∑_{k < K} (-1)^k ⟪ψ, U(k π / γ) ψ⟫ → 0`.

### 4. Unconditional resolution of B114 over `ℤ` (both readings) and partner trichotomy
1. **Natural-cone impossibility (exact and Tate limit).** Suppose `(H, M, ms)`, unitary `U : ℕ+ → (H →L[ℂ] H)` with `U n ms.Ω = ms.Ω` and `ms.J.conjOp (U n) = star (U n)`, and `A₀ ∈ M` with `α_n A₀ := U n * A₀ * star (U n) ∈ M` have natural-cone form `F(N, a) := Re ⟪ms.Ω, X(a) (ms.J.conjOp (X(a)) ms.Ω)⟫` (`X(a) = ∑_{i < N} (a i : ℂ) • α_{i+1} A₀`) whose Tate limit `F(N, m • a) / m² → integerProbe N a` holds for all `N, a`. Since `F(N, m • a) = m² F(N, a)`, `F(N, a) = integerProbe N a`. Polarizing on `e_i + e_j` (`i = m - 1`, `j = n - 1`) and using Section 1.2 together with `atomGram_eq_ratio` and `atomGram_im = 0` gives `splineCorr(log(m / n)) = (g(m * n) : ℂ)` for `g(k) = Re ⟪(star A₀) ms.Ω, (star (U k)) (ms.J (A₀ ms.Ω))⟫`. By Section 2.3 and `continuous_splineCorr`, `splineCorr` is constant on `ℝ`, so `ratCorr` is constant on `posUnits` and `coprimeCrossDiff ratCorr u v = 0` everywhere, contradicting `exists_coprimeCrossDiff_ratCorr_ne_zero`.
2. **Borchers GNS / Lax–Phillips impossibility (exact and Tate limit).** Suppose `(H, B)` (`B : BorchersPair H`) and `ψ₀ ∈ H` satisfy `‖∑_{i < N} ((m • a) i : ℂ) • B.U (log(i + 1)) ψ₀‖² / m² → integerProbe N a` for all `N, a`. By homogeneity, `‖∑_{i < N} (a i : ℂ) • B.U (log(i + 1)) ψ₀‖² = integerProbe N a ≥ 0` for all `N, a`, hence:
   - `RiemannHypothesis` holds (`riemannHypothesis_iff_integerProbes`), so `rightZeros zetaZeroConfig = ∅`.
   - Polarizing on `e_i + e_j` and using density of `{log(m / n) : m, n ∈ ℕ+}` in `ℝ` plus continuity of `y ↦ Re ⟪ψ₀, B.U y ψ₀⟫` and `continuous_splineCorr` yields `Re ⟪ψ₀, B.U y ψ₀⟫ = Re (splineCorr y)` for all `y ∈ ℝ`.
   - Under `rightZeros zetaZeroConfig = ∅`, `ratCorr_eq_zetaKernel`, `orbitKernel_eq_onLine_add_pairs`, and `orbitKernel_onLine_eq_bohrSum e` (`e : ℕ ≃ zetaOnLine.carrier`), combined with uniform convergence (`summable_onLineWeight e`) and log-density of `posUnits`, give `splineCorr y = ∑' j : ℕ, (onLineWeight e j : ℂ) * exp(i (e j).im y)` for all `y ∈ ℝ`, with `onLineWeight e j ≥ 0`.
   - By `criticalSeen_infinite`, `{ρ ∈ criticalSeen | ρ.im ≠ 0}` is nonempty (`{ρ ∈ criticalSeen | ρ.im = 0}` is a subsingleton `{1/2}`), yielding `j₀ : ℕ` with `γ₀ := (e j₀ : ℂ).im ≠ 0` and `0 < onLineWeight e j₀`.
   - Evaluating at `y_k = k π / γ₀`, dominated convergence on `∑' j` shows `(1/K) ∑_{k < K} (-1)^k Re (splineCorr (k π / γ₀)) → ∑' j, (if -exp(i (e j).im π / γ₀) = 1 then onLineWeight e j else 0) ≥ onLineWeight e j₀ > 0` (at `j = j₀`, `-exp(iπ) = 1`), contradicting `(1/K) ∑_{k < K} (-1)^k Re ⟪ψ₀, B.U (k π / γ₀) ψ₀⟫ → 0` from Section 3.3.
