## Exact theorem

Let `V` be any finite set of qubit sites. On the two-replica Hilbert space,
write `F_v` for replica swap at site `v`. For a Boolean word
`x : V -> {0,1}`, put

\[
 S_x=\bigotimes_{v\in V}F_v^{x_v}.
\]

These `2^|V|` matrices are linearly independent. More strongly, every
coefficient of a linear combination `sum_x c_x S_x` is recovered by an
explicit tensor Möbius functional: at each site the off-diagonal swap entry
selects `F`, while diagonal evaluation minus that swap entry selects `I`.
Consequently the physical map

\[
 \iota(c)=\sum_xc_xS_x
\]

is injective for every finite site set, with no dimension-count argument.

For distinct sites `u,v` and axes `a,b in {1,2,3}`, define the literal
weight-two Pauli string `P_(uv;ab)` and its two-replica collective generator

\[
 G_{uv;ab}=P_{uv;ab}\otimes I+I\otimes P_{uv;ab}.
\]

The physical edge Casimir is

\[
 K_{uv}=\sum_{a,b=1}^3\operatorname{ad}_{G_{uv;ab}}^2.
\]

Every summand is generated by a Pauli string of weight exactly two. If an
arbitrary two-site two-replica matrix `A` is tensored with arbitrary local
spectator matrices outside `{u,v}`, then

\[
 K_{uv}(A\otimes S_{V\setminus\{u,v\}})
 =K_{\mathrm{edge}}(A)\otimes S_{V\setminus\{u,v\}}.
\]

Thus the four-coordinate edge operator previously computed in the local
identity/swap basis is not a surrogate. It is exactly intertwined with the
nine literal physical double commutators on the global matrix algebra:

\[
 K_{uv}\,\iota(c)
 =\iota\!\left(K^{\mathrm{coeff}}_{uv}c\right).
\]

In the ordered endpoint basis `(00,01,10,11)`,

\[
K^{\mathrm{coeff}}_{uv}c=
\begin{pmatrix}
-32(c_{01}+c_{10})\\
64c_{01}+16c_{10}\\
16c_{01}+64c_{10}\\
-32(c_{01}+c_{10})
\end{pmatrix},
\]

so its kernel is exactly the endpoint-matched sector `c_01=c_10=0`.

Let `G` be any finite nonempty preconnected simple graph on `V`. Then

\[
 \bigcap_{\{u,v\}\in E(G)}
 \ker\left(K_{uv}\big|_{\iota(\mathbb C^{\{0,1\}^V})}\right)
 =\operatorname{span}_{\mathbb C}
 \left\{I^{\otimes V},F^{\otimes V}\right\}.
\]

Equivalently, if every literal edge Casimir annihilates `iota(c)`, then `c`
is supported only on the all-identity and all-swap words, and the converse
holds.

## Proof

Reassociate a pair of global replica configurations with a configuration of
local two-replica indices. Sitewise tensor-product matrices then multiply
sitewise. For fixed endpoints `u,v`, split every intermediate configuration
into its endpoint pair and all outside indices. Finite product--sum
factorization gives the exact edge-extension multiplication identity

\[
 \operatorname{Ext}_{uv}(S,A)\operatorname{Ext}_{uv}(T,B)
 =\operatorname{Ext}_{uv}(ST,AB).
\]

The global collective generator generated by `P_(uv;ab)` is precisely
`Ext_(uv)(I,G_(ab))`. Applying the multiplication identity twice to the
commutator square proves the global/local Casimir equality.

The global swap coefficient space decomposes into blocks indexed by outside
swap assignments. In every block the endpoint coefficients form the local
four-coordinate model. Reindexing the finite sum by outside assignment and
endpoint label proves exact global intertwinement. Injectivity of `iota`
then transfers the local edge-kernel law to physical matrices. Finally,
vanishing on every graph edge forces the Boolean word to be constant on each
connected component. Preconnectedness leaves exactly the two constant words.

## What this does not prove

This theorem supplies exact quadratic recovery on the two-replica singlet
sector. It does not by itself prove the all-subspaces Hall inequality for the
full mixed singlet/nonsinglet matrix space. A common-kernel Casimir law cannot
replace Hall expansion. It also says nothing yet about long-time cavity decay,
circuit anti-concentration, complexity growth, plateau measure, or recurrence
scale.
