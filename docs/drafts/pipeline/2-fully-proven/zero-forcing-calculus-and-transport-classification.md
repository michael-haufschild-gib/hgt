### 1. Quartet forcing and closed transport configurations (`[PROVED HERE]`)
- **Quartet of an off-line zero.** If `ζ(ρ) = 0` and `Re ρ > ½`, then `Re ρ ≤ 7/8` (`riemannZeta_zero_mem_quasiRH_strip`) and `Im ρ ≠ 0` (since `(x − 1)ζ(x) > 0` on `x > 0` forces `ζ(x) < 0` on `(0, 1)`). Conjugation `ξ(s̄) = conj(ξ(s))` and functional reflection `ξ(1 − s) = ξ(s)` force `Q(ρ) = {ρ, ρ̄, 1 − ρ, 1 − ρ̄}` to consist of four pairwise distinct zeros of `ζ` of identical analytic/meromorphic order (`Re ρ ≠ 1 − Re ρ` and `Im ρ ≠ −Im ρ`).
- **`k`-fold descent (`ζ(s)^m/ζ(ks)`, `k ≥ 2`, `m ≥ 1`).** Let `Z ⊆ {0 < Re s < 1}` be locally finite (on compact subsets of `{0 < Re s < 1}`) and symmetric under `z ↦ 1 − z̄`.
  - Under full-strip descent (`∀ z ∈ Z, z/k ∈ Z`), `z/k^n` violates `Re > 0` or accumulates outside compact strip bounds unless `Z = ∅` (more directly, `ψ_k(z) = 1 − z̄/k` maps `{0 < Re z < 1}` into `[1 − 1/k, 1) ⊂ [½, 1)` and converges to `k/(k + 1) ∈ (0, 1)`, whereas `k/(k + 1)/k^2 = 1/(k(k + 1))` and `1 − 1/(k(k + 1)) ≠ k/(k + 1)`).
  - Under right-zero descent (`∀ z ∈ Z, Re z > ½ → z/k ∈ Z`), `ψ_k(z) = 1 − z̄/k` satisfies `Re ψ_k(z) = 1 − (Re z)/k ∈ (1 − 1/k, 1 − 1/(2k)) ⊂ (½, 1)` whenever `½ < Re z < 1`, and `ψ_k^[n](z) = k/(k + 1) + (−1/k)^n (Re z − k/(k + 1)) + i (Im z)/k^n → k/(k + 1)`. If `z ∈ Z` has `Re z > ½` and `z ≠ k/(k + 1)`, the orbit `{ψ_k^[n](z)}` is infinite and lies in a compact subset of `{0 < Re s < 1}`, contradicting local finiteness. Conversely, `k/(k + 1)` steps to `1/(k + 1)` with `Re(1/(k + 1)) ≤ 1/3 < ½`, where right-zero descent halts. Thus `Z` is closed iff `Z ∩ {Re s > ½} ⊆ {k/(k + 1)}`. When `Z` has no real zeros (`∀ z ∈ Z, Im z ≠ 0`), `Z` is closed iff `Z ⊆ {Re s = ½}`. In particular, `Z_crit ∪ Q(ρ)` (`½ < Re ρ < 1`, `Im ρ ≠ 0`) is never closed.
- **Doubling transport (`ζ(2s)/ζ(s)`).** Let `Z ⊆ {0 < Re s < 1}` be closed under `z ↦ z̄` and `z ↦ 1 − z`.
  - Under full-strip or right-zero doubling (`Re z > ½ → 2z ∈ Z`), `Re(2z) > 1` leaves `{0 < Re s < 1}`, so full-strip closure forces `Z = ∅` and right-zero closure holds iff `Z ⊆ {Re s ≤ ½}` (hence `Z ⊆ {Re s = ½}` by reflection).
  - Under left-zero doubling (`Re z < ½ → 2z ∈ Z`), an off-line point `ρ = (½ + δ) + iγ` (`0 < δ < ½`) reflects to `1 − ρ̄ = (½ − δ) + iγ` (`Re < ½`), doubling to `(1 − 2δ) + 2iγ` at critical distance `T(δ) = |2δ − ½|` and ordinate `2γ`. By induction on `n ≥ 1`, for `δ ∈ (0, ½)`, `(∀ j < n, T^[j](δ) > 0) ∧ T^[n](δ) = 0` holds iff `δ = m / 2^{n+1}` for an odd integer `1 ≤ m < 2^n` (`n = 1`: `|2δ − ½| = 0 ⇔ δ = ¼ = 1/2^2`; inductive step splits `2δ < ½` vs. `2δ > ½`, giving `½ − 2δ = m'/2^n` or `2δ − ½ = m'/2^n`, i.e. `δ = (2^n ∓ m')/2^{n+1}`). Every step doubles `|Im|`, so if `Z` has no real zeros (`Im z ≠ 0` on `Z`), `Z` has finite off-line part and is closed under left-zero doubling iff every `ρ ∈ Z` with `Re ρ > ½` has `Re ρ − ½ = m / 2^{n+1}` (`n ≥ 1`, `1 ≤ m < 2^n` odd) and `½ + 2^n i Im ρ ∈ Z`. A single quartet `Q(ρ)` (`½ < Re ρ < 1`, `Im ρ ≠ 0`) with no partner is never closed (`2|Im ρ| ≠ |Im ρ|`), and `Z_crit ∪ Q(ρ)` is closed iff `Re ρ = 3/4` and `½ + 2i Im ρ ∈ Z_crit`.

### 2. Witt monomials, squarefree pole ruler, shift margin, and Brauer cancellation (`[PROVED HERE]`)
- **Witt Euler-product monomials.** For `M_e(s) = ∏_{j : Fin K} ζ((j + 1)s)^{e_j}` (`e : Fin K → ℤ`), away from `(j + 1)s = 1`, meromorphy gives `ord_s(M_e) = ∑_j e_j ord_{(j+1)s}(ζ)`. If `½ < Re ρ < 1`, `(j + 1)Re ρ > 1` for `j ≥ 1`, so `ord_{(j+1)ρ}(ζ) = 0` and `ord_ρ(M_e) = e_0 ord_ρ(ζ)`. On any single-quartet divisor `Z_crit ∪ Q(ρ_0)` (`½ < Re ρ_0 < 1`, `Im ρ_0 ≠ 0`), for `j ≠ 1`, `(j + 1)(ρ_0 / 2)` has real part `< ½` (`j = 0`) or imaginary part `(j + 1)/2 · Im ρ_0 ∉ {±Im ρ_0}` with real part `≠ ½` or outside `Q(ρ_0)` — specifically for `j = 0`, `Re(ρ_0/2) ∈ (¼, ½)` and `ρ_0/2 ≠ 1 − ρ_0, 1 − ρ̄_0` since `Im(ρ_0/2) = ½ Im ρ_0 ∉ {±Im ρ_0}`, while for `j ≥ 2`, `|Im((j+1)ρ_0/2)| = ((j+1)/2)|Im ρ_0| > |Im ρ_0|`, so if `e_1 < 0` and either `(j+1)Re(ρ_0/2) ≠ ½` for `j ≥ 2` or `½ + i(j+1)Im(ρ_0)/2 ∉ Z_crit`, `s = ρ_0/2` is an uncancelled pole of order `−e_1 mult(ρ_0)`.
- **Unconditional `[½, 9/16)` squarefree pole ruler.** Let `F_m(s) = ((s − 1)ζ(s))^m / ζ(2s)` (`m ≥ 1`). For every `β ∈ [½, 9/16)`, `F_m` is analytic on `{Re s > β/2}` iff `zetaZeroAbscissa ≤ β`:
  - `(⇐)`: On `{Re s > β/2}`, `Re(2s) > β ≥ zetaZeroAbscissa` (and `2s = 1` is impossible since `β/2 ≥ ¼` gives `Re(2s) > 1` when `β ≥ ½`), wait: at `2s = 1`, `s = ½`, and if `β = ½` then `{Re s > ¼}` CONTAINS `s = ½`! Good catch: at `s = ½`, `ζ(2s)` has a simple POLE, so `1/ζ(2s)` VANISHES at `s = ½` (it is analytic at `s = ½`, not a pole)! Specifically, `zetaResidueUnit (2s) = (2s − 1)ζ(2s)` is entire and nonzero at `2s = 1`, so `(2s − 1) / zetaResidueUnit (2s)` equals `1 / ζ(2s)` away from `s = ½` and extends analytically across `s = ½`! Using `meromorphicOrderAt F_m s ≥ 0` on `{Re s > β/2}` (pole-freeness: `∀ s, β/2 < Re s → 0 ≤ meromorphicOrderAt F_m s`), at `s = ½` we have `ord_{1/2}(ζ(2·)) = −1`, so `ord_{1/2}(F_m) = m · ord_{1/2}(ζ) + 1 ≥ 1 ≥ 0` automatically! And for `s ≠ ½` with `Re s > β/2`, `2s ≠ 1` and `Re(2s) > β ≥ Θ`, so `ζ(2s) ≠ 0`, making `F_m` analytic at `s` with `ord_s(F_m) ≥ 0`!
  - `(⇒)`: Suppose `∀ s, β/2 < Re s → 0 ≤ meromorphicOrderAt F_m s`. For any `ρ` with `ζ(ρ) = 0` and `β < Re ρ < 1`, at `s = ρ/2` (`Re s > β/2`, `s ≠ 1`, `2s = ρ ≠ 1`), `0 ≤ m · ord_{ρ/2}(ζ) − ord_ρ(ζ)` with `ord_ρ(ζ) ≥ 1` forces `ord_{ρ/2}(ζ) ≥ 1`, i.e. `ζ(ρ/2) = 0`. Applying `riemannZeta_ne_zero_of_halving` with `α = β/2 ≥ ¼` excludes all zeros in `β < Re z < 2 − 2β`. Since `β < 9/16`, `2 − 2β > 7/8`, and `riemannZeta_ne_zero_of_seven_eighths_lt_re` excludes `Re z > 7/8` (and `7/8 < 2 − 2β` covers `z = 7/8` directly!), `ζ` has no zeros with `Re z > β`, whence `zetaZeroAbscissa ≤ β`! At `β = ½`, pole-freeness of `((s − 1)ζ(s))^m / ζ(2s)` on `{Re s > ¼}` is unconditionally equivalent to `RiemannHypothesis`.
- **Ramanujan / Rankin–Selberg shift margin.** For all `a, b, ρ ∈ ℂ`, `max(0, Re a, Re b, Re(a + b)) ≥ (0 + Re(a + b))/2 = Re(a + b)/2`, so `(1 + max(0, Re a, Re b, Re(a + b))) − Re((ρ + a + b)/2) ≥ 1 − Re ρ / 2`. For every nontrivial zero `ρ` of `ζ` (`0 < Re ρ < 1`), `Re ρ ≤ 7/8` gives `1 − Re ρ / 2 ≥ 9/16`.
- **Brauer / Kuroda trivial-character cancellation.** For any subgroup `H` of a finite group `G`, `(1/|G|) ∑_{g ∈ G} (Ind_H^G 1)(g) = (1/|G|) · |H|⁻¹ ∑_{g, x : G} 1_{x g x⁻¹ ∈ H} = 1` (each fixed `x` maps `g ↦ x g x⁻¹` bijectively onto `G`, hitting `H` exactly `|H|` times). Hence for any finite family `(c_i, H_i)` of integer weights and subgroups, `(1/|G|) ∑_{g ∈ G} (∑_i c_i Ind_{H_i}^G 1)(g) = ∑_i c_i`. Whenever `∑_i c_i Ind_{H_i}^G 1` has zero multiplicity at the trivial character (average `0` over `G`), `∑_i c_i = 0`, cancelling the base `ζ(s)^{∑_i c_i}` factor identically.

### 3. Isolated-quartet Galois invariants and mixed-trace dichotomy (`[PROVED HERE]`)
Let `B = primeTraceField`, `E = primeTraceExtension`, `G = Gal(E/B)`, and `ρ ∈ XiDivisorSupport` with `β = Re ρ ≠ ½` and `t = Im ρ`. Let `u_p = primeOrdinateValue p ρ = 2 cos(2t log p)` and `v_p = primeWidthValue p ρ = p^{2β−1} + p^{1−2β}`.

  3. For every prime `p`, `A_{t,p}²` is a square in `B` iff `(A_{t,p} : ℂ) ∈ B` iff `(u_p : ℂ) ∈ B` iff `(v_p : ℂ) ∈ B` iff `G` has no partial flip on `Q(ρ)`.
  4. Every divisor multiplicity copy on `Q(ρ)` has equal count `k = ((divisor xi univ) ρ).toNat ≥ 1` (by `xi_divisor_conj` and reflection invariance), so for every integer prime vector `m : Nat.Primes →₀ ℤ`, the height-`t` mixed trace factors as

     which is identically symmetric between `β − ½` and `it`.
