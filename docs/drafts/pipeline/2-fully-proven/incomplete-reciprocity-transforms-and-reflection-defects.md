### 1. Exact Doubly-Incomplete Cusp Reciprocity Identity and Phase/Target Retention
Let $O = \mathbb{Z}[\omega]$ be the ring of Eisenstein integers, $c \in O \setminus \{0\}$ with conductor norm $Q_c = N(c) = \|c\|^2$, $\Psi : (O / (c)) \to^* \mathbb{C}$ with $\|\Psi\| \le 1$, and $W_0 \in C_c^\infty([a, b])$ ($0 < a < b$). For $s \in \mathbb{C}$, define the complex-twisted radial window
$$W_s(y) := y^{1/2 - s} W_0(y), \qquad V^*(W_s)(y) = y^{1/2} W_s(y) = y^{1 - s} W_0(y).$$
For $X > 0$ and cube-norm cutoffs $Y_0 > 1, Y_0' > 1$, split the ideal-indexed Gauss sum `completedIdealT` (`completedIdealT_eq_completedT`) at $N(J) < Y_0$ vs $N(J) \ge Y_0$ and split the polar-free finite-cusp full-index reflection (`completedT_finite_cusp_full_reflection`, `SourceCuspDatum.mellin_entire`) at $N(J') < Y_0'$ vs $N(J') \ge Y_0'$:
$$\operatorname{incompleteIdealT}_{Y_0}(\Psi_c, W_s, X) = \operatorname{incompleteCuspDual}_{Y_0'}(c, \Psi, d, W_s, X) + \operatorname{reciprocityBoundaryDefect}_{Y_0, Y_0'}(c, \Psi, d, W_s, X),$$
where $\Psi_c = \Psi \circ \operatorname{mk}_{(c)}$ and
$$\operatorname{reciprocityBoundaryDefect}_{Y_0, Y_0'}(c, \Psi, d, W_s, X) := \operatorname{dualCubeTail}_{\ge Y_0'}(c, \Psi, d, W_s, X) - \operatorname{directCubeTail}_{\ge Y_0}(\Psi_c, W_s, X).$$

1. **Exact target retention:** Since $N((1)) = 1 < Y_0$, the $J = (1)$ summand of $\operatorname{incompleteIdealT}_{Y_0}$ equals $\operatorname{CompletedGauss.summand}(\Psi_c, W_s, X, I, 1) = X^{-1/2} \operatorname{columnWeight}(\Psi_c, I) W_s(N(I)/X)$ identically, whose third convolutional power carries $\mu(I)$.

3. **Non-reducibility to full monomial completion:** For any dyadic support $0 < a < b < 4a$, any $W_0$ with $W_0(y_0) \ne 0$ ($y_0 \in [a, b]$), and any $\eta \in (0, 1/3)$, set $J_m = ((-2)^{2m}) = (4^m)$, $X_m = 4096^m / y_0$, and let $c_m \in O \setminus \{0\}$ be the product of all odd integers $\le 2\lceil b X_m \rceil_+ + 1$ with trivial Dirichlet character $\Psi_m = 1_{\operatorname{MulChar}} \bmod c_m$. Because $b < 4a$, $N(I) N(J)^3 \in (\frac{1}{4} 64^{2m}, 4 \cdot 64^{2m})$ isolates the unique pair $(I, J) = ((1), J_m)$, giving $\operatorname{directCubeTail}_{\ge X_m^\eta}(\Psi_m, W_0, X_m) = \operatorname{summand}(\Psi_m, W_0, X_m, 1, J_m) \ne 0$ for all large $m$.

### 2. Milestone 1: Uniform Sub-Cubic Power Saving vs Sub-Conductor Obstruction
Fix any compact complex rectangle $\mathcal{R} = \{s \in \mathbb{C} \mid \sigma_1 \le \operatorname{Re} s \le \sigma_2,\; |\operatorname{Im} s| \le T\}$. On $[a, b] \subseteq (0, \infty)$, the family $s \mapsto W_s$ has uniformly bounded $C^k$-seminorms for $s \in \mathcal{R}$; set $M_{\mathcal{R}} := \sup_{s \in \mathcal{R}, y \in [a,b]} \|V^*(W_s)(y)\| < \infty$.

1. **Uniform direct-tail upper bound:** For $\|\Psi\| \le 1$, $\|\operatorname{columnWeight}(\Psi, I) / \sqrt{N(I)}\| \le 1$ and $\|\operatorname{cubeWeight}(\Psi, J)\| \le N(J)^{-1}$. For each nonzero $J$ with $N(J) \ge Y_0$, the support condition $N(I) N(J)^3 \le b X$ restricts $I$ to $N(I) \le b X / N(J)^3$; if $b X / N(J)^3 < 1$ the inner sum vanishes, and if $b X / N(J)^3 \ge 1$ there are at most $128 b X / N(J)^3$ ideals $I$ (`finite_ideal_count_real`), giving inner norm $\le 128 b M_{\mathcal{R}} X N(J)^{-4}$. Summing over dyadic shells $2^k Y_0 \le N(J) < 2^{k+1} Y_0$ ($\#J \le 256 \cdot 2^k Y_0$) yields, uniformly for all $c \ne 0$, $\|\Psi\| \le 1$, $X > 0$, $Y_0 \ge 1$, and $s \in \mathcal{R}$:
   $$\|\operatorname{directCubeTail}_{\ge Y_0}(\Psi_c, W_s, X)\| \le C_{\text{dir}}(\mathcal{R}, W_0) \cdot X \cdot Y_0^{-3}.$$
2. **Uniform dual-tail upper bound:** By iterated Mellin integration by parts on `Vstar W_s` uniformly over $s \in \mathcal{R}$, for every $N \ge 2$ there exists $B_N(\mathcal{R}, W_0) > 0$ such that $\|\operatorname{paperKernel}(V^*(W_s))(x)\| \le B_N x^{-N}$ for all $x > 0$. On the dual tail $N(J') \ge Y_0'$, every $p = (u, k, (I', J'))$ satisfies $\operatorname{sourceCuspRadialLength}(\theta(p)) = 3^k N(I') N(J')^3 \ge (Y_0')^3$ and $\ge (Y_0')^{3/2} \operatorname{sourceCuspRadialLength}(\theta(p))^{1/2}$; using $\sum_h \|a_{j,z}(h)\| \ell(h)^{-3/2} < \infty$ (`sourceCuspRadialCoefficient_weighted_summable`) and $d_i.\operatorname{smoothingScale}(X) \ge \operatorname{sourceReflectionScale} \cdot X / \|9c\|^4 = (\operatorname{sourceReflectionScale}/6561) X / Q_c^2$, for every $N \ge 2$:
   $$\|\operatorname{dualCubeTail}_{\ge Y_0'}(c, \Psi, d, W_s, X)\| \le C_{\text{dual}}(\mathcal{R}, W_0, N) \, |O / (9c)| \left(\frac{X}{Q_c^2}\right)^{-N} (Y_0')^{-(3N - 9/2)} \quad (N \ge 2).$$
3. **Milestone 1 affirmative theorem ($Q_c \le X^{1-\delta}$, $\frac{1}{6} < \eta < \frac{1}{3}$):** In `completedIdealT` normalization, the trivial row bound is $O(X)$ and square-root cancellation (`RawMoment` normalization $X^{-1/2} \operatorname{completedIdealT}$) is $O(X^{1/2})$. Fix $\delta \in (0, 1)$, $\eta \in (1/6, 1/3)$, and $\eta' = \max(\delta/3, (1 - \delta)/3) \in (0, 1/3)$. When $Q_c \le X^{1-\delta}$, $(X / Q_c^2)(X^{\eta'})^3 \ge X^\delta$; choosing $N$ with $\delta N \ge 2$ bounds the dual tail by $O(X^{-1/2})$, while the direct tail is $\le C_{\text{dir}} X^{1 - 3\eta} = C_{\text{dir}} X^{1/2 - (3\eta - 1/2)}$. Hence `reciprocityBoundaryDefect` achieves the uniform power saving $X^{-(3\eta - 1/2)}$ **below $X^{1/2}$** (and $X^{-3\eta}$ below the trivial bound $X$) across the entire reflection box $Q_c \le X^{1-\delta}$, $s \in \mathcal{R}$.
4. **Milestone 1 sub-conductor obstruction ($Q_c \ge X^{1+\kappa}$):** In the `RawMoment` regime $Q_c \ge X^{1+\kappa}$ ($\kappa > 0$), $d_i.\operatorname{smoothingScale}(X) \le C_0 X / Q_c^2 \le C_0 X^{-(1 + 2\kappa)}$, so $d_i.\operatorname{smoothingScale}(X) \cdot (Y_0')^3 \le C_0 X^{3\eta' - 1 - 2\kappa} \to 0$ for every sub-cubic $\eta' \le 1/3$: no sub-cubic dual truncation reaches the decay regime of `paperKernel`.
