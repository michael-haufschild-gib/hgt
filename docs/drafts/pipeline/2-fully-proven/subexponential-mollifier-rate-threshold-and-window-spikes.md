- **Statement:**
  1. **Hermitian analytic trace and removal of real-coefficient assumptions (`hbr`):** For every finite complex Dirichlet polynomial $\Psi(s) = \sum_{n \in s} a_n n^{-s}$ ($s \subseteq \mathbb{N}_{\ge 1}$) and height $T \in \mathbb{R}$, the entire function
     $$\operatorname{edPolyHermitianTrace}(a, s, T)(z) := \frac{\Psi(z + iT) + \Psi^*(z - iT)}{2}, \qquad \Psi^*(w) := \sum_{n \in s} \overline{a_n}\, n^{-w},$$
     satisfies $\operatorname{edPolyHermitianTrace}(a, s, T)(x) = \operatorname{Re}\Psi(x + iT)$ for all $x \in \mathbb{R}$, $\|\operatorname{edPolyHermitianTrace}(b, s, T)(4)\| \ge \tfrac{5}{16}$ when $b_1 = 1$ and $\|b_n\| \le 1$, and $\|\operatorname{edPolyHermitianTrace}(a, s, T)(z)\| \le \sum_{n \in s} \|a_n\| n^{-x}$ on $\operatorname{Re} z \ge x$. Consequently, the Backlund horizontal-edge bound, the Levinson mollified Littlewood budget, the critical-line log-integral ceiling $\int_T^{2T} \log\|\zeta(\tfrac{1}{2}+it)\|\,dt \le \tfrac{\varepsilon}{2}T + C + K(\log T + \log N)$, the clustering implication `ComplexMollifiedSecondMomentLaw → CriticalClustering`, the log-free density implication `ComplexSecondMomentRate K₀ → LogFreeNearLineZeroDensity`, and the left-of-line second-moment floor all hold **unconditionally for arbitrary complex coefficients** $b : \mathbb{N} \to \mathbb{C}$ ($b_1 = 1$, $\|b_n\| \le 1$).
  2. **Uniform stretched-exponential necessary-length law and exact `exp(c log²T)` rate threshold:** Eventually as $T \to \infty$, **simultaneously for all integers $1 \le N \le \exp(T^{1/60})$** and **all complex Dirichlet polynomials** $M(s) = \sum_{n=1}^N b_n n^{-s}$ with $b_1 = 1$ and $\|b_n\| \le 1$,
     $$\int_T^{2T} \left\|\zeta\!\left(\tfrac{1}{2}+it\right) M\!\left(\tfrac{1}{2}+it\right)\right\|^2 dt \;\ge\; \left(1 + \frac{\log T}{8\log T + 6\log N}\right) T.$$
     In particular:
     - Any complex normalized mollifier achieving $\int_T^{2T} \|\zeta(\tfrac{1}{2}+it)M(\tfrac{1}{2}+it)\|^2 dt \le (1 + \mathcal{E}) T$ ($\mathcal{E} > 0$) satisfies $\log N \ge \min\!\big(T^{1/60},\, \tfrac{\log T}{6\mathcal{E}} - \tfrac{4}{3}\log T\big)$ eventually in $T$.
     - Any complex mollifier family achieving the `D_zero`/`D_win`-forcing rate $\int_T^{2T} \|\zeta M(\tfrac{1}{2}+it)\|^2 dt \le (1 + K_0 / \log T) T$ ($K_0 > 0$) must satisfy $\log N(T) \ge \frac{(\log T)^2}{6 K_0} - \frac{4}{3}\log T$ eventually ($N(T) \ge \exp((\frac{1}{6K_0} - o(1))(\log T)^2)$); no quasi-polynomial family of length $N(T) \le \exp(\delta (\log T)^2)$ with $\delta < \frac{1}{6 K_0}$ can realize excess $K_0 / \log T$.
     - Any complex mollifier family whose normalized critical-line second moment tends to $1$ forces $\frac{\log N(T)}{\log T} \to +\infty$ (and $\min(T^{1/60}, \log N(T)) / \log T \to +\infty$).
  3. **Superposed multi-window critical-line spike and window-occupancy bound (`D_win`):** For any $R \ge 1$, $\delta > 0$, $V \ge R + 4$, and any finite set $B \subseteq [\lceil V\rceil, \lfloor 2V\rfloor]$ of Burnol unit windows each containing a $\xi$-zero $\rho$ with $|\operatorname{Re}\rho - \tfrac{1}{2}| \ge \delta$, every complex prefix-cancelling mollifier $\Psi(s) = \sum_{d=1}^X b_d d^{-s}$ ($b_1 = 1$, $\|b_d\| \le B_0$, $\sum_{n=2}^{X_1} \|c_n\| n^{-(1/2+\delta)} \le \tfrac{1}{8}$, $Y \ge 1$) meeting the uniform Cahen–Mellin Gaussian tail bounds on $[V - 3, 2V + 3]$ satisfies
     $$\int_{V - R - 3}^{2V + R + 3} \left\|\zeta\!\left(\tfrac{1}{2}+it\right)\Psi\!\left(\tfrac{1}{2}+it\right)\right\|^2 dt \;\ge\; \frac{|B|}{\lceil 2R + 7\rceil} \cdot \frac{3\delta}{4}\, e^{-\alpha/2} Y^{2\delta},$$
     and when $2\alpha \le \log Y$ satisfies the sharper spike
     $$\int_{V - R - 3}^{2V + R + 3} \left\|\zeta\!\left(\tfrac{1}{2}+it\right)\Psi\!\left(\tfrac{1}{2}+it\right)\right\|^2 dt \;\ge\; \frac{|B|}{\lceil 2R + 7\rceil} \cdot \frac{3\delta}{4}\, e^{-2\alpha\delta^2} Y^{2\delta}.$$
