- **Statement:** A non-mirror RH proof must first prove a source-defined landscape in which the completed object is uniquely constrained; zero placement is then read as a residue. Any proof whose primary quantified object is an off-line-zero configuration, an RH-equivalent positivity tower, or a zero-fed moment measure remains inside the mirror unless it is source-built from non-zero data.

## Motivation

The user correction is right at the logical-type level: RH cannot be generated by finding a finite flow for `zeta`. Hypertranscendence rules out that class of handle. The proof shape, if it exists in this programme, must be a rigidity/uniqueness statement for the ambient landscape: the object self-selects because all degrees of freedom have already been spent by source constraints.

This is not a theorem. It is a gate for avoiding false progress.

## Gate

A candidate RH route is a landscape proof only if it passes all of these:

1. The category or landscape is defined from non-zero source data: completion, functional equation, Euler/prime data, Gamma boundary data, finite order, positivity/polarization, or another independently motivated constraint.
2. The proof first establishes rigidity, purity, uniqueness, or a forced index property of that landscape.
3. Zero placement is not an input. It is a downstream reading of the unique constrained object.
4. Fake families are separated by a named source gate, not by saying that their zeros are wrong.
5. The argument does not reduce to an RH-equivalent sign condition unless that sign condition is source-built without zero feeding.

Failure cases:

1. Quantifying over possible off-line zero configurations and eliminating them one by one. This is RH in disguise.
2. Naming `kappa_- = 0`, Weil positivity, Hankel/Stieltjes positivity, Jensen hyperbolicity, or scalar Weyl positivity without a source-built construction. These are mirrors.
3. Building the decisive object from the zero divisor `{rho}`, reciprocal moments `T_k`, or a measure such as `nu'` before proving how source data produce it.
4. Treating computation as discovery when the qualitative answer was known before the run.

## Current Audit

The big-picture document correctly names the target as constraint, not flow. It also correctly warns that the positivity wall is a mirror if treated as the target.

The unresolved weakness is that much of the sharp finite anatomy still lives in zero-divisor coordinates:

- reciprocal moments `T_k`;
- the signed measure `sigma = nu' - a_* delta_{y_*}`;
- the scalar Weyl/Christoffel gate `s_d`;
- the condition `s_d > 0 for all d`.

These are useful charts. They are not yet the landscape proof. They become non-mirror only after a source-built functor constructs the same signed object from non-zero data and proves the repair sign without reading the zero locations.
