## 2026-06-24 Haiku entropy audit -- finite-state obstruction is known input/output elimination

Entropy selected C16 after the finite-observation and Böttcher finite-truncation gates. The clean theorem is:

**Finite DA state-space no-go.** Let `K` be a differential field. Suppose a scalar output `y` is produced by a
finite tuple of hidden states `x_1,...,x_n` satisfying a finite algebraic differential system over `K` whose
inputs are DA over `K`, and suppose the output is algebraic/rational over the differential field generated by
those states and inputs. If the state equations define a finite-dimensional differential-algebraic realization
rather than smuggling in `y` as an oracle, then `y` is differentially algebraic over `K` after eliminating the
hidden states. Therefore no function HT over `K` can have such a finite DA state-space realization.

This is the intended C16 obstruction, but it is not a new theorem. It is exactly the input/output elimination
principle from differential-algebraic control theory: eliminate latent state variables from an algebraic
differential state representation to obtain an external input/output differential equation. Diop, *Elimination
in control theory* (Math. Control Signals Systems 4, 1991), states in the abstract that differential-algebraic
elimination derives an equivalent representation without state variables for nonlinear systems with state or
latent variables. Sontag--Wang, *Input/Output Equations and Realizability* (1991), state a correspondence between
realizability and algebraic differential equations relating input and output derivatives.

Promptability audit: once the system is restricted to finite DA states and DA inputs, the result is the standard
elimination argument. If the system is allowed arbitrary HT coefficients, oracle inputs, or a state variable that
already contains `f`, the no-go is false by construction. Thus C16 is useful protocol vocabulary but not a
significant new HT theorem.

Verdict: keep in backlog as BRIDGE/source-adjacent. Do not promote unless a broader realization class is defined
where state elimination is not already known to produce an input/output ADE, and a genuinely new obstruction is
proved for that broader class.
