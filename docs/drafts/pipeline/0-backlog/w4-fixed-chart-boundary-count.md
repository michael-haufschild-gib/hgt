# W4 — a fixed affine chart of the coordinate boundary

- **Stage:** 0-backlog
- **Type:** CANDIDATE
- **Statement:** Fix one homogeneous coordinate to one and let `m≥1` coordinates remain. The number of boundary points is `q^(m−1)−B_m(q)−mB_{m−1}(q)`.

The affine hyperplane has `q^(m−1)` points. Remove the all-nonzero stratum and the `m` disjoint strata with exactly one zero. The projective stratum count and full boundary Tate trace are formalized separately; this fixed-chart cardinal identity still needs its own bijections.
