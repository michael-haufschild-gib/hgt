## Goal
Closes the C7 gap. C7 (autonomy) is **NOT MET** (#48). The charter's test
(`00-charter-wall-and-door.md:27`): *"The field develops from its own definitions; a foundational core
(definitions + one structural theorem) stands without constant appeal to a parent."* The current
structural results — the multi-`q` Picard–Vessiot correspondence, inverse-Galois, the Tannakian main
theorem (G4, #24/#25) — are flagged **likely IMPORT** under Door-2
(`door-C5-irreducibility-and-door-2-retest.md`, the "likely IMPORT" list): they rest on Etingof,
classical IGP, Deligne, Tate as their **proof engines**. So the present "core" leans on parents at every
load-bearing step. C7 = MET requires a core that stands without that constant appeal.

One of the four criteria still open for the **"this is actually a branch"** milestone — and, with C5, one
of the two genuinely hard ones. The two are **coupled**: a native C5 theorem proved from an axiomatized
core would close both.

## Door passport (why it would be native)
- The flagship structural theorem must itself survive **Door-2** — else it is a relabeled parent theorem
  and the "autonomy" is illusory.
- **Door-1 + Door-4:** the core must live in the native zone (`{multiple independent bases} ∩
  {difference} ∩ {infinite/arithmetic base}`), built from the `σ_p`-family and `G_L`.
- **Coupling to C5:** the cleanest way to satisfy C7 is for the autonomous core's flagship theorem to
  **be** the C5 theorem (`../1-in-progress/combination-mode-baker-reducibility.md`, C5★) — a theorem the
  parents provably cannot reach, proved from the native definitions.

## Approach
1. **Axiomatize N1–N4** as a standalone foundation: the infinite-base multi-`q` module (N1), the
   connection / cocycle `F_{pq}` (N2), the invariants `G_L` / `corank` / difference-trdeg / holonomy type
   (N3), the borders (N4) — stated so the rest follows **from them**, not from a parent's category.
2. **Pick the flagship structural theorem.** Strongest candidate: the **existence + uniqueness of the
   infinite-base Picard–Vessiot extension and the Galois correspondence** (G4 #24), re-proved with the
   construction **internal** to the field (a direct limit of the native data) rather than imported
   wholesale from Tannakian reconstruction. Audit each step for parent-dependence; replace any imported
   engine with a native one, or record it as a border/import (if it stays imported, that step is
   not autonomy and must be redone).
3. **Alternatively / additionally:** let the **C5★** theorem serve as the autonomy witness once proven (a
   theorem provably beyond the parents, derived from the axiomatized core).
4. **Run Door-2** on the flagship: confirm it is not a relabeled parent theorem. Re-grade C7 → MET.
