# Gamma Field Vertical-Strip Tameness

- **ID:** gamma-field-vertical-strip-tameness
- **Stage:** 0-backlog
- **Type:** CANDIDATE — HOLD / source-risk high
- **Source:** Haiku reversal, Wheeler location-escape attempt, Professor Gamma c-point control, 2026-06-23
- **Statement:** Finite elements of the Gamma differential field can have unbounded-height poles and `T log T` leading density, but their unbounded poles escape every fixed vertical strip.

## Goal

Replace the false pole-confinement invariant in `gamma-zeta-differential-independence.md` with a sharper field-level divisor invariant.

The killed invariant was too strong:

1. false: every `C(s)<Gamma>` element has bounded-height poles;
2. false: no `C(s)<Gamma>` element has `T log T` pole density.

The repaired invariant is location-sensitive:

> A finite Gamma-field expression may create an inverse-Stirling pole lattice, but any unbounded branch must escape fixed vertical strips. Therefore it cannot encode the nontrivial zeta divisor, which has infinitely many zeros in `0 < Re(s) < 1`.

## Candidate Theorem

For any finite `n`, any nonzero

`F in C(s)(Gamma, Gamma', ..., Gamma^(n))`,

and any real `a < b`, `F` has only finitely many poles in the vertical strip

`a <= Re(s) <= b`.

Equivalently, every unbounded pole branch of a finite Gamma-field expression must escape horizontally.

## Proof Sketch

Write `F=A/B`, where `A` and `B` are differential polynomials in `Gamma` with rational coefficients, and clear rational denominators. Poles away from the fixed rational poles come from zeros of

`B(s, Gamma, Gamma', ..., Gamma^(n))`.

In a fixed vertical strip as `|Im(s)| -> infinity`, uniform Stirling gives

`Gamma(s) = exp((s-1/2)Log s - s + (1/2)log(2*pi)) (1 + O(1/s))`,

and differentiation gives, for each fixed `j`,

`Gamma^(j)(s) = Gamma(s) (Log s)^j (1 + lower powers of 1/s and Log s)`.

Group `B` by total Gamma-jet degree.

If the degree-zero part is nonzero, it is a rational function of `s` and dominates all positive-degree terms, since `Gamma(s)` is exponentially small in a fixed vertical strip. It has only finitely many zeros in the strip.

If the degree-zero part vanishes, take the least positive total Gamma-jet degree `m`. Then

`B = Gamma(s)^m P(s, Log s, 1/s) + smaller exponential-degree terms`,

where `P` lies in a finite asymptotic scale generated by powers of `s`, `Log s`, and `1/s`. If the first nonzero term in this scale is not identically zero, it cannot have infinitely many zeros as `|Im(s)| -> infinity` inside a fixed vertical strip. Thus `B` is eventually nonzero in the strip.

The only way the leading asymptotic scale could vanish at every level is if the original differential polynomial vanishes identically on `Gamma`; Holder hypertranscendence rules this out for a nonzero differential polynomial.

## Corollary

No element of `C(s)<Gamma>` can have poles precisely at the nontrivial zeros of `zeta`, because those zeros are infinite and remain in the critical strip `0 < Re(s) < 1`.

This proves only a field-level divisor non-encoding statement. It does **not** prove full differential independence of `Gamma` and `zeta`: if `zeta` were differentially algebraic over `C(s)<Gamma>`, then `zeta'/zeta` would be differentially algebraic over that field, not necessarily an element of it.

## Relation To Gamma C-Point Control

`1/(Gamma(s)-1)` refutes bounded-height and leading-density invariants, because its poles include a first-quadrant branch with

`Im(s_k) ~ 2*pi*k/log k`,

hence `T log T` leading count. But that branch also has `Re(s_k) -> +infinity`, so it supports the repaired location-sensitive invariant.

Wheeler's location-escape idea is therefore right in class, but the branch asymptotic should be corrected: on the principal first-quadrant branch, `Re(s_k)` grows roughly like `k/(log k)^2`, not like `log k`.

This is structurally the same asymptotic domination mechanism as the candidate proof sketch here.
