## 1. The geometry: one reflection does everything

`lineReflection μ z := 2μ − conj z`, the reflection across the vertical line
`Re = μ`. On an annulus centered at `a` with `a.re = μ`:

- it is an involution fixing every point of the line (`lineReflection_eq_self`),
- it fixes the annulus (`lineReflection_mem_annulus` — the reflected offset is the
  negated conjugate offset, same norm),
- it **swaps the two slit charts** (`lineReflection_mem_chartRA/LA` — the slit rays
  exchange under the horizontal flip, conjugation preserving the slit plane),
- it **fixes both vertical basepoints** `a ± ci` (they sit on the line).

## 2. The canonical pair

`reflectedRoot μ G := z ↦ conj (G (lineReflection μ z))` — the Schwarz reflection of
a right-chart root across the symmetry line. For a line-symmetric member
(`f ∘ lineReflection = conj ∘ f` on the annulus):

- `analyticAt_conj_comp_conj`: Schwarz reflection preserves analyticity (the new
  engine — eventual differentiability pulled back along conjugation),
- `reflectedRoot_analyticOnNhd`: the reflected root is analytic on the left chart,
- `reflectedRoot_sq`: it squares to `f` there.

So ONE chart root generates the whole gluing datum. No choice is made on the left
chart: the member's own symmetry makes it.

## 3. The sign dichotomy and the observable

At a reflection-fixed port `p`, the member value is real
(`im_eq_zero_of_lineSymmetric_fixed`), and any square root `w` of a nonzero real
obeys the dichotomy (`conj_eq_self_of_sq_pos` / `conj_eq_neg_of_sq_neg`): positive
value ⟹ `w` real, `w/conj w = 1`; negative value ⟹ `w` purely imaginary,
`w/conj w = −1`.

The deck class of the canonical pair at the two fixed ports is the double
conjugation ratio (`deckClass_reflectedRoot`), hence:

- `deckClass_reflectedRoot_one_of_sign_pos`: same sign at the two ports ⟹ class `1`;
- `deckClass_reflectedRoot_neg_one_of_sign_change`: opposite signs ⟹ class `−1`;
- `deckClass_reflectedRoot_ne_one_iff`: **the parity is exactly the sign
  observable** — nontrivial class ⟺ the (real) member changes sign between the two
  critical-line ports.

The hole parity of the two-sheeted cover is the sign change of a real function
across the hole along the symmetry line. The doc-119 open core is discharged: the
canonical datum exists, and its arc mismatch does not merely *relate* to the deck
class — it computes it.

## 6. What this opened

The parity hypothesis that ran through docs 117–119 as an assumption
(`deckClass ≠ 1`) is now generated by a sign change of a real-valued function at
two explicit points. Read as a CONSTRAINT, not a flow: the hole parity (bulk,
topological) equals the axis sign pair (boundary data on the symmetry line) at a
pinned configuration — holography, the founding metaphor, made a theorem. Height
never flows here: the steering admissibility `hcap` bounds
`a.im + c < π/(4·log 2) ≈ 1.133`, so the banked weld lives in one fixed window;
"sign changes as the height grows" (Hardy's move) is both flow-framed and vacuous
against the theorem. Widening the window is a Chebyshev-budget constants problem
in the staircase, not a height problem.

**Mod-2 blindness — why the off-line move is forced, not optional.** The member's
zeros pair under the line reflection (both order-pairing inputs are banked:
`completedSEM_orderAt_conj` and `analyticOrderAt` under `1 − z`), so off-line
zeros inside the hole contribute EVEN counts to the parity: the axis sign
observable reads exactly the ON-line zero count mod 2 between the ports and
cannot see an off-line pair. The canonical datum, as built, is an on-line
detector.
