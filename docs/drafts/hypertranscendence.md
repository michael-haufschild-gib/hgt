# Main property

A hypertranscendental object has **no finite algebraic-differential handle**.

It cannot be captured by:

* a polynomial equation,
* a polynomial equation using derivatives,
* any finite system of such equations.

For a **function** (f(x)), this means there is no nonzero polynomial relation like:
[P(x, f, f', f'', \dots, f^{(n)}) = 0]
for any finite (n).

# Formal representations
$$
\mathcal{HT}(D)
=
\left\{
f\in C^\infty(D)
:
\forall n\ge 0,\
\forall P\in \mathbb C[x,Y_0,Y_1,\dots,Y_n]\setminus\{0\},
\quad
P\bigl(x,f(x),f'(x),\dots,f^{(n)}(x)\bigr)\not\equiv 0
\right\}.
$$

Here:

- $D$ is the domain of the functions.
- $Y_j$ is a formal placeholder for the $j$-th derivative $f^{(j)}$.
- $P\not=0$ means the polynomial relation is not the zero polynomial.
- $\not\equiv 0$ means the expression does **not** vanish identically on $D$.

In words:

$$
f\in\mathcal{HT}(D)
$$

means that **no nonzero polynomial in $x$, $f$, and finitely many derivatives of $f$ vanishes identically**.

## Differential algebra notation

Let

$$
\mathbb C[x]\{Y\}
=
\mathbb C[x][Y,Y',Y'',\dots]
$$

be the ring of differential polynomials in one unknown function $Y$.

Then the same class can be written compactly as:

$$
\mathcal{HT}(D)
=
\left\{
f\in C^\infty(D)
:
\forall 0\ne P\in \mathbb C[x]\{Y\},
\quad
P(f)\not\equiv 0
\right\}.
$$

If rational rather than polynomial coefficients in $x$ are allowed, use $\mathbb C(x)$ instead:

$$
\mathcal{HT}_{\mathbb C(x)}(D)
=
\left\{
f
:
\forall 0\ne P\in \mathbb C(x)\{Y\},
\quad
P(f)\not\equiv 0
\right\}.
$$

This is usually called the class of **differentially transcendental functions** over $\mathbb C(x)$. In older terminology, these are often called **hypertranscendental functions**.

## Complementary class

The complementary class is the class of **differentially algebraic functions**:

$$
\mathcal{DA}(D)
=
\left\{
f
:
\exists n\ge 0,\ \exists 0\ne P\in \mathbb C[x,Y_0,\dots,Y_n]
\text{ such that }
P\bigl(x,f,f',\dots,f^{(n)}\bigr)\equiv 0
\right\}.
$$

Therefore, the desired class can also be written as:

$$
\boxed{
\mathcal{HT}(D)=C^\infty(D)\setminus \mathcal{DA}(D)
}
$$

or, for analytic/meromorphic functions:

$$
\boxed{
\mathcal{HT}_{\mathbb C(x)}
=
\{f:
 f \text{ is differentially transcendental over } \mathbb C(x)\}
}
$$

The case $n=0$ already excludes ordinary algebraic functions, since it forbids relations of the form:

$$
P(x,f(x))\equiv 0.
$$

The cases $n\ge 1$ exclude algebraic-differential relations involving derivatives.


# Properties That Follow from Hypertranscendence

A hypertranscendental function has **no finite algebraic-differential handle**. More formally, over a differential base field such as

\[
K=\mathbb C(x),
\]

we say that \(f\) is hypertranscendental, or differentially transcendental, over \(K\) if there is **no nonzero differential polynomial**

\[
P\in K\{Y\}=K[Y,Y',Y'',\ldots]
\]

such that

\[
P(f)=0.
\]

Equivalently, there is no finite relation of the form

\[
P(x,f,f',f'',\ldots,f^{(n)})=0
\]

for any finite \(n\).

The following properties follow from this definition.

---

## 1. \(f\) is automatically transcendental

Ordinary algebraic functions satisfy an equation

\[
P(x,f)=0.
\]

But this is just a differential-polynomial relation of order \(0\). Therefore:

\[
\text{hypertranscendental} \Longrightarrow \text{transcendental}.
\]

The converse is false. For example, \(e^x\) is transcendental as a function, but it satisfies

\[
y'-y=0,
\]

so it is **differentially algebraic**, not hypertranscendental.

---

## 2. Every finite jet is algebraically independent

For every finite \(n\), the functions

\[
f,\ f',\ f'',\ldots,\ f^{(n)}
\]

are algebraically independent over \(K\). Equivalently,

\[
\operatorname{trdeg}_{K} K(f,f',\ldots,f^{(n)})=n+1.
\]

So:

\[
f' \notin \overline{K(f)},
\]

\[
f'' \notin \overline{K(f,f')},
\]

and so on. Each derivative contributes a genuinely new algebraic degree of freedom.

This is one of the most important consequences: no finite derivative stage controls the later derivatives algebraically.

---

## 3. The full differential field generated by \(f\) has infinite transcendence degree

The differential field generated by \(f\) is

\[
K\langle f\rangle=K(f,f',f'',\ldots).
\]

Because every finite jet is algebraically independent,

\[
\operatorname{trdeg}_{K}K\langle f\rangle=\infty.
\]

More precisely, as an ordinary field extension, it has countably infinite transcendence degree over \(K\).

However, as a **differential** field extension, it is generated by one differential-transcendence generator:

\[
f.
\]

So ordinary algebra sees infinitely many independent quantities,

\[
f,f',f'',\ldots,
\]

while differential algebra sees one freely differentiable generator.

---

## 4. No derivative can be solved algebraically from previous ones

A differentially algebraic function may satisfy an equation like

\[
P(x,f,f',\ldots,f^{(n)})=0.
\]

If this equation genuinely involves \(f^{(n)}\), then \(f^{(n)}\) is algebraic over the lower jet

\[
K(f,f',\ldots,f^{(n-1)}).
\]

For a hypertranscendental function, this never happens. There is no finite-order algebraic rule of the form

\[
f^{(n)}=\text{algebraic expression in }x,f,f',\ldots,f^{(n-1)}.
\]

So \(f\) cannot be governed by any finite-order algebraic ordinary differential equation, whether linear, nonlinear, explicit, or implicit.

---

## 5. \(f\) is not D-finite / holonomic

A D-finite, or holonomic, function satisfies a linear differential equation with polynomial or rational coefficients:

\[
a_n(x)f^{(n)}+a_{n-1}(x)f^{(n-1)}+\cdots+a_1(x)f'+a_0(x)f=0.
\]

This is already a polynomial differential relation. Therefore:

\[
\text{hypertranscendental} \Longrightarrow \text{not D-finite}.
\]

So hypertranscendental functions lie outside the usual holonomic world. Classical functions defined by linear ODEs, such as exponentials, trigonometric functions, Bessel functions, Airy functions, and many hypergeometric functions, are not hypertranscendental over their usual base fields.

---

## 6. \(f\) is not elementary or Liouvillian over the same base

Elementary and Liouvillian functions live inside the differentially algebraic world, assuming the starting base field is differentially algebraic.

Therefore, if \(f\) is hypertranscendental over \(K\), then \(f\) cannot be built from \(K\) by finitely many uses of algebraic operations, exponentials, logarithms, integrations, and the usual Liouvillian operations.

In slogan form:

\[
\text{hypertranscendental} \Longrightarrow \text{not Liouvillian} \Longrightarrow \text{not elementary}.
\]

The base field matters. “Not elementary over \(\mathbb C(x)\)” is not the same as “not elementary over a larger differential field that already contains special functions.”

---

## 7. All derivatives of \(f\) are themselves hypertranscendental

If \(f'\) satisfied a differential algebraic equation, then there would be a relation

\[
P(x,f',f'',\ldots,f^{(n+1)})=0,
\]

which is also a forbidden differential-polynomial relation involving the derivatives of \(f\).

Therefore:

\[
f',\ f'',\ f^{(3)},\ldots
\]

are all hypertranscendental over \(K\).

---

## 8. Any antiderivative is hypertranscendental

Suppose

\[
F'=f.
\]

If \(F\) were differentially algebraic, then \(F'\) would also be differentially algebraic, because differentially algebraic functions are closed under differentiation.

But

\[
F'=f,
\]

so this would contradict the hypertranscendence of \(f\). Therefore:

\[
f \text{ hypertranscendental } \Longrightarrow \int f\,dx \text{ is hypertranscendental}.
\]

---

## 9. Nonconstant algebraic transformations preserve hypertranscendence

Let \(R(x,y)\) be a rational function that is nonconstant in \(y\). If

\[
g(x)=R(x,f(x)),
\]

then \(g\) is hypertranscendental, provided the expression is defined and does not collapse to an element of the base field.

Examples include:

\[
f+1,
\]

\[
f^2,
\]

\[
\frac{1}{f},
\]

\[
\frac{af+b}{cf+d}.
\]

The reason is that if \(R(x,f)\) were differentially algebraic over \(K\), then \(f\) would be algebraic over a differentially algebraic extension of \(K\), forcing \(f\) itself to be differentially algebraic.

Similarly, adding or multiplying by a differentially algebraic function cannot destroy hypertranscendence unless there is a trivial cancellation. For differentially algebraic \(a\), with \(a\neq 0\):

\[
f+a,
\]

\[
af,
\]

\[
\frac{f}{a}
\]

are hypertranscendental, unless the expression collapses in a degenerate way.

---

## 10. Nonconstant differential-rational expressions are hypertranscendental

More generally, consider a nonconstant differential-rational expression built from \(x\), \(f\), and finitely many derivatives:

\[
R(x,f,f',\ldots,f^{(n)}).
\]

Typical examples are:

\[
f+f',
\]

\[
\frac{f'}{f},
\]

\[
f''f-(f')^2,
\]

\[
\frac{f^{(3)}}{1+f^2}.
\]

Except in cases where the expression collapses to an element of \(K\), such expressions are also differentially transcendental over \(K\).

A good informal rule is:

\[
\text{no nontrivial finite algebraic-differential expression in } f
\]

can become differentially algebraic without imposing a forbidden relation on \(f\) itself.

---

## 11. Its finite jet curve is Zariski dense

For each finite \(n\), consider the jet map

\[
x\mapsto \bigl(x,f(x),f'(x),\ldots,f^{(n)}(x)\bigr).
\]

Hypertranscendence says that this image is not contained in any proper algebraic hypersurface over the base field.

Equivalently, no polynomial cuts out the finite jet curve:

\[
P(x,f,f',\ldots,f^{(n)})\neq 0
\]

for every nonzero polynomial \(P\).

So algebraic geometry sees each finite jet of \(f\) as maximally unconstrained.

---

## 12. The differential ideal of relations is zero

For an algebraic function, there is a nonzero ideal of polynomial relations.

For a differentially algebraic function, there is a nonzero differential ideal of differential-polynomial relations.

For a hypertranscendental function, the differential ideal of relations is simply zero:

\[
I(f/K)=\{P\in K\{Y\}:P(f)=0\}=0.
\]

So \(f\) behaves, from the viewpoint of polynomial differential equations, like a formal differential indeterminate.

A useful mental model is:

\[
f,\ f',\ f'',\ldots
\]

act algebraically like independent variables.

---

# What does **not** follow

Hypertranscendence is strong, but it does not imply every possible kind of wildness.

---

## 1. It does not mean “no equations at all”

A hypertranscendental function may still satisfy:

- functional equations,
- difference equations,
- recurrence relations,
- integral equations,
- infinite-order differential equations,
- non-polynomial differential equations.

For example, the gamma function satisfies the functional equation

\[
\Gamma(z+1)=z\Gamma(z),
\]

but Hölder’s theorem says that \(\Gamma(z)\) is differentially transcendental over \(\mathbb C(z)\).

So \(\Gamma\) has structure, but not finite algebraic-differential structure.

---

## 2. It says little about individual values

Hypertranscendence is a statement about functions, not automatically about special values.

From the algebraic independence of

\[
f,\ f',\ldots,f^{(n)}
\]

as functions, it does **not** follow that the numbers

\[
f(a),\ f'(a),\ldots,f^{(n)}(a)
\]

are algebraically independent.

A hypertranscendental function may take algebraic values at special points.

---

## 3. It does not imply analytic pathology

Hypertranscendence does not imply:

- chaotic behavior,
- noncomputability,
- fast growth,
- discontinuity,
- lack of analyticity.

Many hypertranscendental functions are highly structured analytic or meromorphic functions.

---

## 4. It is relative to the base field

One must always say:

\[
f \text{ is hypertranscendental over } K.
\]

The base field \(K\) matters. A function can be hypertranscendental over \(\mathbb C(x)\) but not over a larger differential field that already contains enough information about it.

For example, over a field containing \(f\) itself, the function trivially satisfies

\[
Y-f=0.
\]

So hypertranscendence is not an absolute property of the function alone; it is a property relative to a chosen differential base field.

---

# One-sentence summary

A hypertranscendental function is one whose infinite derivative tower has **no finite algebraic collapse**: every finite jet

\[
f,\ f',\ f'',\ldots,f^{(n)}
\]

remains algebraically free over the chosen base field.
