## The organizing thesis (one paragraph)

The completed object `Λ = Γ∞·ζ` is best read **not as a scalar amplitude** but as a
**constraint-preserving logarithmic transport connection** `ω = d log ξ`, i.e. the weld
`H = ∂_s log Λ = A + P` of an archimedean generator `A = ∂_s log Γ∞` (Source A) and a prime term
`P = ζ'/ζ` (Source B), on the affine `𝔾_a ⋊ 𝔾_m` geometry with universal curvature `[∂_s,M_p] = −log
p`. The seam is `Re(s) = ½ = Fix(ι)`, `ι:s↦1−s`. The object is *fixed by the order-2 constraint `ι`,
not propagated by a flow*. RH is then the confinement of all source-carrying transport defects (the
zeros) to the seam — equivalently, a single **archimedean positivity** (`κ₋ = 0`), tool-independent
across ~10 reformulations and **distinct from** the realization/value apex (Schanuel-for-prime-logs),
the two being joined only at the seam.
