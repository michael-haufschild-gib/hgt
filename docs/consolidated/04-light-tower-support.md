## LT1 — Transport, not scalar amplitude

- `[OBSERVED]` **The carrier survives amplitude-regression.** After regressing out *all* amplitude
  features (`|Γ∞|, |P|`, ratios, max, min), the true left-strip phase residual **survives**
  (`σ=0.3` gap **+0.45** over controls); over-controls that include `|Γ∞+P|` correctly kill it
  (synthesis §2.A, conway margin-neutralized residual). The carrier is *phase*, not magnitude.
- `[OBSERVED]` **No scalar finite-cutoff surrogate exists.** R1 non-renormalizability (no
  bounded-degree local counterterm reconstructs the carrier) and R2 order-of-limits invariance
  (cutoff-first + best scalar rate `c_N` cannot reach it) (synthesis §2.G).
- `[PROVED — BRIDGE]` **The RH-bearing quantity is a faithful index, not an amplitude.**
  `κ₋ = #off-line zero-pairs` (Sylvester inertia), `RH ⟺ κ₋ = 0` — a signed integer, blind to which
  no magnitude/density is a substitute (`intrinsic-rh-locus-pure-polarized.md`; Lean
  `kappa-minus-offline-pairs`). Minimal form: *the object's RH content is `(1|∞)`-signature
  positivity of `Q_W`, not a size.*
