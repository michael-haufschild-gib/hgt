## Short answer

The likely transcendence detector is **not** (Q_0), (T_k), (D_2), the phase carrier, or any source-geometry observable. Those live on the RH/positivity wall: divisor **geometry**, i.e. where the zeros sit. The corpus now says the genuine HT detector must live on divisor **arithmetic**, i.e. algebraic/value relations among ({\gamma_n}), ({S_k}), ({\log p}), and the explicit-formula value families.

The best current candidate is:

[
\boxed{
\textbf{a prime-locked arithmetic relation-height detector.}
}
]

Not “are the seam values (S_k) generic?” — because same-density random divisors are generic too. The real test is:

[
\boxed{
\textbf{are the zero-side values generic in the specific way forced by the prime-log explicit formula?}
}
]

The one-wall/RH side is now cleanly charted by reciprocal seam moments (T_k), but that is still divisor geometry, not HT.  The A-axis must test arithmetic relations in the fused seam family, where (S_k) splits into (\zeta(2k)), (\beta(2k)), and prime-side derivatives.

# 1. Candidates for the genuinely new transcendence detector

## 1. Prime-locked relation-height spectrum

This is my top candidate.

Define a coupled value family

[
\mathcal V_N
============

{S_k}*{k\le N}
\cup
{\zeta(2k),\beta(2k)}*{k\le N}
\cup
\left{
\left(\frac{\zeta'}{\zeta}\right)^{(2k-1)}!\left(\frac12\right)
\right}*{k\le N}
\cup
{\log p_j}*{j\le M(N)}.
]

Then compute exact shell minima

[
\mathcal A_{\mathcal V}(N,d,H)
==============================

\min_{\substack{0\ne P\in\mathbb Z[x_1,\ldots,x_m]\
\deg P\le d,\ \mathrm{height}(P)\le H}}
|P(\mathcal V_N)|.
]

This detector asks whether the seam values and prime-log values form a **specific arithmetic structure**, not merely whether they look non-periodic.

Why it is promising: the fused seam formula gives a concrete bridge from zero-side seam moments to archimedean constants and prime-side derivatives:

[
S_k
===

2^{2k}
-\frac14(2^{2k}-1)\zeta(2k)
-2^{2k-2}\beta(2k)
-\frac{1}{2(2k-1)!}
\left(\frac{\zeta'}{\zeta}\right)^{(2k-1)}!\left(\frac12\right).
]

That is exactly where value arithmetic appears.

What would be surprising: if (\zeta) separates from same-density random zero divisors **only when the prime-side derivatives or (\log p) are included**, that would be the first real hint of a zeta-specific arithmetic detector rather than a genericity detector.

## 2. Explicit-formula arithmetic-transfer detector

This is the theorem-shaped version of candidate 1.

Try to build a map:

[
\text{zero-side relation among }S_k
\quad\Longrightarrow\quad
\text{prime-log relation among }\log p.
]

A candidate theorem would look like:

[
P(S_1,\ldots,S_N)=0
\quad\Rightarrow\quad
Q(\log p_1,\ldots,\log p_M)=0
]

with controlled degree/height.

If that implication existed, then Schanuel-for-prime-logs would obstruct algebraic relations among the seam values.

This is probably very hard, but it is the cleanest “A-axis bridge.” The big-picture docs frame the value apex precisely as Schanuel-for-prime-logs / algebraic independence of prime logs, not as a geometry statement.

So a genuine detector must pass:

\boxed{

What would be surprising: if ({S_k}) alone fails, but ({S_k}+) prime-side data succeeds. That would isolate the explicit formula as the source of HT-relevant arithmetic.

## 4. Algebraic-dependence matroid, not rank

A lot of earlier “value detectors” collapsed to shift/derivative matrix rank. The corpus says a real HT detector must not be another rank statistic.

So instead define a bounded algebraic-dependence matroid:

A subset of values (X_I\subset\mathcal V_N) is dependent at level ((d,H,\epsilon)) if there exists

[
0\ne P\in\mathbb Z[x_i:i\in I],
\qquad
\deg P\le d,\quad H(P)\le H,
]

with

[
|P(X_I)|<\epsilon.
]

Then compare the matroid growth of:

[
\zeta\text{-values}
]

against:

[
\text{AP divisor},\quad
\text{same-density random divisor},\quad
\text{prime-randomized decoy},\quad
\text{D-algebraic controls}.
]

What would be surprising: a dependence-matroid signature that separates (\zeta) from random controls while not reducing to shift/derivative rank.

## 5. Prime-log shell-minimum detector

This is the hardest but most direct Conjecture-A candidate.

For

[
L_N=(\log p_1,\ldots,\log p_N),
]

compute

[
\mathcal M_{N,d}(H)
===================

\min_{\substack{0\ne P\in\mathbb Z[x_1,\ldots,x_N]\
\deg P\le d,\ H(P)\le H}}
|P(L_N)|.
]

This directly attacks Schanuel-for-prime-logs. Even degree (2) for (\log2,\log3) is open, so this is not expected to prove anything. But experimentally it can reveal what a real arithmetic detector must look like.

What would be surprising: not “no relation found,” but a stable shell-minimum law that differs from generic real vectors and from constructed algebraically dependent controls.

## 6. Divisor-arithmetic compression detector

Contrast:

[
\sin \pi s
]

has order (1), an infinite divisor, and is D-algebraic because its zeros are an arithmetic progression.

[
\xi
]

also has order (1), but its divisor arithmetic is far more complex. The source-quotient of (\xi'/\xi) removes exactly the divisor and leaves tame data; that is why HT is divisor-encoded.

Define a finite-generator compression score:

[
C_N(\gamma_1,\ldots,\gamma_N)
=============================

\min {\text{description complexity of arithmetic model fitting first }N\text{ ordinates}}.
]

Controls:

* arithmetic progression;
* finite union of progressions;
* algebraic recurrences;
* random matrix-like sequences;
* same-density random sequences;
* explicit-formula prime-locked sequences.

What would be surprising: a compression feature that separates zeta zeros from both simple and random controls.

# 3. What would be genuinely surprising?

## Surprising positive signals

* (\zeta) separates from same-density random only when prime-side data are included.
* A relation-height profile for ({S_k,D_k,\log p}) differs sharply from random controls.
* Zero-side near-relations induce controlled prime-log relations.
* The algebraic matroid of fused seam values is non-rank and zeta-specific.
* A finite-generator model tied to prime logs predicts zeros out of sample better than same-capacity decoys.

## Route killers / no-gos

* ({S_k})-only relation tests behave exactly like same-density random.
* All detectors reduce to shift/derivative rank.
* Prime-side data improve only by fitted leakage, not independent explicit-formula input.
* Same-geometry random controls pass the detector.
* Symmetry quotienting erases the signal.
* Exact shell minima show no distinction from generic real vectors.
