The proof route is now much narrower than “prove a nice positivity statement.” The target is:

[
\boxed{
\textbf{Prove source-aware (Q_0) positivity for the folded reciprocal zero divisor of (\Xi).}
}
]

Let

[
\Xi(w)=\xi!\left(\frac12+w\right),\qquad \Xi(w)=\Xi(-w).
]

For each folded FE orbit ([w]={w,-w}), set

[
y_{[w]}=-w^{-2},
]

with trace weight (2m_w). Define

[
T_k=\sum_{[w]}2m_w,y_{[w]}^k,\qquad k\ge1.
]

The proof target is:

[
\boxed{
\forall d\ge0,\qquad
[T_{i+j+1}]_{i,j=0}^{d}\succeq0.
}
]

Equivalently, for every real polynomial (p(y)=\sum_i c_i y^i),

[
\boxed{
Q_0[p]
======

\sum_{i,j}c_i c_jT_{i+j+1}
\ge0.
}
]

If this is proven for the actual (\xi)-divisor, then every reciprocal atom (y=-w^{-2}) must lie in (\mathbb R_{>0}), hence (w\in i\mathbb R), hence RH. The reciprocal-seam chart is the clean global coordinate where the zero-divisor wall is a moment-positivity problem; local contour moments (M_k) and (D_2), Li, Jensen, Hankel, Weil, and (\kappa_-) are other charts of the same divisor wall.

## What the proof must **not** be

It cannot be “pole cancellation implies positivity.” The seam cancellation explains why (S_k) exists and why (S_k^A) and (S_k^P) cancel so deeply, but it does not imply Stieltjes positivity. The seam note connects the weld (A+P), phase defect (\Delta), superzeta values (S_k), and entireness as one cancellation phenomenon; it explicitly says this explains where the RH-relevant values sit, not their sign.

It cannot be “FID positivity implies RH.” FID is the same reciprocal-squared moment instrument applied to the **integer divisor**, where positivity is automatic:

[
\zeta(2k+1)=\sum_{n\ge1}\frac1n\left(\frac1{n^2}\right)^k.
]

That is a positive Stieltjes moment sequence unconditionally. RH lives on the **zero divisor** sequence (T_k), not on the integer-divisor sequence. The bridge must be the explicit-formula transfer between the two, not the positivity of the integer side.

It cannot be “line curvature is negative everywhere.” The (\Phi_2(t)<0) crest condition is necessary but not sufficient; far-off-line high zeros can be hidden by the on-line background. (Q_0) is source-aware and sign-faithful where (\Phi_2) is only line-local.

It cannot be “Li coefficients are positive, therefore (T_k) is positive.” The Li-to-(T_k) kernel is infinite and signed. A finite Li prefix is not a finite shifted-Hankel prefix in disguise.

So the proof has to show something stronger and more specific:

[
\boxed{
\textbf{The completed explicit-formula residue is nonnegative on every reciprocal-seam square test (Q_0[p]).}
}
]

## What the proof might look like

### 1. A direct square-test identity

The dream formula would be an identity of the form

[
Q_0[p]
======

## \mathcal A[p]

\mathcal P[p],
]

or

[
Q_0[p]
======

\mathcal B[p],
]

where (\mathcal B[p]) is manifestly nonnegative from source-built completed data, not from zero locations.

For example, one would want something like

[
Q_0[p]
======

\int |\mathcal K_p(x)|^2,d\mu_{\mathrm{arch/prime}}(x)
\ge0,
]

or a Weil-type square formula whose test function is canonically associated to (p(y)).

This is the cleanest possible proof shape:

[
\boxed{
p(y)\longmapsto \text{explicit-formula test function }h_p
}
]

such that the zero-side sum equals (Q_0[p]), and the archimedean/prime side is manifestly nonnegative.

The key challenge: ordinary Weil positivity is already RH-equivalent, so the map (p\mapsto h_p) cannot smuggle in RH. It must be source-built from the completed weld.

### 2. A positivity-preserving explicit-formula transfer

Since FID is positive on the integer divisor but RH concerns the zero divisor, the bridge might be a theorem saying that the explicit-formula map

[
\text{integer/prime reciprocal moments}
\longrightarrow
\text{zero reciprocal moments }T_k
]

preserves the (Q_0) square tests.

That would look like:

[
\boxed{
\text{integer-side total positivity}
+
\text{completed archimedean correction}
\Longrightarrow
Q_0[p]\ge0\quad\forall p.
}
]

But this must use the **actual explicit formula**, not an abstract positivity cone. The FID note makes clear that positivity on the integer divisor alone is RH-empty; only the integer-to-zero map can carry RH content.

Computationally, this means studying the map from the fused seam formula

[
S_k
===

2^{2k}
-\frac14(2^{2k}-1)\zeta(2k)
-2^{2k-2}\beta(2k)
-\frac{1}{2(2k-1)!}
\left(\frac{\zeta'}{\zeta}\right)^{(2k-1)}!\left(\frac12\right)
]

to (Q_0[p]), and looking for square-completion, total-positivity, or variation-diminishing structure.

### 3. A continued-fraction / Jacobi-parameter proof

If (Q_0) is positive, then the shifted moment sequence

[
m_n=T_{n+1}
]

has a Stieltjes-type continued fraction / Jacobi recurrence with positive parameters.

So another possible proof route is:

[
\boxed{
\text{derive positive Jacobi/Stieltjes parameters directly from (\Xi), without assuming RH.}
}
]

That means computing the orthogonal-polynomial recurrence coefficients of (m_n=T_{n+1}):

[
\beta_n>0,\qquad \alpha_n\in\mathbb R,
]

or the corresponding Stieltjes (J)-fraction coefficients, and proving their positivity/source origin.

Computationally, this may be the most informative route because a breakdown in recurrence coefficients would immediately show where the proposed positivity fails.

### 4. A contradiction-localization proof

Assume (Q_0) fails. Then there is a polynomial (p) with

[
Q_0[p]<0.
]

For a single off-line folded conjugate pair (y,\bar y), the degree-one obstruction is explicit:

[
\det H_1^{(0)}
==============

-4\mu^2 |y|^2(\operatorname{Im}y)^2.
]

So an off-line zero creates a negative direction in reciprocal space. The local contour instrument (D_2) detects the same phenomenon in forward source-width coordinates:

[
D_2(R)
======

\sum_{\rho\in R}m_\rho(\beta_\rho-\tfrac12)^2.
]

The contour-moment note proves (M_k(R)) recovers local divisor power sums from (\xi'/\xi), and (D_2(R)=0) exactly when all zeros in the window lie on the seam.

A proof by contradiction would need to show that any such negative (Q_0) direction would violate a completed explicit-formula positivity constraint. This is essentially the same as the square-test route, but phrased locally.

## Computations that can move us closer

### A. Build a certified (Q_0) engine

Compute (T_k) in three independent ways:

[
T_k=(-1)^kS_k,
]

where (S_k) comes from:

1. Taylor coefficients of (\log\Xi(w)),
2. zero sums with certified tails,
3. the fused closed form involving (\zeta(2k)), (\beta(2k)), and ((\zeta'/\zeta)^{(2k-1)}(1/2)).

Because (S_k) is the residue of enormous (A/P) cancellation, seam-Taylor extraction needs roughly (2.9k) guard digits. The seam note gives the cancellation scale: the separate halves grow like (2^{2k}), while the residue decays like (\gamma_1^{-2k}).

For each (d), compute

[
H_d^{(0)}=[T_{i+j+1}]_{i,j=0}^{d}.
]

Report:

[
\lambda_{\min}(H_d^{(0)}),
]

Schur complements,

condition numbers,

tail errors,

guard digits,

and independent-method agreement.

This does not prove positivity, but it tells us where the wall numerically lives.

### B. Compute Jacobi / continued-fraction parameters

From the moment sequence

[
m_n=T_{n+1},
]

compute orthogonal polynomial recurrence coefficients or Stieltjes continued-fraction coefficients.

If all computed recurrence parameters stay positive with stable tails, that suggests a proof might be expressible as a Jacobi/Krein/continued-fraction positivity theorem.

If they become unstable or depend strongly on regularization, then that route is probably not the proof.

Report:

[
\alpha_n,\ \beta_n,
]

tail sensitivity,

precision sensitivity,

and synthetic off-line zero insertion response.

### C. Off-line zero injection tests

Insert a synthetic quartet

[
w=\pm a\pm i\gamma
]

into a known RH-line zero set and compute how (H_d^{(0)}) first fails.

Verify the formula

[
\det H_1^{(0)}
==============

-\frac{64a^2\gamma^2}{(a^2+\gamma^2)^6}
]

for the local pair.

Vary:

[
a,\quad \gamma,\quad \text{multiplicity},\quad \text{background zeros}.
]

Goal: identify which finite (d) detects which off-line geometry. This tells you the resolution profile of (Q_0).

### D. Polynomial localization experiments

For a synthetic off-line atom (y_0), construct real polynomials (p) that isolate (y_0) from the rest of the reciprocal support and make

[
Q_0[p]<0.
]

Then apply analogous polynomial searches to the actual (T_k).

This gives a computational version of:

[
\text{off-line zero}
\Rightarrow
\text{negative (Q_0) direction}.
]

If polynomial localization becomes numerically impossible at high height, the proof will need hard-edge tail estimates.

### E. Hard-edge tail tests

Since reciprocal atoms satisfy

[
y_\rho\to0,
]

the hard edge at (0) is the main analytic difficulty.

Use the theorem you found:

[
Q_r[y^j q]\text{ tail}
======================

O(G^{1-2r-4j}\log G).
]

For (Q_0) with (p(0)\ne0), the tail is the bottleneck:

[
O(G^{-1}\log G).
]

So run computations separating:

[
p(0)\ne0
]

from

[
p(y)=y^j q(y).
]

If all failures or numerical instability concentrate in the constant term / hard-edge sector, then the proof must supply a hard-edge positivity estimate.

### F. Li-kernel stress test

Since

[
L_n(y)=2-2T_n!\left(\frac{4-y}{4+y}\right)
]

has signed coefficients in (T_k), Li positivity cannot be used by coefficientwise positivity.

But the **full kernel** might still preserve positivity in a subtler way.

Compute the transform matrix

[
c_{n,k}
]

from (T_k) to (\lambda_n), with truncation error control. Test whether Li positivity sees the same negative directions as (Q_0), and whether any finite Li prefix misses (Q_0) failures.

Possible outcomes:

* If Li consistently misses (Q_0)-negative synthetic defects, Li is a poor proof coordinate.
* If Li detects them but only through infinite signed cancellation, the proof must use full kernel analysis.

### G. FID comparison as a negative control

Run the same (Q_0)-style square tests on the integer divisor:

[
y_n=n^{-2},
\qquad
m_n=n^{-3}\text{ or }n^{-1}\text{ depending on shift}.
]

Its Hankel matrices are strictly totally positive by Cauchy–Binet. This is the control showing that abstract total positivity is easy on the wrong divisor and RH-empty.

Use this as a calibration benchmark:

* What does a known-positive reciprocal divisor look like?
* Which numerical methods falsely make it indefinite?
* Which stability passports are necessary?

### H. Explicit-formula square-test decomposition

For a finite polynomial (p), expand

[
Q_0[p]
======

\sum_{i,j}c_ic_jT_{i+j+1}.
]

Now substitute the fused closed form for each (T_k), producing

[
Q_0[p]
======

Q_{\mathrm{arch}}[p]
+
Q_{\mathrm{prime}}[p].
]

Compute these separately.

Look for:

[
Q_{\mathrm{arch}}[p]\approx -Q_{\mathrm{prime}}[p]
]

with a positive residue,

or a hidden square structure,

or a kernel that is positive after a non-obvious transform.

This is probably the best way to discover “what the proof must look like.”

## Computations that would tell us “this is wrong”

A certified negative value

[
Q_0[p]<0
]

for the actual (\xi) sequence would disprove RH. So that is not expected unless RH is false or numerics are wrong. But there are weaker “wrong route” diagnostics:

1. **If (Q_0) positivity depends on (Q_1) for the actual source-aware representation**, then the source-aware simplification was false.

2. **If the Li kernel loses (Q_0)-negative synthetic directions**, then Li is not a viable proof coordinate.

3. **If finite-rank/ridge/regularization creates false (Q_0) positivity**, then that method is not proof-grade.

4. **If hard-edge tails dominate all low-degree positivity**, then proof must focus on hard-edge estimates, not finite determinants.

5. **If explicit-formula decomposition has no stable positive structure and only massive cancellation**, then the proof is unlikely to be a simple square-completion identity.

6. **If source-built boundary conditions change (\kappa_-)**, then the operator route is incomplete without a canonical extension.

## Computations that tell us “this cannot be the proof”

The following proof approaches are already heavily constrained:

* **Pole cancellation alone:** false; finiteness after cancellation does not imply positivity.
* **FID positivity:** wrong divisor; unconditional and RH-empty.
* **Coefficientwise Li positivity:** false; Li kernel has negative coefficients in (T_k).
* **Line curvature (\Phi_2<0):** necessary but not sufficient; blind to far-off-line high zeros.
* **Unshifted (T_0) tower:** invalid; (T_0=\infty).
* **Scalar reporter / non-congruent index:** can miss (\kappa_-).
* **Finite window positivity:** finite passports are blind unless source-accountable.
* **Prime-side-only positivity:** likely orthogonal unless the archimedean boundary is included.
