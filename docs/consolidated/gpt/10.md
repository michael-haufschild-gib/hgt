## What theorem statements should be added?

### A. Local Jensen anisotropy theorem

For each finite (d,n), the hyperbolic Jensen polynomial lies in a hyperbolicity cone. The boundary is the discriminant locus. Directional stability is not captured by a scalar root or coefficient margin.

A regularized Hankel/Jensen test is admissible only if the transformation is either:

\boxed{

This is the same lesson as the reporter-normalization gate for (\kappa_-): transformations that improve readability can destroy the faithful index.

## What can be decided analytically?

Several finite statements can be made rigorous now:

1. **Discriminant-boundary geometry.**
   For fixed (d), the non-hyperbolic boundary of Jensen coefficient space is algebraic, given by the discriminant. Directional radius to that boundary is a well-defined finite-dimensional quantity.

2. **Scalar margin insufficiency.**
   One can prove by linear algebra/examples that two perturbation directions with the same norm can have different hyperbolicity radii. Therefore averaged margin is not a tensorial certificate.

3. **Ridge changes the object.**
   (H+\epsilon I) is not generally congruent to (H). It alters eigenvalues and the moment/Hankel structure. Thus a PSD pass after ridge is not a PSD proof for (H).

4. **Congruence preserves inertia.**
   If (H\mapsto B^\ast H B) with (B) invertible, inertia is preserved. This gives the formal criterion for allowed normalizations.

5. **Finite-passport blindness remains.**
   A finite low-order Jensen/Hankel pass is not a uniform wall crossing. The open content is still all (d,n), not any fixed degree.
