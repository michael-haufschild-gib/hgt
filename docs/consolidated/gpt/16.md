[

\text{different arithmetic alignment}.

If it cannot tell those apart, it is B/C geometry, not A-axis arithmetic.

Updated classification:

This is still useful. It gives a lower-level A-axis gate: a candidate must at least separate (\zeta) from AP/sine. But the real win condition is now:
