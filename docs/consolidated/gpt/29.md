# 3. The proof shape suggested by this

The bridge theorem should no longer be phrased vaguely as:

[

\Longrightarrow Q_0\ge0.

It should be decomposed into two parts.

## Part A — pole-direction cancellation

Prove that for every degree (d), the archimedean form has exactly one negative direction, the pole-evaluation vector

[
u_d=(1,-4,(-4)^2,\ldots,(-4)^d),
]

and that the prime-side form supplies the equal-and-opposite pole contribution along that direction.

In idealized form:

[
Q_{\mathrm{arch}}[p]

-C_d,p(-4)^2

R_{\mathrm{arch}}[p],

[
Q_{\mathrm{prime}}[p]
=====================

+C_d,p(-4)^2
+
R_{\mathrm{prime}}[p],
]

[
Q_0[p]
======

R_{\mathrm{arch}}[p]+R_{\mathrm{prime}}[p].
]

The exact coefficient (C_d) may depend on the finite truncation/form normalization, but the structural statement is:

[
\boxed{
\text{the only negative archimedean direction is the (s=1) pole direction, and the zeta pole cancels it.}
}

This is **entireness at the form level**.

## Part B — residual positivity

After the pole direction has cancelled, prove

[
R_{\mathrm{arch}}[p]+R_{\mathrm{prime}}[p]\ge0

for every real polynomial (p).

That is now the true bridge theorem.

So the final proof target becomes:

[
\boxed{
\textbf{pole-direction cancellation + residual positivity.}

Not merely:

[
\text{pole cancellation}.
]

Your previous countermodel already showed pole cancellation/finiteness alone does not imply Stieltjes positivity. This new result says the pole cancellation is nevertheless the *right first move* — it just needs to be followed by residual positivity.
