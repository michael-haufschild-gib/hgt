## 1. Reciprocal folding: the atoms have even multiplicity

In seam coordinates

[
w=\rho-\frac12,\qquad \Xi(w)=\xi\left(\frac12+w\right),
]

the completed function is even:

[
\Xi(w)=\Xi(-w).
]

So if (w\neq0) is a zero of multiplicity (m), then (-w) is also a zero of multiplicity (m). In the reciprocal coordinate

[
y=-w^{-2},
]

the pair (w,-w) folds to the **same** (y)-atom:

[
-w^{-2}= -(-w)^{-2}.
]

So the atom has weight

[
\boxed{2m.}
]

An off-line quartet

[
{w,-w,\overline w,-\overline w}
]

becomes a conjugate pair

[
{y,\overline y},
]

each with weight (2m). An on-line pair (w=\pm i\gamma) becomes one positive atom

[
y=\gamma^{-2}>0
]

with weight (2m).

So the reciprocal moment sequence should be written using the **folded divisor**:

[
\boxed{
T_k=\sum_{[w]} 2m_w\left(-w^{-2}\right)^k,\qquad k\ge1,
}
]

where ([w]={w,-w}). Any unit-weight conjugate-(y) experiment is underweighted relative to the completed divisor and should be treated as inadmissible unless it explicitly states it is a toy model.

This is consistent with the canonical “one wall” note: the wall is the reciprocal seam-squared Stieltjes problem for the completed zero divisor, not for an arbitrarily reweighted synthetic divisor.

## 2. The unshifted form is not a third condition; its admissible domain is (Q_1)

This is a very useful clarification.

The formal unshifted quadratic form would be

[

[

[

[
U[p]

Thus the ordinary finite polynomial domain of (U) is exactly

[
p(y)=yq(y).

[

=====

\sum_{[w]}2m_w,y_w^2q(y_w)^2.

If

[

[
\boxed{
Q_1[q]=\sum_{i,j}c_i c_j T_{i+j+2}.

So the “repaired unshifted form” is not a new object. It is exactly the second shifted square-test form (Q_1).

\sum_{i,j}c_i c_j T_{i+j+1}.

So the corrected proof target is exactly two shifted forms:

[

No (T_0). No third unshifted tower.
