## 3. CO6 needs a coefficient-host passport

The second result is a serious algebraic hygiene correction.

The formula

[
g_p=g_p^{-1}\Rightarrow g_p=\pm1
]

is valid only in the intended connected/scalar coefficient host.

In a commutative ring with (2) invertible,

[

]

is equivalent to

[
g=2e-1,
\qquad e^2=e,
\qquad e=\frac{g+1}{2}.
]

So self-inverse units are controlled by idempotents. In a connected/idempotent-free scalar host, the only idempotents are (0,1), hence (g=\pm1). But in a product host such as (\mathbb C^n), there are sectorwise signs. In a matrix/projector host, one can have

[
g=2P-I.
]

So CO6 should be rewritten as:

[
\boxed{
g^2=1
\Longleftrightarrow
g=2e-1,\ e^2=e;
\quad
g=\pm1\text{ only in a connected/idempotent-free scalar host.}
}
]

This does not break the original scalar use. It adds a **host passport**:

[
\boxed{
\text{before using CO6 as }g=\pm1,\text{ declare and prove the coefficient host is connected/scalar.}
}
]

This matters because hidden product/projector extensions can create sector signs that an even or squared reporter misses. It connects to the earlier holonomy-parity warning: one-pass/odd-sector holonomy cannot be replaced by two-pass/even positivity unless the odd sector is proven absent. The formula graph currently lists CO6 in the cocycle cluster, so it should be replaced by this idempotent-aware version.
