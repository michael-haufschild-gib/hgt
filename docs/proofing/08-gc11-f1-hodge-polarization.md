# G-C11 Proof Attempt: F1/Hodge Polarization

Source: `docs/consolidated/08-conjectures-required.md` appendix.

Claim status: `[CONJECTURE]`.

## Target Claim

The missing absolute-geometric object supplies a Hodge-index-style
polarization that forces the faithful index to vanish.

## Attempt

If an F1/Hodge object supplies a polarized form `Q` and an isomorphism

```text
Q ~= Q_W
```

on the faithful carrier, then Hodge-Riemann positivity would imply `Q_W >= 0`,
hence RH.

## Weakened Theorem

F1/Hodge polarization proves RH conditional on a comparison isomorphism to the
Weil faithful carrier.

## Obstruction

Every known restatement can reduce to an RH-equivalent positivity unless the
geometry is source-built and supplies the signature theorem independently.

## Missing

The absolute-geometric object, polarization, primitive decomposition, and
comparison with `Q_W`.
