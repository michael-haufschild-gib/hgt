# Brown–Susskind · live proof routes

**The fixed-error second law remains open.** At $1/10$ the gate floor is extensive from inverse-size time through $\delta K^{65/64}$. Most centers of sufficiently long records lie in intervals of radius $2^{K-O(\sqrt K)}$ above a floor of order $2^K/K$. A sufficiently late prescribed spectral antipode lies in a genuine excursion whose next polynomial-budget return takes doubly exponential time. Open on the same draw are a linear ramp through exponential time, concentration near the actual maximum, and a doubly exponential first wait from the crossing after identity. [Target](second-law.md) · [Killed routes](brown-susskind-killed-routes.md)

Draw one infinite open chain with independent standard Gaussian onsite and nearest-neighbour Pauli coefficients. On its $K$-qubit prefix put $D=2^K$, $P=\lfloor D/[64(K+1)]\rfloor$, and $G=2^{D^c}$ for a suitable deterministic $c$. Write $C_e(t)$ for minimum two-qubit gate count at projective operator error $e$ without ancillas, $m_e=\max_t C_e(t)$, $m=m_{1/10}$ and $x_e=2\arcsin(e/2)/\pi$. The first crossing $\sigma$ reaches distance $9/80$ from the $P$-gate set. The first subsequent $s$-gate visit at $1/10$ is $v_s=\sigma+\Delta_s$. Write $v_s(e),\Delta_s(e)$ when the return error varies. Prefix asymptotics hold almost surely unless a probability or another limit is specified.
