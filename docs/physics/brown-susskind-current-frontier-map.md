# Brown–Susskind · live proof routes

**The fixed-Hamiltonian second law remains open.** At error $1/10$, the actual orbit maximum $m$ is exponential in $K$. Time below $m^{1/3}$ has doubly exponentially small upper density, and every budget $s_K=o(2^K/K)$ has the same long-time occupation exponent as the empty circuit. The first low-cost return after the first robust crossing has a doubly exponential upper deadline. Matching linear growth, exponential plateau onset, concentration near $m$ and a doubly exponential lower bound on that first waiting time remain open. [Target](second-law.md) · [Killed routes](brown-susskind-killed-routes.md)

**Model.** Draw the three onsite and nine nearest-neighbour bond Pauli coefficients independently from the standard normal law, once on an infinite chain. On its open $K$-site prefix put $D=2^K$. Cost means minimum number of arbitrary two-qubit gates, no ancillas, projective operator-norm error $1/10$. All three claims must hold on the same typical draw. A lower bound witnessed on a state or in Choi distance can certify operator hardness. A return needs whole-operator control.
