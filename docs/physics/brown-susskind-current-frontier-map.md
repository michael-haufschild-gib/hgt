# Brown–Susskind · live proof routes

**The fixed-error second law remains open.** At error $1/10$, Lean now dates the first loss of each small gate budget and separates quadratic-budget visits from all sub-$c\sqrt K$ visits for growing time intervals. From the first robust crossing, the first polynomial-budget wait still has an exponential lower bound and a doubly exponential upper bound. The missing steps are a linear ramp through exponential time, concentration near the actual maximum by then, and a doubly exponential lower bound for that first wait. [Target](second-law.md) · [Killed routes](brown-susskind-killed-routes.md)

**Model.** Draw independent standard Gaussian onsite and nearest-neighbour Pauli coefficients once on an infinite open chain. On its $K$-qubit prefix, $D=2^K$ and $C_\epsilon(t)$ is the minimum number of arbitrary two-qubit gates, without ancillas, at projective operator-norm error $\epsilon$. A visit uses error $1/10$ unless specified. Write $m=\max_t C_{1/10}(t)$, $P=\lfloor D/[64(K+1)]\rfloor$ and $G=2^{D^c}$ for a deterministic $c$. The first time the orbit reaches distance $9/80$ from the $P$-gate set is $\sigma$. Write $v_s$ for the first subsequent $s$-gate visit and $\Delta_s=v_s-\sigma$ for its waiting time. Statements below hold almost surely on sufficiently long prefixes unless specified.
