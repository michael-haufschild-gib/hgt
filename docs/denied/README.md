# Denied — drafts that did not come through the Door

These documents were **denied entry to the new field's workspace** (`../drafts/`) by the litmus test in
`../drafts/00-charter-wall-and-door.md`. **They are preserved, not deleted.** The pruning is reversible: a
denied draft is **re-admitted** if and only if a genuinely native theorem (one that passes the Door) is shown
to *reroute through it*.

Denial is not a judgment that a document is worthless or wrong. It is a judgment that, by the master key
(**Door-2**: *strip the multi-`q`-difference-Galois vocabulary — does a parent discipline still prove it?*), the
document is **not native to the branch**. Most of these are good classical mathematics, or honest inspiration.
They are simply on the **old-country side of the wall**.

## The three reasons for denial

- **IMPORT** — classical mathematics (analytic number theory, moment theory, representation theory, Avila/
  Deligne/Baker, etc.) *reframed* in the field's vocabulary. Valuable as a *map* of where known results sit
  relative to the field's borders; not the field's own theorems. Fails Door-2.
- **EMBASSY** — metaphor / physics allegory (cosmology, PT-symmetry, holography, Wheeler–DeWitt). Inspiration
  and conjecture-seeds; explicitly **not mathematics**. Fails Door-1 (no native object).
- **EXTRACTION-PENDING** — the founding / foundations drafts. These genuinely *contain* native **definitions
  and conjectures**, which have been (or are being) distilled into
  `../drafts/00-foundations-native-objects-and-gatekeepers.md`. They are denied from the clean workspace
  because their bulk is import/embedded-conjecture, but they are **earmarked for a careful read** to pull any
  *further* native gatekeepers into the foundations doc. Until that read is complete, treat them as the source
  archive of the gatekeepers, not as denied-and-closed.
- **META (superseded)** — old indices/roadmaps/atlases that catalogued the pre-cleanup body; superseded by
  `../drafts/00-manifest-wall-census.md`.
