==========================================================================
 STEP8: MEMORY LENGTH (P-recursive order) of value sequences  [non-blind value relation]
==========================================================================
  2^n (geometric: finite memory, r=1)              -> FINITE memory (r=1,d=0, resid=0.0e+00)
  n! (factorial: finite memory, r=1)               -> FINITE memory (r=1,d=1, resid=1.1e-17)
  Fibonacci (finite memory, r=2)                   -> FINITE memory (r=1,d=1, resid=3.7e-11)
  Bernoulli B_2n ~ zeta(2n) (holonomic?)           -> FINITE memory (r=1,d=2, resid=6.1e-18)
  zeta(n), n=2..30 (HT values: infinite?)          -> FINITE memory (r=2,d=2, resid=5.3e-10)
  nth prime (arithmetic: infinite memory)          -> INFINITE memory (best resid=1.7e-05)

 VERDICT: finite-memory (P-recursive/holonomic) sequences vs infinite-memory ones;
 the granular 'memory length' distinguishes DA-type from HT/arithmetic value sequences.
