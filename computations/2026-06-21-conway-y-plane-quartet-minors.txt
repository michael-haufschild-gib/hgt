y-plane conjugate-pair shifted minors
================================================
T_k = mu * (y^k + conjugate(y)^k), y = u + i v
det H_1^(0) = -4*mu**2*v**2*(u**2 + v**2)
det H_1^(1) = -4*mu**2*v**2*(u**2 + v**2)**2

For a simple FE/conjugation quartet w = ±a ± i gamma, mu=2:
Re(y) = (-a**2 + g**2)/(a**2 + g**2)**2
Im(y) = 2*a*g/(a**2 + g**2)**2
|y|^2 = 1/(a**4 + 2*a**2*g**2 + g**4)
det H_1^(0) = -64*a**2*g**2/(a**2 + g**2)**6
det H_1^(1) = -64*a**2*g**2/(a**2 + g**2)**8

Read: for a genuine off-line quartet with a*gamma != 0, Im(y) != 0,
so both shifted degree-one minors are strictly negative.
