# Zeta occurrence versus radial conditioning: computation report

The frozen primary statistic passed and its intended arithmetic interpretation failed.

For each of 192 known critical-line zero ordinates, the experiment compared `log delta`, where `delta=|det A|/||A||_F^2`, with symmetric controls at one quarter of the next-zero gap. All 64 contrasts were positive in each discovery, holdout, and distant cohort. Mean/median contrasts were `6.17e-7/1.72e-9`, `7.74e-11/4.95e-11`, and `1.51e-12/1.21e-12`. Hypergeometric values repeated at 100/160 digits. Endpoint-series checks agreed through index 128, with selected matrix discrepancies from `4.98e-156` to `1.69e-50`.

The precommitted curvature challenge moved every center from a zeta zero to the adjacent nonzero midpoint while preserving half-width. It again found positive contrasts in all 64 cases of every cohort; midpoint medians were `1.67e-9`, `4.89e-11`, and `1.21e-12`. This falsifies arithmetic specificity: the primary sign is smooth radial curvature, not Selection enforced by occurrence of a zeta zero. The statistic is retired without retuning.

Positive residue: along the sampled critical line, complete radial conditioning changes smoothly toward `delta≈0.4517536`; the singular-value ratio reaches `≈0.6324543` by index 320. These are empirical trends, not asymptotic theorems. The independent endpoint series becomes catastrophically ill-conditioned in the distant cohort: indices 257/288/320 give incompatible deltas and huge absolute matrix discrepancies. Distant results therefore rely only on internally stable hypergeometric precision repeats and are not independently representation-validated.

No zeta value was evaluated and no statistical-independence claim is made. This factor-level test omits angular, onset, causal/contact, spacetime-boundary, and other action sectors. Guarded runtimes were 7.57 s for the primary run and 5.60 s for the curvature control. Protocols, 192 input ordinates, raw outputs, run statuses, and code are retained.
