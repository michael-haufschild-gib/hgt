XF1 reciprocal square-test admissibility audit
====================================================
h_{r,p}(t) = t^(-2r) p(t^(-2))^2, r in {1,2}

p(u) = 1
  degree(p) = 0; order_0(p) = 0
  r=1:
    t -> 0:        h(t) ~ C |t|^(-2)
                   not locally integrable at the hard edge
    |t| -> infinity: h(t) ~ C |t|^(-2)
                   only polynomial decay, hence not Schwartz
  r=2:
    t -> 0:        h(t) ~ C |t|^(-4)
                   not locally integrable at the hard edge
    |t| -> infinity: h(t) ~ C |t|^(-4)
                   only polynomial decay, hence not Schwartz

General nonzero p:
  If deg(p)=d, then h(t) has hard-edge order 2r+4d >= 2.
  If ord_0(p)=j, then h(t) decays at infinity like |t|^-(2r+4j).
  Therefore direct standard explicit-formula substitution is invalid.
